# Polymaker artwork

The Wiki references the unchanged official logo hosted by the Lumina website;
the artwork is not copied into this public documentation repository. Polymaker
owns the logo and trademark. They are not sublicensed under the Wiki or software
license and must not be modified, recolored or reused for other promotion.

The authorized display covers Panchroma PLA identification and actual support.
The component checks the one-year authorization at browser render time and
falls back to the brand name after expiry. Renewals or early termination must
update `authorization.ts`. Keep the non-endorsement notice in the sponsor
section notice.
