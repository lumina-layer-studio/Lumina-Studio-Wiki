# 在线预览与导出额度

打开 [Lumina Studio 在线预览站](https://test.luminastudio.com.cn/)，无需登录即可上传图片、调整配色并导出模型。在线站的计算在服务端完成；导出后下载 3MF，再用本机切片软件打开。

## 每日额度怎样计算

| 使用方式 | 每日新图导出额度 |
| --- | --- |
| 免登录试用 | 3 张不同原图 |
| 连接 Lumina 社区账号 | 免登录 3 张 + 额外赠送 3 张，共 6 张不同原图 |

免登录额度按同一 IP 统计。计数对象是**成功导出的不同原图**，不是点击按钮的次数：同一张图调整参数后反复导出，不重复消耗新图额度；生成失败和排队等待也不扣新图次数。

页面会显示当天剩余额度与恢复时间，时间按北京时间计算。多人共用同一网络出口时，可能共用免登录额度。耗尽后可等待恢复，或改用本地桌面版继续制作。

## 连接社区账号

在在线站右下角状态卡点击 **“登录 Lumina 账号 · 再享 +3 张/天”**，也可从耗材／LUT 库的社区账号入口连接。按登录页提示完成验证，核对网页与 Studio 显示的 **10 位一次性连接码**，确认账号正确后允许连接。连接成功当天即可在免登录 3 张新图的基础上，再获赠 3 张新图额度，合计每天 6 张。反复登录不会重复赠送额度。

**在线站已由服务端统一预装公开耗材与 LUT 库**。连接账号后，可直接在选择器中按个人点赞、收藏筛选预装资源，无需在网页端逐条下载安装。网页中的“下载到本地”会提示“公开耗材与色卡已在线预装”，不会将这些资源另存到你的电脑。

如需按需下载云端资源到自己的私人库、管理本地耗材，或将自测校准结果“贡献到公共库”，请使用桌面版；“我的投稿”管理也在桌面版完成。账号连接与投稿步骤见[社区账号、收藏与投稿](../../reference/materials-and-recipes/community-resources/community-resources.mdx)。

## 从预览到打印

1. 上传原图，选择与手头耗材对应的档案或 LUT。
2. 设置成品尺寸、层高等参数，点击预览检查配色。
3. 生成完成后下载 3MF，保存在自己的电脑上。
4. 在切片软件中打开，核对机器、喷嘴、耗材槽位与层高，再切片打印。

同一任务正在生成时等待结果即可，无需连续点击。下载或生成异常时，见[页面与生成问题排查](../../knowledge/web-generation-troubleshooting/web-generation-troubleshooting.mdx)。

## 桌面版需要登录吗

不需要。桌面打包版可以不绑定社区账号，直接使用本地耗材、LUT、离线资源和模型生成功能。社区账号提供的是收藏、投稿等联网功能；在线站的每日新图导出额度不套用到桌面本地工作流。
