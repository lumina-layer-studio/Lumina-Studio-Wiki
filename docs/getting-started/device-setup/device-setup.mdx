# 首次使用：配置切片软件、打印机与喷嘴

首次打开 Lumina Studio 时，请先按你的真实硬件配置切片软件、打印机型号与喷嘴尺寸。后续生成的 3MF 工程、打印盘尺寸与线宽尺度都会直接基于这三项设置计算。

> 下方截图以 **BambuStudio**、**Bambu Lab P1S** 和 **0.4 毫米**喷嘴为例，操作时请按你实际使用的软件和硬件选择。

## 开始前确认

- 平时使用的切片软件
- 打印机的完整型号
- 当前安装在机器上的喷嘴口径（不确定时可查看机身设置或喷嘴本体刻字）

## 配置步骤

### 1. 打开系统设置

点击顶部导航栏右侧的 **“设置”**，进入系统设置页面。

<img
  src={require('./assets/settings-device-zh-01-open-settings.webp').default}
  alt="点击页面顶部的设置"
/>

### 2. 展开切片软件列表

在“系统设置”中找到 **“切片软件”**，点击下拉菜单查看当前受支持的切片软件。

<img
  src={require('./assets/settings-device-zh-02-open-slicer.webp').default}
  alt="打开切片软件下拉菜单"
/>

### 3. 选择切片软件

在下拉列表中选择你日常使用的切片软件。

<img
  src={require('./assets/settings-device-zh-03-select-slicer.webp').default}
  alt="选择实际使用的切片软件"
/>

### 4. 选择打印机型号

在下方机型列表中点选你的打印机完整型号。

<img
  src={require('./assets/settings-device-zh-04-select-printer.webp').default}
  alt="选择实际使用的打印机型号"
/>

### 5. 选择喷嘴尺寸

在所选打印机卡片上点击当前实际安装的喷嘴规格。

<img
  src={require('./assets/settings-device-zh-05-select-nozzle.webp').default}
  alt="选择当前安装的喷嘴尺寸"
/>

### 6. 核对设置摘要

在页面底部确认切片软件、打印机型号与喷嘴尺寸均准确无误。更改会自动立即保存，无需手动点击保存按钮。

<img
  src={require('./assets/settings-device-zh-06-check-summary.webp').default}
  alt="核对设备设置摘要"
/>

后续如果更换了打印机、切片软件或喷嘴口径，请随时回到 **“设置”** 同步更新，再重新生成模型。

## 常见问题

### 列表中找不到我的打印机型号？

可选机型列表随所选切片软件变化，请先确认第 3 步选对了切片软件。如果核对后仍无对应型号，说明当前版本暂未内置该机型配置。

### 为什么页面上没有“保存”按钮？

设备配置在选择后即自动生效并持久保存，可以直接切回其他工作区继续使用。
