# 使用启动器激活 Lumina Studio

:::note[开源源码与启动器]
Lumina Studio 现已在 [Lumina-Layers 仓库](https://github.com/lumina-layer-studio/Lumina-Layers)公开开发，个人和企业均可免费使用软件；从源码运行无需购买或激活启动器。本文介绍启动器要求验证已有权益时的操作，具体以所用启动器的界面和官方说明为准。
:::

如果你使用的 Lumina Launcher 要求验证购买或支持权益，可以在准备使用软件的电脑上按本教程激活。激活完成后，可以在启动器里下载、安装和打开其提供的 Lumina Studio 版本。

本教程分别介绍爱发电、官网和 Patreon 三种渠道的激活方法。请按照自己购买时使用的渠道操作。

## 开始之前

1. 从官方渠道下载并安装 Lumina Launcher，然后打开它。国内用户也可以从[官方夸克网盘](https://pan.quark.cn/s/c97fa97c2aba)下载。
2. 确认电脑已经联网。
3. 准备购买时使用的订单号，或能够登录 Patreon 的账号。

打开启动器后，如果这台设备还没有激活，你会看到“激活此设备”页面。页面里有一个“订单号或激活码”输入框，以及“通过 Patreon 激活”按钮。

图中显示的是未输入订单号时的状态；粘贴内容后再点击激活按钮。

| 购买渠道 | 需要准备什么 | 在哪里操作 |
| --- | --- | --- |
| 爱发电 | 爱发电订单号 | 填入“订单号或激活码” |
| 官网银行卡付款（Waffo） | 官网订单号，以 `LUM-` 开头 | 填入“订单号或激活码” |
| Patreon | 购买时使用的 Patreon 账号 | 点击“通过 Patreon 激活” |

即使你是从 Lumina 官网点进去购买的，也要看最终是在哪个平台付款：在爱发电付款就按爱发电步骤操作；在 Patreon 付款就按 Patreon 步骤操作。

如果你收到的是单独发放的 Lumina 激活码，也可以填入同一个“订单号或激活码”输入框。

## 通过爱发电激活

### 1. 在爱发电找到订单号

1. 打开爱发电 App 或[爱发电网页](https://ifdian.net/)，登录购买 Lumina Studio 时使用的账号。
2. **电脑网页版**：点击页面顶部的“管理”，进入后点击“订单”。**手机 App**：点击“个人”，再点击“订单”；不同版本的页面位置可能略有不同。
3. 在订单列表中找到 Lumina Studio 的订单。可以对照创作者名称、购买时间和档位，确认是自己购买的那一笔。
4. 电脑网页版的“已支付”列表会直接显示“订单号”。点击号码旁边的“复制”，就能复制完整订单号。如果你的页面没有直接显示，可以打开订单详情查找。

<img src={require('./assets/afdian-orders.webp').default} alt="爱发电电脑版订单与已支付入口" />

<img src={require('./assets/afdian-copy.webp').default} alt="爱发电订单号和复制按钮，订单内容已遮挡" />

注意复制的是**爱发电订单号**，不是微信或支付宝账单里的交易号。如果列表里找不到订单，先检查是否登录了购买时使用的爱发电账号；有多个订单时，认准购买 Lumina Studio 的那一笔。

### 2. 在启动器中激活

1. 回到 Lumina Launcher，在“订单号或激活码”输入框中粘贴刚才复制的订单号。
2. 点击“激活此设备”，等待验证完成。
3. 激活成功后，启动器会进入首页，可以继续安装软件。

输入框中的内容会显示为圆点，这是为了保护订单信息，不代表粘贴失败。

启动器里的输入框和按钮可参考上面的第一张图。

如果订单号在手机上，而启动器在电脑上，可以在电脑浏览器登录同一个爱发电账号，按上面的步骤重新找到订单，然后复制到启动器。也可以通过只属于你自己的文件传输工具把订单号发到电脑；不要发送到公开群聊。

## 通过官网银行卡订单激活

### 1. 在付款结果页找到订单号

1. 完成官网付款后，回到刚才付款时使用的浏览器，打开 Lumina 官网的付款结果页面。
2. 在页面上找到“订单编号”。它下面以 `LUM-` 开头的一串字符，就是启动器需要的官网订单号。
3. 用鼠标选中并复制完整订单号，包括前面的 `LUM-`。不要只复制后半部分，也不要复制支付平台的交易号。
4. 看一下页面的付款状态。如果显示“付款已确认”，可以继续激活；如果显示“付款已提交”或“付款状态暂时无法核验”，先保留订单号，等待付款确认后再试。

如果刚才关掉了页面，可以先在付款时使用的浏览器标签页或浏览记录中查找 Lumina 的付款结果页。请尽量使用付款时的同一个浏览器；如果页面提示无法读取订单编号，或仍然找不到，请联系官方支持并提供必要的订单证明。不要为了找回订单号重复购买。

### 2. 在启动器中激活

1. 回到 Lumina Launcher，把完整的官网订单号粘贴到“订单号或激活码”输入框。
2. 点击“激活此设备”，等待验证完成。
3. 激活成功后，启动器会进入首页，可以继续安装软件。

爱发电订单号和官网订单号使用同一个输入框，不需要另外选择支付渠道。

## 通过 Patreon 激活

Patreon 不需要把订单号填进输入框，而是通过登录 Patreon 账号完成验证。

### 1. 不确定用了哪个 Patreon 账号？先检查会员记录

1. 在电脑浏览器打开 [Patreon](https://www.patreon.com/)，登录你认为购买时使用的账号。
2. 打开左下角的账号菜单，选择“设置”（Settings），再进入“会籍”（Memberships）。不同账号的导航布局可能略有差异。
3. 在会员列表中找到 **Lumina Studio**，点击“查看详情”（View Details），检查是否是自己购买的会员记录和档位。
4. 如果列表里没有 Lumina Studio，请检查是否登录了另一个 Patreon 账号。确认账号后，继续下面的激活步骤。

<img src={require('./assets/patreon-memberships.webp').default} alt="Patreon 设置中的会籍入口" />

这里检查的是赞助账号，不需要把 Patreon 的付款收据或订单号填进启动器。会员列表可能同时显示免费和付费会员；实际能否激活，以购买方案包含的权益及验证结果为准。

### 2. 在启动器中验证 Patreon

1. 在 Lumina Launcher 的激活页面，点击“通过 Patreon 激活”。
2. 启动器会打开浏览器。在 Patreon 页面登录**购买时使用的账号**，并按照页面提示完成授权。
3. 完成后回到启动器，等待验证结果。账号中的支持记录及对应权益核验通过后，启动器会进入首页。

<img src={require('./assets/launcher-patreon.webp').default} alt="启动器中的通过 Patreon 激活按钮" />

如果在浏览器中取消了授权，或者启动器提示验证超时，可以重新点击“通过 Patreon 激活”再试一次。请勿向任何人提供你的 Patreon 密码。

## 安装并打开 Lumina Studio

激活和安装是两步操作。激活成功后，启动器会显示“已激活”；如果本机还没有安装 Lumina Studio，请继续：

1. 在启动器“首页”找到可用版本，点击“安装”。
2. 等待下载和安装完成。
3. 点击“启动 Lumina”打开软件。也可以在“版本”页面查看和启动已安装的版本。

## 不熟悉复制、粘贴？

在电脑上，用鼠标选中订单号后：

- Windows：按 `Ctrl + C` 复制；点击启动器输入框，再按 `Ctrl + V` 粘贴。
- Mac：按 `Command + C` 复制；点击启动器输入框，再按 `Command + V` 粘贴。

也可以在选中文字后点击鼠标右键，选择“复制”；再到启动器输入框里点击右键，选择“粘贴”。手机上通常可以长按订单号，选择文字后点击“复制”。不同页面的选择方式可能略有不同。

## 常见问题

### 显示“正在验证订单”，需要重复付款吗？

不需要。请保持启动器联网，等待验证完成；页面会在验证完成后继续。不要反复付款。如果长时间没有变化，可以保存提示截图并联系官方支持。

### 提示无法激活，应该检查什么？

先确认订单属于购买 Lumina Studio 并获得对应使用权益的那笔记录。爱发电请检查订单号，官网请检查是否完整复制了 `LUM-` 开头的订单号；Patreon 请检查是否登录了购买时使用的账号。

也请检查网络连接，再根据启动器提示重试。如果仍然无法完成，联系官方支持时说明购买渠道、启动器版本和看到的提示，并附上错误截图。

### 输入后只看到圆点，是不是没输进去？

不是。启动器会隐藏输入内容，这是正常的。确认已经复制并粘贴完整订单号或激活码后，点击“激活此设备”即可。

### 已经激活了，为什么没有看到可下载版本？

先点击启动器中的“检查更新”，等待版本列表刷新。如果提示“激活信息已保存，版本列表未能刷新”，稍后重试即可，不需要再次激活。列表刷新后仍没有可用版本，请联系官方支持。

### 找不到“通过 Patreon 激活”按钮怎么办？

请确认使用的是从官方渠道获取的新版启动器。如果更新后仍没有该按钮，请联系官方支持，并附上启动器版本和页面截图。

### 联系支持时需要提供什么？

请提供购买渠道、启动器版本、遇到问题的步骤和提示截图。订单号或订单证明如需核对，请通过官方私信或支持渠道私下提供，不要发到公开群聊或评论区；也不要发送账号密码和完整付款信息。
