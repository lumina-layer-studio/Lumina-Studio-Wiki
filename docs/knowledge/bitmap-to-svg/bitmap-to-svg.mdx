# 从位图生成 SVG，再发送到图像转换

当手头只有 PNG、JPG、WebP 或 BMP 位图，而图案本身是边界清晰的 Logo、图标、线稿或纯色色块时，可以先用 Lumina Studio 的“图像转矢量”工具将像素描摹为 SVG 路径，再送入“图像转换”继续建模。

如果不清楚何时保留位图、何时使用 SVG，可先阅读[位图与矢量图有什么区别？](pathname:///zh/docs/knowledge/bitmap-vs-vector/)。

:::info[流程概览]
本文涵盖从上传位图、调整矢量化参数、对比原图与 SVG，到下载文件或直接发送到“图像转换”的完整步骤。照片、复杂绘画与柔和渐变通常建议直接使用原始位图。
:::

## 先判断素材是否适合矢量化

**适合自动矢量化：**

- Logo、图标、文字轮廓与简单标志；
- 边界分明、颜色种类较少的平涂色块图；
- 背景干净、线条清晰的线稿；
- 需要在矢量编辑器中进一步修改路径、节点或填充色的图案。

**建议保留原始位图：**

- 人像照片、毛发、皮肤、云雾与复杂自然纹理；
- 大面积柔和阴影、半透明、发光与连续渐变；
- JPG 压缩伪影明显或噪点较重的低清图片；
- 以像素方格作为视觉风格的像素画。

自动矢量化会根据现有像素拟合轮廓，无法凭空恢复低清原图中已经模糊或缺失的五官、小字与细微纹理。开始前请先保存一份原始位图备份。

## 第一步：上传位图并生成基准结果

1. 点击 Lumina Studio 顶部导航栏的“图像转矢量”；
2. 将 PNG、JPG、WebP 或 BMP 文件拖入上传区（或点击上传）；
3. 确认上传区已正确显示目标图片；
4. 首次运行保持默认参数，点击“开始矢量化”。

<img
  src={require('./assets/01-upload-and-defaults.webp').default}
  alt="在图像转矢量页面上传位图并保留自动颜色、默认平滑度和默认细节设置"
/>

默认状态下，颜色数量设为自动判断，平滑度处于中间档位，统一细节控制保持关闭。先跑一次默认结果作为对照基准，更容易看清后续需要针对哪一处微调。

## 第二步：了解三个基础参数

| 参数 | 作用 | 何时调整 |
| --- | --- | --- |
| 颜色数量 | 控制允许保留或归并的颜色类别数 | 自动结果出现过多相近杂色，或图案本身只有固定几种颜色时，切换为手动指定 |
| 平滑度 | 控制路径抽稀与边缘平滑程度 | 轮廓锯齿明显时逐步调高；小字、尖角或细线开始钝化消失时适当回调 |
| 细节等级 | 启用后用单个滑块联动多项细节阈值 | 想在不逐项展开高级参数的情况下，快速对比“更简练”与“保留更多细节”两档效果时开启 |

这里的“颜色数量”指 SVG 归纳出的色块类别数，而非打印所需的真实耗材卷数。进入“图像转换”后，软件会结合所选的经典 LUT 或耗材档案重新计算叠色方案。调整时以关键轮廓和文字清晰度为准即可，无需追求过高的颜色数或形状数。

## 第三步：并排核对原图与 SVG 预览

矢量化完成后，界面会并排展示“原始图片”和“SVG 预览”。放大画面，按以下顺序检查关键部位：

<img
  src={require('./assets/02-compare-result.webp').default}
  alt="Lumina Studio 并排显示原始位图和自动矢量化后的 SVG 结果"
/>

1. **外轮廓**：斜边、圆角与尖角是否保持原有走势；
2. **小字与细线**：字怀孔洞、细笔画与窄线条是否连贯未断；
3. **封闭区域**：眼睛、镂空与独立小色块有无被填死或粘连；
4. **背景区域**：透明背景、JPG 噪点或纸张底纹有没有被误描成多余色块；
5. **渐变过渡**：连续渐变拆分成色带后，分区边界是否自然可接受；
6. **成品尺寸表现**：缩放到目标打印尺寸观察，整体观感是否优于直接使用位图。

上图的测试素材在默认参数下生成了 **155 个形状、24 种颜色、900 × 600 像素画布**，用于直观反映当前 SVG 的路径复杂度与色块统计。

:::warning[先检查细节]
如果文字、五官或细线在 SVG 预览中已经丢失，后续生成 3MF 时无法恢复。请先在当前页面回调参数重新矢量化，或改用原始位图配合高保真模式。
:::

## 按问题现象微调参数

建议每次只调整一项参数并重新生成对比，以便确认每次修改的实际效果：

| 观察到的现象 | 优先调整 | 避免的做法 |
| --- | --- | --- |
| 出现大量近似色碎块 | 手动调低颜色数量，或小幅提高平滑度 | 一次性把所有高级过滤滑块拉满 |
| 细线、小字或尖角缺失 | 降低平滑度，调小区域过滤，或开启细节等级微调 | 仅因文件体积更小就保留缺损结果 |
| 相邻色块间露出细白缝 | 保留“输出增强”中的描边与覆盖修复，必要时微调宽度 | 大幅加粗描边导致相邻色块互相侵占 |
| 轮廓边缘仍有锯齿毛刺 | 小幅提高平滑度，观察曲线与转角变化 | 试图靠拉高细节等级修复低清马赛克 |
| 形状数极高、响应变慢 | 减少颜色数量、先清理原图噪点，或适度过滤微小杂斑 | 完全不清理照片噪点直接矢量化 |
| 渐变被切成明显色阶带 | 属于矢量色块的正常特征；可与原位图的高保真预览对比 | 盲目拉高颜色上限生成成千上万条碎路径 |

其中，“输出增强”用于消除色块接缝并保护细线；“高级参数”提供预处理、超像素分割、曲线拟合与区域过滤。常规图形使用基础参数即可满足需求；确需精细控制时再展开对应高级分组单项微调。

## 第四步：下载 SVG，或发送到图像转换

结果栏会汇总形状数、颜色数、画布尺寸与提取出的色板，并提供两个后续入口：

  alt="矢量化结果区域显示形状数、颜色数，并提供发送到图像转换和下载 SVG 两个按钮"

### 下载 SVG

适用于需要将结果留档，或先导入 Inkscape、Adobe Illustrator 等矢量软件手动修整节点、删减杂色路径、修改填充与画布边界的场景。下载文件默认名为 `vectorized.svg`，建议及时按项目与版本重命名（例如 `logo-vector-v1.svg`），方便后续管理。

### 发送到图像转换

确认 SVG 预览满意后，点击“发送到图像转换”，Lumina 会自动将该 SVG 载入转换器并切换至“矢量模式”。

<img
  src={require('./assets/04-vector-mode.webp').default}
  alt="发送完成后图像转换页面自动选择矢量模式"
/>

接下来按标准建模流程完成配置即可：

1. 选择色彩数据来源（经典 LUT 或耗材档案）及实际使用的耗材组合；
2. 设置目标宽高、底板厚度与单双面结构；
3. 点击“预览”，核对配色方案、色块边界与分层叠色；
4. 预览无误后导出 3MF，并在切片器中检查实际刀路。

色彩来源与建模模式的选型指南，请参阅[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)与[高保真、像素艺术与矢量模式怎么选？](pathname:///zh/docs/knowledge/image-mode-selection/)。

## SVG 颜色与打印耗材的关系

矢量化阶段提取的是原图的屏幕 RGB 色块与路径边界；而最终 3D 打印效果由真实线材的透光率、层高、底板色、叠层顺序和喷嘴线宽共同决定：

- SVG 识别出 24 种颜色，并不需要准备 24 卷实体耗材，Lumina 会用所选的几卷耗材通过多层叠色组合出相近色彩；
- 屏幕上的 SVG 颜色在匹配到具体耗材配方后会产生色域映射，最终效果需结合 Lumina 预览、切片器逐层预览与试打样件综合确认。

各阶段预览的差异说明见[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)。

## 常见问题 Q&A

### 位图转成 SVG 后画质一定会变清晰吗？

不会自动提升原图清晰度。SVG 的优势是路径可任意缩放而不产生像素马赛克，但路径形状来自对原图像素的描摹；若原图本身存在模糊、锯齿或压缩色块，这些瑕疵也会被描摹进路径里。

### 颜色数量设多少合适？

首次运行建议先用“自动”档查看基准效果。Logo 和图标可手动设为原设计的实际配色数；若复杂插画需要设极高的颜色数才能勉强还原层次，直接使用原始位图配合高保真模式往往更自然。

### 形状数越多代表细节越好吗？

不一定。形状数偏高既可能是保留了丰富细节，也可能是把背景噪点、压缩伪影和渐变切成了大量细碎色块。判断标准是主体轮廓是否准确、文件后续预览和切片是否顺畅。

### 为什么连续渐变转成 SVG 后变成了一条条色带？

矢量图由边界明确的填充色块组成，处理连续渐变时会自动离散为有限级数的色阶区域。如果平滑渐变是画面的核心表现，建议保留原始位图并使用高保真模式。

### 发送到图像转换后，为什么还要重新选 LUT 或耗材档案？

SVG 文件只记录二维几何路径与屏幕显示色，不包含任何打印机与耗材叠色配方。选定经典 LUT 或耗材档案后，Lumina 才能将 SVG 色块转换为可打印的多层结构。

### 发送到图像转换后还能换回原始位图吗？

可以随时重新上传此前备份的原始位图。由于矢量化是有损重绘过程，无法从生成的 SVG 反向还原原图的全部像素与纹理。

### SVG 导入图像转换后出现白底、破洞或局部缺失怎么办？

先核对“图像转矢量”页面的 SVG 预览是否正常；若预览正常而转换页面异常，可按[SVG 上传失败、白底、破洞和细节异常怎么排查？](pathname:///zh/docs/knowledge/svg-troubleshooting/)逐项检查画布边界、路径闭合、蒙版与滤镜。
