# 怎样读懂 Lumina 分层预览？

在 Lumina Studio 中，**主预览**展示多层耗材叠加后预计呈现的表面成色，而**分层预览**则拆解展示每一个显色层在各个位置具体使用的耗材颜色。

将两者结合对照，既能看清最终画面效果，也能摸清任意色块背后的叠层配方。

:::tip[层序方向]
**第 1 层代表最外侧的观赏面，层号越大越靠近底板。** 这套编号按光学观察方向排列，与切片器中从热床自下而上计算的物理打印层号方向不同。
:::

## 三种预览各自看什么？

| 预览视图 | 核心用途 | 需要配合后续步骤验证的内容 |
| --- | --- | --- |
| Lumina 主预览 | 预测多层耗材透光叠加后的最终表面颜色 | 实体线盘身份、料槽映射与物理切片走线 |
| Lumina 分层预览 | 查看每个显色层在各区域的耗材分布 | 喷嘴线宽、接缝位置、擦拭塔、支撑与物理打印顺序 |
| 切片器逐层预览 | 检查打印机实际执行的每一道挤出路径 | 耗材透光叠加后的真实光学成色（由 Lumina 档案负责预测） |

在 Lumina 中确认主预览与分层预览无误后，导出 3MF 仍需在切片器内完成最终的逐层走线检查。

## 第一步：生成有效预览并加载分层图

1. 上传图片素材；
2. 选择本次使用的耗材档案组合或经典 LUT；
3. 设定建模模式、成品尺寸与显色层数；
4. 点击“预览”；
5. 等待主预览图与下方的分层缩略图加载完成。

每次预览成功后，分层缩略图会自动呈现在操作栏下方。若缩略图暂未刷出，可点击“查看分层”手动触发加载（请求期间按钮显示为“加载分层…”）。

修改图片、色彩来源、显色层数、层高或其他核心转换参数后，请重新点击“预览”刷新分层图，确保查看的是最新配方数据。

## 第二步：按“观赏面 → 底板侧”顺序读图

Lumina 分层预览统一从外侧观赏面往内侧底板方向排列：

- **第 1 层**：最贴近人眼观察侧的表层显色层；
- **中间各层**：在表层下方参与透光、遮盖与混色的中间显色层；
- **最后一层**：最贴近结构底板的内侧显色层。

<img
  src={require('./assets/02-read-layer-order.webp').default}
  alt="五张真实分层输出按第1层观赏面到第5层底板侧排列"
/>

每一张缩略图都代表**同一件作品**在对应显色层上的耗材分布。例如某个图形在第 1 层显示黄色、第 2 层显示蓝色，说明该区域通过不同高度的异色耗材叠加来调配出目标表面色彩。

:::warning[区分打印层号]
切片器的物理层号（Z 层）从热床第 1 层自下而上递增，且包含底板结构层、首层与浮雕高度；Lumina 分层预览仅展示显色配方层，并从观赏面起算第 1 层。此外，结构底板通常由多层同色基础耗材印制而成，分层预览的最后一张仅代表最贴近底板的那一层显色层，而非整块底板厚度。
:::

## 第三步：按五项清单逐层核对

浏览分层缩略图时，建议按以下顺序排查：

1. **外轮廓完整性**：作品边界、镂空孔洞与透明抠图区域在各层是否整齐一致；
2. **关键微细结构**：眼睛高光、文字笔画、细线或微缩图案是否在某一层意外断裂或消失；
3. **跨层叠色逻辑**：同一区域在各层间的耗材切换是否符合预期档案或自定义配方；
4. **显色总层数**：展示的分层总张数是否与当前所选 LUT、耗材档案设置或扩层配方一致；
5. **局部改色同步**：在颜色工作站中刚执行的颜色替换或自定义配方是否已准确反映在对应层上。

在浅色网页背景下，缩略图中的**白色耗材容易与页面底色融为一体**。点击任意缩略图打开放大视图后，模型轮廓外部会显示灰白棋盘格（代表透明无模型区域），轮廓内部的纯白区域即为实际的白色耗材。

## 第四步：放大视图并固定位置跨层对比

点击任一分层缩略图即可打开高清大图查看器：

- 点击左右箭头按钮，或按键盘方向键 `←`、`→` 切换上/下一层；
- 滚动鼠标滚轮，以光标所在位置为中心自由缩放；
- 放大后按住画面拖拽平移，细致检查边缘与微小色岛；
- 点击“重置缩放”一键恢复全图视野；
- 点击右上角 `×`、按 `Esc` 键或点击弹窗外侧空白处关闭大图。

<img
  src={require('./assets/03-zoom-and-compare.webp').default}
  alt="Lumina 分层大图中的层编号、上一层下一层和重置缩放控件"
/>

排查局部异常时，建议先将画面放大并停留在目标区域，再按键盘 `←`、`→` 连续切换相邻层。保持视野固定能一眼抓出仅在单层闪现的孤立碎点、断线或配方跳变。

## 第五步：悬停主预览读取单像素叠层配方

将鼠标指针停留在 Lumina 主预览画面的任意位置稍候片刻，会弹出像素级悬停检查卡：

- **局部放大镜**：清晰放大光标周围的像素网格；
- **像素坐标**：标明当前位置坐标，便于改色前后精准回到同一点对比；
- **预测颜色**：所有显色层叠加透光后预计呈现的表面颜色及色值；
- **第 1–N 层颜色**：自观赏面到底板侧，该像素在每一层实际铺设的耗材颜色。

<img
  src={require('./assets/04-hover-read-recipe.webp').default}
  alt="Lumina 主预览悬停检查卡显示像素坐标、预测颜色和每一层颜色"
/>

在上图示例中，目标像素的表面预测颜色为 `#D46F5E`，而下方五层分别由黄、品红、白等基础色耗材叠成。由于 Lumina 会根据耗材档案计算各层材料的透光率、遮盖力与层序光学反应（而非简单平均 RGB 数值），最终预测色与任一单层耗材本色不同属于正常的光学叠色原理。

实际打印成色还会受线材批次、实际首层与显色层高、挤出流量及观察环境色温影响。

## 第六步：常见分层异常速查

| 观察到的现象 | 优先排查方向 |
| --- | --- |
| 主预览整体色调明显失真 | 检查原图、色彩来源类型、所选耗材档案/LUT、量化颜色数与建模模式 |
| 主预览正常，但某单层出现孤立杂色块 | 检查原图压缩噪点、该区域的颜色替换记录或自定义叠层配方 |
| 所有显色层在同一位置都缺了一块 | 检查原图透明通道、裁剪选框、SVG 闭合路径或结构模式 |
| 分层总张数与预期不符 | 核对当前转换层数设置、自定义配方扩层记录，或重新点击“预览”刷新旧缓存 |
| 白色图案在缩略图里看似消失 | 点击放大进入大图视图，借助外部棋盘格区分透明背景与轮廓内的白色耗材 |
| 改色后分层图仍停留在旧状态 | 稍候自动重载；若改动了左侧核心设置，请重新点击“预览” |
| Lumina 分层无误，但切片器里颜色错乱 | 核对 3MF 导入方式、项目耗材列表、实体线盘与供料槽位映射 |
| Lumina 与切片器均正确，但实物偏色 | 检查耗材档案匹配度、线材新旧批次、打印层高、挤出流量与照明光线 |

若分层区域持续空白、全灰或长时间加载失败，请先用一张小尺寸简单测试图配合默认参数重新点击“预览”；若问题依旧，请按[网页、预览和生成故障排查](pathname:///zh/docs/knowledge/web-generation-troubleshooting/)逐步定位。

## 第七步：导出后衔接切片器检查

Lumina 分层预览专注于显色配方，以下物理制造细节需在切片器中最终确认：

- 喷嘴实际走线宽度与细微笔画保留情况；
- 首层附着面积、象脚外扩与底面平整度；
- 接缝落点、擦拭塔位置、支撑与桥接路径；
- 项目耗材与打印机 AMS / ACE / MMU 或外置料架实体槽位的对应关系；
- 自下而上的物理打印层序与换料次数。

导出 3MF 后的标准核对流程，请参阅[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)；若发现网页预览、切片器与实物成色存在偏差，请参阅[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)。

## 常见问题 Q&A

### 为什么第 1 层是观赏面，而不是热床上最先打印的第一层？

两套编号服务于不同环节：Lumina 分层预览用于解读光学叠色配方，从人眼观察的表面（第 1 层）往内层排列更直观；切片器则按喷嘴自下而上的物理成型顺序（Z 层）编号。

### 为什么悬停看到的“预测颜色”和下面五层的耗材颜色都不一样？

预测颜色是多层半透明耗材按特定厚度依次透光、反射后合成的表面视觉色。正因为各层透光率与排列顺序共同改变了光线吸收，少量几种基础色耗材才能混合出远超线盘数量的丰富中间色。

### 为什么有些项目的显色层不是 5 层？

显色层总数取决于当前选用的耗材档案层数设置、经典 LUT 规格或颜色工作站中的自定义扩层配方。无论实际是几层，分层预览与导出的 3MF 都会按当前生效的真实层数生成。

### 既然分层缩略图会自动加载，“查看分层”按钮有什么作用？

当网络波动导致缩略图延迟显示，或你希望主动重新拉取一次当前分层图像时，点击“查看分层”即可立即刷新。

### 悬停检查卡里显示“透明”代表什么？

说明光标当前停留在模型轮廓外部的空白区域，或该像素位置无实体填充，结合悬停放大镜即可看清轮廓边界。

### 能直接照着分层预览的层号来插 AMS 料槽吗？

不能混为一谈。分层预览的“第 1–N 层”代表模型厚度方向上的叠色层序，而非供料器的 1–4 号硬件料槽。硬件料槽映射请在导入 3MF 后按切片器中的项目耗材列表逐一指定。

### 分层预览里能看清小字，就一定能打印出来吗？

分层预览能说明文字已进入颜色配方数据，但如果笔画宽度小于喷嘴线宽，切片引擎仍可能将其忽略或合并。微缩文字、细线与尖角请务必在切片器的逐层路径预览中二次确认。

### 在颜色工作站替换颜色后，需要重新点左侧的“预览”吗？

在颜色工作站内应用颜色替换后，主预览与分层预览会自动同步更新；只有当你返回左侧修改了原图、色彩来源、层数、层高或建模模式等基础参数时，才需要重新点击“预览”。
