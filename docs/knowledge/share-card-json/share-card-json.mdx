# 保存项目与分享卡：导出、恢复和继续编辑

完成配色后，可通过“保存项目”导出可继续编辑的 `.lumina.json` 工程文件，或通过“导出分享卡”生成嵌入了项目数据的预览 PNG。两者都用于还原编辑状态；正式打印时仍需生成 3MF 并在切片软件中切片。

## 文件类型对比

| 文件 | 界面入口 | 用途 |
| --- | --- | --- |
| `.lumina.json` | 保存项目 | 本地项目留档、跨设备迁移、后续继续微调 |
| PNG 分享卡 | 导出分享卡 | 直观展示预览封面，同时将可恢复的项目数据随原始 PNG 一并分享 |
| 3MF 或 ZIP | 生成、生成并下载 | 导入切片软件检查走线并打印，不包含二次编辑所需的图层与选区状态 |

PNG 分享卡在图像数据之外内嵌了原始素材与配色参数。若经过截图、转存为 JPG、社交平台有损压缩或画图软件重新保存，画面虽会保留，但内嵌的项目数据会丢失。需要让他人导入继续编辑时，请发送原图文件或打包为压缩包传输。

## 保存项目

1. 上传图片，选定色彩来源、耗材与成品尺寸，点击生成预览；
2. 在“颜色调整”中完成全局换色、区域配方调整与选区操作；
3. 待当前编辑同步完成后，点击操作栏的“保存项目”或“导出分享卡”；
4. 重要作品建议同时归档原图、项目文件、所用耗材档案或 LUT 以及最终导出的 3MF。

若界面提示“编辑或选区仍在提交”，请稍候片刻或按提示完成同步后再导出，确保最新一步修改完整写入文件。

## 项目文件包含的内容

- 原始图像或 SVG 素材，以及当前转换参数；
- 已确认的全局换色与局部换色记录；
- 区域配方、逐层耗材组合与可还原的编辑状态；
- 当前激活的选区；
- 打印机型号、耗材预设选择及底座、挂环等模型附加设置。

恢复项目时会重新生成预览，并校验局部编辑与原图内容及工作坐标是否匹配：单纯修改原文件名称不影响恢复；若更换了底图或对原图做过裁剪、旋转，请另存为新项目。

## 导入并继续编辑

1. 在图像转换页面的上传入口选择 `.lumina.json` 文件或原始 PNG 分享卡；
2. 在弹出的确认窗口核对素材缩略图、尺寸、色彩来源及兼容性提示；
3. 确认恢复，等待素材载入与预览重建完成；
4. 检查局部换色、区域配方与选区状态，继续编辑；
5. 修改完成后另存新项目；需要打印时重新点击生成 3MF（旧会话的临时下载链接不会随项目导入恢复）。

重新点击预览会保留当前已确认的颜色编辑；执行撤销或二次换色后，请先刷新预览核对效果，再导出 3MF。

## 旧版文件与外部耗材资源

早期版本导出的文件若未记录局部区域信息，导入时仅恢复全局转换参数，具体可恢复范围会在确认窗口中列出。

项目文件记录的是色彩来源引用，不包含完整的耗材档案、经典 LUT 或切片器预设本体。在新设备上打开项目前，请先确保耗材库中已导入对应的耗材档案或 LUT；若系统提示无法匹配同名资源，在导入窗口中手动重新指定即可。

## 手动编辑 JSON 的说明

`.lumina.json` 中的常规转换参数只要符合当前模式与字段格式规范，手动修改后仍可正常导入；若内嵌素材、局部区域数据损坏，或选区坐标与原图尺寸失配，恢复将会中止。日常调整尺寸、配色与耗材，建议直接导入软件修改后重新保存。

## 模型贴图模式说明

启用“模型贴图”时，场景还依赖外部三维底模（STL / OBJ）及曲面选面坐标，当前项目格式暂不打包此类三维贴图状态，因此“保存项目”与“导出分享卡”按钮在模型贴图模式下不可用。使用模型贴图时，请单独归档三维底模、贴图原图与最终 3MF，并记录所选贴图面、朝向与缩放位置。

## 分享前隐私与版权检查

分享卡与 `.lumina.json` 内部均包含完整的原始设计图，而非仅有缩略封面。公开分享前请确认你拥有原图素材的相应授权，且文件中不含未公开稿件或个人隐私信息；仅需展示成品预览时，导出普通截图即可。
