# Lumina 2.0 怎样选择和保管耗材？

为 Lumina Studio 挑选耗材时，优先确认打印机能够稳定打印、线盘身份清晰且有对应的耗材档案，再去比较屏幕上的近似颜色。

仅凭“红色 PLA”这样的描述不足以锁定叠色效果。材质、品牌、产品系列、色号、批次、表面质感、透光率、含水状态以及所选耗材档案，都会直接影响最终成色。

## 买料与选料的五步筛选

### 1. 核对机器、供料系统与喷嘴兼容性

选料前先核对耗材厂商与设备厂商的硬件要求：

- 打印机与自动供料系统是否支持该材质、线盘规格与软硬度；
- 喷嘴材质与口径是否适配线材中的填料；
- 切片器中是否有适配当前机型的材料预设；
- 打印板材质、温度范围、封箱环境与通风条件是否满足要求。

夜光、碳纤维、玻纤、金属粉、木粉等高填料耗材具有磨蚀性，且更容易堵塞细喷嘴。使用 0.2 mm 喷嘴、普通黄铜喷嘴或自动供料系统前，请先确认耗材与设备的兼容说明，按需更换硬化喷嘴或更大口径喷嘴。

### 2. 先确定材料体系，再挑选颜色

PLA 和 PETG 都可用于平面叠色作品，但两者的打印温度、首层附着、流动性、拉丝表现与层间结合特性各不相同。由于 PLA 与 PETG 层间粘附力较弱（常被用作易剥离支撑界面），在彩色主体中直接混叠容易分层脱落。

同一件作品建议统一使用同一材料体系。若确实需要跨材料混打，请提前确认：

- 打印机与切片器支持该材料组合；
- 每个项目耗材均保留了对应的材料预设；
- 相邻材料在当前模型结构中能够稳固结合；
- 冲刷量与换料温度切换不会污染后续浅色层；
- 正式打印前已通过小样测试。

### 3. 区分表面质感与透光特性

即使同样标为“白色”或“红色”，不同表面与配方的线材在叠色中的光学表现也会明显不同，不宜直接共用同一份档案：

| 类型 | 对叠色结果的影响 | 使用前检查重点 |
| --- | --- | --- |
| 基础色 | 表现稳定，适合作为基础对照，不同品牌和批次仍有差异 | 核对品牌、系列、色号和批次 |
| 哑光 | 哑光助剂与表面散射会改变明度和透光率 | 单独测试验证，避免直接套用同色基础 PLA 档案 |
| 丝绸、金属光泽 | 观察角度与入射光线会明显改变表面观感 | 在固定光线下对比小样 |
| 透明、半透明、自然色 | 底板与下层颜色更容易透出，混色层数更深 | 优先自制档案，并同时核对白底与黑底表现 |
| 夜光、木粉、金属粉、碳纤维等填料 | 改变透光与散射特性，同时增加喷嘴磨损、堵头或送料阻力 | 先核对硬件要求，评估是否适合细喷嘴与多色供料系统 |
| 再生料、混色料或批次波动较大的线材 | 同名线盘之间可能存在色差或透光波动 | 新批次先打小样，关键作品重新验证档案 |

### 4. 将实体线盘与耗材档案一一对应

选择耗材档案时，请逐项核对：

1. 材质类型；
2. 品牌与产品系列；
3. 商品颜色、色号与表面效果；
4. 档案测试时使用的层高；
5. 实际装入打印机的线盘与料槽位置。

屏幕色块与 HEX 色号仅用于界面识别，无法反映耗材在不同叠层厚度、底色与光照下的真实显色。关于色彩数据来源的选择方法，请参阅[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)。

### 5. 用实物小样完成定稿验证

正式打印大尺寸作品前，建议先跑通一次“小图导入 → Lumina 预览 → 切片器逐层预览 → 实物试打”的完整流程。试打小样应使用与正式作品一致的线盘、材料预设、喷嘴、显色层高和底板设置。

若小样成色与预览差异明显，请优先检查实际线盘、耗材档案、料槽映射与受潮状态，确认材料环节无误后再微调原图。

## TD 值与 Lumina 耗材档案的关系

TD 是 Transmission Distance（透光距离）的缩写，在耗材叠色工作流中常用来表示实心线材阻挡绝大部分光线所需的厚度（单位为 mm）。通常情况下，较低的 TD 能更快遮盖下层颜色，较高的 TD 则允许下层颜色在更多层内参与混色。

在 Lumina 2.0 中，单一 TD 数值无法替代完整的耗材档案：

- TD 无法单独表达色相、明度以及红、绿、蓝三个通道的透光差异；
- 无法替代白底与黑底上的实测梯度变化；
- 无法完整反映哑光、丝绸、填料及表面散射带来的光学影响；
- 测量方式、光源、样片厚度与批次不同，测得的 TD 也会有所波动。

Lumina 2.0 的耗材档案提取自白底与黑底梯度色卡的实拍数据，记录了色彩预测所需的完整光学拟合参数。网上的 TD 参考值有助于了解耗材的大致透明度，但不能替代与手头线盘对应的耗材档案。

### 开封时建立线盘身份卡

建议在线盘侧面或密封袋上记录以下信息：

- 材质、品牌、系列、颜色、色号与批次；
- 开封日期；
- 对应的 Lumina 耗材档案名称；
- 档案测试层高与最近验证日期；
- 烘干记录、打印异常备注与剩余重量。

余料请勿混装到其他包装袋中，也避免仅凭肉眼深浅区分相近颜色的线盘，以免混淆后无法与软件档案准确对应。

### 区分密封保存与主动烘干

闲置线材应放入密封袋或密封干燥箱，配合有效干燥剂避光保存，日常减少开盖次数并定期检查密封条与干燥剂状态。

密封箱与干燥剂的作用是维持低湿环境、减缓线材继续吸湿；已经受潮的线材内部水分难以仅靠静置排出，需要放入烘干设备进行主动加热干燥。

### 按厂商参数设定烘干温度

不同材质配方与线盘材质的耐温上限差异较大：温度过低难以排出水分，温度过高则可能导致线材粘连或线盘变形。烘干时建议遵循以下步骤：

1. 查阅该线材厂商给出的推荐烘干温度与时长；
2. 确认线盘材质本身能够承受该温度；
3. 使用控温稳定的耗材烘干设备；
4. 烘干结束后趁热移入密封低湿容器保存；
5. 在线盘身份卡上更新本次烘干日期。

### 理性排查拉丝原因

耗材受潮常伴随表面粗糙、气泡、挤出爆裂声、漏料、层间结合变弱或拉丝增多；但喷嘴温度偏高、回抽参数不当、空驶路径过长或材料本身特性同样会导致拉丝。

排查时建议每次只调整一个变量：先使用同一个小型测试件对比烘干前后的打印表现，再决定是否微调温度与回抽设置。

## 打印前的一分钟检查清单

- 实体线盘标签与 Lumina 中选用的耗材档案一致；
- 切片器中的每个项目耗材均保留了正确的材料类型；
- 供料槽位中实际装入的线盘与映射记录一致；
- 线材无受潮、脆断、缠绕或送料阻力异常；
- 含填料线材符合当前喷嘴材质、口径与供料系统要求；
- 更换档案、层高或线盘后，已重新生成预览并完成切片；
- 打印大幅正式作品前已完成小样验证。

关于导出模型后对象与实体料槽的对应方法，请参阅[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

## 常见问题 Q&A

### PLA 和 PETG 都能建立耗材档案吗？

只要打印机、切片器与实际工作流支持对应材质，PLA 和 PETG 都可以分别建立并使用各自的耗材档案。由于两种材质的光学表现与打印温度不同，请勿混用同一份档案；跨材质同盘叠打前需单独测试层间结合力与冲刷温度。

### 找不到完全同色的耗材时，需要按最接近的 HEX 色号买料吗？

不必刻意追求完全相同的 HEX 色号。屏幕显示色相近并不代表透光率与叠色规律相近。优先选择打印稳定、身份明确且具备可靠耗材档案的线材，再结合 Lumina 预览与实物小样评估成色。

### 同品牌同色号换了新批次，需要重新校准吗？

可以先用现有档案试打小样。若成色、透光表现或表面质感与旧批次基本一致，可直接沿用；若新批次出现明显色差，且当前作品对色彩一致性要求较高，建议对新批次执行复验或新建档案。

### 哑光 PLA 可以直接套用基础 PLA 的同色档案吗？

建议先单独验证。哑光助剂会改变表面漫反射与内部光线散射，即使色号名称相同，叠层后的明度与色相也可能偏离基础 PLA。对成色精度要求较高时，建议为哑光耗材单独制作档案。

### 透明线材的 TD 值越高越好吗？

应根据画面需求搭配选择。高透光耗材适合拉宽混色过渡层次，低透光耗材则擅长快速遮盖底色、提亮局部高光。结合作品风格、层高与其他搭配耗材选型，并通过预览和小样确认即可。

### 0.2 mm 喷嘴能否打印木粉、碳纤维或夜光耗材？

需严格遵循耗材与打印机厂商的规格说明。多数含颗粒或纤维填料的耗材容易堵塞 0.2 mm 喷嘴，且夜光、碳纤维等材质通常要求使用 0.4 mm 及以上的硬化钢喷嘴。仅在双方厂商明确标注支持当前喷嘴口径与供料系统时再投入使用。

### 密封箱里放了干燥剂，为什么线材打印时还是拉丝？

密封箱与干燥剂主要用于阻止外部湿气继续进入，无法高效抽出已渗入线材内部的水分。请先按厂商推荐温度主动烘干线材后再做对比测试；若烘干后仍有拉丝，再依次排查打印温度、回抽距离与空驶路径设置。
