# 高保真、像素艺术与矢量模式怎么选？

选择建模模式时，先看原图最核心的视觉特征，再挑选对应保留该特征的模式：

- 照片、复杂插画、柔和渐变与丰富纹理，优先选择 **高保真**；
- 像素画、方格拼图与马赛克风格图案，优先选择 **像素艺术**；
- 原生 SVG 格式的 Logo、文字、图标、线稿与纯色图形，优先选择 **矢量模式**。

三种模式分别针对不同的画面结构设计，并无高低优劣之分。同一份素材也可以切换不同模式分别预览，再结合成品尺寸、模型复杂度与个人审美做决定。

## 三种模式分别保留什么？

/>

*注：上图为原理示意图，用于说明三种建模方式各自的边界处理逻辑，并非同一文件导入后的实际输出。真实效果还会受颜色数量、成品尺寸、喷嘴线宽与切片参数影响。*

### 高保真：保留连续色彩、纹理与光影过渡

高保真模式将输入画面作为连续图像处理，重点保留色彩渐变、笔触肌理与明暗层次，适合以下素材：

- 人物、宠物、风景与产品照片；
- 带有笔刷纹理、阴影、发光或柔和渐变的复杂插画；
- 带透明背景的复杂 PNG 图像；
- 虽为 SVG 文件，但希望按最终栅格画面而非路径轮廓处理的图形。

实际打印能呈现的最小细节仍受物理喷嘴限制：原图中比喷嘴线宽更细的睫毛、微缩文字或噪点，在模型生成或切片阶段可能会合并或省略；色彩变化极度细碎时，生成的色块区域与计算耗时也会相应增加。建议结合计划打印的实际尺寸查看预览效果。

### 像素艺术：保留规则网格与有限色板

像素艺术模式将规则排列的像素方格作为结构单元直接保留，适合以下素材：

- 像素风角色、道具与场景；
- 方格拼豆图案、马赛克与十字绣图稿；
- 经过降色处理、色块边界严格对齐网格的图像；
- 希望打印成品呈现清晰阶梯方格感的设计。

若将普通照片切入像素艺术模式，连续的面部、天空与阴影过渡会被拆分为肉眼可见的方块，仅适合刻意追求像素化风格的创作。

准备像素画素材时，请尽量保留原始像素网格；如需放大源图，请使用“最近邻（Nearest Neighbor）”插值，避免双线性或平滑缩放把方格边缘变模糊。导入后还需确认单个像素格在目标打印尺寸下的物理宽度大于喷嘴线宽，以免切片时丢失细节。

### 矢量模式：按 SVG 路径重建平滑边界

矢量模式直接读取 SVG 中的路径、轮廓与填充信息来构建三维几何体，适合以下素材：

- 原生导出的 SVG Logo、图标与徽章；
- 已转为轮廓路径的文字；
- 边缘利落的单色或多色线稿；
- 颜色数量精简、色块边界清晰的平面图形。

矢量模式仅在上传 SVG 文件时可选（上传位图时该项不可用）。由于边界直接由数学路径生成，不依赖固定像素分辨率，放大或缩小成品尺寸时依然能保持曲线与斜边的平滑利落。

需要注意的是，部分 `.svg` 文件内部可能嵌有位图，或使用了滤镜、蒙版、复杂渐变、剪切路径与特殊描边效果。不同解析器对高级 SVG 特性的支持存在差异，导入后请重点核对是否存在缺失区域、填色变化、孔洞异常、路径重叠或未转曲文字变形。

## 常见素材选型速查表

| 素材类型 | 推荐首选模式 | 预览检查重点 |
| --- | --- | --- |
| 人物、宠物或风景照片 | 高保真 | 五官、毛发、暗部过渡、背景噪点与细碎色块 |
| 带肌理和柔和渐变的插画 | 高保真 | 渐变是否出现断层、细碎纹理是否过多 |
| 原生像素画 | 像素艺术 | 像素网格是否对齐、前期缩放是否被意外平滑 |
| 马赛克或方格拼图 | 像素艺术 | 单个方格的物理尺寸是否满足喷嘴线宽 |
| 原生 SVG Logo 或图标 | 矢量模式 | 路径闭合、孔洞镂空、图层重叠、填充色与画布边界 |
| 文字与线稿 | 矢量模式或高保真 | 文字是否已转路径、细线与小字在目标尺寸下能否成形 |
| 透明背景 PNG | 按画面内容选择 | 边缘白边或灰边、半透明过渡像素与背景孤立杂点 |
| 自动描摹生成的 SVG | 对比矢量模式与高保真 | 节点是否杂乱、色块是否碎裂、轮廓是否变形 |

上表可作为首次预览的起点。例如只有三种纯色的清晰 PNG Logo 可直接使用高保真模式；若同时拥有设计软件导出的原生 SVG，也可切入矢量模式对比边缘平滑度与模型结构，择优导出。

## 透明 PNG 该选哪种模式？

透明背景 PNG 本质仍是像素位图：

- 画面为照片、复杂插画或柔和渐变时，选择 **高保真**；
- 画面为原生像素画时，选择 **像素艺术**；
- 画面为纯色 Logo 或线稿但手头没有原生 SVG 时，可直接使用 **高保真**，或借助描摹工具另存一份 SVG 与 **矢量模式** 对比效果。

抠图后的透明边缘常残留浅白边、灰边或半透明杂色像素。这些杂边在深色或浅色单一背景上不易察觉，但生成模型后可能变成独立的一圈异色边缘。建议导入前分别在深色与浅色底色下检查一遍边缘干净度。

### 透明边缘

清理抠图残留的白边、灰边与游离半透明杂点。若画面本身设计了柔和羽化或发光边缘，可先直接用高保真模式预览过渡效果，无需一刀切删光半透明区域。

### 杂点与细小碎片

提前擦除画面主体之外的压缩噪点、扫描灰尘与孤立小色斑，避免模型生成大量无意义的细微独立区域、拖慢切片速度。

### 过细线条与微缩文字

按计划打印的物理毫米尺寸评估线宽与字号。屏幕上放大可见的细线，缩放到 60 mm 或 100 mm 幅面后可能窄于单道挤出线宽。必要时提前加粗笔画、放大字号或简化繁琐暗纹。

### 渐变、滤镜与蒙版

若画面效果高度依赖模糊、发光、阴影或复杂蒙版，建议保留位图或导出高分辨率 PNG，使用高保真模式处理；若希望使用矢量模式，请在矢量设计软件中先将外观与描边扩展为普通闭合路径和纯色填充，再导出 SVG。

:::note[原图清理提示]
导入前清理杂边、噪点与小于线宽的碎屑，能让生成的色块边界更干净，使模型集中表现主体画面。
:::

## 模式选择的四个关键认知

### 自动描摹 SVG 无法恢复已丢失的细节

位图转矢量的自动描摹算法只能根据现有像素推算轮廓：对清晰的简单色块 Logo 往往能理顺边缘，但对模糊照片或高压缩图片则容易把噪点与锯齿拆成成百上千个碎路径，原图中已经糊掉的五官或文字并不会因此变清晰。

### 打印清晰度同时受成品尺寸与喷嘴线宽制约

高分辨率原图能提供充足的采样输入，而最终能印出多细的纹理，仍取决于成品物理尺寸、喷嘴口径与切片线宽。关于尺寸与线宽的换算关系，请参阅[0.2 和 0.4 喷嘴相当于多少分辨率？](pathname:///zh/docs/knowledge/nozzle-equivalent-resolution/)。

### 矢量模式决定路径边界，不增加可用颜色数

矢量模式的优势在于平滑还原几何轮廓，而作品最终能呈现多少种颜色，依然由当前选用的耗材档案（或 LUT）与叠层配方决定。

### 像素艺术的方格感属于明确的视觉风格

像素画通过有限网格与精简色板塑造造型，清晰的方格台阶正是其核心设计语言；盲目用平滑算法抹平锯齿反而会破坏原有的像素美感。更多格式差异可参考[位图与矢量图有什么区别？](pathname:///zh/docs/knowledge/bitmap-vs-vector/)。

## 一分钟选型流程

拿到素材后，可按以下顺序快速判断：

1. **看画面类型**：属于照片/复杂插画、像素画，还是 Logo/文字/线稿？
2. **查文件结构**：若是 SVG，内部是干净的闭合路径，还是内嵌位图与复杂滤镜？
3. **定保留目标**：优先保留连续色彩过渡、规则像素方格，还是平滑路径轮廓？
4. **做基础清理**：排查透明杂边、背景噪点、过细线条与极小文字。
5. **按目标尺寸预览**：重点放大检查五官、文字笔画、镂空孔洞与独立小色块。
6. **双模式对比**：拿不准时切换两种模式对比预览与切片路径，挑选观感更佳的一版。

## 常见问题 Q&A

### 单独上传 SVG 后，为什么软件默认切到了矢量模式？

上传单个 SVG 文件时，Lumina 会默认启用矢量模式以保留路径轮廓。若该 SVG 含有复杂渐变、滤镜或内嵌位图，可随时手动切换到高保真模式对比预览效果。

### JPG、PNG 和 WebP 能否使用矢量模式？

不能直接开启。这类格式存储的是像素矩阵，仅上传 SVG 时才可使用矢量模式。如需按路径建模，请先准备设计原稿导出的原生 SVG，或通过矢量描摹工具转换并检查路径后再上传（直接修改文件扩展名为 `.svg` 无效）。

### Logo 素材一定要转成 SVG 吗？

不一定。分辨率充足、边缘清晰的 PNG Logo 使用高保真模式同样能获得干净的打印效果。原生 SVG 在任意缩放尺寸和保持曲线平滑上更有优势；但如果手头只有位图且自动描摹后出现了杂乱节点，直接使用原 PNG 高保真模式往往更稳妥。

### 像素画可以使用高保真模式吗？

可以。像素艺术模式会严格锁定网格单元，而高保真模式会将其视作普通连续图像做区域划分。你可以根据想要保留硬朗方格感还是略微柔化的边缘自由选择。

### 矢量模式导入后少了一部分图形怎么办？

常见原因包括 SVG 内含嵌入位图、滤镜、蒙版、剪切路径、特殊描边、未转曲文字，或部分图元超出了画布（`viewBox`）范围。可在矢量编辑软件中将文字转曲、将外观与描边扩展为普通填充路径后重新保存导入；也可直接导出高分辨率 PNG 改用高保真模式。

### 同一张图在多种模式下都能正常生成时，按什么标准定稿？

结合目标打印尺寸下的预览清晰度、色块碎裂程度、关键细节还原以及切片后的实际走线来挑选即可，无需拘泥于模式名称。
