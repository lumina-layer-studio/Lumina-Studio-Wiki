# 批量生成多个作品：文件列表、结果与失败重试

当多张图片需要使用**同一套颜色来源和建模参数**时，可以使用批量生成将它们一次导出为同一个合并 3MF，方便在切片软件中统一排版。

核心规则速览：

- **进入方式**：首次上传时一次选择多张图片，或在单图页面点击“添加更多图片”，即可进入批量模式。
- **共享参数**：列表中的所有图片共用同一套经典 LUT 或耗材档案、目标宽度、底板厚度、结构模式与建模模式。
- **前期准备**：批量页面不支持逐张裁剪、旋转、颜色工作站微调或单图预览，这些调整需在加入批量前完成。
- **结果与下载**：生成完成后会显示“成功 / 总计”统计；若有部分文件失败，合并 3MF 仅包含成功生成的模型。
- **热床预览**：模型较多或尺寸较大时，网页端 3D 热床仅预览部分模型，完整对象列表可在切片软件中查看。

## 适用与不适用场景

**适合使用批量生成：**

- 同一系列的徽章、冰箱贴、挂牌或测试样件，使用相同的耗材组合与层高；
- 多张素材已统一整理好朝向、透明边缘与构图，只需套用同一套参数导出；
- 希望把多个模型打包进同一个 3MF，再进入切片软件集中排盘；
- 文件数量较多，希望先批量跑完，再单独处理个别异常素材。

**建议使用单图流程：**

- 每张图片需要不同的 LUT、耗材档案、厚度、单双面结构或建模模式；
- 素材还需逐张裁剪、旋转、局部换色或修图；
- 新耗材组合尚未经过单图预览与切片验证；
- 需要使用拼图、验证色卡或独立高度图浮雕等批量模式不支持的功能。

如果不确定色彩数据来源怎么选，可先参阅[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)。

## 第一步：整理图片素材

批量模式直接读取当前页面的共享设置，不会逐张弹出裁剪窗口。导入前请确认每张图片：

1. 方向已摆正，无需再旋转 90°、180° 或 270°；
2. 透明边缘、阴影、描边与画布留白干净准确；
3. 文件可正常打开，且文件名清晰易辨，便于核对结果列表；
4. 适合套用相同的颜色来源、结构模式和目标宽度；
5. 已妥善保存原始文件备份。

如需调整画布或构图，可参考[上传、替换、裁剪和旋转图片](pathname:///zh/docs/knowledge/image-upload-crop-rotate/)先导出处理好的图片副本，再统一导入。

:::warning[共享参数说明]
批量模式统一应用当前页面的参数，不会沿用每张图片之前的单图设置。如果某张图片需要单独的尺寸、换色或耗材组合，请将它移出列表并按单图流程处理。
:::

## 第二步：建立并核对文件列表

首次上传时多选图片，或上传单张后点击“添加更多图片”，左侧面板顶部就会列出已导入的文件数量与名称。

<img
  src={require('./assets/01-batch-file-list.webp').default}
  alt="Lumina Studio 批量模式中的两张图片文件列表、移除按钮和添加更多图片区域"
/>

配置参数前，先核对三项信息：

- **文件数量**：顶部的“已选 N 个文件”是否与计划生成的总数一致；
- **文件名称**：是否有重复文件、旧版本或误选的临时素材；
- **列表增删**：点击文件名右侧的“×”仅将该图片移出本次任务，不会删除本地磁盘文件。

点击“添加更多图片”可随时追加素材。增删列表文件后，此前的生成结果会失效，需要重新点击生成；当列表删减至只剩 1 张图片时，界面会自动切回单图模式。文件较多时列表会折叠显示前几项，实际队列总数以顶部统计数字为准。

## 第三步：配置共享颜色来源与参数

<img
  src={require('./assets/02-shared-settings.webp').default}
  alt="旧版 Lumina Studio 批量页面中的来源类型、品牌和已选传统 LUT"
/>

上图为早期界面截图；当前版本已将“传统 LUT”更名为“经典 LUT”，并移除了反推 LUT 入口。

依次选择来源类型及对应的经典 LUT 或耗材档案。选定有效的颜色来源后，右侧“批量生成”按钮才会激活。

同一批次中的所有文件共用以下设置：

- 颜色来源（经典 LUT 或耗材档案）；
- 目标宽度与底板厚度；
- 单面或双面结构；
- 高保真、像素艺术或矢量建模模式；
- 当前页面支持的颜色细节、高级匹配与设备参数。

所有图片共用同一个目标宽度，另一边尺寸则按各图的原始长宽比自动缩放，因此不同模型的实际高度和热床占地面积可能各不相同。

:::info[先用单图验证]
首次使用某套耗材组合或参数时，建议先挑一张代表图在单图模式下完成 2D / 3D 预览、导出与切片检查，确认颜色、层数和厚度符合预期后再批量导入。
:::

关于建模模式与功能叠加规则，可进一步参考[高保真、像素艺术与矢量模式怎么选？](pathname:///zh/docs/knowledge/image-mode-selection/)和[哪些功能可以一起用？](pathname:///zh/docs/knowledge/feature-compatibility/)。

## 第四步：点击“批量生成”

确认颜色来源与参数无误后，点击右侧的“批量生成”按钮开始处理。

<img
  src={require('./assets/03-batch-generating.webp').default}
  alt="点击批量生成后按钮变浅并显示转圈，表示任务正在处理"
/>

处理期间按钮会置灰并显示加载动画。总耗时取决于文件数量、分辨率、轮廓复杂度、目标宽度与细节精度。请等待任务完成，避免中途刷新页面或重新上传文件。

软件会按顺序处理队列中的图片，并将所有成功生成的模型打包进同一个 3MF；即使个别文件生成失败，其余成功项仍会正常保留并汇总展示。

## 第五步：查看结果并下载合并 3MF

<img
  src={require('./assets/04-batch-result.webp').default}
  alt="批量生成完成后显示成功 2 总计 2、下载批量 3MF 按钮和热床中的两个模型"
/>

任务完成后，结果面板会显示四项关键信息：

1. **成功数**：顺利完成建模的文件数量；
2. **总计**：本次队列参与处理的文件总数；
3. **失败文件**：仅在存在失败项时按文件名列出；
4. **下载批量 3MF**：只要有至少 1 个模型成功即可下载，文件内包含全部成功模型。

上图中显示“成功 2 / 总计 2”，中央热床预览区展示了生成的两个模型，右侧可直接下载合并 3MF 或调用已配置的切片器打开。建议在生成完成后及时保存 3MF，以免刷新页面、改动文件列表或会话过期导致临时下载链接失效。

### 为什么热床预览里的模型比成功数少？

当成功模型数量较多或当前热床单盘放不下所有模型时，网页 3D 预览只会加载前若干个可稳定展示的模型，并提示合并 3MF 仍包含全部成功项。下载后在切片软件的对象列表中即可看到完整模型。

### 提示“部分模型可能超出热床范围”怎么办？

出现该提示时，合并 3MF 仍会包含所有成功模型，但自动排盘后的位置超出了当前打印机的热床边界。导入切片软件后，请先使用自动排列、旋转或新增盘面功能整理好排版，再执行切片打印。

## 第六步：在切片软件中排盘与核对

将合并 3MF 导入 Bambu Studio、OrcaSlicer 或你常用的切片软件后，打印前请核对：

- 对象列表中的模型数量与“成功数”一致；
- 所有模型均位于热床有效范围内，且彼此无重叠；
- 各模型的实际毫米尺寸符合原图比例预期；
- 项目耗材已准确映射到实际料槽与线盘，打印机型号与喷嘴规格匹配；
- 单面 / 双面结构的观赏面与底板朝向正确；
- 切片预览中的逐层配色、换料次数与预计耗材用量正常。

如果网页预览与切片预览存在差异，可按[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)逐步排查。

## 失败文件的排查与重试

例如结果提示“成功 3 / 总计 5，失败 2”时，可按以下顺序处理：

1. 先点击“下载批量 3MF”，保存好已成功的 3 个模型；
2. 记录失败列表中的 2 个文件名；
3. 切换回单图模式，单独上传其中一个失败文件，用相同参数尝试预览和生成；
4. 检查图片文件是否损坏、画布留白是否异常、SVG 路径节点是否过多，或尺寸与精度设置是否过高；
5. 修复问题后单独导出，或仅将修复后的文件组成小批次重新生成。

单图模式同样报错或卡住时，请参阅[打不开、一直转圈或生成失败，应该先查什么？](pathname:///zh/docs/knowledge/web-generation-troubleshooting/)；若素材为 SVG，可对照[SVG 上传失败、白底、破洞和细节异常怎么排查？](pathname:///zh/docs/knowledge/svg-troubleshooting/)检查画布、路径、滤镜与嵌入位图。

## 常见问题 Q&A

### 为什么批量模式只有“批量生成”，没有单独的“预览”按钮？

批量模式面向已验证好参数的成组素材，点击后会直接完成整批计算并给出热床预览与合并下载。如需在导出前精细查看色彩分布、使用颜色工作站换色或逐张确认结构，请使用单图流程。

### 同一次批量任务可以为每张图设置不同宽度或厚度吗？

不可以。同一批次共用一套目标宽度、厚度和建模设置。不同尺寸规格的素材请分批处理或逐张生成。

### 其中一张图片失败，会影响其他成功模型下载吗？

不会。只要有至少 1 个文件生成成功，即可下载包含所有成功模型的合并 3MF，失败文件名会单独列出以便补做。

### 下载前又添加或删掉了图片，之前的结果还能直接下载吗？

修改文件列表会使上一轮批量结果失效。如需保留上一轮文件，请先点击下载，再增删列表并重新生成。

### 为什么设置了相同的目标宽度，各个模型的高度或占地却不一样？

目标宽度固定的是模型横向尺寸，纵向尺寸和轮廓边界则由每张原图的长宽比、透明区域与附加结构共同决定。可在切片软件中查看每个对象的精确毫米尺寸。

### 一次导入的文件越多越省时间吗？

批量模式省去了重复选参数、点生成和逐个导入切片器的操作，但每张图片的几何计算仍需依次完成。文件较多时，建议先用 2–3 张做小批量测试，确认无误后再分批处理。

### 下载合并 3MF 后可以直接发送打印吗？

打印前请先在切片软件中检查热床边界、模型间距、料槽映射、喷嘴直径与分层刀路预览，确认排版和换料无误后再开始打印。
