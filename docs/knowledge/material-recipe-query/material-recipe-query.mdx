# 组合耗材层、预测叠色并生成验证色块

同样几卷半透明或彩色耗材，只要叠层顺序、层高或基底颜色不同，从观赏面看到的颜色就会明显变化。“配方查询”用于在正式打印前组合耗材层、对比预测色值，并将多组候选配方一键排版为可打印的小型验证色块板。

借助这项功能，你可以快速确认：

- 同一组耗材（如红、白、黑）按不同前后顺序叠放时的显色差异；
- 同一配方叠在白色基底与黑色基底上的颜色变化；
- 如何将多组候选叠层合并生成一块验证色块 3MF 集中试打；
- 图例中的行列编号如何与切片预览及打印实物一一对应。

:::info[功能定位]
“配方查询”采用**正向预测**：由你选定耗材档案、叠层顺序、基底与层高，软件据此估算观赏面的混合颜色，不支持输入目标色号反向检索耗材组合。
:::

## 开始前准备

1. “耗材管理 → 耗材库”中已导入所需耗材的耗材档案，且耗材批次与校准条件一致；
2. “设置”中的切片软件、打印机型号与喷嘴尺寸已按实际设备选定；
3. 待对比的多组候选配方计划采用相同显色层层高；
4. 导入切片器后，按项目耗材列表核对真实线盘与料槽映射。

如果尚未建立耗材档案，请先参阅[生成并打印梯度卡](pathname:///zh/docs/tutorials/gradient-card-generate-print/)和[拍摄并提取梯度卡](pathname:///zh/docs/tutorials/gradient-card-extract-profile/)；如需编辑、备份或复验现有档案，请参阅[管理耗材档案](pathname:///zh/docs/knowledge/material-library-management/)。

## 第一步：打开配方查询

1. 打开 Lumina Studio；
2. 点击顶部导航栏的“耗材管理”；
3. 在二级标签中选择“配方查询”。

界面分为五个功能区：

- **左上**：基底颜色与层高设置；
- **左下**：耗材库搜索框与耗材卡片列表；
- **中间**：按“观赏面 → 基底”排列的当前配方层；
- **右侧**：混色计算后的预测色块、色值与配方摘要；
- **左侧下方（配方队列）**：暂存多组候选配方并生成验证色块 3MF。

## 第二步：选择基底和层高

先根据作品的实际背板选择基底：

- **白色基底**：估算显色层叠在白色背板上时的颜色；
- **黑色基底**：估算显色层叠在黑色背板上时的颜色。

接着选择每一显色层的层高（支持 **0.04 mm、0.08 mm 和 0.10 mm**）。该层高既参与混色预测计算，也会写入导出的验证色块 3MF，请与后续切片计划保持一致。

:::warning[统一队列层高]
同一块验证板上的所有色块共用同一切片层高。若中途切换了层高（例如从 0.08 mm 改为 0.04 mm），请先清空队列，按相同层高分组生成验证板。
:::

生成的验证色块默认采用白色分隔网格与白色中央背板（本文示例使用白色基底与 0.08 mm 层高）。若需进行黑底实物验证，导入切片器后请将背板对象指定为对应的黑色耗材。

## 第三步：搜索并选择耗材档案

耗材库较多时，可在左下方搜索框按以下任一信息筛选：

- 耗材名称
- 品牌名称
- 档案目录名
- 十六进制色号

输入关键词后，列表会自动收起无关分组，仅展示匹配的耗材卡片。同名、近似色或不同批次耗材的透光率可能存在差异，点选前请核对品牌、名称与档案目录。

<img
  src={require('./assets/02-search-materials.webp').default}
  alt="在配方查询页面按品牌搜索耗材档案，再点击对应耗材卡片"
/>

点击耗材卡片即可将其加入中间的配方列表；继续点击其他卡片时，新层会依次追加在**更靠近基底的一侧**。

## 第四步：按“观赏面 → 基底”排列层序

中间列表自上而下对应从外侧观赏面到底层基底的物理顺序：最上方为观赏面第一层，最下方紧贴基底。

例如依次点选：

1. PLA 大红色
2. PLA 白色
3. PLA 黑色

对应的实际叠层结构为：

**观赏面 → 大红色 → 白色 → 黑色 → 白色基底**

<img
  src={require('./assets/03-layer-order.webp').default}
  alt="三层耗材按观赏面到基底排列为大红色、白色和黑色"
/>

列表上方提供三个调整按钮：

- **撤销最后一层**：移除刚添加、最靠近基底的一层；
- **反序**：将当前整套层序首尾翻转；
- **清空**：清空当前全部配方层，重新点选。

调整或反序后，请重新点击“计算混色”刷新右侧预测结果。

## 第五步：计算并对比预测颜色

确认层序后点击“计算混色”，右侧面板会显示：

- 预测颜色色块
- 十六进制色号（HEX）与 RGB 数值
- 总层数、单层层高与基底类型
- 各层耗材名称与排列顺序

该预测直接基于耗材档案的光学测量参数与当前叠层条件计算，无需预先生成经典 LUT。

以同一组红、白、黑三层耗材为例：

- **大红色 → 白色 → 黑色**：预测色值为 **#90505E**；
- 点击“反序”重新计算（**黑色 → 白色 → 大红色**）：预测色值变为 **#423839**。

<img
  src={require('./assets/04-order-changes-result.webp').default}
  alt="相同三种耗材反序前后的真实预测结果对比，分别为 #90505E 和 #423839"
/>

同一组线材仅翻转顺序就会呈现截然不同的明度与色相，因此记录配方时需同时保留完整的层序。

:::note[影响实物的因素]
实物显色还会受线材批次、含水率、打印温度、流量、首层压实度、打印板表面纹理及观察光源影响。屏幕色值适合横向筛选候选方案，最终选型请以同条件下打印的实物色块为准。
:::

## 第六步：将候选配方加入队列

点击“添加到队列”，可将当前配方（含耗材层序、预测色号、层高与基底设置）暂存到左侧队列。随后可继续调整层序、重新计算，把其他候选方案逐一加入同一队列（完全相同的配方不会重复入队）。

同一队列适合对比相同层高、基底与设备条件下的多组方案；若更换了基底、层高或喷嘴配置，建议先清空旧队列再新建测试。

## 第七步：设置验证色块版式

队列下方提供四项版式参数：

| 设置 | 作用 | 取值与建议 |
| --- | --- | --- |
| 色块尺寸 | 单个方形色块的边长 | 范围 5–50 mm；尺寸越大越便于观察大面积显色与表面质感 |
| 间距 | 相邻色块之间的白色分隔网格宽度 | 范围 0.5–10 mm；用于清晰隔离相邻配方 |
| 列数 | 每行排列的色块数量 | 填 `0` 时按队列数量自动排版；也可手动指定 1–20 列 |
| 结构模式 | 单面或双面显色 | 单面仅生成一个显色面；双面会在中央白色背板两侧对称生成相同配方 |

<img
  src={require('./assets/05-queue-settings.webp').default}
  alt="配方队列包含两组候选配方，并设置色块尺寸、间距、列数和单面或双面结构"
/>

候选配方较少时无需凑满整行，将“列数”设为 `0` 即可自动计算行列，空余格位会由白色基础结构自动补齐。

## 第八步：生成并下载验证色块 3MF

点击“生成验证色块”，生成完成后：

1. 页面出现“下载 3MF”按钮；
2. 队列下方展示按行、列编号排列的配方图例，每个格位标有预测色、配方摘要与各层颜色圆点；
3. 点击“下载 3MF”保存完整项目文件，并截图留存图例。

<img
  src={require('./assets/06-swatch-ready.webp').default}
  alt="验证色块生成成功后出现下载 3MF 按钮和带行列编号的配方图例"
/>

例如使用两组配方、15 mm 色块尺寸、2 mm 间距、自动列数（`0`）与单面结构，生成的 3MF 文件约 **33 KB**，内含白色分隔网格、背板以及各配方层对应的独立耗材对象。图例中的行列号与验证板实物位置一一对应（如“第一行第二列”即首行第二个色块），留存图例截图便于打印后直接核对。

## 第九步：在切片器中核对并切片

在 Bambu Studio、OrcaSlicer 或设置中选定的切片软件内，将 3MF **作为完整项目**打开，依次核对：

1. 打印机型号与喷嘴尺寸与实际机器一致；
2. 项目耗材列表完整保留；
3. 将项目耗材准确映射到 AMS 槽位或外置线盘；
4. 检查各色块对象分配的项目耗材编号；
5. 执行切片，翻至显色面并拖动层滑块逐层核对颜色顺序与背板材料；
6. 确认无误后发送打印。

切片器映射细节请参阅[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

:::warning[核对耗材槽位]
导出 3MF 仅包含项目耗材定义，不会自动绑定打印机当前的物理料槽。发送打印前，务必在切片预览中确认项目耗材编号、真实线盘与硬件槽位三者对应无误。
:::

## 第十步：观察与评估实物色块

待验证板完全冷却后取下，在稳定、均匀的中性光线下评估：

1. 对照图例行列号定位每组配方；
2. 从作品实际采用的观赏面观察；
3. 综合对比色相、明暗层次、遮盖力与表面平整度；
4. 记录所用耗材品牌、批次、层高、打印温度、喷嘴与基底条件，选定最终配方或返回页面微调层序。

手机自动曝光与自动白平衡容易改变色块照片的明暗和冷暖对比。如需拍照归档，请固定光源、机位、曝光与白平衡参数。

## 常见问题

### 能直接输入目标颜色，自动搜索最接近的耗材组合吗？

“配方查询”仅提供指定叠层的正向混色估算。若需将图片颜色自动匹配为耗材叠层配方，请直接使用图像转换流程。

### 为什么只把层序反过来，预测颜色就变了？

不同耗材对光线的吸收率与透射率不同。表层材料直接反射环境光，下层颜色则需穿透上层材料后才进入人眼，因此调换前后顺序会显著改变最终显色。

### 叠层数量可以超过五层吗？

界面支持添加五层以上的耗材组合。不过叠层越厚，打印时间、换料次数与模型总厚度都会相应增加，建议结合目标模型的实际显色层数设定。

### 白色基底和黑色基底怎么选？

按作品最终使用的真实背板颜色选择：白底作品选白色基底，黑底作品选黑色基底。生成的验证色块默认使用白色背板结构，验证黑底配方时请在切片器中同步修改背板对象的耗材。

### 修改层高后，队列里原有的配方怎么处理？

队列保留的是入队时按当时参数计算的结果。更改层高、基底或设备规格后，请清空队列并重新计算，确保同一块验证板上的所有色块采用一致的切片条件。

### 为什么屏幕预测色与打印实物仍有细微差别？

预测模型反映的是标准校准条件下的主要叠色规律，而线材批次差异、含水率、喷嘴温度、流量、首层挤压程度、打印板纹理及环境光色温都会影响实物观感。请以相同打印条件下产出的实物验证色块作为最终依据。

### 下载的 3MF 在切片器里颜色或对象不对怎么办？

请确认导入时选择了“作为完整项目打开”而非“仅导入几何体”，随后检查打印机型号、喷嘴、项目耗材与料槽映射。若最初在 Lumina“设置”中选错了目标切片器或机型，返回修改后重新生成 3MF 最为稳妥。

### 忘记保存图例截图还能找回格子对应的配方吗？

若配方查询页面尚未关闭或清空，可直接返回页面补截；若队列仍在，也可按相同列数重新生成一次以查看图例。建议每次下载 3MF 时将图例截图与 3MF 保存在同一文件夹中。
