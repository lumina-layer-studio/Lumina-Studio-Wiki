# 切片器没检测到，或者 3MF 打不开怎么办？

遇到“打不开 3MF”时，问题通常出现在以下四个环节之一：

1. Lumina 尚未成功生成 3MF；
2. 3MF 文件未完整下载到本机；
3. 3MF 文件正常，但 Lumina 未检测到或未能自动拉起本地切片软件；
4. 切片软件已打开文件，但只导入了纯几何外形，未载入对象列表、耗材与项目参数。

先定位卡在哪一步，就能直接采取对应的解决方法。

<img
  src={require('./assets/04-open-diagnosis-flow.webp').default}
  alt="从 Lumina 生成、3MF 下载、手动打开和项目完整性四层判断打不开问题"
/>

:::tip[快速判断]
先在 Lumina 中点击“下载 3MF”，再从切片软件菜单栏点击“文件 → 打开项目”手动载入。若手动打开一切正常，说明 3MF 文件完好，仅需检查自动检测、系统权限或应用路径；若手动也无法打开，再排查导出格式、文件体积与切片软件版本。
:::

## 第一步：确认设置中的目标切片软件

进入“设置”，核对以下三项：

- **切片软件**：选定你实际使用的切片软件（如 BambuStudio 或 OrcaSlicer）；
- **打印机型号**：选定实际打印机型；
- **喷嘴尺寸**：选定机器当前安装的喷嘴直径。

“切片软件”选项同时决定了自动打开的目标程序以及写入 3MF 的机器预设与工艺参数。选择 BambuStudio 时请搭配 Bambu Studio 打开；选择 OrcaSlicer 时请搭配 OrcaSlicer 打开。更改切片软件、机型或喷嘴后，需返回转换页面重新生成 3MF，此前已导出的旧文件不会自动更新。

:::warning[匹配导出格式]
当电脑上同时安装了多款切片软件时，请确保打开 3MF 的切片软件与 Lumina“设置”中选定的导出格式一致，以免部分机器预设或项目参数无法完整解析。
:::

## 第二步：检查自动检测状态

Lumina 会在本机常见安装目录中自动扫描受支持的切片软件，并根据扫描结果显示对应按钮：

| 页面状态 | 显示按钮 | 含义 |
| --- | --- | --- |
| 已检测到匹配切片器，尚未生成 | “生成并在 Bambu Studio 中打开”等 | 生成完成后自动调用该切片器打开项目 |
| 已检测到匹配切片器，已经生成 | “在 Bambu Studio 中打开”等 | 使用刚生成的 3MF 直接启动该切片器 |
| 未检测到可用切片器 | “生成并下载”或“下载 3MF” | 正常生成 3MF 供本地下载，跳过自动拉起 |
| 导出格式与本机检测结果不一致 | “当前导出格式为……但本机未检测到……” | 设置中选定的切片器在本机默认目录未找到 |

即使提示未检测到切片软件，3MF 生成与下载也不受影响——点击下载后在切片器中手动打开即可。

若希望恢复一键自动打开，请确认：

1. 切片软件已正式安装到系统目录，而非直接在安装包（`.dmg`）或压缩包内临时运行；
2. 切片软件已手动启动过至少一次，且通过了 macOS 首次打开的安全确认；
3. 切片软件与 Lumina 后端运行在同一台电脑上（若用浏览器远程访问另一台主机上的 Lumina，请直接下载 3MF 到当前电脑打开）；
4. 移动过切片软件安装位置后，已重启 Lumina。

## 第三步：在 macOS 中手动指定 `.app` 路径

macOS 版若因自定义安装目录导致自动检测未命中，可在“设置”页面下方的“手动切片软件路径”中直接指定路径：

<img
  src={require('./assets/01-export-format.webp').default}
  alt="Lumina Studio 设置页面中的手动切片软件路径、校验并保存和清除按钮"
/>

1. 打开 Finder 的“应用程序”目录，找到已安装的切片软件；
2. 核对磁盘上的真实应用包名称（注意空格与大小写）；
3. 在输入框填入完整的 `.app` 路径；
4. 点击“校验并保存”；
5. 页面提示“已识别……”后，返回转换页面即可使用一键打开。

常见路径格式参考（请以本机实际应用包名称为准）：

- `/Applications/BambuStudio.app`
- `/Applications/OrcaSlicer.app`
- `~/Applications/某个受支持的切片软件.app`

## 第四步：核对真实的 `.app` 文件名

应用窗口标题与磁盘上的 `.app` 包名未必一致，多一个或少一个空格都会导致校验不通过。以 Bambu Studio 在 macOS 上的默认包名为例：

- `/Applications/Bambu Studio.app`：校验失败（磁盘文件名不含空格）；
- `/Applications/BambuStudio.app`：校验通过，成功识别为 Bambu Studio。

<img
  src={require('./assets/02-path-validation.webp').default}
  alt="Bambu Studio 手动路径的失败和成功真实校验对比"
/>

若提示“未识别到受支持的切片软件，请确认路径指向 .app 应用包”，请逐项检查：

- 该路径在磁盘上是否真实存在；
- 路径末尾是否停在 `.app` 层级（不要深入到包内的 `Contents` 或二进制可执行文件）；
- 应用是否已拖入“应用程序”文件夹（而非留在“下载”目录或挂载镜像中）；
- 空格与大小写是否与 Finder 显示完全一致。

校验保存后，Lumina 将优先按该手动路径启动切片器；点击“清除”可恢复默认自动检测。

:::info[Windows 用户]
“手动切片软件路径”仅面向 macOS 的 `.app` 应用包（请勿填入 Windows 的 `.exe` 路径）。Windows 端通过系统安装注册信息自动识别切片器；若未自动识别，请确认切片器已通过官方安装程序正常安装并启动过一次，或直接下载 3MF 后从切片器的“文件 → 打开项目”载入。
:::

## 第五步：使用“打开项目”手动载入（通用备用方案）

一键启动受阻时，手动打开同样能完整保留全部项目数据：

1. 点击“下载 3MF”，确认文件下载完成且大小不为 `0`；
2. 启动 Bambu Studio、OrcaSlicer 或设置中对应的切片软件；
3. 在菜单栏选择“文件 → 打开项目”，选中刚下载的 `.3mf` 文件；
4. 若弹窗询问导入方式，选择**作为项目打开**（而非仅导入几何体）。

<img
  src={require('./assets/03-open-full-project.webp').default}
  alt="Bambu Studio 中完整打开 Lumina 3MF 后保留对象列表、项目耗材和模型"
/>

以完整项目打开后，打印盘、对象/零件层级、项目耗材列表与工艺预设都会一并载入。若列表中只剩一个无法展开的合并网格，请关闭当前窗口，重新通过“打开项目”导入。

此外，3MF 本质上是带内部引用关系的工程包，请直接使用原始下载文件打开，避免手动解压修改后再重新压缩导致内部元数据失效。

## 第六步：常见提示与处理对照

| 页面提示或现象 | 原因说明 | 处理方式 |
| --- | --- | --- |
| 未检测到切片软件 | 默认目录未扫描到受支持的切片器 | 下载 3MF 手动打开；macOS 可配置手动 `.app` 路径 |
| 当前导出格式为 A，但本机未检测到 A | 设置中选定的导出软件与本机已装软件不一致 | 在“设置”中切换为实际安装的切片软件并重新生成 3MF |
| 未找到切片软件 | 原有路径下的应用程序已被移动、改名或卸载 | 重新核对应用位置并校验保存新路径 |
| 找不到要打开的 3MF | 临时生成产物已过期或被清理 | 返回转换页面重新生成 |
| 下载文件暂时无法读取 | 临时下载链接已失效 | 重新生成并立即下载保存 |
| 准备切片器打开文件失败 | 无法写入临时启动副本 | 检查本机剩余磁盘空间与目录权限，或直接下载后手动打开 |
| 启动切片器失败 | 系统安全拦截或路径异常 | 先从“应用程序”手动打开一次切片软件，再重试 |
| 打开后缺少对象层级或项目耗材 | 仅导入了几何模型，或导出格式与当前切片器不匹配 | 重新选择“作为完整项目打开”，并核对 Lumina 导出格式 |

由于顶部气泡提示会在数秒后自动收起，若遇到报错建议第一时间截图留存完整文字。

## 第七步：区分启动异常与文件损坏

### 下载后手动能正常打开

说明 3MF 文件本身完好，排查重点放在自动检测、手动 `.app` 路径、macOS 首次运行权限，以及 Lumina 与切片器是否运行在同一台本机。（注：一键打开使用的是临时副本，在切片器内继续所做的修改不会反向写回 Lumina 网页端。）

### 仅某一款切片器打不开

核对 Lumina“设置”中的导出格式是否与该款切片器对应，并检查切片器版本是否为较新正式版。不同切片器对专有项目元数据的兼容范围不同，使用匹配导出格式的切片器打开最为稳妥。

### 所有切片器均无法打开

1. 先检查下载文件大小：若仅有数字节、后缀变为 `.html` 或下载中断，重新下载即可；
2. 回到 Lumina 重新生成一份 3MF 并对比两次文件大小；
3. 若重新生成的文件仍无法在对应版本的切片器中打开，保留原始 `.3mf` 文件及双方版本号提交反馈。

## 第八步：导入切片器后的打印前核查

成功载入项目后，发送打印前请完成以下核查：

- 打印机型号与喷嘴直径与实物机器一致；
- 项目耗材列表及各对象/零件的耗材编号分配无误；
- 项目耗材已准确映射到 AMS 槽位或外置线盘；
- 执行真实切片后，在“预览”中逐层确认显色面、底板与各层颜色顺序。

映射操作详见[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)；若预览颜色与切片或实物存在差异，请参阅[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)。

## 提交反馈时建议附上的信息

1. Lumina Studio 版本号（或页面显示的构建信息）；
2. 操作系统名称与系统版本；
3. 切片软件名称与具体版本号；
4. Lumina“设置”中选定的切片软件、打印机型号与喷嘴尺寸；
5. 报错提示的完整截图；
6. 具体表现属于“仅一键启动失败”还是“下载后手动打开也报错”；
7. 未经修改的原始故障 `.3mf` 文件，以及是否能被其他切片软件打开。

公开提交前请隐去截图与路径中的个人账号、邮箱、服务器地址及未公开商业素材。

## 常见问题

### 为什么“设置”页面修改机型后没有单独的“保存”按钮？

切片软件、打印机型号与喷嘴尺寸在切换后立即自动生效保存；仅“手动切片软件路径”需要点击“校验并保存”，用于验证目标 `.app` 应用包是否有效且受支持。

### 手动路径已经显示识别成功，为什么转换页面还提示另一款切片器？

一键打开需要“设置”中选定的**切片软件（导出格式）**与手动路径指向的切片器一致。将“切片软件”切换为同一款软件后重新生成 3MF 即可。

### 把切片软件移到别的文件夹后，原来保存的手动路径为什么失效了？

手动路径记录的是绝对路径位置。移动、重命名或重新安装应用后，请重新填入新路径并点击“校验并保存”。

### 点击一键打开后切片软件启动了，里面却是空白新项目？

当切片软件首次冷启动较慢时，启动参数可能未被及时接收。待切片软件完全打开后，再次点击“在……中打开”，或直接通过“文件 → 打开项目”载入已下载的 3MF。

### 隔了一段时间再点下载链接提示失效，是文件损坏了吗？

生成产物保存在临时会话中，超时或清理后旧链接会自动失效。返回页面用当前设置重新生成并及时保存到本地文件夹即可。

### 在电脑里双击 `.3mf` 文件默认打开了别的软件怎么办？

双击行为由操作系统的默认文件关联决定。你可以在目标切片软件内通过“文件 → 打开项目”导入，或在系统文件属性中将 `.3mf` 的默认打开方式改为常用切片软件。
