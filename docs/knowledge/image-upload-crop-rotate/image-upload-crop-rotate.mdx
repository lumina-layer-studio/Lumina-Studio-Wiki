# 上传、替换、裁剪和旋转图片

导入素材后，你可以在 Lumina Studio 中直接裁剪构图、调整旋转方向，或追加多张图片进入批量转换：

- **首次导入**：点击上传区域，或直接将图片拖入虚线框；
- **单图与批量切换**：“更换当前图片”会留在单图流程，“添加更多图片”则会切入批量流程；
- **裁剪与旋转**：裁剪用于保留选定画幅，旋转用于调整 90°、180° 或 270° 方向；
- **状态刷新**：更换、裁剪或旋转图片后，旧图的预览、局部改色与导出文件会自动清空，重新点击“预览”与“生成”即可。

## 开始前保留原图备份

Lumina Studio 在裁剪或旋转时仅修改当前网页任务中的工作副本，不会改动电脑磁盘上的原始文件。不过，一旦在窗口中应用裁剪或旋转，当前任务即以处理后的新画面为准；若想恢复完整画幅，重新上传原图最为直接。

遇到以下情况时，建议在本地保留好原始文件与工作副本：

- 手头仅有唯一一份相机原片、手机照片或设计源稿；
- 后续可能还要微调透明边缘、画布留白或长宽比例；
- 同一张素材计划导出多种裁剪比例或摆放方向；
- 重要商业项目需要长期归档原图、分享卡参数与最终 3MF。

:::info[支持图片格式]
支持导入 JPG / JPEG、PNG、WebP、HEIC / HEIF 与 SVG，同时兼容部分相机 RAW 格式。其中 HEIC / HEIF 与 RAW 在首次生成缩略图时耗时略长，SVG 则会保留自身的路径与画布信息。请确保文件内容本身完整可用（仅修改损坏文件的扩展名无法正常解析）。
:::

## 第一步：上传单张或多张图片

打开“图像转换 → 核心设置”，在左侧“基础设置”顶部找到虚线上传框：

1. 点击上传框，从系统文件窗口中选择图片；
2. 或从访达 / 资源管理器将图片直接拖入上传框；
3. 若一次框选多张图片，将直接创建批量转换任务。

只上传一张图片时，界面进入单图流程，缩略图下方显示“裁切与旋转”等单图操作；一次上传多张图片时，界面直接展示批量文件列表（批量模式下不提供逐张独立裁剪与旋转）。

导入较大的 HEIC、HEIF 或 RAW 文件时，请稍候缩略图加载完成，无需重复点击选择同一文件。

## 第二步：按需裁剪画幅

在单图流程中，若已开启“上传后裁剪”开关，选择位图后会自动弹出裁剪窗口。该开关会记住上一次的状态；若日常无需每次裁剪，将其关闭即可。

裁剪窗口内置“自由”、1:1、4:3、3:2、16:9、9:16 和 3:4 常用比例。你可以直接拖拽蓝色裁剪框，也可以在底部输入精确的 X、Y 像素起点与宽度、高度数值。

确认前可核对窗口底部的两组尺寸：

- **原图**：当前导入文件的完整像素宽高；
- **选区**：裁剪后实际保留的像素宽高。

调整满意后点击“应用更改”；若放弃本次裁剪，点击“取消”或右上角关闭按钮即可。图片导入后，随时可点击缩略图下方的“裁切与旋转”再次打开该窗口。

:::warning[透明边缘留白]
透明 PNG 的投影、外发光、描边与抗锯齿边缘往往包含肉眼不易察觉的半透明像素。若裁剪框紧贴实色边缘切齐，生成的模型外圈可能出现断边或缺口。建议先在深浅背景上确认透明过渡范围，向外适当留出少量边距。
:::

### 裁剪与画面分辨率

裁剪的作用是收紧构图范围，选区内的像素总数即为剩余可用像素。将原图中很小的一块局部裁出并拉大打印尺寸时，细节上限仍受该局部的像素量与喷嘴线宽制约。关于目标尺寸与细节表现的关系，请参阅[0.2 和 0.4 喷嘴相当于多少分辨率？](pathname:///zh/docs/knowledge/nozzle-equivalent-resolution/)。

### 为什么上传 SVG 时不会弹出裁剪窗口？

单独上传 SVG 时，Lumina 默认优先保留原生矢量路径，不走位图像素裁剪流程。SVG 的可视范围由文件自身的 `viewBox`、画布尺寸与路径坐标决定。如需调整画幅边距，建议在矢量设计软件中修改 `viewBox` 或画板大小后重新导出；也可另存为高分辨率 PNG 按位图流程裁剪。

## 第三步：区分“更换当前图片”与“添加更多图片”

单图上传完成后，缩略图下方提供两个文件操作入口：

### 更换当前图片

用新图片替换当前图片，并继续留在单图流程（直接点击图片缩略图也会触发同一替换操作）。替换后，针对旧图生成的预览、颜色工作站局部调整、3D 预览及下载链接会自动清空。

### 添加更多图片

保留当前图片并追加新文件，同时自动切换到批量流程。批量流程会对列表内的所有图片统一应用同一套转换参数；若每张图片需要独立的裁剪比例、旋转方向或结构设置，建议按单图逐一处理。

若原本只想换图却误点了“添加更多图片”（界面出现文件列表与“批量生成”按钮），只需点击多余文件名右侧的 `×` 将其移除；当列表仅剩一张图片时，界面会自动切回单图流程。

## 第四步：旋转图片方向

在单图流程中点击“裁切与旋转”，使用“向左旋转 90°”或“向右旋转 90°”调整朝向（向同一方向连续点击两次即为旋转 180°），核对构图无误后点击“应用更改”，放弃修改则点击“取消”。

应用旋转后，后续的 2D 预览、3D 预览与模型导出均采用新方向（此前已下载到本地电脑的旧文件不会改变）。注意旋转 90° 或 270° 会互换画面宽高，若固定了目标宽度，成品高度与构图比例也会随之变化。

SVG 文件同样支持在该窗口中旋转方向并完整保留矢量路径。

:::note[SVG 异常处理]
旋转仅用于调整画面朝向。若 SVG 出现缺块、白底、破洞或画布偏移，请按[SVG 专项排查](pathname:///zh/docs/knowledge/svg-troubleshooting/)检查闭合路径、画布范围、滤镜与内嵌位图。
:::

## 第五步：核对批量文件列表

进入批量模式后，开始生成前请核对列表信息：

- 顶部显示的文件总数与计划处理张数一致；
- 列表中无重复导入或选错版本的图片；
- 如需继续添加文件，可点击列表下方的“添加更多图片”；
- 如需剔除单张文件，点击对应文件名右侧的 `×` 即可。

由于批量模式不提供逐张裁剪与旋转，需要调整构图的素材请先在外部修图软件中裁好工作副本，再批量导入。

## 换图与编辑后的重置规则

当输入图片或工作模式变动时，Lumina Studio 会自动清理不再匹配旧画面的临时状态：

| 执行操作 | 当前图片变化 | 工作模式 | 旧预览与下载结果 | 后续操作 |
| --- | --- | --- | --- | --- |
| 更换当前图片 | 替换为新图片 | 保持单图 | 自动清空 | 核对裁剪、色彩来源与参数后重新点击“预览” |
| 裁剪并应用更改 | 更新为选区画面 | 保持单图 | 旧预览失效 | 核对目标尺寸与比例后重新点击“预览” |
| 旋转并应用更改 | 更新为旋转后画面 | 保持单图 | 自动清空 | 确认长宽尺寸无误后重新点击“预览” |
| 添加更多图片 | 保留原图并追加新图 | 切入批量 | 单图预览清空 | 核对文件列表与统一转换参数后执行“批量生成” |
| 移除批量列表中的图片 | 移除所选文件 | 剩多张时保持批量；剩 1 张时回到单图 | 原批量打包结果过期 | 确认剩余文件无误后重新生成 |

## 常见问题 Q&A

### 为什么上传位图后没有自动弹出裁剪窗口？

请检查上传框附近的“上传后裁剪”开关是否已开启。此外，一次多选进入批量模式、或单独上传 SVG 文件时，都不会触发位图自动裁剪。已上传单张位图时，可直接点击缩略图下方的“裁切与旋转”手动打开窗口。

### 可以不裁剪画幅、只旋转图片方向吗？

可以。打开“裁切与旋转”窗口，保留默认的完整全图选区，点击旋转按钮调好方向后直接点击“应用更改”即可。

### 连续点击两次 90° 旋转能直接转成 180° 吗？

可以。在同一次打开的窗口中朝同一方向点击两次旋转按钮，再点击一次“应用更改”即可一步完成 180° 旋转。

### 误入批量模式后怎样退回单图界面？

在批量文件列表中点击多余图片右侧的 `×`，删至只剩最后一张目标图片时，界面会自动恢复为单图流程。删除前请留意文件名，确保留下的是需要处理的那一张。

### 为什么透明 PNG 裁剪后外圈少了一层柔边？

透明投影、发光与抗锯齿边缘由浅淡的半透明像素构成，裁剪框贴得过紧时会将其一并裁掉。重新上传原图，在“裁切与旋转”中把选框向实色边缘外适当留出一圈余量即可。

### 图片缩略图方向已经摆正，但导入切片器后模型朝向不对怎么办？

先确认 Lumina 中的缩略图与 2D 预览方向正确，再检查结构模式（如正打/倒打观赏面）以及切片器内的模型摆放面与热床朝向。网页端图片旋转管的是画面正方向，切片器内摆放管的是物理打印朝向，两者各司其职。

### 上传图片后迟迟不显示缩略图怎么排查？

先换一张体积较小、本地能正常打开的标准 JPG 或 PNG 测试。若小图同样无法加载缩略图，请按[打不开、一直转圈或生成失败的排查顺序](pathname:///zh/docs/knowledge/web-generation-troubleshooting/)依次检查网络连接、文件格式与服务状态。
