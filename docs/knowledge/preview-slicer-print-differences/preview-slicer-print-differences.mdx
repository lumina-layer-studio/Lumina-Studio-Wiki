# 为什么 Lumina 预览、切片器预览和打印实物不一样？

Lumina 预览、切片器预览与打印实物分别呈现了工作流中三个不同阶段的结果：

- **Lumina 预览**：按当前色彩数据来源与建模设置计算出的目标配色及几何结构；
- **切片器预览**：结合打印机型号、喷嘴、线宽与耗材映射生成的真实挤出走线路径；
- **打印实物**：由真实耗材、机器状态、首层挤压、打印板纹理与环境光线共同呈现的物理成品。

三者在屏幕与肉眼之间存在光泽和亮度差异属于正常现象，但关键轮廓、颜色分区与每层耗材映射应当逐层对应。若对 Lumina 中的“第 1 层”、预测色与逐层配色的含义尚不熟悉，建议先阅读[怎样读懂 Lumina 分层预览？](pathname:///zh/docs/knowledge/layer-preview-guide/)。

## 快速定位差异类型

| 现象 | 原因判断 | 处理建议 |
| --- | --- | --- |
| 切片器色块颜色与实物不像，但对象和槽位映射均正确 | 仅切片器标识显示色不同 | 不影响实际出料，可继续其余检查 |
| 某个对象、色块区域或底板指向了错误的项目耗材或料槽 | 耗材映射错位 | 先修正对象与料槽映射，重新切片 |
| Lumina 与切片器均正常，但实物整体偏绿、偏灰、偏暗或偏暖 | 耗材档案、线材批次、打印状态或观察光源偏差 | 先打小样逐项排查材料与打印参数 |
| 小字、细线或微小色块在切片后消失 | 成品尺寸过小，或超出当前喷嘴与线宽下限 | 放大成品尺寸、调整原图或换用细喷嘴后再切片 |
| Lumina 预览本身全黑、偏绿、出现破洞或边界错乱 | 色彩来源、输入原图或建模模式异常 | 先在 Lumina 中修复预览，暂不导出正式 3MF |

表格前两项最容易混淆：切片器里的纯色方块只是界面识别标识，色块色差本身不会改变吐丝；只有当模型对象绑定的项目耗材编号有误，或项目耗材映射到了错误的 AMS 槽位时，才会真正打错耗材。

## 七步排查顺序

  src={require('./assets/difference-troubleshooting-flow.webp').default}
  alt="从版本与档案到光线的七步固定排查顺序"
/>

建议按以下顺序从上游到下游逐一核对，避免在上游映射尚未确认时盲目修改温度、流量或原图。

### 第一步：核对色彩数据来源与档案

确认“色彩数据来源”选用的是耗材档案还是经典 LUT，并检查：

- 所选耗材档案或 LUT 文件完整可读；
- 材质、品牌、系列及颜色与即将上机的真实线材一致；
- 切换色彩来源后已重新点击生成预览；
- 使用经典 LUT 时，显色层数、层高与耗材排列顺序与当前项目参数一致。

若 Lumina 预览在这一步就已偏色或报错，请先核查色彩来源设置，详见[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)。

### 第二步：核对四层耗材映射关系

将以下四层对应关系逐项对齐：

1. Lumina 中选定的耗材档案或调色板；
2. 导出 3MF 内的项目耗材列表；
3. 切片器中每个对象或零件绑定的项目耗材编号；
4. AMS、多色系统或外置料架上装载的真实线盘。

点击切片器的“同步料仓”只能读取硬件槽位信息，仍需人工确认每个模型区域对应的项目耗材已指向正确的物理线盘。完整操作见[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

### 第三步：核对喷嘴、线宽、层高与成品尺寸

“准备”界面可见的细微三维几何，若窄于单条挤出线宽，切片时会被自动过滤。请检查：

- 切片器选定的机型与喷嘴直径是否与实际硬件一致；
- 当前线宽是否足以容纳画面中的小字、细线与独立小色块；
- 显色层层高是否与 Lumina 校准档案及项目设置匹配；
- 成品尺寸是否缩得过小，导致细节低于当前喷嘴的采样下限。

层高决定 Z 方向叠色厚度，喷嘴与线宽决定 XY 平面细节上限；喷嘴与尺寸的换算方法见[0.2 和 0.4 喷嘴相当于多少分辨率？](pathname:///zh/docs/knowledge/nozzle-equivalent-resolution/)。

### 第四步：检查 Lumina 二维与三维预览

依次查看配色完成后的二维预览与三维结构预览，确认：

- 主体轮廓与透明镂空区域准确；
- 关键色块未被意外合并或替换；
- 底板、外轮廓描边与挂环等附加结构符合设置；
- 眼睛、文字、细线等重点细节完整保留；
- 画面无整片发黑、异常色偏、破洞或边缘错位。

若 Lumina 预览阶段已存在结构或配色异常，请先返回原图、建模模式或配方设置修正，再导出 3MF。

### 第五步：执行真实切片并逐层检查显色面

在 Bambu Studio、OrcaSlicer 或常用切片器中点击**切片**并切换到“预览”视图（“准备”视图仅展示几何外形，不含真实走线）。

若作品显色面贴合打印板朝下，请将视角翻至底面，拖动右侧层滑块从显色面往内逐层检查：

- 首层轮廓与各色块边界是否完整闭合；
- 每一层调用的项目耗材是否正确；
- 细线与微小色块是否真正生成了挤出路径；
- 底板、描边、挂环等结构是否使用了预期耗材；
- 是否存在耗材自动替换、缺层、悬空或超出热床边界的警告。

若 Lumina 预览正常而切片预览异常，重点排查 3MF 打开方式（需作为完整项目打开）、对象耗材绑定、喷嘴规格与线宽设置。

### 第六步：检查首层、流量、热床与机器状态

当 Lumina 预览与切片走线均正常，但打印实物出现细部糊连、断线、拉丝擦除或表面发花时，检查硬件与工艺状态：

- 首层间隙是否过低（挤溢串色）或过高（附着不牢被带走）；
- 打印板是否清洁无油污、表面平整且匹配当前材质；
- 喷嘴温度与流量比例是否贴合当前线材；
- 喷嘴外壁是否挂有残料、半堵或刮擦已打印走线；
- 耗材是否受潮，或同款不同批次存在明显透光差异。

建议每次只调整一个变量并先打印局部小样对比，便于准确锁定原因。

### 第七步：在稳定中性光线下比对实物

显示器依靠背光主动发光，实体打印件依靠环境光反射与层间透射显色。暖黄灯光、有色墙面反光以及手机相机的自动白平衡、HDR 和锐化算法都会显著改变照片色彩。

比对色差时，请将实物置于稳定、中性的光源下同一位置直接用肉眼观察；如需拍照记录，请关闭滤镜与自动增强并锁定白平衡。

## 五种高频现象速查

### 仅切片器显示色与实物不符

选中模型对象查看其绑定的项目耗材编号，确认该编号已映射到正确的物理槽位。只要对象绑定与真实槽位无误，修改切片器内的色块显示颜色仅用于方便屏幕辨认，不会改变实际打印所用的线盘。

### 对象或槽位映射错误

先取消打印，依次修正“模型对象 → 项目耗材”与“项目耗材 → 物理料槽”两级映射，重新切片并逐层复核（仅修改对象名称不会改变实际挤出耗材）。

### 实物整体色偏

确认档案与上机线材完全对应后，依次排查线材批次、干燥度、打印温度、层高、首层压实度及观察光源。若同一卷线材在稳定工况下持续偏色，建议重新打印梯度卡为该批次建立专属耗材档案。

### 细小色块糊掉、被带走或消失

回到切片器逐层预览分情况处理：

- **切片预览中无走线**：适当放大成品尺寸、加粗原图细部，或换用 `0.2 mm` 喷嘴；
- **切片有走线但实物缺失**：清洁热床，校准首层高度与流量，检查喷嘴残料拖拽及耗材干燥度；
- **走线被并入相邻底色**：检查对象耗材绑定与槽位映射。

### Lumina 预览全黑、偏绿或边界破损

1. 核对色彩数据来源、耗材档案 / LUT 与底板耗材设置；
2. 切换色彩来源后重新点击生成预览；
3. 检查原图的透明通道、色彩空间与分辨率；
4. 若输入为 SVG，检查未闭合路径、填充规则、`viewBox` 与滤镜蒙版，详见[SVG 上传失败、白底、破洞和细节异常怎么排查？](pathname:///zh/docs/knowledge/svg-troubleshooting/)；
5. 用一张简单纯色小图或最小化 SVG 做对照测试，确认问题是否仅出现在当前源文件。

- Lumina 二维配色预览与三维结构预览截图；

- 在中性光线下拍摄的实物照片。

## 常见问题

### Lumina 预览和切片器预览颜色不一样，可以直接打印吗？

先区分是“界面显示色差异”还是“实际映射 / 走线差异”。若颜色分区、对象绑定、槽位映射或逐层路径不一致，请先修正并重新切片；若仅是切片器色块示意色不够贴近线材外观，且所有槽位映射和逐层走线均准确无误，即可正常打印。

### Lumina 预览里有细线，切片后消失了，需要去调颜色吗？

无需调色。细线在切片阶段消失通常是因为线条宽度低于当前喷嘴的挤出线宽下限。请先在切片预览中确认路径状态，通过放大成品尺寸、加粗原图线条或换用更细喷嘴即可解决。

### 两个软件预览都正常，为什么打印出来的实物偏暗？

显示器自发光比反射环境光的塑料件更明亮，轻微亮度落差属于物理特性。若实物出现明显且持续的整体发暗，请检查深色底层耗材是否映射错位、显色层层高与首层是否过薄，以及线材批次透光率是否偏高。

### 肉眼看实物很正常，但手机拍出来偏绿，需要重做耗材档案吗？

不需要。这通常是手机自动白平衡或室内频闪光源造成的拍摄色偏。关闭相机美颜与色彩增强，在自然光或标准中性光下锁定白平衡并放入白色参照物重拍即可验证。

### 小线条打印时“被擦掉”，一定是回抽参数不对吗？

先看切片逐层预览是否生成了该条路径：若本来就没有路径，属于成品尺寸或线宽限制；若切片路径完整但打印后脱落，优先清洁热床并检查首层压实度、流量与喷嘴外壁残料拖拽，最后再微调回抽与擦嘴参数。
