# 颜色工作站入门：选择、替换、撤销和自由色

完成图片预览后，可以在颜色工作站中精细调整局部或全局配色：先框定需要修改的区域，再替换为当前耗材可组合出的目标颜色，或将特定色块提取为自由色对象。

基本操作流程如下：

1. 点击“预览”生成基础分色与调色板；
2. 选择合适的选区工具；
3. 在预览图或调色板中选中源色或局部色块；
4. 从当前经典 LUT 或耗材档案的可达色候选中选定目标色；
5. 核对“源色 → 目标色”并点击“确认替换”；
6. 检查更新后的 2D、3D 与分层预览，重新点击“生成”导出新 3MF。

面板中的“撤销”“清空替换”和“清除自由色”分别对应单步回退、重置全部换色与移除自由色标记三种独立操作。

## 启用前提与会话规则

颜色工作站基于当前图片的分色结果与调色板运行，成功生成首次预览后即可打开使用。

如果中途更换了原图、切换了耗材档案或经典 LUT，或修改了显色层数与层高，基础分色结果会随之改变，原有的选区和高亮需按新预览重新点选。完成任何颜色调整后，请重新生成 3MF，以确保导出的模型包含最新配色。

### 同颜色全选

选中某一种匹配色后，整张画面里凡是使用该匹配色的区域都会一并纳入选区；也可以连续多选几种相近匹配色，统一归并为同一个目标色。

- **适合场景**：统一替换全图的某一种背景灰、合并相邻阶梯色带，或为整类颜色套用同一条自定义配方。
- **留意边界**：若人物眼睛与衣服恰好匹配到了同一种颜色，使用该工具会同时改变这两处；仅修改单处细节时请改用“点选色块”。

### 相近颜色

点击画面中的某个色块，自动一并选中色彩接近的区域。调高容差会扩大纳入的颜色范围，容差设为 `0` 时仅选中完全相同的匹配色。处理渐变附近区域时，先观察高亮边界再确认替换。

### 点选色块

在预览图上逐个点击连通色块以添加或取消选中，适合精准修改眼睛、高光、小字或局部饰品等独立细节。

### 选区画笔

按住鼠标在预览图上涂抹并应用选区。画笔会完整选中笔迹触及的连通色块，支持调节画笔粗细，涂抹后可通过高亮轮廓确认实际命中范围。

### 跨工具组合选区

四种选区工具共享当前选中状态，切换工具不会清空已有选区，方便先框选大块再用点选微调。如需清空重选，点击“全不选”即可。

## 完成一次颜色替换

### 第一步：确认基础预览正常

开始局部微调前，先确认原图的主体轮廓、透明抠图与整体色调正常。若基础预览存在大面积偏色、破洞或轮廓错位，建议先调整原图、色彩来源或建模模式，再进入颜色工作站细修。

### 第二步：选定修改范围

根据目标属于“全图同色”还是“独立连通色块”选用对应工具，并通过画面上的高亮遮罩核对实际选区边界。

### 第三步：挑选并确认目标色

可选的目标色取决于当前使用的色彩数据来源：

- **经典 LUT**：直接从该 LUT 已标定的色板中挑选目标颜色；
- **耗材档案**：输入期望接近的颜色值后，软件会基于当前已选耗材实时计算可拼配出的相近候选色，供你从中点选最合适的一项。

点选目标色后，面板会展示待生效的“源色 → 目标色”对照条。核对两端色块与选区无误后点击“确认替换”；若想放弃本次选择，点击旁边的“取消”即可，已生效的历史修改不会受影响。

### 第四步：核对更新后的预览

确认替换后，依次检查以下细节：

- **2D 预览**：仅目标区域变色，其他同色小细节未被连带改动；
- **3D 预览**：模型表面已同步刷新为新配色（3D 网格重算稍慢于 2D 时，等待加载完成即可）；
- **悬停 / 分层预览**：逐层耗材叠放顺序符合新配方；
- **重新导出 3MF**：在切片软件中核对对象与实体线盘映射正常。

## 撤销、清空替换与取消的区别

- **撤销 / 重做**：“撤销”回退上一步选区或换色操作，“重做”恢复刚撤回的修改。操作后可结合预览画面与高亮状态确认当前步骤。
- **清空替换**：移除当前会话中的所有全局换色与局部区域替换，直接按初始自动匹配结果重建预览，适合多轮尝试后想回到起点重新微调时使用。重置后如需下载基础版模型，请重新点击生成 3MF。
- **取消（待确认项）**：仅放弃当前尚未点击“确认替换”的那一条预览配对，不影响此前已确认的换色记录。

## 自由色的作用与用法

点击“标记为自由色”会将当前选中的**匹配色**登记为自由色，并在下次生成 3MF 时把画面中所有使用该匹配色的区域提取为独立的 `Free_颜色值` 对象：

- **主要用途**：将该颜色区域在切片器中单独选中，直接指定给手头某一卷专色、丝绸或夜光等实体线材；或在自动叠色不便表现时改由切片器手动指定耗材槽位。
- **作用范围**：按匹配色值提取对象（画面中凡属同一匹配色的色块都会归入同一个 `Free_` 对象），且实际可用颜色种类仍取决于打印机的多色料槽容量与实体线盘。

已标记的自由色会在色板上显示专属标识。点击“清除自由色”只会移除自由色对象标记，不会清空已完成的颜色替换或自定义配方。导出 3MF 后，请在切片器对象列表中找到对应的 `Free_颜色值` 对象，手动为其绑定目标耗材与物理料槽。

## 渐变分组（海带纹）处理

在耗材档案模式下，平滑渐变有时会被匹配成几条交替切换的相邻材料色带。当系统识别到这类区域时，会在面板中列出“渐变分组（海带纹）”供你按需处理：

- 先点击查看分组或子区域的高亮位置；
- 若属于影响观感的杂乱色带，可将单个局部区域或整组统一合并为代表色；
- 若该分组恰好是你想保留的阴影层次或肤色柔和过渡，保持原样即可（自动合并默认关闭）。

## 常见问题 Q&A

### 为什么点击调色板色块没有反应？

请先确认已完成首次“预览”，并留意当前激活的选区工具：“点选色块”和“选区画笔”直接在预览画布上点选或涂抹；想从调色板整组选色时，请切换至“同颜色全选”。

### 为什么只想改眼睛颜色，衣服也跟着变色了？

当眼睛和衣服使用了同一个匹配色时，“同颜色全选”会一并选中两处。点击“撤销”退回上一步，改用“点选色块”单独点中眼睛区域并确认高亮范围后再替换即可。

### 为什么输入了目标 RGB，给出的候选色仍有细微差别？

耗材档案模式会严格从当前已选实体耗材、层数与层高所能拼出的真实配方中筛选最接近的可达色。挑选观感最接近的候选色后，建议打印小样确认实物效果。

### 完成替换后需要重新点击预览和生成吗？

点击“确认替换”会自动刷新当前的 2D、3D 与分层预览；确认画面满意后，需要重新点击“生成”以导出更新后的 3MF 文件。

### 自由色和颜色替换有什么区别？

“颜色替换”改变的是显色配方，让选中区域改用另一套可达叠色方案；“自由色”改变的是 3MF 对象拆分结构，把该匹配色单独导出为一个几何对象，留待切片器里手动绑定实体线材。

### 怎样保存当前的换色方案以便下次继续编辑？

可通过[分享卡与 JSON：导出、导入和继续编辑](pathname:///zh/docs/knowledge/share-card-json/)导出配方文件，与原图、所用耗材档案 / LUT 及最终 3MF 一并归档保存，方便日后载入继续微调。
