# 管理耗材档案：编辑、复验、历史、导入和导出

完成梯度卡提取后，Lumina Studio 会将结果保存为一份可复用的**耗材档案**。档案中除了显示名称与识别色块外，还完整记录了该卷耗材在指定层高下的光学拟合参数、历次验证记录以及供图像转换调用的测量数据。

本篇介绍耗材库中的日常管理操作：查找与核对档案身份、修改显示信息、追加复验、回看历史记录，以及使用 ZIP 压缩包完成备份和跨设备迁移。

## 梯度卡 ZIP 和耗材档案 ZIP 有什么区别

| 压缩包类型 | 获取方式 | 导入位置与用途 |
| --- | --- | --- |
| 梯度卡配置 ZIP | 在“梯度卡生成”页面生成并下载 | 在“梯度卡提取”中导入，配合同批次打印的白底卡、黑底卡实拍图提取新档案 |
| 耗材档案 ZIP | 从“耗材库”导出备份，或由他人分享 | 在“耗材库”中点击“导入耗材 ZIP”，直接安装已制作完成的耗材档案 |

两种文件虽同为 `.zip` 扩展名，但内部数据结构与导入入口各不相同，不可交叉混用。如需从零制作新档案，请参阅[生成并打印梯度卡](../../tutorials/gradient-card-generate-print/gradient-card-generate-print.mdx)与[拍摄并提取梯度卡](../../tutorials/gradient-card-extract-profile/gradient-card-extract-profile.mdx)。

:::info[阅读前提]
本篇面向已在“耗材管理 → 耗材库”中拥有至少一份耗材档案的用户。首次制作档案请先阅读[生成并打印梯度卡](pathname:///zh/docs/tutorials/gradient-card-generate-print/)和[拍摄并提取梯度卡](pathname:///zh/docs/tutorials/gradient-card-extract-profile/)。
:::

## 第一步：进入耗材库定位目标档案

1. 打开 Lumina Studio，点击顶部导航栏的“耗材管理”；
2. 在二级标签页中切换到“耗材库”；
3. 点击展开对应的品牌分组，找到需要管理的耗材卡片。

耗材库默认按品牌折叠，品牌名称右侧的数字代表该分组下的档案总数。工具栏左侧实时统计“已选择 / 总数”，右侧依次提供全选、导入、导出与刷新按钮。

<img
  src={require('./assets/01-library-overview.webp').default}
  alt="Lumina Studio 耗材库顶部显示选择数量，并提供全选、导入 ZIP、导出和刷新按钮"
/>

刚保存或导入新档案后，若列表暂未显示，先点击右上角的“刷新耗材库”再展开对应品牌即可，避免重复导入同一份 ZIP。

## 第二步：读懂耗材卡片上的关键指标

每张卡片对应一份独立耗材档案。在编辑、调用或删除前，建议先核对卡片上的核心信息：

<img
  src={require('./assets/02-material-card.webp').default}
  alt="一份 Lumina Studio 耗材档案卡片显示名称、颜色、目录、拟合误差、验证次数、使用次数和层高"
/>

| 字段名称 | 含义说明 | 核对要点 |
| --- | --- | --- |
| 名称与品牌 | 用于列表分组与检索的展示标签 | 不同批次或不同用户制作的档案可能同名，需结合目录名与验证记录区分 |
| 显示颜色与 HEX 值 | 用于界面快速辨认的参考色块 | 仅作视觉标识，实际叠色预测以内部光学参数为准 |
| 目录名 | 系统区分档案身份的唯一内部标识 | 修改显示名称后目录名保持不变，不会打断已有引用 |
| 创建时间 / 最近更新 | 首次建档与最后一次修改的时间戳 | 存在多份相近档案时，可用于分辨新旧版本 |
| 拟合误差 | 光学模型与实拍采样数据的平均偏差 | 在同一套布光与拍摄条件下数值越低拟合越紧密；跨设备、跨光线不宜直接横向对比 |
| 验证次数 | 该档案累计合并的独立验证轮数 | 结合每次拍摄质量综合评估稳定性 |
| 使用次数 | 在图像转换任务中被选用的累计次数 | 统计日常使用频率 |
| 层高 | 校准提取该档案时所用的打印层高 | 转换作品时应匹配对应层高（如 `0.08 mm` 档案对应 `0.08 mm` 显色层高） |

若界面提示存在同名同品牌的重复项，说明本地同时安装了多份相近档案。可展开卡片逐一比对目录名、更新时间、验证次数与测试层高后再做取舍。

## 第三步：修改名称、品牌与显示色块

点击卡片底部的“编辑信息”，可随时调整以下展示字段：

- 耗材名称；
- 所属品牌；
- 用于界面辨识的显示颜色（或十六进制色号）。

<img
  src={require('./assets/03-edit-dialog.webp').default}
  alt="编辑耗材信息窗口可以修改名称、品牌和显示颜色，同时显示不可直接修改的目录名"
/>

保存修改后，底层目录身份与过往验证历史均原样保留，非常适合修正拼写、统一品牌归类或调整色块辨识度。

:::warning[仅改显示信息]
“编辑信息”仅更新卡片外观与文字标签，不会重新解析梯度卡照片或重算 `E`、`K`、`C0` 等物理拟合参数。若更换了线材批次或需要修正成色偏差，请使用“再次验证”。
:::

## 第四步：回看历次验证历史

点击卡片上的“展开验证历史”，即可按时间倒序查看该档案的历次校准详情（最新一轮排在最上方）：

<img
  src={require('./assets/04-verification-history.webp').default}
  alt="验证历史窗口按时间显示多次耗材验证的颜色、拟合误差、RMSE、方向和诊断参数"
/>

日常核查可重点关注这五项指标：

1. **验证时间**：确认对应哪一卷线材批次与哪一次拍摄；
2. **估算颜色**：观察多轮采样的色相与明度是否稳定一致；
3. **拟合误差**：在相同布光与相机参数下对比各轮拟合表现；
4. **线性 RMSE**：辅助评估模型对全梯度采样点的整体拟合优度；
5. **识别方向**：确认白底卡与黑底卡照片朝向识别正常。

窗口底部列出的 `E`、`K`、白底 `C0` 与黑底 `C0` 为底层光学诊断参数，日常使用无需手动记录。若两轮验证数值相差悬殊，请优先排查布光均匀度、相机固定曝光、白平衡、四角框选位置以及色卡是否出自同一卷线盘。

## 第五步：对已有档案执行“再次验证”

遇到以下场景时，可在目标卡片上点击“再次验证”：

- 改善了灯箱布光或固定了相机参数，希望补拍一组更干净的样本；
- 购入了同款同色的新批次耗材，希望在同一档案下留存对比记录；
- 上一轮实拍图存在局部反光、色温漂移或角点偏移；
- 希望增加一轮独立采样以提高参数稳健性。

跳转至梯度卡提取页面后，顶部横幅会提示“当前正在进行耗材复验”，并标明目标耗材名称与已有验证次数。核对目标无误后，导入与该组实体色卡配套的梯度卡配置 ZIP，并上传新拍摄的白底与黑底照片。

<img
  src={require('./assets/05-reverify-target.webp').default}
  alt="再次验证时梯度卡提取页面显示目标耗材、现有验证次数和合并结果入口"
/>

提取完成后点击“合并结果”，新数据将写入当前档案；如需中途退出，点击“取消复验”即可。

:::tip[保持数据一致]
复验时导入的配置 ZIP、白底照片与黑底照片，必须来自同一卷耗材、同一次梯度卡生成任务和相同的打印层高，切勿将不同批次或不同层高的数据混入同一次复验。
:::

## 第六步：导出耗材 ZIP 备份或迁移

1. 勾选需要备份的一张或多张耗材卡片（备份整库可点击顶部“全选耗材”）；
2. 点击“导出所选耗材”；
3. 浏览器会自动下载打包好的 Lumina 耗材档案 ZIP；
4. 为 ZIP 文件备注日期与品牌范围，妥善存放在本地备份目录或网盘中。

无论勾选单份还是多份档案，系统都会统一打包为一个标准耗材档案 ZIP，专用于档案备份、多台电脑同步或团队共享（不可作为 3MF 模型直接放入切片器）。

<img
  src={require('./assets/06-import-export.webp').default}
  alt="耗材库选择一份档案后成功导出 ZIP，顶部同时提供导入耗材 ZIP 的入口"
/>

建议在执行以下操作前先导出一份离线备份：

- 清理或删除本地耗材档案；
- 批量整理品牌分组与命名；
- 更换电脑、重装系统或迁移工作目录；
- 在获得授权的前提下与同伴共享自测耗材档案。

## 第七步：导入外部耗材档案 ZIP

1. 在耗材库顶部点击“导入耗材 ZIP”；
2. 选择一个或多个由 Lumina 导出的 `.zip` 耗材归档包；
3. 等待导入完成并自动刷新列表；
4. 展开对应品牌，核对新档案的名称、目录名、验证次数与层高；
5. 若出现同名提示，展开卡片比对目录名与更新时间以区分原档与新导入档。

为保护本地已有数据，导入器不会强行覆盖现有档案：完全一致的修订包会自动跳过重复安装，而目录重名但内容不同的档案则会以带时间戳后缀的新目录独立并存。

导入时请直接使用原始导出的完整 `.zip` 文件，切勿手动解压改名内部 JSON 后重新打包，也不要将普通图片、3MF 模型或梯度卡配置包误投到此入口。

## 第八步：安全删除不再需要的档案

“删除耗材”会将所选档案从本地耗材库中永久移除，且无法直接在界面内撤销。执行删除前请按顺序确认：

1. 核对卡片目录名与更新时间，防止误删同名的有效档案；
2. 先执行一次“导出所选耗材”，确认备份 ZIP 已妥善落盘；
3. 确认当前没有正在使用该档案的转换任务；
4. 核对弹窗中的档案名称与目录标识后再点击确认。

若只是想改名、归整品牌或调亮识别色块，直接使用“编辑信息”即可；若只是想更新实测数据，使用“再次验证”即可，均无需删档重建。

## 常见问题 Q&A

### 修改了卡片的“显示颜色”，会影响打印出来的颜色吗？

不会。显示颜色仅用于耗材库内的色块识别与列表展示，图像转换时的叠色计算完全依据档案内部的光学拟合数据。如需更新测量结果，请重新拍摄梯度卡并执行“再次验证”。

### 拟合误差数字越小，代表打印成色一定越准吗？

拟合误差适合在同一套均匀布光与标准拍摄流程下辅助判断拟合优度。如果拍摄时存在局部炫光、曝光失准或色温偏离，单纯追求更小的误差数字并不能提升实物还原度。建议结合估算颜色、历史一致性与实物试打小样综合验证。

### 为什么导入 ZIP 后出现了两张一模一样名字的卡片？

耗材名称与品牌属于可重复的显示标签。当导入包与本地已有目录发生命名冲突且内容不同时，系统会自动新建带后缀的独立目录妥善保留两份数据。比对目录名、验证次数和更新时间后，导出备份并删掉多余的一份即可。

### 可以把自己导出的耗材 ZIP 分享给朋友用吗？

可以正常导入。分享前请确认自己对包内的实测数据与相关内容拥有分享权限；接收方导入后，也需核对手头线材的品牌系列、批次与层高是否一致，并先打印小样确认匹配度。

### 一个耗材 ZIP 里最多能打包几份档案？

数量不限，导出时勾选几份就会把几份打进同一个 ZIP；导入时也支持一次多选多个 ZIP 批量导入。档案较多时，按品牌或材质分包导出并在文件名上标注日期会更便于日后检索。

### “耗材库”和“云端耗材”有什么区别？

“耗材库”管理当前已安装到本地、可直接供图像转换调用的档案；“云端耗材”则用于在线浏览和下载官方或社区发布的档案包。编辑或删除带有“官方”标识的档案前，同样建议先导出备份，留意后续云端同步或版本更新的影响。

### 在多份档案之间挑选时要注意什么？

请结合材质、品牌系列、色号、批次与目标层高综合挑选，详细判断方法见[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)。

### 建好耗材档案后，怎样提前测试不同颜色的叠层效果？

可前往“耗材管理 → 配方查询”，按从观赏面到底板的顺序自由排列档案、实时查看预测颜色，并将多组候选配方一键导出为验证色块 3MF 试打确认。操作步骤详见[组合耗材层、预测叠色并生成验证色块](pathname:///zh/docs/knowledge/material-recipe-query/)。
