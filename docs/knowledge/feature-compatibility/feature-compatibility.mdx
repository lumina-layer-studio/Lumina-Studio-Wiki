# 哪些功能可以一起用？

在 Lumina Studio 中，**色彩微调与外观附件大多可以自由叠加**，而**改变几何结构或导出流程的专用模式则存在明确的互斥规则**：

- **可自由叠加的常规项**：颜色工作站、自定义配方、外轮廓、透明镀层与分离底板，均可配合常规单面或双面作品使用。
- **结构与流程专用项**：浮雕、冰箱贴磁铁槽、拼图、大画幅与批量模式会改变底层几何或分包逻辑，需按各自支持范围开启。
- **磁铁槽互斥项**：冰箱贴磁铁槽仅支持单面结构，且不可与拼图、大画幅或挂件环同时开启。
- **拼图互斥项**：拼图不可与批量模式、大画幅、磁铁槽或挂件环同时开启。
- **浮雕与掐丝珐琅**：原生矢量模式不支持浮雕；掐丝珐琅入口在当前版本已隐藏。
- **切片核对**：每叠加一项结构或附件功能后，建议重新生成 3MF 并在切片器中逐层确认刀路。

## 按功能类型理解组合逻辑

### 1. 色彩与叠色配方

颜色工作站中的全局换色、局部区域替换与自定义配方，只调整显色层如何使用已选耗材。它们可与外轮廓、透明镀层、分离底板及各类单面结构顺畅共用。每次调整配色后重新导出 3MF 即可，具体用法见[颜色工作站入门](pathname:///zh/docs/knowledge/color-workstation-basics/)。

### 2. 外观附件与对象拆分

外轮廓、透明镀层、分离底板和自由色会在保持主体结构不变的前提下，新增或拆分导出的 3MF 对象：

- **外轮廓**：沿图像有效透明边界生成外围边框（无透明通道或路径过于复杂的 SVG 可能无法生成完整轮廓）；
- **透明镀层**：在显色表面生成一层独立的保护覆盖对象，导入切片器后需将其映射到透明耗材；
- **分离底板**：将底板拆为独立对象导出，方便单独指定耗材或切片参数，底板总厚度保持不变；
- **自由色**：将指定匹配色区域提取为独立对象，便于在切片器里手动绑定专色线盘。

叠加多项附件会相应增加 3MF 内的对象数量，导入切片器后展开对象列表逐一核对材料分配即可。

### 3. 几何结构与专用导出

浮雕、挂件环、冰箱贴磁铁槽、拼图、大画幅与批量模式直接改变三维几何形态或导出包结构，彼此设有自动互斥保护；导入旧版分享配方时若包含冲突开关，系统也会自动关闭冲突项以确保配置有效。

## 五类常见作品的推荐配置

### 普通平面摆件或画片

选用“高保真 / 像素艺术 / 矢量模式”之一，先生成基础预览并用颜色工作站微调色彩；确认画面满意后，再按需逐项开启外轮廓、透明镀层或分离底板。

### 钥匙扣与随身挂件

采用单面结构并开启**挂件环**，可搭配外轮廓与透明镀层。导出切片后重点放大检查挂件环与主体边缘的咬合宽度、环孔通畅度及层间连续刀路（开启挂件环时请勿同时勾选磁铁槽或拼图）。

### 冰箱贴

切换为单面结构并开启**磁铁槽**，可搭配颜色工作站、外轮廓与透明镀层（不与挂件环、拼图或大画幅共用）。设置时需确保底板厚度充足，使磁铁槽深度不会侵入显色层，且槽底留有足够的支撑壁厚。

### 浮雕画

使用位图素材配合单面结构，先单独开启**浮雕**确认高低起伏方向符合预期，再决定是否叠加外轮廓或透明镀层。原生矢量模式不支持浮雕；批量模式仅支持基于颜色计算高度的浮雕，不支持单独上传外部高度图。

### 拼图、大画幅与批量生成

这三项属于独立的专用导出流程：

- **拼图**：关闭大画幅、批量、磁铁槽与挂件环，按拼图专用参数生成并检查咬合公差；
- **大画幅**：先在单件模式下验证好配色与层高，再按[大画幅：分块尺寸、拼接顺序和 ZIP 文件](pathname:///zh/docs/knowledge/large-format/)设置单块尺寸上限并逐块切片；
- **批量生成**：先用一张代表素材在单图模式下跑通全部参数，再导入整批图片统一导出。

## 为什么开启某项功能后，另一个开关会自动关闭？

当两个功能在几何结构上互斥时，Lumina Studio 会自动关闭冲突项以保证生成的网格合法：

- 开启**冰箱贴磁铁槽** → 自动切为单面结构，并关闭拼图、大画幅与挂件环；
- 开启**拼图** → 自动关闭大画幅、挂件环与磁铁槽；
- 开启**浮雕** → 自动切为单面结构（旧版中还会同步关闭掐丝珐琅）；
- 进入**批量模式** → 拼图入口自动禁用。

切换结构类功能后，扫一眼右侧或面板中的当前设置摘要即可确认最终生效的组合。

## 底板层高修改器的适用边界

底板层高修改器专为常规底板结构与兼容的 Bambu 系切片器设计，在以下场景中需区别对待：

- **梯度色卡**：具有固定的校准层高与打印规范，不套用常规底板层高修改器；
- **拼图等专用导出**：由专用结构自行管理切片参数，无需叠加额外高度范围；
- **双面、浮雕与磁铁槽模型**：切片后需拖动层滑块确认粗层高区间仅覆盖纯底板部分，未触及显色层或磁铁槽壁；
- **分离底板**：分离底板改变的是对象拆分，底板层高修改器改变的是 Z 轴局部层高，两者互不替代。

详细原理与核对方法见[底板、显色层和层高修改器应该怎样设置](pathname:///zh/docs/knowledge/base-color-layer-height/)。

## 叠加多项功能后的标准核对清单

1. **先看基础预览**：确认建模模式、色彩来源、目标尺寸与单双面结构无误；
2. **逐项叠加预览**：每增加一项外观或结构功能，及时对照 2D、3D 与分层预览；
3. **重新导出 3MF**：每次改动开关或配色后点击“生成”下载最新文件；
4. **按完整项目导入切片器**：展开对象列表，核对底板、显色层、自由色、镀层、外轮廓与附件对象齐全；
5. **绑定物理料槽**：将各项目耗材准确映射到 AMS 或多色系统中的实体线盘；
6. **逐层检查切片刀路**：旋转至显色面并拖动层滑块，检查每层材料、局部层高过渡与附件连接强度；
7. **关键结构先打小样**：首次尝试磁铁槽公差、细挂环、双面镀层或新耗材组合时，建议先切局部小样试打。

对象与料槽核对流程详见[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

## 常见问题 Q&A

### 外轮廓、透明镀层和挂件环可以同时开启吗？

制作单面钥匙扣或挂牌时可以同时开启这三项。导出切片后请重点确认三件事：外轮廓未遮盖主体细节、镀层对象已指定为透明耗材、挂件环与主体连接处有连续扎实的打印路径。

### 能同时加磁铁槽和挂件环做成两用款吗？

Lumina 内置开关将磁铁槽与挂件环设为互斥项。如需制作带挂环的冰箱贴，可先导出带挂件环的 3MF，再在切片软件中添加圆柱体“负零件”制作背部磁铁槽。

### 为什么切换到矢量模式后找不到浮雕选项？

浮雕依赖连续像素灰度或高度信息构建起伏曲面，原生矢量模式仅生成平层路径结构。制作浮雕作品请上传 PNG、JPG 或 WebP 位图并选用单面结构。

### 为什么大画幅模式导入 SVG 后边缘看起来像位图？

大画幅模式会优先按原生矢量路径分块；若遇到超复杂路径或不支持直接矢量裁切的 SVG 特性，会自动回退为高精度栅格分块以保证顺利生成。建议先打印单块边角样件确认边缘精度。

### 导入别人的分享配方后少了一个开关，是文件损坏了吗？

通常不是文件损坏。当旧版分享配方中同时记录了新版已设为互斥的选项时，Lumina 会自动关闭其中冲突的一项以恢复合法状态，导入后核对一次设置摘要与预览即可。

### 切片软件没有报错，是不是就能直接打印了？

切片无报错说明三维网格闭合合法，而磁铁槽剩余壁厚、挂环抗拉宽度、透明镀层材料分配以及显色面朝向仍需人工在切片“预览”视图中逐层核对确认。
