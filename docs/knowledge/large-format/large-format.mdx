# 大画幅：分块尺寸、拼接顺序和 ZIP 文件

大画幅模式会将超过单张热床打印范围的完整作品按行、列切分为多个相邻分块，为每一块独立生成 3MF 模型并统一打包为 ZIP 下载，适合壁画、门牌与大幅展示板等大型作品。

核心规则一览：

- **总尺寸与分块上限**：总宽、总高代表拼接完成后的完整成品尺寸；分块宽度、分块高度则是单个 3MF 允许占用的最大尺寸上限；
- **行列坐标命名**：文件按从上到下、从左到右编号，`R1C1` 代表左上角第一块，`R2C3` 代表第 2 行第 3 列；
- **末行与末列尺寸**：当总尺寸无法被分块上限整除时，最后一列与最后一行仅保留剩余尺寸，因此会小于设定的上限值；
- **平切边界设计**：各分块沿相邻边界直接平切，不带重叠量，也不会自动生成榫卯、定位孔或胶缝间隙；
- **逐块切片核对**：网页端的 2D 预览与分层预览用于检查整幅画面的配色与叠层，下载解压后仍需将每个 3MF 逐一导入切片器确认热床排版、耗材映射与走线路径。

下文以总尺寸 `450×300 mm`、单块上限 `180×180 mm` 的实操案例演示完整流程（最终生成 `3×2` 共 6 个 3MF 文件）。

## 适用场景与边界

适合开启大画幅模式的场景：

- 成品总尺寸超出打印机单张热床的实际可用范围；
- 所有分块共用同一套色彩来源、模型结构与显色层高；
- 打印完成后可在背板、夹具或平整工作台上对齐拼接与固定；
- 计划按行列编号逐盘切片与打印。

以下场景建议采用其他方案：

- 需要拼图卡扣连接时，请改用拼图模式，或在外部三维软件中设计定位销与搭接结构；
- 各区域需要不同的色彩来源、底板厚度或建模方式时，建议拆分为独立单图工程；
- 需要使用冰箱贴磁铁槽或批量生成功能时（大画幅与拼图、磁铁槽及批量生成互斥）。

:::info[先测普通单图]
首次测试新素材或新耗材档案时，建议先关闭大画幅，用较小幅面跑通一次单图预览、生成与切片，确认配色、层数、透明边缘与基础结构无误后再开启大画幅分块。
:::

## 第一步：填写拼接完成后的总尺寸

上传图片并选定色彩来源后，先输入作品拼接完成后的目标总宽度或总高度（开启长宽比锁定时，修改一边会自动按原图比例计算另一边）。

本例参数如下：

- 总宽度：`450 mm`
- 总高度：`300 mm`
- 成品长宽比：`3:2`

若原图构图比例或朝向需要调整，请先通过裁剪或旋转处理好素材，具体步骤见[上传、替换、裁剪和旋转图片](pathname:///zh/docs/knowledge/image-upload-crop-rotate/)。

## 第二步：开启大画幅并设定分块上限

<img
  src={require('./assets/01-large-format-settings.webp').default}
  alt="Lumina Studio 大画幅设置中的总尺寸、大画幅开关、分块宽度、分块高度和 3×2 计算结果"
/>

开启“大画幅模式”开关，填入**分块宽度**与**分块高度**上限。软件会自动计算所需的列数、行数及末列末行余量：

- 总尺寸：`450×300 mm`
- 分块上限：`180×180 mm`
- 列数：`向上取整(450 ÷ 180) = 3`
- 行数：`向上取整(300 ÷ 180) = 2`
- 分块总数：`3 × 2 = 6`

界面提示 `3×2 = 6 (90×120mm)`，其中括号内的 `90×120mm` 表示最后一列的剩余宽度（`450 - 180 - 180 = 90 mm`）与最后一行的剩余高度（`300 - 180 = 120 mm`）。六个分块的实际物理尺寸分布如下：

| 行列坐标 | 实际物理尺寸 |
| --- | --- |
| R1C1、R1C2 | 180×180 mm |
| R1C3 | 90×180 mm |
| R2C1、R2C2 | 180×120 mm |
| R2C3 | 90×120 mm |

### 如何确定合理的分块上限？

分块上限应按切片器中的**实际可用打印面积**填写，在热床标称尺寸基础上预留出以下余量：

- 裙边（Skirt）、Brim、喷嘴擦拭线与热床安全边距；
- 打印板定位卡扣、切刀避让区或机型配置中的禁打区域（Excluded Area）；
- 外轮廓边框或切片辅助结构占用的额外宽度。

例如标称 `180×180 mm` 的机型，若开启 Brim 或存在角落避让区，可将分块上限设为 `170×170 mm` 等已在切片器中验证稳妥的尺寸。

## 第三步：读懂行列坐标与拼接顺序

<img
  src={require('./assets/02-tile-map.webp').default}
  alt="450×300 毫米作品被分成 3 列 2 行，并标注 R1C1 到 R2C3 拼接坐标的示意图"
/>

导出的文件名通过 `R` 与 `C` 标明每块在整幅作品中的位置：

- `R`（Row，行）：从上往下递增；
- `C`（Column，列）：从左往右递增；
- `R1C1` 为整幅作品左上角，`R1C3` 为第一行最右侧；
- `R2C1` 为第二行最左侧，`R2C3` 为整幅作品右下角。

从下载、切片到下机收纳，建议全程保留原始坐标文件名；打印取件后可立即在模型背面用美纹纸或记号笔标明 `R1C1` 等编号，方便后续快速拼装。

:::warning[平切无重叠]
大画幅模式沿分块交界线直接垂直切开，不包含搭接边、榫卯卡扣、定位销孔或胶缝补偿余量。如需机械定位结构，请在源图设计或外部三维建模工具中预先留好。
:::

## 第四步：预览整幅画面

<img
  src={require('./assets/03-preview-whole-image.webp').default}
  alt="Lumina Studio 大画幅任务的整图 2D 预览和分层缩略图"
/>

点击“预览”，在导出前集中检查整幅作品：

- 画面朝向、长宽比例与有效外轮廓是否准确；
- 所选色彩来源与计划装机的耗材是否匹配；
- 2D 预览是否存在局部偏色、断边或透明抠图残留；
- 分层缩略图中的显色层数与叠色顺序是否符合预期；
- 外轮廓、底板等结构设置是否正常生效。

若有配色或边缘问题，在此阶段先行调好再开始分块生成。关于三个阶段预览的差异排查，可参阅[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)。

## 第五步：生成并下载分块 ZIP

确认预览无误后点击生成，耐心等待全部区块计算打包完成（生成期间无需重复点击按钮或刷新页面）。

<img
  src={require('./assets/04-download-zip.webp').default}
  alt="Lumina Studio 大画幅生成完成后的分层预览和下载 ZIP 按钮"
/>

本例完成后界面显示 `Generated 6/6 tiles (3×2)`，下载得到的 ZIP 约 16.9 MB，解压后包含以下 6 个文件：

```text
large-format-demo_R1C1.3mf
large-format-demo_R1C2.3mf
large-format-demo_R1C3.3mf
large-format-demo_R2C1.3mf
large-format-demo_R2C2.3mf
large-format-demo_R2C3.3mf
```

:::warning[核对分块数量]
当个别分块因复杂几何生成失败时，界面仍允许先行下载已成功的分块并标出缺失编号。解压后请核对文件总数与 `R1C1` 至末行末列的连续坐标，补齐缺失分块后再安排整套打印。
:::

下载完成后建议立即解压并完成四项检查：

1. 3MF 文件数量与界面提示的总块数一致；
2. 行列编号从 `R1C1` 连续覆盖至最后一块，无跳号缺漏；
3. 每个文件大小正常，均可顺利解压打开；
4. 已将 ZIP 与解压后的 3MF 保存到本地项目文件夹（网页端临时下载链接在刷新页面或发起新任务后会失效）。

## 第六步：逐块导入切片器核对

按坐标顺序将每个 3MF 导入切片器，逐盘核对以下项目：

- 模型的毫米长宽与前文分块尺寸表一致；
- 模型完整落在热床可打印范围内，无越界报警；
- 观赏面朝向、底板位置与旋转角度保持统一；
- 机型配置、喷嘴口径、层高及实体料槽映射准确无误；
- 逐层预览中各色挤出路径连续完整，接缝边缘无缺口或悬空细丝；
- 检查切片器是否自动添加了 Brim 或裙边，避免边缘加宽影响后续严密拼接。

同一幅作品的所有分块建议固定使用同一台机器配置、同一喷嘴、同一批次耗材与相同的打印板表面及摆放角度，以尽量减少不同盘之间的光泽差与热收缩误差。关于对象与料槽的对应方法，请参阅[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

## 第七步：先干拼对齐，再固定安装

全部打印完成后，建议先在桌面上干拼确认无误，再做粘接或上墙固定：

1. 在平整台面或背板上从左上角 `R1C1` 开始向右依次排出第一行；
2. 接着排布第二行及后续各行，核对跨块图案线条自然衔接；
3. 检查各块朝向、底边平整度与拼缝间隙（如有轻微首层象脚毛刺，可先用修边刀轻刮平整）；
4. 根据耗材材质、作品重量与展示环境，选用合适的背板、定位夹具、结构胶带、胶黏剂或机械固定件；
5. 正式粘接固定时以一个直角边为基准逐行推进，避免定位误差向四周发散累积。

大型上墙或户外长期展示的作品，正式安装前建议先用同材质边角料测试胶黏剂强度与耐候安全性。

## 功能兼容与 SVG 分块提示

- 大画幅属于独立导出流程，不可与拼图、冰箱贴磁铁槽或批量生成同时开启；
- 挂件孔环等依赖整体轮廓定位的附件，不建议在分块后再单独盲加；
- 当复杂 SVG 含有暂不支持直接矢量切分的特性时，系统会自动回退为栅格分块并在界面提示；回退后建议放大检查曲线、细线与小字边缘清晰度；
- 修改总尺寸、分块上限、色彩来源或结构参数后，需重新点击生成以获取更新后的 ZIP 包。

完整功能互斥表请参阅[哪些功能可以一起用？](pathname:///zh/docs/knowledge/feature-compatibility/)；若 SVG 出现白底、破洞或细节丢失，可按[SVG 上传失败、白底、破洞和细节异常怎么排查？](pathname:///zh/docs/knowledge/svg-troubleshooting/)逐步处理。

## 常见问题 Q&A

### 为什么分块上限填了 180×180 mm，最后一块却只有 90×120 mm？

`180×180 mm` 是单块的最大尺寸上限。当总尺寸无法被上限整除时，末列与末行只生成剩余部分：本例总宽 `450 mm` 扣除前两列各 `180 mm` 后末列宽 `90 mm`；总高 `300 mm` 扣除第一行 `180 mm` 后末行高 `120 mm`。

### 能让所有分块的尺寸完全一致吗？

可以。只需将成品总宽与总高设为分块上限的整数倍（或在原图四周预先留白补齐比例），每一块切出来就会完全等大。调整时请注意保持原图纵横比，避免画面拉伸变形。

### 软件会在拼缝处自动预留重叠边或卡扣吗？

不会。大画幅输出的是相邻无重叠的平切分块。如需搭接边、定位孔或榫卯结构，请在前期图形设计或三维建模软件中预先制作，并将附加结构一并计入热床可用尺寸。

### 网页整图预览很正常，为什么导入切片器后提示某一块超出打印范围？

网页端的 2D 预览展示的是拼接后的整幅画面，不包含具体机型的热床禁打区、擦拭线或 Brim 宽度。可在切片器中关闭不必要的 Brim、调整模型位置，或返回 Lumina 将分块上限调小几毫米后重新生成。

### 能把六个 3MF 同时摆进同一盘打印吗？

若单张热床本身就放得下整幅作品，直接关闭大画幅导出单个完整 3MF 即可，还能省去后期拼接。大画幅专为超出单盘面积的作品设计；对于较窄的末列或末行小分块，只要不越界、不重叠，也可以在切片器中视剩余空间合理拼盘。

### 解压后发现其中某一个 3MF 打不开，需要重改整套参数吗？

先保留已正常解压的其余分块，用相同参数重新生成一次对比。若固定某一个坐标反复报错，重点检查原图对应区域是否有极细碎的噪点或特殊 SVG 路径。若网页持续转圈或生成中断，请按[打不开、一直转圈或生成失败，应该先查什么？](pathname:///zh/docs/knowledge/web-generation-troubleshooting/)排查。

### 拼接后为什么拼缝依然明显？

数字模型严丝合缝，但实体打印会受到热胀冷缩、首层象脚（Elephant Foot）外扩、打印板局部纹理差异与光线折射影响。保持各盘切片参数与摆放方向一致、适度开启切片器的象脚补偿、打印后轻修边缘毛刺并借助平整背板定位，能显著改善拼缝观感。
