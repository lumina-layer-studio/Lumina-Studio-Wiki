# 位图与矢量图有什么区别？

数字图像主要分为两类记录方式：

- **位图（光栅图）**：由固定数量的像素网格组成，每个像素单独记录自己的颜色值。
- **矢量图**：记录点、直线、贝塞尔曲线、轮廓与填充规则，打开或缩放时按数学公式实时绘制图形。

两种格式各有所长：照片、柔和渐变与数字绘画适合用位图表现细腻层次；Logo、图标、文字轮廓、线稿与平涂色块图形则适合用矢量路径保持利落边缘。根据素材本身的特点来选择格式，效果最稳定。

:::info[直观理解]
位图就像一张填满色块的方格纸；矢量图则像一份写明“起点坐标、曲线弧度与填充颜色”的制图说明。
:::

- **左侧（位图）**：像素总数固定，超出原始分辨率放大后会出现锯齿状像素格。
- **右侧（矢量图）**：软件根据路径方程按新尺寸重新计算边缘，曲线和斜线依然平滑。

显示器最终仍通过物理像素呈现画面，矢量图的优势在于源文件保存的是几何描述，放大时可重新计算清晰边界，而不是单纯拉伸原有像素。

## 位图与矢量图速查表

| 对比维度 | 位图 | 矢量图 |
| --- | --- | --- |
| 记录的数据 | 固定网格中的像素颜色 | 点、线、曲线、闭合路径与填充 |
| 放大后的表现 | 超过原始分辨率后出现像素格或模糊 | 原生路径按目标尺寸平滑重绘 |
| 擅长表现的素材 | 照片、复杂光影、自然纹理、柔和渐变、数字绘画、像素画 | Logo、图标、转曲文字、线稿、平涂色块图形 |
| 常见文件扩展名 | JPG/JPEG、PNG、WebP、HEIC/HEIF、BMP、TIFF | SVG、AI、EPS |
| 常用编辑方式 | 画笔涂抹、选区裁切、像素级调色与修图 | 调整锚点、路径走向、描边宽度与填充色 |
| Lumina 推荐用法 | 直接导入原图，按画面特征选择高保真或像素模式 | 优先保留设计软件导出的原生 SVG 路径导入 |

文件扩展名只是外层格式标识。例如 PDF 与 SVG 标准都支持在同一个文件内混合存放矢量路径与嵌入位图，因此 `.svg` 文件里也可能包含未经矢量化处理的位图图层。

## 不同素材该选哪一种？

  src={require('./assets/use-case-map.png').default}

/>

### 适合保留位图的素材

- **摄影照片**：人物五官、毛发、天空、光影与材质肌理包含丰富的连续色彩过渡；
- **厚涂与复杂插画**：笔刷肌理、柔光渐变与半透明叠色难以用少量闭合路径还原；
- **数字绘画**：绝大多数板绘作品直接在像素画布上创作完成；
- **像素画**：清晰的方格边界本身就是像素艺术的造型语言，适合原样保留。

### 适合保留矢量路径的素材

- **Logo 与徽标图标**：常需缩放至不同成品尺寸，同时要求边缘干净锐利；
- **文字轮廓**：将文字转曲（创建轮廓）后导出，可避免跨设备缺字或字形走样；
- **黑白与彩色线稿**：矢量路径便于统一调整线宽、锚点与转角；
- **平涂色块图形**：色块分界清晰，用闭合路径描述最为精准紧凑。

:::note[按素材选格式]
分辨率足够的 PNG Logo 同样可以直接用于高保真转换；结构极其繁复的矢量插画有时栅格化后反而更易处理。选择格式的目标是顺应现有素材的优势。
:::

## 修改扩展名不会转换图像格式

直接把 `picture.png` 重命名为 `picture.svg` 并不会把像素变成路径，反而会导致软件因文件头与扩展名不符而报错。以下两种容器封装情形也值得留意：

1. **把 PNG 嵌入 SVG 容器**：外层扩展名虽为 `.svg`，内部其实只是嵌入了一张位图，放大后清晰度与原 PNG 完全相同。
2. **把位图另存为 PDF**：PDF 是复合文档容器，内部既可能是矢量图形，也可能是扫描图片。

想确认文件里是否包含真正的矢量路径，可用 Inkscape 或 Illustrator 打开文件并尝试框选锚点：若能单独选中线条节点与色块轮廓，说明是原生路径；若只能选中一整块矩形画布，则说明内部是嵌入位图。

## 自动矢量化与画质的关系

“图像转矢量”工具通过分析像素色差来重新描摹轮廓与色块，适合把边界干净的位图转成可缩放路径，但也会带来以下变化：

- 相近色调被归并成同一平涂色块；
- 柔和渐变被拆分为一级一级的离散色带；
- 照片噪点、纸张纹理和 JPG 压缩伪影被描摹成大量细碎节点；
- 极小的文字、细线与尖角可能被平滑简化；
- 复杂画面的路径数量激增，反而拖慢后续预览与建模速度。

边界清晰的 Logo、图标与线稿通常能获得干净的矢量化结果；人像照片与复杂绘画则建议直接保留位图。

:::warning[缩放与细节]
低分辨率位图描摹为 SVG 后虽然可以任意放大，但原图因模糊或马赛克产生的轮廓变形也会随之放大，并不会自动找回缺失的原始细节。
:::

## 在 Lumina Studio 中的选型建议

开始前先备份原始素材，再按素材来源选择对应流程：

### 照片或复杂插画

直接上传原始 JPG、PNG 或 WebP 位图，配合高保真模式预览色彩与细节，无需先转成 SVG。

### 原生设计的 Logo、图标或线稿

如果设计稿本身就是矢量格式，直接导出原生 SVG（文字提前转曲、保持透明背景与闭合路径）并上传至 Lumina，避免先存成低清 PNG 再二次描摹。

### 只有位图，但需要使用矢量模式

先使用 Lumina 内置的“图像转矢量”生成候选 SVG，并与原图对比五点：

1. 五官、文字、细线与尖角是否完整保留；
2. 渐变区域拆成色带后是否自然；
3. 背景与阴影是否产生了多余碎路径；
4. 色块数量与路径复杂度是否适中；
5. 导入“图像转换”后的预览效果是否优于直接使用原位图。

详细操作步骤请参阅[从位图生成 SVG，再发送到图像转换](pathname:///zh/docs/knowledge/bitmap-to-svg/)。

## 导入前的快速自查清单

1. **看来源**：区分相机照片、网络压缩图与设计软件导出的原生矢量稿；
2. **看尺寸**：原图在目标打印尺寸下已经足够清晰时，可直接使用；
3. **放大看边缘**：放大出现像素格的是位图，在矢量软件中能编辑锚点的是原生路径；
4. **查容器内容**：`.svg`、`.ai`、`.eps` 和 `.pdf` 均可能内嵌位图；
5. **留存原件**：任何矢量化或裁剪操作都另存新副本，方便随时回退对比；
6. **看预览定方案**：结合 Lumina 的 2D / 3D 预览，选择边缘最干净、细节最符合预期的一版。

## 常见问题 Q&A

### PNG 一定是位图吗？

是的。PNG 属于光栅像素格式。即使它是从矢量设计稿导出的，导出后的 PNG 也只保留固定分辨率的像素阵列，不再包含可编辑路径。

### 扩展名为 `.svg` 就一定是纯矢量图吗？

不一定。SVG 规范允许原生路径与嵌入位图共存。在矢量编辑器中检查能否单独选中锚点和色块路径，是最准确的判断方式。

### 矢量图一定比位图更清晰吗？

两者适用的清晰维度不同。原生矢量路径在任意缩放时都能保持边缘锐利；而真实世界的皮肤质感、光影层次与丰富纹理，则由高分辨率位图表现得更自然。

### 低清模糊图转成 SVG 能修复细节吗？

不能。描摹算法只能依据现有像素推算边界，可以让锯齿边缘变得平滑规整，但无法复原已经丢失的五官、笔画与纹理细节。

### 可以根据文件大小判断位图还是矢量图吗？

不能单凭体积判断。简单图形的 SVG 只有几 KB，但包含上万节点的复杂 SVG 可能很大；反过来，经过压缩的位图也可以很小，而内嵌了高清图片的 SVG 体积同样会很大。

### 像素画需要转成矢量图吗？

不需要。像素方格本身就是像素画的核心特征。在 Lumina Studio 中直接上传像素画并使用“像素艺术”模式即可精准还原方格边缘。
