# SVG 上传失败、白底、破洞和细节异常怎么排查？

遇到 SVG 导入或预览异常时，最快的定位方式是**先备份原稿，再将副本精简为“有效画布 + 单一闭合路径 + 纯色填充”的最小文件**。若最小文件预览正常，将文字、渐变、蒙版等元素逐类加回即可锁定问题结构；若最小文件仍复现异常，直接保留该文件提交反馈即可。

SVG 既能存放闭合矢量路径，也能容纳未转曲文字、嵌入位图、滤镜、蒙版与外部引用。浏览器能够正常渲染的视觉效果，不一定都是可直接生成三维实体的闭合几何。

## 稳定建模的 SVG 基准条件

排查或准备用于 3D 打印的 SVG 时，建议满足以下特征：

- 带有准确的 `viewBox`，画布边界完整包住全部图形；
- 画面中的文字已全部转为轮廓路径；
- 所有需要生成实体的区域均为闭合路径，并带有明确的纯色填充；
- 粗细线条已在设计软件中执行“扩展描边”转为填充轮廓；
- 镂空与复合路径方向规范，使用明确的填充规则；
- 不含多余的高斯模糊、发光阴影、复杂蒙版、剪切路径、外部字体或远程图片链接；
- 节点数量与图形复杂度匹配，无大量重叠碎片。

Lumina Studio 支持多种常见 SVG 结构与部分线性、径向渐变；源文件结构越清晰，解析结果越一致且可预期。

## 症状一：SVG 无法上传或上传后无预览

按以下顺序逐一核查：

1. **确认文件为真实 SVG**：用文本编辑器打开文件，检查是否包含 `<svg ...>` 根节点（仅把 PNG 或 JPG 直接改后缀为 `.svg` 无法被解析；转换入口支持原生导出的 JPG、PNG、SVG、WebP 与 HEIC）。
2. **在浏览器与矢量设计软件中打开**：若两者均报错，先在设计软件中修复或重新导出源文件。
3. **重新导出标准 SVG**：在 Illustrator、Inkscape、Figma 或 Affinity 中使用“另存为”或“导出”生成标准 SVG，避免使用截断的网页内联代码片段。
4. **检查画布范围**：确保具备非零 `viewBox`，且图形坐标未全部落在画布边界之外。
5. **消除外部依赖**：将外部链接图片嵌入文件或转为矢量，将外部字体转为路径。
6. **最小对照测试**：新建一个仅含单个纯色矩形的 SVG 上传，确认当前转换入口工作正常。

## 症状二：透明背景变成了整块白色

先区分两种不同成因的“白底”：

### 情况 A：Lumina 生成的实体支撑底板

SVG 的透明画布代表背景无填充色；为了把画面中互不相连的色块托举成一件可整体取下的打印件，Lumina 会按当前设置生成实体底板。

- 如需更换底板颜色，在转换页面调整**底板耗材**；
- 如需在切片器中单独选中、隐藏或处理底板对象，可在高级设置中开启**分离底板**。

### 情况 B：SVG 源文件自带白色背景对象

若整个矩形画布都被意外识别成了白色图案区域，请在矢量编辑器的图层面板中检查：

- 底层是否有一块与画布等大的白色矩形；
- 是否嵌入了一张不透明白底位图；
- 蒙版或剪切路径在导出时是否被栅格化烘焙成了白底图像；
- 仅供画板预览的参考背景层是否未隐藏便一并导出。

删除多余背景层后重新导出即可，也可导出带透明通道的 PNG 在高保真模式下对比效果。

## 症状三：路径出现破洞、断线、重叠或自交

屏幕上看似相连的线条，在几何层面可能并未闭合：

### 断线或色块缺失

- 将需要生成实体的开放路径首尾闭合；
- 对仅有描边（Stroke）无填充（Fill）的线条执行**描边转路径**或**扩展描边**；
- 确保关键细线在目标成品尺寸下的物理宽度不小于喷嘴挤出线宽；
- 检查缺失部分是否超出 `viewBox` 或被剪切路径裁切。

### 镂空孔洞被填死或错位

- 检查复合路径绕向与 `fill-rule`（如 `evenodd` / `nonzero`）；
- 在设计软件中用布尔**差集**（减去顶层）直接切出真实孔洞，避免用白色色块盖在深色图形上来模拟镂空（白色色块会生成白色实体耗材）；
- 解组嵌套编组后，确认内孔与外轮廓属于同一个复合路径。

### 重叠与自交路径

- 对同色相连区域执行布尔**联集**合并；
- 修复、简化或重绘自身交叉（8 字形自交）的路径；
- 清理肉眼不可见的原位重复路径与极小碎屑（操作前请先留存原稿副本）。

Lumina 会自动尝试修复轻度几何异常，但严重自交路径在自动拆分时可能产生多边形碎裂，开路孤立线段则可能被忽略；提前在矢量软件中清理路径最为稳妥。

## 症状四：渐变、滤镜、蒙版或文字丢失

### 渐变

矢量模式会将连续渐变离散化为有限层数的耗材叠色区域。简单的线性与径向渐变可直接预览确认；多层叠加透明度或混合模式渐变建议通过以下两种方式二选一：

- **侧重柔和过渡**：从设计软件导出高分辨率透明 PNG，改用**高保真**模式转换；
- **侧重锐利矢量边界**：在设计软件中先将渐变分段扩展为明确的纯色色阶路径。

### 滤镜、蒙版与剪切路径

模糊、外发光、投影、图案填充与多层嵌套蒙版在不同 SVG 解析引擎下表现不一。建议：

- 将关键造型扩展为常规闭合路径与纯色填充；
- 若作品依赖光影滤镜质感，直接导出高分辨率透明位图使用高保真模式；
- 删除隐藏图层与不参与打印的装饰滤镜。

此外，开启大画幅矢量切分时，含未转曲文字、嵌入图像、图案、剪切路径、蒙版或滤镜的复杂 SVG 会受更严格限制（必要时会自动回退栅格切分），建议先在常规尺寸下验证源文件。

### 文字

保留字体引用的文本对象依赖运行环境安装同名同款字体，且可能无法直接作为闭合多边形参与建模。导出前请将全部文字**创建轮廓 / 转为路径**，并检查 `O`、`A`、`B`、`e` 等字腔内孔的复合路径以及小字号笔画宽度。

## 症状五：位图自动描摹转 SVG 后边缘锯齿严重

位图转矢量的自动描摹算法会忠实拟合原图像素边界：

- 低分辨率 Logo 的像素阶梯会被拟合为波浪状弯曲路径；
- JPG 压缩伪影会碎裂成大量杂色小块；
- 照片噪点会生成数以万计的冗余锚点；
- 半透明抗锯齿边缘会被拆解成多圈细碎灰边。

简洁图形与徽标可在清理边缘后重新描摹；照片与厚涂插画直接保留原位图走**高保真**模式效果更自然。模式对比请参阅[高保真、像素艺术与矢量模式怎么选？](pathname:///zh/docs/knowledge/image-mode-selection/)，软件内置描摹流程请参阅[从位图生成 SVG，再发送到图像转换](pathname:///zh/docs/knowledge/bitmap-to-svg/)。

## 症状六：节点过多导致预览卡顿或生成缓慢

SVG 的处理耗时取决于锚点与路径数量而非文件字节大小——几百 KB 的描摹稿也可能包含数十万个节点。可按顺序瘦身：

1. 删除画板外、隐藏图层与重复堆叠的对象；
2. 合并同色相邻色块；
3. 在保持主轮廓不变形的前提下适度简化锚点（切勿一次拉满简化强度，以免吞掉五官、锐角与孔洞）；
4. 清除远小于喷嘴线宽的微小孤立碎点；
5. 将局部照片或重度纹理区域栅格化处理；
6. 先在常规单板尺寸下验证通过，再开启大画幅切分或批量生成。

## 用最小化文件精准定位问题

<img
  src={require('./assets/svg-minimal-test.webp').default}

/>

1. **复制源文件副本**，保持原稿不动；
2. 删去其余元素，仅保留有效 `viewBox` 与一条闭合纯色路径；
3. 上传至 Lumina 生成预览；
4. 若预览正常，每次加回一类结构（其余路径、转曲文字、渐变、蒙版等），观察哪一步开始触发异常；
5. 根据测试结果分流处理：
   - **加回某类效果后才异常**：在矢量软件中展开该效果，或改用透明 PNG 高保真模式；
   - **源文件在浏览器或编辑器中也显示异常**：先修复导出源；
   - **最小文件在外部查看器正常、在 Lumina 中稳定报错**：保留该最小 SVG 与复现步骤提交反馈；
   - **Lumina 预览正常、仅切片后缺损**：转入切片器检查喷嘴、线宽、对象映射与逐层走线。

## 提交反馈时建议附上的资料

- 可复现问题的最小化 SVG 文件（隐去姓名、订单号、私有链接等元数据；若原图涉密或受版权限制，可用相同结构画一个简单几何图形复现）；
- 设计软件或浏览器中预期的正确显示截图；
- Lumina Studio 版本、色彩数据来源与建模模式；
- 目标成品尺寸；
- 从上传到出现异常的操作步骤，以及最早出现异常的预览截图。

## 常见问题

### SVG 明明是透明背景，为什么生成出来还是有底板？

三维打印件需要物理底板将分散的图案色块连成整体。请先确认它是 Lumina 自动生成的底板（可通过**底板耗材**改色或开启**分离底板**），还是 SVG 源文件图层中残留的白色矩形背景。

### 为什么浏览器里看着完整，上传到 Lumina 后少了一块？

浏览器支持直接渲染未转曲字体、纯描边线条、剪切蒙版与滤镜，而三维建模需要闭合填充多边形。将缺失的文字转为路径、描边扩展为填充、蒙版烘焙裁剪后重新导出即可恢复。

### 文字转成路径后就一定能完整打印出来吗？

转曲消除了字体缺失问题，但打印效果还取决于目标尺寸下的笔画物理宽度是否大于喷嘴线宽，以及字腔孔洞的复合路径方向是否正确。

### 矢量模式预览里色块交界有细白缝，要把所有路径统一加粗吗？

先放大切片器的真实走线预览确认：屏幕预览中的极细亮线往往只是图形渲染抗锯齿间隙，切片走线实际紧密贴合；只有当源文件相邻色块确实留有物理缝隙导致切片缺口时，再针对该处接缝做路径贴合或微调，避免盲目全局加粗堵死孔洞与小字。

### 遇到特别复杂的 SVG，应该继续简化节点还是换高保真模式？

徽标、扁平图标与文字排版优先保留 SVG 并适度精简节点，边缘最锐利；包含照片、噪点肌理、柔和阴影或复杂多层渐变的作品，直接导出高分辨率透明 PNG 使用**高保真**模式效率更高。
