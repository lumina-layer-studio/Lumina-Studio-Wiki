# 打不开、一直转圈或生成失败，应该先查什么？

排查页面与生成问题时，最省力的方式是先找出**最早出现异常的环节**，每次只调整一个变量。

Lumina Studio 的完整处理链路分为六个阶段：**打开页面 → 连接后端 → 准备最小输入 → 完成最小预览 → 生成文件 → 下载、打开或提交报告**。上游环节尚未走通时，先解决上游即可恢复整条链路。

## 排查前注意四点

- **等待单次请求返回**：加载转圈期间无需连续点击“预览”或“生成”，以免重复排队触发限流；
- **先保留现场再清理**：记录最早出现的完整报错文字后再做后续操作，不必第一时间点击“清除缓存”；
- **使用真实导出的文件格式**：将不支持的文件直接改后缀为 `.png` 仍会因内部格式不符而报错；
- **注意隐私脱敏**：在公开群聊或社区提问前，先隐去未公开稿件、商业文件及个人账号信息。

## 六步排查顺序

### 第一步：确认页面能否正常加载

如果浏览器直接报错、白屏，或长时间未显示 Lumina Studio 主界面，问题处于访问入口层：

1. 确认访问的是当前官方地址或本地正式启动入口（而非失效的旧书签、临时分享链接或调试端口）；
2. 普通刷新页面，观察现象是否一致；
3. 同一时间用手机热点或另一台设备访问同一地址做横向对照；
4. 记录发生时间、所在地区与网络类型。

仅单台设备无法打开时，优先检查该设备的浏览器扩展、系统代理或本地网络；多台设备与不同网络同时无法访问时，多为服务端或线路波动，稍后重试或反馈维护团队即可。

### 第二步：查看顶栏后端连接状态

刚打开页面时短暂显示“正在检查后端…”属于正常握手过程，随后会变为“后端已连接”。

若顶栏持续提示“后端不可达”：

- **在线版**：记录时间、网络环境与状态提示，稍后重试或提交反馈；
- **本地版**：通过官方启动器重新启动 Lumina Studio 服务，再刷新页面。

上传、预览与模型生成均依赖后端服务运行，顶栏恢复“后端已连接”后再继续测试输入文件。

### 第三步：用最小输入隔离文件与环境问题

准备一张尺寸较小、内容简单的常规 JPG 或 PNG，搭配一份此前验证可用的耗材档案或经典 LUT；暂时关闭批量生成、大尺寸分割及挂环等附加结构，仅保留基础转换参数，并确认：

- 图片已真正上传完毕（显示缩略图而非仅文件名）；
- 色彩数据来源已选定，且对应的耗材档案、品牌或 LUT 已勾选就绪；
- 图片分辨率、色彩通道及 PNG 透明区域正常；
- 若输入为 SVG，先排除外部字体、复杂蒙版、滤镜或画布越界，详见[SVG 上传失败、白底、破洞和细节异常怎么排查？](pathname:///zh/docs/knowledge/svg-troubleshooting/)。

若简单小图能够顺利预览而原文件报错，说明问题集中在原文件或特定参数组合；若最简图片同样失败，再继续检查软件服务状态。

### 第四步：跑通一次最小预览

使用常规成品尺寸与默认参数，发起单次“预览”并等待结果返回或弹出明确提示。

若预览持续转圈或报错：

1. 确认顶栏仍保持“后端已连接”；
2. 确认图片与色彩来源均已就绪；
3. 关闭大尺寸分割、批量、拼图等扩展功能；
4. 换用简单小图做一次对照预览，并记录首条完整错误提示。

最小预览跑通后，再每次只恢复一项原有条件（原图、目标尺寸或高级选项），最先重新触发失败的那一项即为问题根源。

### 第五步：处理“生成”按钮置灰或生成报错

“生成”按钮需要建立在一次**有效的当前预览**之上才能启用。若按钮呈灰色不可点，按顺序核查：

- 图片与色彩数据来源均已选妥；
- 当前参数下已成功完成过一次预览；
- 更换图片、色彩来源或关键建模参数后，已重新点击“预览”刷新状态；
- 当前建模模式、耗材档案、附加结构与导出方式彼此兼容；
- 成品尺寸、热床范围或大尺寸分割未触发阻断性警告。

若预览正常但点击“生成”后报错，请先截图保留完整报错文字，关闭非必要附加选项，用同一张简单小图做一次最小生成验证。

### 第六步：区分文件下载异常与切片器打开异常

生成完成后，先点击下载将 `.3mf` 或 `.zip` 完整保存到本机磁盘，再根据现象分流处理：

- **下载按钮失效或提示文件不存在**：临时会话产物已过期，重新执行一次预览与生成并及时保存；
- **文件已下载但未能自动打开切片器**：检查“设置”中的切片软件选项与本地应用路径，或直接在切片器中通过“文件 → 打开项目”载入，详见[切片器没检测到，或者 3MF 打不开怎么办？](pathname:///zh/docs/knowledge/slicer-path-and-open-troubleshooting/)；
- **切片器打开后颜色或耗材不对**：核对模型对象、项目耗材与真实料槽映射，详见[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)；若三阶段显色不一致，另见[为什么 Lumina 预览、切片器预览和打印实物不一样？](pathname:///zh/docs/knowledge/preview-slicer-print-differences/)；
- **大尺寸切分或批量导出为 ZIP**：先将 ZIP 完整解压到本地文件夹，再导入其中的 `.3mf` 文件（切勿直接在压缩包预览窗口内双击打开）。

## 什么情况下使用“清除缓存”

“清除缓存”用于在本地版出现临时会话、预览或下载状态卡死，且重启软件与最小对照测试仍未恢复时重置临时状态。清理前请留意：

- 当前未保存的临时预览与下载链接会一并清空，需重新上传、预览并生成；
- 清理临时缓存不会删除用户耗材库中的耗材档案与配置预设；
- 图像格式错误、参数冲突或切片器槽位映射问题无需通过清缓存处理。

## 常见报错类型速查

遇到弹窗提示时，直接按完整提示归属的类别处理即可：

| 报错含义 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 输入无效或缺少必填信息 | 未选定色彩来源、参数未填齐或文件内容损坏 | 退回最小输入基准，逐项补齐必选项 |
| 不支持该文件类型 | 文件实际编码与扩展名不符，或当前模式不支持 | 从设计或看图软件重新导出标准 JPG、PNG、SVG、WebP 或 HEIC |
| 文件体积或复杂度超限 | 分辨率极高或 SVG 锚点过多 | 另存适度缩小的副本测试，保留原稿不动 |
| 文件或会话不存在 | 临时生成产物超时清理、页面刷新或会话切换 | 重新选择输入文件，执行预览与生成 |
| 当前任务过多 | 短时间内连续点击，或后台仍在处理上一任务 | 暂停点击，待当前任务结束后再单次发起 |
| 服务暂时不可用或超时 | 后端进程异常、网络抖动或单次计算耗时过长 | 记录时间与首条报错文字，稍后用最小小图重试或反馈 |

## 标准最小复现流程

排查疑难故障时，可用以下固定组合快速验证基础环境是否健康：

1. 当前官方网址或本地标准启动器入口；
2. 一张确认可正常查看的小尺寸纯色 JPG 或 PNG；
3. 一份此前成功生成过的耗材档案或经典 LUT；
4. 常规单板成品尺寸与默认建模参数；
5. 关闭批量、大尺寸分割及全部附加结构；
6. 单次点击“预览”，待预览完成后单次点击“生成”。

## 提交反馈前建议准备的资料

- Lumina Studio 版本号，以及使用的是在线版还是本地版；
- 故障发生时间、所在地区与网络类型；
- 卡住的具体环节与第一条完整错误提示文字；
- 从打开页面起的复现步骤；
- 原始输入文件，或可复现同一现象的脱敏最小示例文件；
- 所选色彩来源类型、耗材档案 / LUT 名称、建模模式、成品尺寸及关键开关；
- 报错界面截图，以及（若已成功生成）导出的原始 `.3mf` 或 `.zip` 文件。

使用软件内置错误报告功能时，可在提交前展开“自动收集的信息”预览将发送的页面状态、参数选择与诊断日志（截图为可选项，请勿附带密码、密钥或无关商业原稿）；若网络受限导致在线提交失败，可复制备用报告文本通过官方渠道反馈。

## 常见问题

### 顶栏“正在检查后端…”停多久算异常？

页面刚加载时通常在数秒内切换为“后端已连接”。若长时间停留不变或转为“后端不可达”，请直接按第二步检查网络或重启本地服务。

### “生成”按钮一直是灰色，是账号权限受限吗？

与账号权限无关。“生成”按钮在图片、色彩来源及当前参数下的有效预览全部就绪后自动点亮；修改过图片、色彩来源或关键建模参数后，请重新点击一次“预览”。

### 为什么手机热点能打开，宽带 Wi-Fi 打不开？

这种差异表明软件与输入文件本身正常，问题出在本地运营商线路、路由器 DNS 或代理规则。记录两侧网络表现、时间与地区反馈给维护者即可，无需改动本地耗材库或切片设置。

### 点击“清除缓存”会把我自己校准的耗材档案删掉吗？

不会。“清除缓存”仅清理临时会话、预览缓存与临时导出产物，耗材库中的用户耗材档案与预设配置均会保留。

### 为什么刷新浏览器后，刚才生成的下载按钮不能用了？

预览与导出文件绑定在当前临时会话中，刷新页面、超时或清理缓存后旧临时链接即会释放。重新选入图片执行一次预览与生成，并在完成后立即保存到本地文件夹即可。

### 反馈 Bug 时必须上传我的未公开原图吗？

不需要。只要用一张简单的公开图形或色块复现出相同报错，提交该最小复现文件并说明原图的格式与尺寸特征即可。
