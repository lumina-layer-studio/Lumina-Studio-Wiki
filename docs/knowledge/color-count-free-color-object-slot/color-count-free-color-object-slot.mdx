# 颜色数、自由色、对象与料槽有什么区别？

从导入图片到上机打印，Lumina Studio 与切片器中的几个“颜色/数量”概念分别对应流程中的不同环节，彼此数值无需相等。例如：一张插画可以聚类为 **48 个量化颜色组**，由 **4 卷实体耗材**通过 **5 层叠色配方**混出丰富色彩；导出的 3MF 可能包含 **多于 4 个几何对象**，最终再映射到打印机上任意编号的 **4 个物理料槽**。

## 八个概念速查表

| 名称 | 作用与含义 | 与其他层级的边界 |
| --- | --- | --- |
| 原图颜色 | 图片文件中每个像素原始的 RGB 颜色值 | 需经过量化与耗材配方匹配后才能转换为打印结构 |
| 量化颜色数 | 高保真模式将相近像素聚类成的目标色组上限 | 只控制图像分色粒度，独立于实体线盘数、AMS 槽位数与 3MF 对象数 |
| 匹配色 / 叠色配方 | 每个目标色在当前色彩来源中匹配到的可达色与层序 | 依靠多层混色实现，无需为每种画面结果色准备单独一卷线材 |
| 已选耗材 | 当前耗材档案或经典 LUT 参与计算的真实材料通道 | 决定可用基础材料种类，无需与机器物理槽位保持同号 |
| 叠色层数 | 单个像素配方沿 Z 轴参与混色的显色层数 | 控制纵向混色层数，同一份耗材可在多层中重复使用 |
| 自由色 | 将指定匹配色区域额外拆分为独立的 `Free_颜色HEX` 对象 | 便于在切片器中单独指定线盘，仍受机器实际槽位数限制 |
| 3MF 对象 / 零件 | 切片器中可独立选中与指定材料的几何体 | 底板、轮廓、挂环与分离色块都会生成独立对象，多个对象可共用同一份耗材 |
| 项目耗材与实际料槽 | 3MF 内的材料编号定义，以及实体线盘所在的机器槽位 | 两套编号互相独立，切片前将项目耗材映射到对应物理槽位即可 |

## 量化颜色数：控制高保真模式的分色粒度

照片、渐变插画与抗锯齿边缘往往包含成千上万种细微变化的 RGB 值。高保真模式会先通过颜色聚类将相近像素归纳为有限数量的目标色组，该上限即“量化颜色数”：

- **适用模式**：仅作用于高保真模式；矢量模式直接使用 SVG 色块，不经过像素聚类。
- **取值范围**：常规范围为 `8–256`，也可开启“自动计算”；解锁上限后最高支持 `8192`（内存占用与计算耗时大幅增加，仅用于色彩层次极其复杂的特殊素材）。
- **调节效果**：调高可保留更细腻的渐变过渡；调低则归并出更简练的大色块并加快预览速度。

将量化颜色数设为 `48`，代表软件最多把画面归纳为约 48 个目标色组，后续这些色组会共用你所选的那几卷真实耗材，通过不同叠层顺序表现出来。

:::tip[调整时机]
大面积柔和渐变出现生硬色阶断层时，可保持其他参数不变、适度调高量化颜色数；画面配色简单或预览较慢时则可适当调低。
:::

## 匹配色与叠色配方：少量线材混出丰富色彩

完成像素量化后，每个目标色会匹配到当前耗材档案或经典 LUT 能组合出的最接近配方。通过改变多层耗材的堆叠顺序与重复次数，少量基础线材即可混出远超线盘数量的视觉颜色。

例如选择白、红、黄、蓝 4 份耗材档案、5 层叠色时，不同色组可分别采用：

- 白 → 红 → 白 → 白 → 白
- 白 → 黄 → 红 → 白 → 白
- 白 → 蓝 → 红 → 黄 → 白

三种配方同样只用这 4 卷线材，却能呈现不同的浅红、橙红与暗紫色调。因此，画面最终呈现的颜色种类可以远多于已选耗材数；若发现整体缺乏某一色系（如缺少鲜艳绿色或冷青色），补充对应色系的耗材档案比单纯拉高量化颜色数更有效。色彩来源的选型方法见[耗材档案和经典 LUT 怎么选？](../material-profile-selection/material-profile-selection.mdx)。

## 已选耗材与叠色层数：材料种类 vs. 纵向层数

在耗材档案模式下，四个常见参数分工明确：

- **已选耗材**：允许参与混色计算的实体材料档案；
- **底板耗材**：指定用于底板支撑与衬底的材料；
- **叠色层数**：每个像素配方沿 Z 轴堆叠的显色层数；
- **层高**：每一层显色材料的物理厚度。

因此，“选用 4 份耗材档案 + 5 层叠色”是非常标准的组合——5 层之中可以多次重复使用同一种耗材，无需准备第 5 卷线材。

同理，经典 LUT 名称中的 2 色、4 色、5 色、6 色或 8 色，代表该 LUT 标定所用的基础材料通道数，与高保真量化颜色数、叠色层数互不冲突。只需确保打印机当前可用的多色料槽（或手动换料计划）能容纳本次实际使用的材料通道数即可。

## 自由色：将特定色块拆分为独立对象

生成预览后，在颜色工作站中选中某个已匹配的颜色并点击“标记为自由色”，重新导出 3MF 时，Lumina 会将该颜色覆盖的区域单独提取为名为 `Free_颜色HEX` 的独立几何对象。

**适用场景：**

- Logo、文字或关键色块希望直接指定给手头某一卷专色线材；
- 需要在切片器对象列表中单独选中该区域并手动指定项目耗材；
- 希望将夜光、丝绸、金属等特殊质感线材与常规叠色区域分开管理。

标记或清除自由色后，需重新点击生成以导出包含最新对象结构的 3MF，随后在切片器中将该 `Free_颜色HEX` 对象分配给目标耗材并完成料槽映射。

:::warning[实物显色说明]
自由色用于生成独立的可分配对象，最终打印出的颜色由实际装入机器的实体线材、材料预设、首层质量与环境光线共同决定。
:::

## 对象、项目耗材、真实线盘与实际料槽

导入切片器后，可以按从左到右的四个层级依次核对：

<img
  src={require('./assets/slicer-mapping-layers.webp').default}
  alt="切片器中的项目耗材、对象分配、真实线盘和实际料槽是四个不同层级"
/>

### 1. 对象（零件）

对象是 3MF 中的独立几何网格。底板、各材料显色网格、外轮廓、挂件环与自由色都会各自成为对象，因此对象总数往往多于已选耗材卷数，多个对象可以共用同一份项目耗材。

### 2. 项目耗材

项目耗材是 3MF 文件内保存的材料槽定义。对象旁显示的数字代表它引用的是“项目耗材几号”，色块仅作视觉区分参考。

### 3. 真实线盘与实际料槽

真实线盘是你手头准备上机的实体耗材；实际料槽则是该线盘当前装在 AMS、ACE、MMU 或外置料架上的物理位置。

导入切片器后的标准核对流程：

1. 展开对象列表，确认各对象引用的项目耗材符合预期；
2. 核对每份项目耗材对应的实体线盘品牌与颜色；
3. 在切片及发送打印界面，将项目耗材映射到该线盘实际所在的物理料槽（例如将“项目耗材 3”映射到“AMS A1”）；
4. 执行切片，旋转至显色面逐层检查刀路与换料顺序。

图文映射步骤详见[把 Lumina 3MF 正确导入切片器](pathname:///zh/docs/tutorials/slicer-material-mapping/)。

## 按调整目标快速定位参数

| 期望改善的效果 | 对应调整项 | 说明 |
| --- | --- | --- |
| 渐变色阶断层明显、色块过粗 | 调高**量化颜色数** | 细化目标色组，无需增加实体线盘 |
| 量化已足够细，但整体偏暗或缺某类色相 | 调整**耗材档案 / LUT**及已选耗材 | 补充对应色相或高透/高饱和线材以扩展色域 |
| 希望增加纵向混色过渡细腻度 | 调整**叠色层数** | 同步关注模型总厚度与换料时间变化 |
| 指定某块图形直接使用专色线材 | 标记**自由色**并重新生成 3MF | 导入切片器后为 `Free_` 对象手动指定专色料槽 |
| 切片器对象列表条目较多 | 检查各对象的**项目耗材分配** | 属于正常几何拆分，核对材料归属即可 |
| 项目耗材编号与机器 AMS 槽号不一致 | 在切片器中配置**料槽映射** | 直接指定对应槽位即可，无需手动调换线盘位置 |

## 两个典型示例

### 示例 1：48 个量化色 + 4 卷耗材 + 5 层叠色

高保真模式下将量化颜色数设为 `48`，选用白、红、黄、蓝 4 份耗材档案，叠色层数设为 `5`：

- 原图被聚类为最多约 48 个目标色组；
- 每个色组由这 4 种耗材组合成最多 5 层的叠色配方，全程只需 4 个多色料槽；
- 若同时开启了外轮廓或分离底板，导出的 3MF 对象总数会多于 4 个，各对象仍共享这 4 份项目耗材。

### 示例 2：将红色 Logo 标记为自由色

完成预览后，选中 Logo 区域的匹配红并标记为自由色，重新导出 3MF：

- 原图的量化颜色数保持不变；
- 3MF 中新增一个独立的 `Free_` 对象承载该红色区域；
- 在切片器中将该对象指定给你准备好的正红实体线盘（若新增了第 5 种实体耗材，需确保多色系统有空闲槽位并重新切片）。

## 常见问题 Q&A

### 量化颜色数设为 256，需要 256 个料槽吗？

不需要。256 只是高保真模式对原图像素聚类的目标色组上限，所有色组仍由你选定的那几卷实体耗材通过多层叠色表现。

### 选了 8 种耗材，为什么叠色层数还是 5？

耗材数量代表可选用的材料池大小，叠色层数代表单个像素沿 Z 轴堆叠的层数。每个像素的 5 层配方会从这 8 种耗材中挑选最合适的组合。

### 经典 LUT 的 4 色 / 6 色 / 8 色模式和自由色是一回事吗？

不同。经典 LUT 的色数指该预设标定的基础耗材通道数；自由色则是将某个已匹配色块单独拆成独立 3MF 对象，方便你在切片器里手动指定耗材。

### 转换时只选了 4 种耗材，为什么切片器里出现了七八个对象？

底板、外轮廓、挂环、透明镀层以及自由色都会作为独立几何对象导出，多个几何对象共用同一份项目耗材即可正常打印。

### 项目耗材 2 一定要装进 AMS 2 号槽吗？

不需要。发送打印前在切片器的料槽映射界面将“项目耗材 2”指向该线盘实际所在的槽位即可。

### 切片器里的耗材示意色块和手头线盘颜色有色差，会打错吗？

只要“对象 → 项目耗材 → 物理料槽”的映射关系正确，机器就会抽取对应槽位里的真实线盘打印；软件色块仅用于界面识别，不会改变实际出料。
