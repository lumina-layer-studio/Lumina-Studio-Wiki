# Lumina Studio 2.0 开发月报：2026 年 4 月

> 本月合并 123 个 PR

[← 2026 年 3 月](/zh/docs/releases/2026-03) · [更新日志总览](/zh/docs/releases/overview) · [2026 年 5 月 →](/zh/docs/releases/2026-05)

## 本月概览

4 月，Lumina Studio 2.0 从底层迁移全面转入核心工作流重建。矢量引擎、颜色工作站、LUT 管理、校准与材料档案接入统一的数据与预览管线；拼图、冰箱贴、单阶段生成、大画幅和分享卡等工作流陆续成型，3D 预览体积、会话隔离、结构化日志与问题反馈也得到系统改进。

## 重点更新

### 矢量引擎与预览/3MF 路径统一

SVG 从解析、遮挡裁剪、颜色匹配、网格挤出到 3MF 导出收敛至同一条原生矢量管线。区域换色、自定义配方、额外颜色层和材料档案均同步写入最终模型，并为复杂几何边界提供可打印的回退处理。


### 颜色工作站成为独立编辑流程

新增 2D 颜色工作站，支持按区域或连通色块选择、原图临时对比、自定义配方及分层预览刷新。当平滑渐变被拆分为多种材料色时，系统会自动识别为渐变分组，支持整组或局部一键“去海带纹”，大幅减少逐块点选操作。


### LUT 浏览、对比与色域可视化

材料管理新增 LUT 工作流分组、LUT 对比与 LUT 详情视图，可直观查看调色板、各颜色使用占比、色相分布与 Lab 点云，并按品牌与色数筛选传统 LUT。反推或自定义 LUT 优先采用自身调色板，避免旧全局配置造成错配。


### 一键分享卡与可复现配方

预览结果支持导出包含图案、材料、层序和模型参数的分享卡，重新导入即可恢复核心配方，便于跨设备同步或用户间复现。在缺少部分浏览器加密接口的普通 HTTP 环境下，也提供了兼容导出路径。


## 新功能

### 拼图与冰箱贴工作流

拼图模式补齐切割、分片生成与 SVG 导出；冰箱贴模式新增磁铁槽位以及主体与底板组合逻辑，两者均接入统一的预览、配方和 3MF 导出管线。


### 原生 SVG、单阶段与大画幅

新增原生 SVG 工程包、单阶段材料工作流，以及面向大幅面图案的分块生成。大画幅流程会自动识别 SVG 的可打印边界，让矢量作品优先走高效的原生矢量管线。


### 8 色完整校准与 5 色配方色块

打通 8 色双页校准全流程；5 色扩展模式支持生成配方验证色块，并修复第二页引导提示、层数与基础色读取问题。


## 校准与材料

- 优化梯度卡生成、提取、旋转、角点顺序及黑白底朝向交互；默认层高调整为常用的 0.08 mm，并支持融合多次拍摄样本重新拟合。
- 材料品牌改为可复用的可编辑下拉项，已保存的材料档案支持直接重命名；默认材料输入改为受控选择器，统一槽位命名。
- 提取器在清除角点、切换页面及切换 5/6 色模式时自动同步重置状态，避免残留上一轮识别结果。

## 矢量化与建模

- 自定义配方支持添加 LUT 之外的虚拟材料和额外颜色层，并在导出的 SVG 3MF 中生成对应模型对象。
- 保护插画细线条宽度不被意外加粗；复杂几何布尔合并失败时保留边界回退，避免细节变形或整次生成中断。

## 预览与交互

- 新增 2D 与 3D 悬停检查器，鼠标指向图案即可查看颜色、材料与分层信息；分层遮罩窗口新增跟随光标的局部放大镜。
- 3D 预览由逐像素体素改为轮廓挤出，典型预览体积缩小约 155 倍，显著加快远程加载与浏览器渲染，且不影响最终导出的 3MF 精度。
- 修复画布滚轮缩放带动整页滚动、滑块自动跳半格、放大后光标遮挡小色块以及按钮加载状态受浏览器扩展干扰等问题。
- 转换器面板拆分为“核心”“颜色”“高级”三个子标签页，重排帮助提示、诊断信息、展开动画与工具栏布局，让常用参数一目了然。

## 切片器与 3MF

- 3MF 新增底板层高修改器，导入 Bambu Studio 后底板可独立采用更大层高；同时修复材料定义冲突及 Anycubic Slicer Next 预览占位图卡死问题。

## 问题反馈与更新沟通

- 应用内新增中英文双语更新公告，按日期归档并支持逐条关闭。
- 新增 Bug Report v2.1：提交时自动附带当前工作流、色彩模式、LUT、会话及浏览器信息；邮件发送不可用时自动保存本地 JSON，提交成功后保留工单号便于复制。

## 稳定性、性能与基础设施

建立结构化日志与工作流回归门禁，覆盖颜色提取、预览、换色、SVG、模型生成与多色模式；修复跨会话共享预览文件、长时运行工作进程内存增长、输入文件过早清理等问题，并完成内部可选数据库存储的基础适配。


## 已知限制

- 大画幅、描边、涂层与部分建模模式存在互斥组合，界面会按当前模式自动限制可选项。
- 新版预览内核与可选数据库后端仍处于内部验证阶段，默认未启用。
- 材料档案与传统 LUT 仍在逐步统一，部分旧版 JSON/NPY 文件通过兼容路径读取。
