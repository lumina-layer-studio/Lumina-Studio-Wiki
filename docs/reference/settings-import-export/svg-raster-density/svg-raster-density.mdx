# 高保真 SVG 采样密度

将 SVG 设为“高保真”模式时，软件会先按目标物理尺寸将其栅格化为像素图像，再进入颜色匹配与三维建模流程。“高保真 SVG 采样密度”决定每毫米生成多少像素。

  src={require('./assets/01-svg-density.webp').default}
  alt="高保真 SVG 采样密度滑块"
/>

## 数值范围

- 默认值：`10.0 px/mm`
- 最小值：`2.0 px/mm`
- 最大值：`50.0 px/mm`
- 调整步进：`0.1 px/mm`

例如，宽度为 100 mm 的 SVG 在默认 `10.0 px/mm` 下会栅格化为约 1000 像素宽。调高数值能保留更细腻的边缘和微小图形，但会增加图像处理耗时与内存占用；调低数值可加快计算，细线条或微小间隙则会相对粗糙。

## 生效条件

该设置仅在同时满足以下两项条件时生效：

- 上传的文件格式为 SVG。
- 图片处理模式选择“高保真”。

原生“矢量”模式直接解析 SVG 几何路径，不经过像素栅格化，因此不使用此数值；PNG、JPG 等位图素材同样不受影响。

修改采样密度后，请重新点击预览并生成 3MF 以应用新精度；点击“恢复默认”可重置回 `10.0 px/mm`。
