# 设备与切片软件

系统设置中的设备选项决定 Lumina Studio 如何封装 3MF 工程，以及生成后调用哪个切片软件打开文件。请按照你实际使用的切片软件、打印机型号与已安装的喷嘴规格进行配置。

## 各选项的联动关系

1. **切片软件：** 决定可选打印机列表及 3MF 输出适配格式。
2. **打印机型号：** 决定热床尺寸、多色能力与可用的设备配置。
3. **喷嘴尺寸：** 参与模型细节精度、线宽及部分层高参数的计算。
4. **设备配置：** 区分同一机型下的不同喷头或硬件变体。
5. **打印板：** 选择当前切片软件与机型支持的原生板型，并写入导出的 3MF。

切换切片软件后，打印机列表会立即按兼容性重新筛选；若原先选中的机型、喷嘴或设备配置不在新列表内，Lumina Studio 会自动切到当前可用的有效选项。

更改上述任一设置后，此前导出的文件不再匹配新设备，请重新预览并生成 3MF。

## 手动指定切片软件路径

在 macOS 上可手动填写切片软件的 `.app` 路径（如 `/Applications/Bambu Studio.app`）。点击“校验并保存”后，软件会先验证路径有效性；验证通过后，点击“在切片软件中打开”将优先调用该路径。

手动路径仅指定打开文件所用的应用程序，请确保上方的“切片软件”下拉项仍与该软件类型一致，以便输出匹配的 3MF 格式。

:::note[设备列表加载]
设备列表读取自本机配置。若列表暂时为空，页面会自动重试；若持续无法加载，请检查本地后台服务与配置加载状态。
:::

## 生成前的耗材预设与打印板校验

生成模型前，软件会检查原生耗材预设与所选打印板的兼容性。当某种材料对应多个原生预设时，可从候选列表中明确指定；若提示当前板型与材料不兼容，请调整打印板或耗材类型后再继续生成。

由于不同材料预设的温度、流量与热床参数各不相同，请按实际装机的耗材类型选择。不同设备与喷嘴的偏好会分别保存，导出的工程也会记录对应的耗材配置。

## 自定义模板与擦料塔摆放

如需沿用切片软件中调好的工艺参数，可导入[自定义 3MF 项目模板](../custom-3mf-template/custom-3mf-template.mdx)（模板需与当前选择的切片软件、打印机和喷嘴一致）。

“擦料塔自动摆放”默认开启，由 Lumina 按当前设备尺寸自动排布模型与擦料塔；关闭后则保留模板原有的擦料塔位置参数，方便在切片软件中手动摆放。若导出时提示需人工核对摆放，请在切片软件中检查模型、裙边与擦料塔间距。

QIDI Studio、PrusaSlicer、Flash Studio 等不同切片器各自支持对应的机型、喷嘴规格与多色通道上限，切换切片软件后即可在下拉菜单中查看受支持的设备范围。
