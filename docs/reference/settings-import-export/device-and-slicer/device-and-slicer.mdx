# 设备与切片软件

系统设置中的设备信息决定 Lumina Studio 如何组织 3MF，以及生成完成后使用哪个切片软件打开文件。请按实际使用的
切片软件、打印机和已安装喷嘴选择，不要只按示例设备设置。

## 设置之间的关系

1. **切片软件**决定可选的打印机范围和输出适配方式。
2. **打印机型号**决定打印床、机器能力及可用设备配置。
3. **喷嘴尺寸**参与模型精度、线宽和部分层高参数的计算。
4. **设备配置**用于区分同一机型下的具体喷头或硬件组合。
5. **打印板**用于选择当前切片软件和机型支持的原生板型，写入生成的工程。

更换切片软件后，打印机列表会立即按兼容性重新筛选。如果原先的机型、喷嘴或设备配置不再可用，Lumina Studio
会自动切换到当前列表中的有效选项，避免保留一组不能生成的旧配置。

这些选项发生变化时，之前生成的下载文件会失效。重新预览并生成即可得到与新设备一致的 3MF。

## 手动切片软件路径

macOS 可以填写切片软件的 `.app` 路径，例如 `/Applications/Bambu Studio.app`。点击“校验并保存”后，
Lumina Studio 会先验证该路径；验证通过的路径会优先用于“在切片软件中打开”。

手动路径只改变打开文件时调用的应用，不会把一种切片器格式自动转换为另一种格式。切片软件下拉菜单仍应选择
与该应用相符的类型。

:::note[设备列表加载]
设备列表由当前机器配置提供。列表暂时为空时，页面会重试；持续失败时，检查本机服务和配置加载状态。
:::

## 生成前选择耗材和打印板

截至 2026 年 10 月 19 日，生成流程会检查原生耗材预设与打印板的兼容性。一个材料可能匹配到多个原生预设，
这时需要从候选中明确选择；板型不兼容时，需要调整打印板或材料选择，再继续生成。

选择真实使用的材料，不要为消除警告而随意改成另一种材料。材料预设中的温度、流量等会影响实际切片，
屏幕色块相近不等于材料工艺可以互换。不同设备和喷嘴的选择分别保存，项目也会记录支持的耗材选择。

## 自定义模板与擦料塔

需要沿用切片软件里调好的工艺时，可以导入[自定义 3MF 项目模板](../custom-3mf-template/custom-3mf-template.mdx)。
模板仍须匹配切片软件、打印机和喷嘴；它不能把一种机型的工程直接变成另一种机型的有效配置。

“擦料塔自动摆放”默认开启。关闭后保留模板中的擦料塔参数，便于在切片软件中手动安排；
开启时按当前设备处理模型和擦料塔布局。若提示无法确认安全布局，请实际检查模型、底边和塔的位置。

可用机型以当前列表为准。QIDI Studio、PrusaSlicer、Flash Studio 等适配有各自的机型、喷嘴和多色容量限制，
不应将某一个示例型号的支持范围推广到所有设备。
