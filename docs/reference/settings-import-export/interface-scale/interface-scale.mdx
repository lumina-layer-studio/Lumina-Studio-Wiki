# 界面缩放

桌面版的“界面缩放”用于调整文字、按钮和面板的显示比例，不会改变模型的物理尺寸或导出的 3MF 大小。

打开“设置 → 常规”，在“界面缩放”中可选择 80%、90%、100%、110%、125%、150% 或 175%。100% 跟随操作系统的默认显示缩放；需要放大界面可选更高百分比，希望同屏容纳更多内容则可选更低百分比。所选比例会自动保存，并在下次启动桌面版时继续生效。

也可通过快捷键逐档调节：Windows 与 Linux 按 `Ctrl` 加 `+` 或 `-` 缩放，按 `Ctrl + 0` 恢复 100%；macOS 将 `Ctrl` 替换为 `Command` 即可。

该选项仅在桌面版中提供。在浏览器中使用网页版时，可直接使用浏览器的页面缩放功能，两者缩放比例各自独立保存。
