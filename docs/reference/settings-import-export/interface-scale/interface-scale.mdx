# 界面缩放

桌面版的“界面缩放”用来调整文字、按钮和面板的显示大小，不改变模型尺寸或 3MF 的实际尺寸。

打开“设置 → 常规”，在“界面缩放”中选择 80%、90%、100%、110%、125%、150% 或 175%。
100% 遵循操作系统的显示缩放；觉得界面太小可以选择更大的百分比，太大则选择更小的百分比。
设置会被保存，下次启动桌面版时继续使用。

也可以使用快捷键逐档调整：Windows 和 Linux 使用 `Ctrl` 加 `+` 或 `-`，按 `Ctrl + 0` 恢复 100%；
macOS 使用 `Command` 代替 `Ctrl`。

该选项只在支持此功能的桌面版中显示。通过浏览器使用时，可使用浏览器自己的页面缩放功能；
浏览器缩放与桌面版设置分别保存。
