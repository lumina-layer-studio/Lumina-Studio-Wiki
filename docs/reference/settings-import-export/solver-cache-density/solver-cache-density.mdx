# 穷举缓存精度

耗材档案会枚举当前所选耗材与层数可组合出的叠层配方，并将预测颜色索引到三维 Lab 颜色网格中。“穷举缓存精度”决定该网格的细分程度：档位越高，颜色接近但配方不同的组合越不容易落入同一个网格单元。

## 可选档位

提供 `64³`、`128³`、`256³`、`512³`、`1024³` 和 `2048³` 六个档位。未开启“允许自定义穷举数量”时，构建默认统一采用 `64³`。

调高档位可减少网格碰撞导致的候选配方合并，适合追求细腻色彩区分的耗材档案；最终可达色域与色彩准确度仍由耗材本身的实测光学数据决定。

## 缓存机制与资源限制

缓存采用稀疏存储结构，仅记录物理可达的有效配方，无需分配完整的三维网格空间。每个精度档位各自生成独立的缓存文件，切换档位不会覆盖其他档位已建好的缓存。

缓存构建受资源安全预算保护：

- 小规模组合直接采用精确模式计算。
- 大规模组合会预先评估内存占用与配方总数。
- 超出安全预算时，构建会自动停止，并提示减少耗材数量或叠层层数。

首次在某个新档位下构建缓存时耗时较长，建好后再次使用即可直接读取；查色耗时也会随档位提升略有增加。

:::note[适用范围]
该设置仅作用于耗材档案求解器。传统 LUT 直接读取已有的实测颜色与配方，不使用此处的网格精度。
:::
