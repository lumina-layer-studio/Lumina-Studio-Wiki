# 穷举缓存精度

耗材档案会枚举当前耗材与层数能够形成的配方，并把预测颜色放入 Lab 颜色网格。穷举缓存精度决定这个网格有多细：
网格越细，颜色相近但配方不同的结果越不容易落入同一个格子。

## 档位

可选档位为 `64³`、`128³`、`256³`、`512³`、`1024³` 和 `2048³`。未开启“允许自定义穷举数量”时，构建统一使用
`64³`。

较高档位主要减少网格碰撞造成的候选配方丢失，适合需要更细颜色匹配的耗材档案。它不会增加物理上不存在的颜色，
也不能修正不准确的耗材测量数据。

## 缓存与资源

缓存采用稀疏存储，只保存实际可达的配方，而不是分配完整的三维网格。每个分辨率会建立独立缓存；改变档位不会覆盖
已经存在的其他档位缓存。

构建仍受安全预算约束：

- 小规模组合会使用精确模式；
- 大规模组合按内存估算和配方总数检查；
- 超出当前安全预算时，构建会停止并提示减少耗材数或层数，而不是继续占满系统资源。

第一次使用某个新档位时需要重新构建，所以耗时会明显高于读取已有缓存。查色速度也可能随档位略有增加。

:::note
该设置只用于耗材档案求解器。传统 LUT 直接读取已有颜色与配方，不使用这里的网格精度。
:::
