# 底板层高修改器

开启“底板层高修改器”后，软件会在生成的 3MF 中写入可变层高配置：纯底板部分使用较粗层高以缩短打印耗时，上方的彩色图案区域仍保持原有的精细层高。

## 层高写入规则

底板层高取当前喷嘴直径的一半：

| 喷嘴 | 底板层高 |
| --- | --- |
| 0.2 mm | 0.1 mm |
| 0.4 mm | 0.2 mm |

Lumina Studio 会将该区间写入 3MF 的 `layer_config_ranges` 配置中。切片软件读取工程后，即可在同一对象内为底板层与显色层分别应用对应层高。

## 适用范围

- 目前仅支持 Bambu 系切片器导出，切换为其他切片器时该开关会自动隐藏。
- 双面模型需要同时兼顾正反两面的结构与显色层顺序，生成时会自动跳过该修改器。
- 切换开关或更改喷嘴尺寸后，需重新生成 3MF。

正式打印前，建议在切片预览中检查底板层与显色层的过渡层高及耗材匹配情况。

关于首层厚度、显色层与底板层的配合关系，参见[底色层层高为什么要匹配](../../../knowledge/base-color-layer-height/base-color-layer-height.mdx)。
