# 加载趣味消息

开启“加载趣味消息”后，预览、生成等等待界面会轮换显示简短提示。关闭后仍会显示正常的加载状态，只是不再显示
这些趣味文案。

<img
  src={require('./assets/01-witty-loading.webp').default}
  alt="加载趣味消息开关"
/>

该开关只改变等待界面的文字：

- 不改变图片处理算法；
- 不改变模型或颜色结果；
- 不改变任务的计算速度；
- 不影响错误提示和进度状态。

设置保存在当前浏览器的本地设置中，刷新页面后仍会保留。更换浏览器、清除站点数据或使用另一台设备时，需要重新
设置。
