# 加载趣味消息

开启“加载趣味消息”后，预览、生成等任务等待界面会轮播简短的趣味提示语；关闭后仅显示常规的加载进度与状态。

<img
  src={require('./assets/01-witty-loading.webp').default}
  alt="加载趣味消息开关"
/>

该开关仅控制等待界面的展示文案，不影响图像处理算法、配色与三维模型结果、任务计算速度，也不会隐藏进度状态或错误提示。

偏好保存在当前本地存储中，刷新页面后依然保留；更换浏览器、清除站点数据或切换设备后可重新设置。
