# 3MF 项目模板

“3MF 项目模板”支持导入你在切片软件中调好的单盘 3MF 项目，直接复用其中的耗材与全局工艺参数。保存模板时，请确保其使用的切片软件、打印机型号和喷嘴直径与 Lumina 当前所选设备一致。

## 导入与启用

1. 在切片软件中确认打印机、喷嘴、打印板、耗材与工艺设置无误后，将单盘项目保存为 3MF。
2. 打开 Lumina 系统设置，找到“3MF 项目模板”。
3. 选择该 3MF 文件，按需填写便于识别的模板名称并完成导入。
4. 在模板列表中选中该模板，返回“图像转换”页面即可按模板生成模型。

导入后可在列表中核对识别出的设备摘要与耗材槽数量；导出模型时，Lumina 仍会自动校验模板与当前设备及生成流程的兼容性。

## 保留与覆盖的参数

| 设置类别 | 处理方式 |
| --- | --- |
| 速度、加速度、温度、流量、回抽、冷却 | 沿用模板中的工艺参数 |
| 材料槽 | 结合当前生成流程保留或整理，导出后请在切片软件中核对映射 |
| 层高、线宽、墙层数、顶底壳层、填充率 | 由 Lumina 按显色建模要求自动覆盖 |
| 擦料塔 | 按“擦料塔自动摆放”开关状态处理 |
| 模板原模型、对象级参数、局部修改器 | 不带入新生成的作品 |

模板仅复用全局耗材与工艺配置；原项目中的三维模型与局部修改器不会附着到新作品上，与显色成图直接相关的层高、线宽和壳层参数则由 Lumina 统一接管。

## 支持的导出流程

模板当前适用于普通图像、矢量、耗材档案、大画幅分块和模型贴图导出；批量、拼图、校准板和色块生成使用内置配置。若提示模板与当前打印机、喷嘴或切片软件不匹配，请切换对应的设备选项或重新导入匹配的 3MF 模板。

## 恢复内置配置与删除模板

在列表中切回内置配置即可停用自定义模板。删除已存模板前建议先备份原始 3MF 文件；若原引用的模板已被移除，重新选择有效模板或切回内置配置即可。

在切片软件中打开导出的工程后，建议核对实际耗材映射、打印板类型、显色层顺序与擦料塔位置，完成切片检查后再发起打印。
