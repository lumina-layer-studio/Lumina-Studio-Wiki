# 缓存管理

点击“清除缓存”可删除后台运行期间产生的临时文件、预览模型与转换会话数据，并在完成后显示清理的文件数量与释放的存储空间。

## 清理范围

执行后，Lumina Studio 会依次清理：

- 文件注册表记录的临时文件。
- 当前活动转换会话及其关联临时文件。
- 输出目录 `temp` 与 `models` 下的运行时文件。
- 输出目录顶层可清理的 3MF、GLB、PNG、JPG 和 TXT 文件。

受保护的统计数据与缓存 LUT 会被保留；耗材库、导入的正式 LUT 源文件以及软件系统设置也不会被清理。

## 清理后的影响

清理会一并移除当前正在使用的预览会话，页面上已生成的预览或下载链接将随之失效。继续操作时，请重新上传素材或重新预览，再导出新的工程文件。

由于该操作会重置当前的临时工作状态，建议在长时间运行后回收磁盘空间、会话状态卡死，或按故障排查步骤指引时执行。

生成与下载异常的常规排查顺序参见[网页端生成与下载故障排查](../../../knowledge/web-generation-troubleshooting/web-generation-troubleshooting.mdx)。
