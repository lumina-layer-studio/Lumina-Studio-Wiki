# 渐变自动换色

使用耗材档案将连续渐变映射为有限叠层配方时，平滑过渡区可能会被切分成多条相近色带。开启“渐变自动换色”后，软件会在预览完成时自动识别这些渐变色带组，并将同组颜色统一替换为组内覆盖像素最多的代表色。

## 处理流程

1. 完成常规图像处理与耗材颜色匹配。
2. 分析预览结果中的渐变条带分组。
3. 选出每个分组内像素占比最高的代表色。
4. 批量应用替换并刷新 2D 与 3D 预览。

由于预览完成后会额外执行一次分组分析与批量替换，包含大面积渐变的图片呈现最终预览的时间会略微延长。

## 默认状态与手动微调

该选项默认关闭。保持关闭时，软件保留原始颜色匹配结果；你可在颜色工作站中逐组查看渐变识别结果并按需手动合并。自动换色与手动合并共用同一套分组逻辑，替换后仍可随时撤销或单独微调。

该功能仅合并同一渐变组内的相近色带，不会增加可用总色数，也不会改动渐变组以外的独立色块。
