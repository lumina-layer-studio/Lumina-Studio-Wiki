# 面板显示、折叠、拖动与重置

“图像转换”中的“核心设置”与“创意中心”由多个可移动面板组成。面板既可吸附停靠在工作区左右两侧，也可临时拖到画布上方自由浮动，为中央 3D 视图腾出更大视野。

## 面板控件菜单

点击顶栏的“面板控件”，菜单仅列出**当前一级页面与当前二级页面**所包含的面板：

- 面板名称旁的蓝色圆点表示该面板当前处于显示状态。
- 点击面板名称即可隐藏或重新显示对应面板。
- 切换到其他二级页面时，菜单列表会随之动态更新。
- “颜色调整”采用全屏工作台布局，不包含可停靠的浮动面板。

隐藏面板仅收起界面显示，不会关闭对应功能或清空已设参数；重新勾选显示后，原有数值照常保留。

## 拖动与边缘停靠

按住面板标题栏即可拖动位置。将面板拖至工作区左边缘或右边缘松开时，面板会自动吸附并插入到对应一侧的面板栈中；同侧面板会自动上下排布，无需手动对齐。

调整窗口大小后，软件会自动重算当前页面的面板位置；若自由浮动的面板超出可视边界，会自动归位到左侧停靠栏，确保所有控件始终可见可控。

## 折叠与展开

点击标题栏右侧的三角图标可折叠或展开面板，此外也支持：

- 双击面板标题栏。
- 将键盘焦点移至标题栏后按 `Enter` 键。

折叠后仅收起面板内容区，标题栏与停靠位置保持不变。拖动面板期间，软件会临时按折叠高度计算落点，松开鼠标后再恢复原有的展开状态与内容高度。

## 布局记忆

面板的坐标、左右停靠归属、折叠状态与显示开关均保存在当前浏览器的本地存储中。这些界面偏好不属于工程参数，不会写入分享卡、JSON 或 3MF，也不会跨设备同步。

软件版本升级后，已移除旧面板的历史记录会自动清理，新增面板则按当前版本的默认位置摆放。

## 重置布局

点击“重置布局”可将所有面板一键恢复至默认位置、默认显示状态与默认折叠状态，且不影响当前工作内容：

- 已上传的图片与生成的预览保持不变。
- LUT、耗材档案与结构参数保持不变。
- 颜色替换记录与自定义叠层配方保持不变。
- 系统设置中的打印机、喷嘴与切片软件配置保持不变。

当面板出现遮挡重叠、移出视野或停靠顺序杂乱时，可随时放心使用“重置布局”整理界面。
