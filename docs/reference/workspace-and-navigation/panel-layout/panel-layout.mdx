# 面板显示、折叠、拖动与重置

图像转换的核心设置和高级功能由多个浮动面板组成。面板可以在左右两侧停靠，也可以临时拖到工作区中，
用来给 3D 画面或某个参数组腾出空间。

## 面板控件

点击顶栏的“面板控件”后，菜单只列出**当前一级页面和当前二级页面**实际使用的面板：

- 蓝色圆点表示面板正在显示；
- 点击面板名称可以隐藏或重新显示；
- 切换到另一个二级页面后，菜单内容也会随之改变；
- 颜色调整页面没有停靠面板时，该按钮不会提供无效开关。

隐藏面板不会关闭其中的功能，也不会清除参数。它只是不再渲染这块面板；再次显示后，原值仍在。

## 拖动和停靠

按住面板标题栏拖动。拖到工作区左侧或右侧时，面板会吸附到对应边缘，并按放置位置进入该侧面板栈。
同一侧的面板会自动避让，不需要逐个手动对齐。

在窗口尺寸变化后，软件会重新计算当前页面的面板位置。无法安全保留在画面中的自由浮动面板会回到左侧，
防止控件落到可视区域外。

## 折叠和展开

标题栏右侧的三角按钮用于折叠或展开。也可以：

- 双击标题栏；
- 先让标题栏获得键盘焦点，再按 `Enter`。

折叠只收起内容区，标题栏和面板位置仍保留。拖动中的面板会暂时按折叠高度计算，放下以后恢复原来的展开
状态和实际高度。

## 布局记忆

面板的位置、左右停靠、折叠状态和显示状态保存在当前浏览器的本地存储中。它们不是项目参数，不进入
分享卡、JSON 或 3MF，也不会同步到另一台电脑。

软件升级后若某个旧面板已经删除，旧记录会被丢弃；新增面板会使用当前版本的默认位置。

## 重置布局

“重置布局”会恢复所有面板的默认位置、默认显示状态和默认折叠状态。它不会：

- 删除图片或预览；
- 修改 LUT、耗材或结构参数；
- 清空颜色替换和自定义配方；
- 重置设置页面中的机器、喷嘴或切片软件。

因此，面板重叠、被拖出屏幕或左右顺序混乱时，可以直接重置布局，不必担心转换任务被清空。
