# 导航、语言、主题与连接状态

Lumina Studio 的顶栏分成三部分：软件标识、功能导航和全局状态。切换页面不会自动开始预览、生成或保存，
但正在编辑的页面状态通常会继续保留。

## 一级页面

| 页面 | 主要用途 |
| --- | --- |
| 图像转换 | 上传图片，选择颜色来源和结构参数，预览并生成 3MF |
| LUT 管理 | 管理 LUT、制作校准板、从照片提取 LUT、分析和比较 LUT |
| 耗材管理 | 管理耗材档案、生成或提取梯度卡、查询叠层配方 |
| 图像转矢量 | 把位图转换成可继续编辑或发送到图像转换页面的 SVG |
| 创意工坊 | 浏览和使用创意模块 |
| 设置 | 选择机器、喷嘴和切片软件，并管理计算、缓存与界面选项 |

“LUT 管理”和“耗材管理”下面还有各自的二级页面。再次进入这两个一级页面时，软件会保留当前有效的二级
页面；若当前记录已经失效，则回到该模块的默认页面。

## 图像转换的三个二级页面

- **核心设置：** 图片、来源、尺寸、底板、模式、常用高级选项和操作栏；
- **颜色调整：** 2D 预览、选区、颜色替换、配方和颜色分组；
- **创意中心：** 浮雕、外轮廓、透明镀层、挂件环、磁铁槽和拼图等结构功能。掐丝珐琅入口目前隐藏。

核心设置和创意中心使用可移动面板；颜色调整由全屏颜色工作台接管，因此顶栏中的“面板控件”只会列出
当前页面实际存在的面板。详细行为见[面板显示、折叠、拖动与重置](../panel-layout/panel-layout.mdx)。

## 语言与主题

在“设置 → 常规 → 界面语言 / Language”中选择简体中文或 English。切换后，界面文字改用所选语言。

点击右上角“更多选项”，使用“深色模式”切换浅色和深色主题。主题只改变显示，不改变图片、配方、模型或导出文件。界面布局较窄时，
部分文字标签会收起，只保留图标；一级和二级导航可以横向滚动。

## 连接状态

打开右上角“更多选项”，底部会显示软件与后台的连接状态：

- **绿色：** 最近一次连接检查正常；
- **红色：** 最近一次检查失败或后端不可达；
- **检查中：** 页面尚未收到首次检查结果。

软件在页面载入时立即检查一次，之后每 5 秒重新检查。绿色只证明前后端当前可以通信，不代表某个 LUT、
图片、临时会话或生成任务一定有效。连接异常时，菜单按钮会出现红点；先确认 Lumina 后台仍在运行，再重试当前操作。

## 更新公告

启动后若存在尚未读过的新公告，软件会显示最近的更新记录。直接关闭或选择“稍后再看”只结束本次显示；选择“知道了”
后，当前最新公告版本会记录在本机浏览器存储中。公告阅读状态不会上传，也不会修改转换设置。

## 页面切换会保留什么

界面会保留当前控件值、已选择的页面和面板布局；设备设置还会以尽力而为的方式与后端同步。临时预览、
下载链接和文件会话仍有生命周期，不能把“切换回来还能看到”当作永久保存。需要留档时，应导出分享卡、
JSON、3MF 以及实际使用的 LUT 或耗材档案。
