# 导航、语言、主题与连接状态

Lumina Studio 顶栏由软件标识、工作区导航与全局状态控件三部分组成。切换页面时不会自动触发预览、生成或保存，当前页面已填写的参数与编辑状态会继续保留。

## 一级页面

| 页面 | 主要用途 |
| --- | --- |
| 图像转换 | 上传素材，配置颜色来源与模型结构，预览并导出 3MF |
| LUT 管理 | 管理 LUT、制作校准板、从照片提取 LUT、分析与对比 LUT |
| 耗材管理 | 管理耗材档案、生成或提取梯度卡、查询叠层配方 |
| 图像转矢量 | 将位图转换为可继续编辑或直接发送至“图像转换”的 SVG |
| 创意工坊 | 浏览并使用扩展创意模块 |
| 设置 | 配置打印机、喷嘴与切片软件，管理计算精度、缓存与界面选项 |

“LUT 管理”与“耗材管理”各自包含下属二级页面。再次切回这两个模块时，软件会自动恢复上次停留的有效二级页面；若原记录已失效，则回到该模块的默认子页面。

## “图像转换”的三个二级页面

- **核心设置：** 素材上传、颜色来源、物理尺寸、底板、模式、常用高级选项与操作栏。
- **颜色调整：** 2D 预览、选区工具、颜色替换、叠层配方与渐变分组。
- **创意中心：** 浮雕、外轮廓、透明镀层、挂件环、冰箱贴磁铁槽与拼图等结构功能（掐丝珐琅入口当前隐藏）。

“核心设置”与“创意中心”采用可停靠的浮动面板布局，“颜色调整”则采用全屏颜色工作台布局，因此顶栏的“面板控件”仅列出当前页面实际包含的面板。面板操作详见[面板显示、折叠、拖动与重置](../panel-layout/panel-layout.mdx)。

## 语言与主题

在“设置 → 常规 → 界面语言 / Language”中可切换简体中文或 English。

点击右上角“更多选项”，可通过“深色模式”切换浅色或深色外观主题；切换主题仅改变界面配色，不影响图片、配方、模型与导出文件。窗口宽度较窄时，部分按钮文字会自动收起为图标，一级与二级导航栏均支持横向滚动。

## 后台连接状态

点击右上角“更多选项”，菜单底部会显示前端与本地后台服务的连接状态：

- **绿色：** 最近一次连接检测正常。
- **红色：** 最近一次检测失败或后台服务未响应。
- **检查中：** 页面刚载入，尚未收到首次检测结果。

页面载入时会立即检测一次，随后每 5 秒轮询更新。当连接异常时，“更多选项”图标右上角会亮起红点；请先确认 Lumina 后台进程正在运行，待状态恢复绿色后再重试操作。

## 更新公告

启动软件时，若存在未读的新版更新公告，界面会自动弹出近期更新记录。直接关闭弹窗或点击“稍后再看”仅在本次会话中收起公告；点击“知道了”后，最新已读公告版本号会记录在本地浏览器存储中，后续不再重复弹出。

## 页面切换时保留的数据

在页面间切换会保留当前控件数值、所选子页面与面板停靠布局，设备设置也会同步写入后台配置。临时预览、下载链接与会话缓存文件仅在当前会话周期内有效；需要长期留存工程时，请及时导出分享卡、JSON、3MF 以及对应的原图、LUT 或耗材档案。
