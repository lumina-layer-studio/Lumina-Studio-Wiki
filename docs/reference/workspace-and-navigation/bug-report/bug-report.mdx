# 反馈问题与诊断信息

遇到生成失败、画面异常或操作结果不符合预期时，可以从顶栏打开“反馈问题”。软件会收集当前操作资料，
点击发送后提交到官方问题收集服务，无需配置个人发件邮箱。

本文按截至 2026 年 10 月 19 日的代码核对。

## 先复现，再打开反馈窗口

保留出问题的图片、配方和设置，完成一次能触发问题的操作后再打开反馈。窗口会收集当时的上下文；
如果打开后又换了图片或重做了操作，应使用窗口提供的重新收集操作更新资料。

问题描述中写清楚：

1. 使用哪种输入和颜色来源，例如 SVG + 耗材档案；
2. 按什么顺序操作，在哪一步开始异常；
3. 原本希望看到什么，实际出现了什么；
4. 是否每次都能复现，还是只在某个文件上发生。

联系邮箱是可选项，供维护者联系，不是发送反馈必须配置的邮箱账号。可以另附 PNG、JPG、WebP 或 GIF 截图。
文件不符合要求时，按窗口中的提示调整。

## 会附带哪些资料

报告会根据当前任务收集转换参数、设备选择、最近操作、错误记录，以及能取得的原图、SVG、模型、LUT、耗材档案和生成结果。
内容取决于当前会话实际拥有的文件，并非每一份反馈都有全部附件。

这些资料用于让开发者重现问题。发送前请检查窗口中的上下文与附件提示，尤其确认原图、客户设计和模型是否允许发送。
截图中的账号、通知或其他私人信息，也需要自行检查。

## 工单创建和上传完成是两件事

提交后保存工单编号，并继续看窗口里的上传状态：

| 界面状态 | 含义与操作 |
| --- | --- |
| 正在提交或等待上传 | 仍在处理，等待最终结果 |
| 上传成功 | 报告已交给收集服务；不等于问题已经修复 |
| 上传失败 | 使用“重试”再次上传，并观察新的结果 |
| 附件未完整收集或部分附件未发送 | 按提示检查缺少的资料，必要时重新收集 |
| 上传不可用 | 保留工单编号，使用窗口提供的备用报告和联系入口 |

不要只看到工单编号就关闭窗口。若上传还未完成，维护者可能暂时没有收到完整报告。

## 发送失败后怎么办

先检查网络并使用重试。若仍失败，复制窗口提供的备用报告，与工单编号、复现步骤一起交给维护者。
系统邮件或 QQ 邮箱等备用入口只在相应失败流程中使用，正常提交无需先配置它们。

原图已经关闭、会话被替换或文件没有成功收集时，重新打开相关任务并收集资料，比重复发送同一份不完整描述更有效。
