# 图像转矢量

“图像转矢量”可将 PNG、JPEG、WebP 或 BMP 位图转换为由封闭路径与有限调色板组成的 SVG 文件。该模块非常适合图标、徽标、像素画、平涂插画及边界清晰的设计稿；实景照片同样支持转换，通常会生成更多色阶与路径。

## 操作流程

1. 点击上传区域，选择一张支持的位图文件。
2. 首次转换建议保持默认参数，点击“开始矢量化”。
3. 在预览对比区同步缩放、拖拽原图与 SVG，检查轮廓转折、细线还原度与色块交界。
4. 点击“下载 SVG”将矢量文件保存到本地，或点击“发送到图像转换”继续生成 3D 打印模型。

转换进行时按钮会显示“正在矢量化…”，再次点击即可取消当前任务。重新上传图片会自动清空上一轮结果。

## 处理管线与结果摘要

矢量化依次经历分辨率控制与 Mean Shift 平滑、颜色分割、边界提取、轮廓装配、贝塞尔曲线拟合、轮廓追踪及 SVG 导出七个阶段，面板中的各组参数分别对应上述不同环节。

生成完成后，结果摘要会列出四项关键信息：

- **形状数**：最终 SVG 中保留的封闭路径总数；
- **颜色数**：自动检测或手动指定后实际采用的调色板大小；
- **宽 × 高**：源图像的原始像素尺寸；
- **调色板**：直观展示前 16 种颜色色卡，超出部分以 `+N` 汇总显示。

<img
  src={require('./assets/02-result-summary.webp').default}
  alt="矢量化结果的形状数、颜色数、尺寸和调色板"
/>

形状数越多，保留的细小色块越丰富，同时 SVG 结构也更复杂。微调参数时建议直接放大对比画面边缘与色彩还原度，在细节表现与路径简洁度之间取得平衡。

## 下载或送入图像转换

<img
  src={require('./assets/03-result-actions.webp').default}
  alt="发送到图像转换和下载 SVG 按钮"
/>

点击“发送到图像转换”会将刚生成的 SVG 直接作为原生矢量源载入“图像转换”页面，并保留 Lumina 矢量化标记，方便后续按原生矢量几何流程建模。

生成的临时下载链接保留时长为 20 分钟，离开当前模块也会清空页面状态与预览缓存；需要留存的 SVG 文件请及时下载保存。
