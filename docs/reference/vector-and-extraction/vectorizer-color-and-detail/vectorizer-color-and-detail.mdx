# 颜色数量、平滑度与细节等级

基础参数决定了矢量化结果保留多少种颜色，以及轮廓路径在“贴合原图细节”与“线条简洁流畅”之间的平衡点。

## 颜色数量

设为“自动”（参数值 `0`）时，引擎会根据画面内容自动测算合适的调色板规模，并在结果摘要中列出最终采用的颜色数。

切换为“手动”后，可在 `2–256` 之间指定颜色数量。该数值对应颜色分割阶段的 K-Means 调色板大小（同一颜色可能分布在多个不相连区域，因此不同于最终 SVG 的形状数）：

- **调小数值**：合并相近色阶，色块更干净整洁；
- **调大数值**：保留更多渐变过渡与局部色差，同时也会产生更多细小色块。

处理配色明确的图标、徽标或像素画时，可直接按原图色数手动填写；不确定原图色数时，优先使用“自动”即可。

## 平滑度

取值范围为 `0–1`，默认值为 `0.5`，用于控制轮廓节点的抽稀与平滑力度：

- **靠近 `0`**：尽量保留原始折角与微小起伏，生成的路径节点较多；
- **靠近 `1`**：线条更顺滑、路径更精简，但锐利转角和细微凹凸会被适度柔化。

若画面中存在较多细碎杂色块，仅靠提高平滑度无法消除色块本身，建议配合[图像预处理](../vectorizer-preprocessing/vectorizer-preprocessing.mdx)和[曲线拟合与区域过滤](../vectorizer-curve-and-filtering/vectorizer-curve-and-filtering.mdx)一并调整。

## 细节等级

“细节等级”默认关闭（参数值 `-1`），此时下方各组高级参数彼此独立生效，适合按阶段精细微调。

开启后取值范围为 `0–1`，初始值为 `0.5`。作为全局细节联动滑块，它会同步调节底层多项分割与拟合参数：

- **调低数值**：整体偏向概括的大色块与简洁路径；
- **调高数值**：优先保留细微边缘与小型结构。

调节“细节等级”不会改变“颜色数量”，也不会覆盖高级面板中显示的数值。如需单独锁定并复现某一阶段的高级参数，请先将“细节等级”关闭。
