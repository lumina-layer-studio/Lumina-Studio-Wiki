# 曲线拟合与区域过滤

颜色分割划定色块区域后，引擎会对边界执行点位简化、贝塞尔曲线拟合与 Potrace 轮廓追踪；区域过滤参数则负责按面积合并或剔除零碎色块、孤立小轮廓与细微孔洞。

## 曲线拟合

  src={require('./assets/01-curve-fitting.webp').default}
  alt="图像转矢量的曲线拟合参数"
/>

### 曲线拟合误差

取值范围为 `0.1–5 px`，默认值为 `0.8 px`，定义 Schneider 贝塞尔曲线拟合允许的最大像素偏差：

- **调小数值**：曲线紧密贴合原始像素边界，生成的控制点更多；
- **调大数值**：控制点减少、曲线更舒展平滑，但细小转折会被略过。

### 轮廓简化强度

取值范围为 `0–2`，默认值为 `0.45`。调高后会在进入贝塞尔拟合之前先行精简原始轮廓点，从源头降低路径复杂度；“曲线拟合误差”则约束后续拟合阶段偏离轮廓的幅度，两者配合决定最终节点密度。

### 线段合并容差

取值范围为 `0–0.5`，默认值为 `0.05`。当相邻近线性贝塞尔段的控制点偏差低于该容差时，系统会将其合并为单一段，减少长直边上的多余节点；调得过高时，轻微的折线转折也会被拉直。

## 区域过滤

<img
  src={require('./assets/02-region-filtering.webp').default}
  alt="图像转矢量的区域过滤参数"
/>

### 最小区域面积与最大合并色差

- **最小区域面积**：取值范围为 `0–1000 px²`，默认值为 `50 px²`。颜色分割阶段面积小于该阈值的色块，会优先尝试并入相邻区域。
- **最大合并色差**：取值范围为 `0–500`，默认值为 `200`（单位为 LAB ΔE²），用于限制上述合并允许的最大颜色差异。数值越大，反差更明显的小碎块也能被邻近色块吸收。

### 最小轮廓面积

取值范围为 `0–500 px²`，默认值为 `10 px²`。轮廓追踪完成后，面积仍小于该值的独立悬浮形状会被直接剔除。该步骤在“最小区域面积”合并之后执行，专门清理未能并入邻区的零星残片。

### 最小孔洞面积

取值范围为 `0–100 px²`，默认值为 `4 px²`。色块内部面积小于该值的细小镂空会被自动填平；大于或等于该值的孔洞则保留为空白镂空路径。

排查画面碎片时，可先放大观察目标属于“紧贴邻区的分割小色块”“孤立的小轮廓”还是“色块内部的针孔镂空”，再针对性上调对应阈值。
