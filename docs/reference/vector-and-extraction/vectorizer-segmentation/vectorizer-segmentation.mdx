# 超像素分割与抗锯齿检测

多色矢量化会先通过 SLIC 算法将画面划分为局部超像素，再结合颜色与边缘梯度逐轮细化色块归属。本组参数直接决定相邻色块边界的贴合精度与抗锯齿过渡像素的归并方式。

## 超像素区域大小

取值范围为 `5–100`，默认值为 `20`，用于设定初始 SLIC 超像素的目标尺寸：

- **调小数值**：生成更密集的小超像素，能够捕捉更纤细的局部造型变化；
- **调大数值**：生成更少、更大的超像素，计算更快，色块概括感更强。

后续的颜色合并、边界细化与区域过滤仍会进一步重组色块，因此该数值并非最终 SVG 形状的固定尺寸。

## 边缘敏感度

取值范围为 `0–1`，默认值为 `0.8`，控制 SLIC 遇到明显颜色边界时放宽空间规则约束的程度：

- **调高数值**：更积极地贴合颜色边缘收束分界；
- **调低数值**：优先保持超像素网格的空间匀称度，生成的色块边界更舒展。

## 边界细化次数

取值范围为 `0–20`，默认值为 `6`。每一轮迭代都会参考邻域标签重新修正色块边界：调高次数可让边界更紧贴原图轮廓，同时相应延长处理时间；设为 `0` 则跳过边界细化阶段。

## 抗锯齿检测与容差

开启“抗锯齿检测”后，引擎会自动识别两种颜色交界处的半透明或混合过渡像素，避免将抗锯齿边缘拆成一圈零碎的杂色细带。

- **推荐开启**：边缘柔滑的插画、图标、徽标与文字素材；
- **建议关闭**：需要严格保留逐像素阶梯锯齿感的像素画（Pixel Art）。

下方的“抗锯齿容差”取值范围为 `1–50`，默认值为 `10`（单位为 LAB ΔE）。数值越大，允许归入混合过渡边缘的色差范围越宽。
