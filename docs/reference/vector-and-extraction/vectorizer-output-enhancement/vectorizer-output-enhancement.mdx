# 描边、薄线与覆盖修复

“输出增强”用于在轮廓生成阶段消除相邻色块拼接处的细微白缝，并强化对原图纤细线条的提取保留。

## 启用描边与描边宽度

开启“启用描边”后，每条 SVG 路径在输出填充色的同时会附带同色描边。描边宽度范围为 `0–20`，默认值为 `0.5`：

- **适度调大宽度**：让相邻路径边缘轻微重叠，消除浏览器缩放或渲染时常见的抗锯齿白缝；
- **宽度过大**：描边会向外扩张侵占邻近色块，导致细小结构变粗。

关闭“启用描边”后，“描边宽度”滑块随之隐藏，导出的 SVG 仅保留纯填充路径。

## 薄线检测半径

取值范围为 `0.5–10 px`，默认值为 `2.5 px`。引擎通过距离变换识别半径不超过该值的狭长线条，并在分割与拟合阶段优先保留其连通结构：

- **数值过小**：极细线条容易在平滑或过滤中断裂遗漏；
- **数值过大**：更多普通狭窄色块也会被当作细线特殊保留。

此处的 `px` 指内部工作分辨率下的像素半径，而非 3D 打印成品的毫米线宽。

## 启用覆盖修复与最小覆盖率

开启“启用覆盖修复”后，引擎会在轮廓追踪结束时检测整幅画布的像素覆盖比例。一旦实际覆盖率低于“最小覆盖率”，系统便会自动补齐路径间遗漏的空隙像素。

“最小覆盖率”取值范围为 `0–1`，默认值为 `0.998`。数值越接近 `1`，越容易触发缝隙修补。

该选项专门针对路径交界处的微米级漏白；若色块边界轮廓本身的走势不准确，请优先调整[超像素分割与抗锯齿检测](../vectorizer-segmentation/vectorizer-segmentation.mdx)或[曲线拟合与区域过滤](../vectorizer-curve-and-filtering/vectorizer-curve-and-filtering.mdx)中的参数。
