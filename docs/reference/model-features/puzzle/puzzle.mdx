# 拼图

拼图模式先根据作品的实体边界计算拼图布局，再按每一块的边界分别生成模型并组装为一个可下载的 3MF。
它不是在图片上覆盖几条装饰线。

## 风格与尺寸控制

- **规则拼图：** 使用整齐网格和一致的连接规律；
- **不规则拼图：** 允许边界偏移，可再调整“不规则强度”和“最小脖颈宽度”；
- **按块尺寸：** 输入平均块宽和平均块高，均为 5–200 mm；
- **按行列：** 输入 1–200 行和 1–200 列；
- **按总片数：** 输入 2–2000 片，软件根据作品比例求解网格。

目标值不是强制几何结果。透明剪影、不规则边界和最小结构限制可能使最终行列、片数或平均尺寸发生变化，
因此面板同时显示“目标”和“解析”结果。

## 连接器与编号

“经典风格”和“易切割风格”使用不同的连接器轮廓。易切割更偏向降低复杂边界，最终松紧仍受喷嘴、材料
收缩和切片补偿影响。

“显示编号”会在拼图工作流中提供块编号信息。“背面刻号”当前尚未写入导出几何，界面固定禁用，不能把
预览提示当作已具备的打印功能。

不规则拼图中的“不规则强度”范围为 0–1；“最小脖颈宽度”范围为 0.2–20 mm，用于限制连接处过细。
若求解器需要调整请求，会在“几何警告”中说明。

## 模式限制

批量模式下不能开启拼图。开启拼图还会关闭大画幅、挂件环和冰箱贴磁铁槽。生成前先完成普通预览，因为
拼图布局需要当前作品的实体蒙版和物理尺寸。
