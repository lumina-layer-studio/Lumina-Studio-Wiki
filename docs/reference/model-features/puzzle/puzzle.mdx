# 拼图

拼图模式会根据作品的实体边界规划切分布局，为每一块拼图分别生成实体几何，并组合输出为一份可直接下载的 3MF 工程。

## 风格与尺寸控制

- **规则拼图：** 采用整齐网格排布，连接扣规律一致。
- **不规则拼图：** 对分块边界做偏移变形，并可调节“不规则强度”与“最小脖颈宽度”。
- **按块尺寸：** 输入目标平均块宽和平均块高，范围均为 5–200 mm。
- **按行列：** 直接指定 1–200 行与 1–200 列。
- **按总片数：** 输入 2–2000 片的目标片数，软件按作品宽高比自动求解网格。

受透明剪影、不规则外轮廓和最小结构尺寸约束影响，实际生成的行列数、片数或平均尺寸可能与输入值略有差异，面板会同时显示“目标”和“解析”两组结果供核对。

## 连接器与编号

连接器提供“经典风格”和“易切割风格”两种轮廓，其中易切割风格简化了复杂转折。成品拼合松紧度同时受喷嘴直径、材料收缩率与切片补偿影响。

开启“显示编号”可在拼图工作流中查看分块编号。“背面刻号”功能目前暂未开放（界面开关固定禁用，导出几何中暂不包含刻号）。

在不规则拼图中，“不规则强度”范围为 0–1；“最小脖颈宽度”范围为 0.2–20 mm，用于防止连接颈过细易断。若求解器对局部结构做了安全修正，详情会列在“几何警告”中。

## 模式限制

批量模式下不可开启拼图；开启拼图会自动关闭大画幅、挂件环和冰箱贴磁铁槽。由于拼图排布依赖当前作品的实体蒙版与物理尺寸，请先完成一次普通预览，再配置并生成拼图。
