# 冰箱贴磁铁槽

冰箱贴模式会在模型底板内部切出一个或多个磁铁槽。开启后，结构模式会自动切换为单面，并同时关闭拼图、大画幅和挂件环。

## 预设与自定义尺寸

圆形预设提供 D6×2、D8×3、D10×3 和 D12×3 mm；矩形预设提供 10×5×1、15×5×2 和 20×10×2 mm。切换形状时会先加载该形状的默认预设；手动修改任一尺寸后，当前磁铁会自动变为“自定义”。

自定义参数范围：

- 圆形直径：1–50 mm
- 矩形宽、高：1–80 mm
- 厚度：0.5–3.1 mm
- 中心 X、Y：-999–999 mm

上述数值定义模型中的目标槽位尺寸。由于磁铁实物存在尺寸公差且不同耗材收缩率有别，正式打印前建议实测磁铁并打印小样验证装配余量。

## 多磁铁与自动布局

点击“添加磁铁”会新增一颗默认规格的圆形磁铁，并自动重排所有磁铁位置；点击“自动布局”会保留各磁铁现有尺寸，仅重新计算中心坐标；“删除当前磁铁”仅移除列表中选中的磁铁。

列表选中项与 3D 视图同步（共用同一个磁铁 ID），可通过中心 X、Y 精确微调位置；取消选中不会删除磁铁。

## 底板厚度自动补偿

软件会在最厚磁铁下方保留约 **0.4 mm** 的封底层，并按 **0.08 mm** 层高向上取整。当所需厚度高于当前底板设置时，底板会自动增厚（上限为 3.5 mm），面板中的“当前底板厚度”会实时显示补偿后的厚度。

导出 3MF 后，请在切片软件中逐层检查槽位顶部、封底厚度与边缘壁厚，确认磁铁槽未穿透正面显色层。
