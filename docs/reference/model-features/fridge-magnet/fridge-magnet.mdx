# 冰箱贴磁铁槽

冰箱贴模式会在底板内部切出一个或多个磁铁空腔。开启后，软件强制使用单面结构，并关闭拼图、大画幅和
挂件环，避免这些结构争用同一底板几何。

## 官方预设

圆形预设包括 D6×2、D8×3、D10×3 和 D12×3 mm；矩形预设包括 10×5×1、15×5×2 和
20×10×2 mm。切换形状时会先加载该形状的默认预设；手动修改任一尺寸后，当前磁铁会转为“自定义”。

自定义范围：

- 圆形直径：1–50 mm；
- 矩形宽、高：1–80 mm；
- 厚度：0.5–3.1 mm；
- 中心 X、Y：-999–999 mm。

这些数值描述模型中的目标空腔。真实磁铁存在尺寸公差，正式打印前应测量实物并用小样验证装配余量。

## 多磁铁与自动布局

“添加磁铁”会创建一个新的圆形默认磁铁，并自动重新排列所有磁铁；“自动布局”会保留当前尺寸，只重新
计算中心位置。“删除当前磁铁”只作用于列表中选中的磁铁。

列表选择与 3D 场景选择使用同一个磁铁 ID。中心 X、Y 可用于精确微调；清除选中不会删除磁铁。

## 底板厚度为何自动变大

软件会为最厚磁铁保留约 **0.4 mm** 的封底层，并按 **0.08 mm** 层高取整。所需底板厚度高于当前值
时，底板会自动增加，最高受 3.5 mm 安全范围限制。面板中的“当前底板厚度”显示联动后的结果。

生成后应在切片软件中逐层检查空腔顶部、封底厚度和磁铁边缘，确认槽没有穿透显色面。
