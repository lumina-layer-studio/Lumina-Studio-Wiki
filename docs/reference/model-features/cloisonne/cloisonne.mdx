# 掐丝珐琅（旧版资料）

:::warning[旧版功能说明]
当前版本已隐藏掐丝珐琅设置入口，旧工程中的已有配置仍会保留。以下参数与截图仅供包含该入口的旧版本参考。
:::

掐丝珐琅模式会沿颜色匹配后的色块边界提取线框，生成独立的 **Wire** 对象，并将结构模式切换为单面。该功能在旧版中处于实验阶段，遇到复杂图案或细碎边界时，线框可能无法完全闭合。

## 参数说明

- **金属丝宽度：** 0.2–1.2 mm，步进 0.1 mm，控制线框在水平面上的线宽。
- **金属丝高度：** 0.04–1.0 mm，步进 0.04 mm，控制 **Wire** 对象高出彩色表面的高度。

宽度过小可能低于喷嘴可稳定打印的最小线宽，过大则会遮挡相邻色块；适当增加高度能强化表面浮凸触感，但过高也会增大喷嘴空驶时的擦碰风险。

## 使用限制

- 与浮雕互斥，开启其中一项会自动关闭另一项。
- 矢量建模模式下该开关不可用。
- 预览中的 **Wire** 对象固定以金色显示以便区分，实际打印颜色由切片软件中的耗材映射决定。
- 修改参数后需重新生成 3MF。

在包含该入口的旧版本中使用时，建议导出后在切片软件中逐层检查 **Wire** 对象、对象列表及色块衔接，并先打印小尺寸样件验证效果。
