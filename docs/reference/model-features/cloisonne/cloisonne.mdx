# 掐丝珐琅（开发中）

掐丝珐琅模式从匹配后的颜色边界提取线框，生成独立的 **Wire** 对象，并把基础结构强制为单面。该功能
仍标记为开发中，部分边界和复杂图案可能得到不完整结果。

## 参数

- **金属丝宽度：** 0.2–1.2 mm，步进 0.1 mm。控制线框在平面方向的宽度；
- **金属丝高度：** 0.04–1.0 mm，步进 0.04 mm。控制 Wire 对象高出彩色区域的高度。

宽度过小可能低于喷嘴能够稳定表现的线宽，过大则会覆盖相邻颜色区域。高度增加会强化触感，但也会增加
喷嘴运动和表面碰撞风险。

## 限制

- 与浮雕互斥，开启任意一项会关闭另一项；
- 矢量建模模式当前禁用该开关；
- 当前 Wire 预览使用固定金色帮助识别，真实打印颜色仍取决于切片软件中的耗材映射；
- 修改参数后必须重新生成 3MF。

由于界面明确标记“开发中”，不要把该页视为稳定效果承诺。正式作品前请先检查 3D 预览、对象列表和逐层
切片，并用小尺寸样件验证。
