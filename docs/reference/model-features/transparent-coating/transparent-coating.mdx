# 透明镀层

透明镀层会在作品显色面外侧生成一个名为 **Coating** 的独立对象。导入切片软件后，将该对象映射到透明耗材，即可在画面外表面打印一层透明保护层。

## 镀层高度

可选高度为 **0.04、0.08、0.12 mm**，默认值为 **0.08 mm**。由于打印按整层堆叠，软件会将“镀层高度 ÷ 当前模型层高”四舍五入并至少保留 1 层，最终物理厚度等于**完整层数 × 当前模型层高**。

例如当模型层高为 0.08 mm 时，选择 0.04 mm 会生成 1 层（实际 0.08 mm），选择 0.12 mm 会生成 2 层（实际 0.16 mm）。需要精确控制物理厚度时，建议选择当前层高的整数倍。

镀层默认覆盖当前作品轮廓；同时开启外轮廓时，覆盖范围也会同步扩展至外轮廓边缘。

## 为什么切片后看不到镀层

**Coating** 生成在模型底面外侧，刚导入切片软件时可能位于打印板平面下方——此时对象列表中虽能看到该对象，但切片器会忽略热床以下的部分。

导入后请选中整个模型组合，执行“放置到热床”或“自动摆放”再重新切片，随后在首层预览中确认透明耗材走线已正常生成。

日常打印常搭配透明 PETG 等耗材。不同材料组合的打印温度与层间结合力存在差异，正式打印前建议先打小样验证结合效果。
