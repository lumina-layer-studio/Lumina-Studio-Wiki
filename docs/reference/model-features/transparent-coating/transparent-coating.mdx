# 透明镀层

透明镀层会在作品显色面的外侧生成一个名为 **Coating** 的独立对象。它不会自动获得真实透明材质；导入
切片软件后仍要把该对象映射到准备使用的透明耗材。

## 镀层高度

界面提供 **0.04、0.08、0.12 mm**，默认值为 **0.08 mm**。生成引擎不会生成半层，而是用“镀层高度 ÷
当前模型层高”计算层数、四舍五入后至少保留一层。最终物理厚度等于“完整层数 × 当前模型层高”，因此界面
数值是请求值，不保证原样成为切片后的实际厚度。

例如当前模型层高为 0.08 mm 时，0.04 mm 会保留为一层，即实际 0.08 mm；0.12 mm 会取为两层，即实际
0.16 mm。需要准确厚度时，应让请求值与当前层高的整数倍一致。

镀层覆盖当前作品轮廓。若同时启用外轮廓，覆盖范围也会扩展到外轮廓边缘。

## 为什么切片后看不到

Coating 生成在模型底面外侧，刚导入切片软件时可能位于打印板下方。此时对象列表仍能看到它，但切片器会
忽略位于热床以下的部分。

选中整个模型后执行“放置到热床”或“自动摆放”，再重新切片。然后确认第一层出现透明耗材路径。

透明 PETG 是常见选择，但不是强制品牌或材料。不同材料组合可能需要不同温度，并可能影响层间结合，正式
作品前应先打印小样。
