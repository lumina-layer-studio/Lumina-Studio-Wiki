# 外轮廓

外轮廓会沿作品的实体边界向外扩展，生成一圈独立的描边几何，适用于强化剪影轮廓、为不规则作品加框或增强挂件边缘强度。

## 外轮廓宽度

可调范围为 **0.5–10 mm**，步进 **0.5 mm**，表示从原始边界向外扩展的距离。调大宽度会填平狭窄凹槽并使细小转角更圆润；处理复杂剪影时，建议结合 3D 预览检查整体外形。

轮廓边界提取自当前有效的实体或矢量几何：带透明背景的位图按透明通道形成剪影，SVG 则使用解析后的矢量边界。若素材没有有效边界，生成阶段将自动跳过外轮廓。

## 与其他结构的配合

- 开启透明镀层时，外轮廓会同步向下延伸覆盖镀层厚度，使边缘保持齐平。
- 外轮廓可与分离底板同时启用，两者在 3MF 中各自作为独立对象保存。
- 修改外轮廓宽度后需重新生成 3MF。

导入切片软件后，可在对象列表中确认外轮廓对象已生成，并切片检查细边、凹角与首层走线。若原图边缘带有半透明杂像素，建议先清理背景再生成，以获得干净利落的外圈。
