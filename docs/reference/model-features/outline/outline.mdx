# 外轮廓

外轮廓会沿作品的实体边界向外生成一圈独立几何。它适合加强剪影、给不规则作品增加边框，或为挂件边缘
预留更明显的结构。

## 外轮廓宽度

可设置 **0.5–10 mm**，步进为 **0.5 mm**。宽度描述从原边界向外扩展的距离，不是线条直径。数值增大
会吞并狭小凹槽并圆化细小转角，因此复杂剪影不应只看正面预览，还要检查模型外形。

轮廓边界来自当前有效的实体或矢量几何。带透明背景的栅格图片通常依照透明区域形成剪影；SVG 则使用解析
后的矢量边界。没有可用边界时，生成阶段可能跳过空轮廓。

## 与其他结构联动

- 开启透明镀层时，轮廓会向下延伸覆盖镀层厚度，避免边缘出现高度断层；
- 轮廓与分离底板可以同时使用，但会作为不同对象出现在 3MF 中；
- 修改轮廓宽度后，旧 3MF 不会自动更新，必须重新生成。

生成后在切片软件的对象列表中确认轮廓对象存在，再切片检查细边、凹角和首层路径。对于边界含有大量半透明
像素的素材，建议先清理背景，避免得到意外的外圈。
