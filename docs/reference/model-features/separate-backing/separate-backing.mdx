# 分离底板

“分离底板”决定底板网格是并入底色对象，还是作为独立对象写入导出的 3MF，同时保持底板厚度与耗材归属不变。开启后，符合条件的单面作品还可通过“背板输出”将模型与背板分别保存为独立工程。

此项默认关闭。

## 控件位置

1. 进入“图像转换”。
2. 打开“核心设置”中的“高级设置”。
3. 找到“分离底板”。

## 关闭时

底板会并入当前选定的底板耗材对象。切片软件会将其与使用同一耗材的画面区域视为单个对象，对象列表更精简。

## 开启时

软件会保留独立的底板网格：

- 像素与高保真模型中，底板以独立的 `Backing` 对象写入场景。
- 原生矢量模型中，底板以独立的 `Board` 对象保留。
- 底板仍使用当前选定的底板耗材配置，不会额外占用新的耗材槽位。
- 大画幅分块生成时，每个有效分块都会按相同规则保留独立底板对象。

导入切片软件后，请在对象列表中确认底板对象已生成，并核对其映射的耗材槽位。

## 预览与重新生成

2D 颜色预览仅展示配色效果；切换“分离底板”后请重新生成模型，并在导出的 3MF 及切片软件对象列表中查看拆分结果。该设置会随 Lumina 配方卡一并保存。

## 适用场景

### 背板输出

| 选项 | 下载结果 | 用途 |
| --- | --- | --- |
| 同一工程 | 模型与独立底板对象保存在同一份 3MF 中 | 在切片软件中统一管理与同盘切片 |
| 独立分盘工程（ZIP） | 模型和背板分别输出为独立 3MF 并打包下载 | 两份工程分别切片、分盘打印 |

独立分盘工程会保持作品原始物理尺寸，不会自动缩小以适应打印板。解压后请分别打开每份 3MF，核对模型、裙边（Brim）与擦料塔的摆放位置，若有手动检查提示请先调整妥当再切片打印。

“独立分盘工程（ZIP）”适用于单面、无浮雕的单模型导出；双面、浮雕、五色扩展、批量、拼图、大画幅和模型贴图流程请使用“同一工程”或对应模式自带的分块输出。分盘导出保持原有的显色层顺序，打印完成后可将面板与背板对齐粘接或组装。

### 何时建议开启

- 需要在切片软件中单独选择、隐藏或检查底板参数。
- 需要将底板拆分为独立零件进行分盘打印或后处理。
- 当前打印机或切片工作流需要将底板与显色层对象分开管理。

若无需单独操作底板，保持关闭即可获得更简洁的对象结构。
