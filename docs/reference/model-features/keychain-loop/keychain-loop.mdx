# 挂件环参数

开启挂件环后，软件会在导出的 3MF 中生成独立的挂件环实体。环体总厚度跟随当前模型的总层数，颜色使用生成流程分配给挂件环的材料槽。

## 尺寸参数

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 环宽度 | 2–10 mm，步进 0.5 mm | 控制挂件环外部横向尺寸 |
| 环长度 | 4–15 mm，步进 0.5 mm | 控制挂件环从连接端向外延伸的长度 |
| 环孔直径 | 1–5 mm，步进 0.25 mm | 控制穿过钥匙圈或挂绳的内孔直径 |

设置环孔直径时，请确保其小于外部尺寸，并在孔周留出适配当前喷嘴线宽的壁厚，以兼顾穿绳空间与结构强度。

## 位置参数

- **旋转角度：** -180° 至 180°；0° 为竖直向上，正值顺时针旋转。
- **X 偏移：** -200 至 200 mm；正值向右移动。
- **Y 偏移：** -200 至 200 mm；正值向上移动。

偏移量以模型中心为原点计算。调节位置时请让环体根部与模型边缘适当重叠，避免偏移过大导致挂件环与主体分离。

## 互斥模式与切片检查

开启拼图或冰箱贴磁铁槽时，挂件环会自动关闭并禁用。调整挂件环参数或切换模式后，需重新生成 3MF。

导入切片软件后，请在对象列表中确认挂件环对象存在，并逐层检查切片路径，确认环体与主体连接牢固且内孔未被切片补偿封死。
