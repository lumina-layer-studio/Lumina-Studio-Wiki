# 挂件环参数

挂件环是最终 3MF 中的独立几何，不是预览标记。它的总厚度会跟随当前模型总层数，颜色使用生成流程分配
给挂件环的材料槽。

## 尺寸参数

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 环宽度 | 2–10 mm，步进 0.5 mm | 控制挂件环外部横向尺寸 |
| 环长度 | 4–15 mm，步进 0.5 mm | 控制挂件环从连接端向外的长度 |
| 环孔直径 | 1–5 mm，步进 0.25 mm | 控制可穿过钥匙环或挂绳的内孔 |

孔径必须小于外部尺寸并保留足够壁厚。界面允许的数值不代表每种喷嘴、材料和连接件都能可靠打印。

## 位置参数

- **旋转角度：** -180° 至 180°；0° 为竖直向上，正值顺时针；
- **X 偏移：** -200 至 200 mm；正值向右；
- **Y 偏移：** -200 至 200 mm；正值向上。

偏移量以模型中心为基准。数值过大会让环与主体分离；预览中“看起来靠近”也不等于切片路径已经连接。

## 不能同时开启的功能

拼图或冰箱贴磁铁槽开启时，挂件环会自动关闭并禁用。切换这些模式不会把旧 3MF 改写，完成参数调整后
必须重新生成。

生成 3MF 后，应在切片软件中展开对象列表，确认挂件环对象存在、与主体相连，并检查内孔没有被喷嘴线宽
或切片补偿封闭。
