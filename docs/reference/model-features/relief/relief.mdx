# 浮雕

浮雕可将平面彩色模型转换为具有高低起伏的 2.5D 结构：表面颜色仍由耗材叠层配方决定，各区域的高度由浮雕参数控制。

## 开启后的联动变化

- 结构模式自动切换为单面。
- 掐丝珐琅自动关闭（两者互斥）。
- 若当前已有调色板但尚未建立高度数据，软件会按当前所选深浅方向自动生成初始高度。
- 原有预览与已导出的 3MF 需要重新预览并生成。
- 矢量建模模式下暂不支持浮雕，该开关会自动禁用。

## 最大高度

“最大高度”控制模型最高处的总高度，范围为 **0.08–15 mm**，步进 **0.04 mm**。调整该数值时，已分配给各颜色的高度会按比例同步缩放，保留原有的高低层次关系。

使用耗材档案时，最低可用高度还需容纳当前的光学叠层与底板厚度；软件会自动计算并抬高下限，确保所有颜色层完整成型。

## 自动高度模式

| 模式 | 高度来源 | 结果 |
| --- | --- | --- |
| 深色凸起 | 当前调色板亮度 | 较暗颜色获得更高的高度 |
| 浅色凸起 | 当前调色板亮度 | 较亮颜色获得更高的高度 |
| 根据高度图 | 单独上传的灰度或彩色高度图 | 图像亮度经缩放后映射为连续高度 |

切换“深色凸起”或“浅色凸起”会立即重算颜色高度。选择“根据高度图”时，请先完成一次普通预览以建立会话，再上传 PNG、JPEG、BMP 或 TIFF 图像；上传成功后，软件会保存处理后的高度图预览并在生成模型时应用。

## 调试建议

建议先从较小的最大高度开始生成 3D 预览，确认凸起方向与边缘过渡后再逐步加高；导出后在切片软件中逐层检查最高区域、薄边和底板的连续性。
