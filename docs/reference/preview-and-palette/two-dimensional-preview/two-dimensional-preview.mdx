# 2D 预览与悬停检查

2D 预览展示当前会话实际用于建模的配色结果，支持直接在画布上点选颜色、拾取连通区域并逐层核对光学叠色。

## 缩放与原图对比

- **缩放视图：** 使用鼠标滚轮或触控板双指缩放，倍率范围为 `50%–1000%`。
- **平移与复位：** 按住鼠标右键拖动可平移画布，双击画面恢复初始缩放比例。
- **对比原图：** 按住画布右上角的原图对比按钮，或在输入框外按住 `Shift` 键，可临时切换查看上传原图；松开按钮或 `Shift`（或切换窗口焦点）后立即恢复预览图。

画布采用像素级锐利渲染，高倍率放大时可直接观察每个预览像素的真实边界。

## 悬停检查器

将鼠标指针停留在画面上时，浮动检查器可实时显示该像素的详细信息：

- 当前像素坐标；
- 成品表面的预测颜色；
- 同一像素位置每一光学层的耗材颜色。

可通过中间栏的**放大镜**与**分层颜色**两个独立开关按需开启或隐藏对应模块。分层图像在首次查看时按需加载；透明像素或无材料层会显示为空状态。此处列出的是 Lumina 配方中的光学层序，打印时的物理耗材槽位可在切片软件中自由指定。

## 青色选区轮廓

点击画面后的高亮方式取决于当前使用的[选择模式](../selection-modes/selection-modes.mdx)：按色块或连通区域点选时，系统会沿点击位置的连通边界描绘青色轮廓；使用全局同色选择时，则会在整张图上高亮所有相同匹配色的像素。

若从**渐变分组**面板中点选某个独立区域，工作站会严格按该区域的空间掩码绘制轮廓，画面其他位置即使存在相同 HEX 色值的像素也不会被一并框入。
