# 颜色工作站

完成预览后，进入**颜色调整**即可打开颜色工作站。左侧 2D 预览、中间调色板与右侧候选颜色共用当前预览会话，确认后的换色结果会直接写回该会话。

## 界面布局

- **2D 预览：** 查看成品配色效果，点击像素或连通区域选定修改目标。
- **调色板：** 显示当前预览使用的全部颜色、像素占比、选择工具与编辑历史。
- **目标颜色：** 传统 LUT 模式展示完整 LUT 色库；耗材档案模式展示当前耗材组合可求解出的候选颜色。

若已上传图片但尚未生成预览，打开工作站时会自动执行一次预览；若图片、颜色来源或必要参数尚未设置完整，面板会保持空白状态。

## 编辑结果的保存与生效

确认颜色替换后，系统会先更新当前 2D 与 3D 预览；点击**生成**时，再将修改后的配色写入 3MF 模型。关闭工作站或按 `Esc` 仅返回 3D 查看器，已确认的替换仍会保留。更换输入图片或颜色来源后，请重新核对调色板。

已确认的局部换色、区域配方与选区可随项目一并保存和恢复，重新执行预览时也会保留这些修改。项目保存方法及旧版文件说明见[保存项目与分享卡](../../../knowledge/share-card-json/share-card-json.mdx)。

右侧的[快速换色与相似配方](../quick-recolor/quick-recolor.mdx)支持为当前选区直接指定目标色、从画面吸管取色，或套用相近的叠层配方。
