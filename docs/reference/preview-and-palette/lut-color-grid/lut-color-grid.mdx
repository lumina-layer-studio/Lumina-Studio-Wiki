# LUT 颜色网格

传统 LUT 预览完成后，右栏加载该 LUT 可以输出的全部颜色。图中使用的颜色与其他可用颜色分区显示；先在
左侧选中源色后，顶部会增加按 RGB 距离排序的推荐替换色。

## 查找颜色

搜索框接受以下写法：

- HEX，例如 `#8B5055` 或 `8b50`；
- RGB，例如 `139, 80, 85`；
- 色相筛选：红、橙、黄、绿、青、蓝、紫和中性。

“图中使用”来自当前预览调色板；“其他可用”来自同一 LUT 的其余条目。推荐色只表示数值距离较近，不保证
在特定灯光、打印板和耗材批次下与目标实物最接近。

## 收藏与显示方式

双击色块可收藏或取消收藏。收藏按 LUT 分开保存在本机浏览器中，切换 LUT 后不会混在一起。

支持的 LUT 可以在“色块”和“色卡”之间切换。“色卡”按照 LUT 记录的物理卡片页、行列与 A/B 标签排列，
方便对照实物；没有色卡布局信息的 LUT 只显示色块。

## 确认替换

点击目标色只会建立待确认项。顶部出现“源色 → 目标色”后：

- 选择“确认替换”才会重新计算 2D/3D 预览；
- 选择“取消”不会改变会话；
- 区域来源会沿用精确空间遮罩，不退化为全图 HEX 替换；
- 多色和多区域会在一次请求中批量处理。

耗材档案没有固定 LUT 色网格，会改用[耗材可达色](../material-achievable-colors/material-achievable-colors.mdx)求解器。
