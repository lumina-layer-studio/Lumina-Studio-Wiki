# LUT 颜色网格

使用传统 LUT 完成预览后，颜色工作站右栏会加载该 LUT 可输出的全部颜色，并分为**图中使用**与**其他可用**两组展示。先在左侧选中源色后，面板顶部会列出按 RGB 色差由近到远排序的 12 个**推荐替换色**。

## 搜索与筛选

顶部搜索栏与筛选标签支持快速定位颜色：

- **HEX：** 输入完整或部分色值，例如 `#8B5055` 或 `8b50`；
- **RGB：** 输入十进制分量，例如 `139, 80, 85`；
- **色相筛选：** 按红、橙、黄、绿、青、蓝、紫与中性色快速过滤。

**图中使用**汇集当前预览调色板已包含的颜色，**其他可用**列出同一 LUT 的其余条目。推荐替换色按数值色差排序，实际打印观感还会受观察灯光、打印板纹理与耗材批次影响。

## 收藏与色卡视图

双击任意色块即可加入或移出收藏。收藏记录按不同 LUT 独立保存在本地浏览器中，切换 LUT 时互不干扰。

若当前 LUT 包含物理色卡排版元数据，可在右上角切换**色块**与**色卡**视图。**色卡**视图严格还原实体校准卡的页码、行列与 A/B 分区标签，便于手持实物直接比色；未记录排版信息的 LUT 仅显示**色块**视图。

## 确认替换

点击右侧任意候选色后，中间栏顶部会先建立“源色 → 目标色”待确认项：

- 点击**确认替换**后，系统才会重新计算 2D 与 3D 预览；
- 点击**取消**将放弃本次待选目标色，保持当前会话不变；
- 若选区来自局部空间区域，替换会严格沿用该区域的空间掩码，不会按全图相同 HEX 扩散；
- 同时选中多种颜色或多个区域时，会在一次请求中合并批处理。

耗材档案模式不使用固定 LUT 网格，右侧会自动切换为[耗材可达色](../material-achievable-colors/material-achievable-colors.mdx)求解面板。
