# 渐变分组与区域处理

原图中的平滑渐变在匹配有限的耗材颜色后，容易被切分为一段段阶梯状色带（俗称“海带纹”）。“渐变分组（海带纹）”面板会自动定位这些色带，并提供按整组或按独立空间区域的换色、去海带纹与二次量化工具。

同时满足以下三个条件时，右侧会显示该面板：

1. 颜色来源设为[耗材档案](../../converter-basic/material-archive-source/material-archive-source.mdx)；
2. 当前图片已完成预览；
3. 画面中至少检测到一个符合条件的渐变分组。

未检测到渐变色带时面板自动隐藏；传统 LUT 与推算 LUT 模式不执行此项检测。

## 渐变色带的识别规则

系统会比对原图量化结果与耗材匹配结果：只有原图过渡依然平滑、但耗材匹配在此处发生跳色的边界，才会被归入渐变分组。检测采用以下固定阈值：

| 判定条件 | 固定阈值 | 作用 |
| --- | ---: | --- |
| 原图边界的中位色差 | ΔE 不高于 8 | 排除原图原有的清晰轮廓边 |
| 两种耗材色的相邻边界 | 至少 15 个像素 | 过滤偶然接触与零碎噪点 |
| 单种耗材色的像素占比 | 至少 30 个像素 | 忽略面积过小的零星颜色 |
| 同一分组内的最大色差 | ΔE 不高于 30 | 防止相近色连续串联跨入其他色相 |
| 可展开的连通区域 | 至少 500 个像素，四方向连接 | 过滤面积过小的局部碎片 |

各分组按总像素数从多到少排列。组内像素占比最高的耗材色会作为该组的**代表色**，用于“去海带纹”填充；行内显示的“颜色数”和“像素数”分别代表该组包含的匹配色数量与覆盖总面积。

## 选中整组与选中区域

点击**选中整组**会将该组内的全部耗材色加入[全选模式](../selection-modes/selection-modes.mdx)，并在 2D 预览中高亮显示。此时选择目标色，会将全图中所有相同的匹配色统一替换；若该渐变之外的图案也使用了同一种匹配色，这些位置会一并改色。

点击**展开区域**可查看该分组在画面中的各个独立连通区域。点击某一行上的**选中区域**同样会列出区域内的耗材色，但高亮与后续换色严格限定在该区域的精确像素掩码内，不影响画面其他位置的同色图案。

## 去海带纹

| 操作入口 | 作用范围 | 填充目标色 |
| --- | --- | --- |
| 一键去除海带纹 | 所有已检测分组中的匹配色 | 各分组各自的代表色 |
| 分组行的“去海带纹” | 该分组的精确空间范围 | 该分组的代表色 |
| 区域行的“去海带纹” | 该区域的精确像素范围 | 所属分组的代表色 |
| 合并去海带纹 | 同一分组内勾选的两个或多个区域 | 勾选区域内总像素数最多的颜色 |

**一键去除海带纹**与设置页中的[渐变海带纹自动换色](../../settings-import-export/auto-gradient-replacement/auto-gradient-replacement.mdx)均采用全图颜色映射：在保留已有手动换色的基础上，将各组的非代表色映射为代表色，因此分组外的同色像素也会同步替换。

分组行、区域行与**合并去海带纹**采用空间掩码，仅修改目标区域内部。区域左侧的勾选框用于组合同一分组内的批量处理列表（勾选操作本身不会高亮画布；跨分组勾选时会自动清空上一分组的勾选状态）。

空间区域处理完成后，系统会立即刷新 2D 与 3D 预览，此前生成的分层图与 3MF 需重新生成。空间区域处理独立于常规换色的撤销栈；如需恢复初始匹配结果，重新点击**预览**即可。

## 区域二次量化

**二次量化**会为所选区域单独建立局部调色板，再交由当前耗材求解器重新匹配，既能保留平缓的明暗过渡，又能消减密集交替的细碎色带。

<img
  src={require('./assets/03-requantize-dialog.webp').default}
  alt="区域二次量化对话框，量化色数范围为 12 到 256"
/>

- **色数范围：** **12–256**，默认值为 **64**。
- **调节效果：** 数值越大，保留的局部渐变色阶越丰富；数值越小，过渡越趋近于平坦单色。
- **单区与批量：** 点击单行右侧的**二次量化**仅处理该区域，不会打断已勾选的批量列表；点击顶部的**批量二次量化**会依次处理所有勾选区域，并在完成后清空勾选。
- **独立重算：** 每个区域都会生成各自的局部调色板并单独求解，处理完成后自动刷新渐变分组列表。

## 查看高亮图

点击行末的眼睛图标可打开独立的青色高亮检查窗，用于核对识别范围：分组行的检查窗按匹配色标出全图位置，区域行的检查窗则按精确空间掩码标出该连通区域。该窗口仅供只读核对，不会改变当前选区、主预览或换色记录。

## 与自动换色的配合

设置中的**渐变海带纹自动换色**默认关闭。开启后，每次耗材档案预览检测到渐变分组时，都会自动执行一次与**一键去除海带纹**相同的代表色映射，并在面板顶部提示已自动处理，方便随时查看检测结果。关闭该设置后，仍可在面板中手动执行各项操作。
