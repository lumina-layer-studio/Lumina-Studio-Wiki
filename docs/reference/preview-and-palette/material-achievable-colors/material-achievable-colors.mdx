# 耗材可达色

使用**耗材档案**完成预览后，颜色工作站右栏会根据当前耗材组合动态求解可打印颜色。每次查询都会读取已选耗材及其顺序、叠色层数、层高和基底；调整其中任一参数后，请重新执行预览并再次查询。

## 输入目标颜色

可通过系统取色器选色，或输入三位及六位 HEX 色值（如 `#8CE` 或 `#88CCEE`）。按 `Enter` 或点击**生成建议**后，三位色值会自动展开为六位大写格式；格式无效的 HEX 不会提交。

求解器最多返回 **20** 个候选色，按与目标色的色差 ΔE00 由近到远排列。为避免列表被肉眼难辨的极近色占满，候选色之间会保持最小色差间距，因此实际返回数量可能少于 20 个。

每个色块下方显示预测色差 ΔE；悬停可查看完整 HEX、ΔE 数值及各层配方索引。ΔE 衡量光学模型预测色与目标色的数值差异，实际打印成色还会受耗材批次、层高、打印板表面与观察光源影响。

## 查询来源

结果栏会标明本次建议色采用的求解路径：

- **缓存命中：** 读取与当前耗材、层数、层高、基底及网格精度完全匹配的穷举缓存。
- **运行时命中：** 读取已构建的 3200 万候选智能配方缓存。
- **MITM 实时求解：** 未命中上述缓存时，即时搜索最多 200 万种叠层组合。

实时求解可满足日常快速交互；当耗材数量或叠色层数较多、组合空间超出 200 万实时上限时，建议预先构建穷举缓存或 3200 万智能配方缓存，以提升检索覆盖率与响应速度。构建缓存仅加速查询与扩展搜索范围，不会改动耗材档案参数。

## 应用建议色

若左侧已选中待修改的源色或区域，生成建议后系统会自动将排在首位的候选色放入待确认栏；点击其他候选色块即可切换目标色。点击**确认替换**后才会重新生成 2D 与 3D 预览，点击**取消**则清除本次待确认项。

替换作用范围取决于工作站当前使用的选择方式：

- **全选 / 同颜色全选：** 替换所选源色在整张图中的全部像素；
- **当前 / 局部区域 / 点选色块：** 仅修改单个连通区域；
- **多选：** 一次批量处理已选中的多个区域。
