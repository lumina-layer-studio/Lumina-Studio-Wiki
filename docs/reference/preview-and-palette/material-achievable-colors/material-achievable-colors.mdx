# 耗材可达色

使用“耗材档案”完成预览后，颜色工作站右栏不会显示固定 LUT 色表，而是根据当前耗材组合计算可达色。查询同时
读取已选耗材及其顺序、叠色层数、层高和基底；修改其中任何一项后，应重新预览并重新查询。

## 输入目标颜色

可以使用系统取色器，也可以输入三位或六位 HEX，例如 `#8CE` 或 `#88CCEE`。按 Enter 或点击“生成建议”后，
三位写法会展开为六位，字母统一为大写。无效 HEX 不会提交。

系统最多返回 20 个候选，并按与目标色的 ΔE00 从近到远排列。候选之间还会保留最小色差，避免列表被几乎
相同的颜色占满，因此实际数量可能少于 20。

每个色块显示预测颜色和 ΔE；将指针停在色块上可以查看完整 HEX、ΔE 和配方索引。ΔE 是模型预测色与目标色的
差异，不是对实体打印误差的保证。耗材批次、层高、打印板和观察光线仍会影响实物。

## 查询来源

结果行会标明本次查询来自哪一条路径：

- **缓存命中：** 使用与当前耗材、层数、层高、基底及网格精度匹配的穷举缓存；
- **运行时命中：** 使用已保存的 3200 万候选智能配方缓存；
- **MITM 实时求解：** 前两类数据都不存在时，临时搜索最多 200 万种组合。

实时求解用于保持交互可用。耗材和层数较多时，组合可能超出实时上限，此时应先建立穷举缓存或 3200 万候选的
智能配方缓存。缓存只改变查询范围和速度，不会改变耗材档案本身。

## 应用建议色

生成建议后，如果左侧已经选中有效来源，系统会把第一个候选放入待确认栏；点击其他候选可以改用该颜色。
只有点击“确认替换”才会重建 2D / 3D 预览，“取消”只清除本次待确认项。

替换范围由工作站当前选择模式决定：

- “全选”替换所选颜色在整张图中的全部像素；
- “当前”和“局部区域”只处理一个连通区域；
- “多选”一次处理已加入的多个区域。
