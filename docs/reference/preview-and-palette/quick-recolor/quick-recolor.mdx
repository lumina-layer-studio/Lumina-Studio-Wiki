# 快速换色与相似配方

**快速换色与相似配方**位于**颜色调整**界面右侧。先在左侧预览图中选中要修改的局部或色块，再指定目标颜色或挑选一条相近的叠色配方。修改仅作用于当前选区，其余同色位置保持不变。

## 选择要修改的区域

完成预览后打开**颜色调整**，在中间栏选用合适的选择工具：

| 工具 | 选区范围 |
| --- | --- |
| 同颜色全选 | 选中画面中具有该颜色的全部色块 |
| 相近颜色 | 选中与点击处色差不超过容差的所有可见色块 |
| 点选色块 | 逐个添加或取消独立的连通色块 |
| 选区画笔 | 选中画笔涂抹轨迹触及的完整色块 |

未建立选区时仍可浏览目标色与候选配方，选中区域后即可执行替换。

## 调节相近颜色容差

**相近颜色**的容差按视觉色差 ΔE00 计算，数值越大，纳入选区的邻近色阶越广：

- 默认值为 **6**，滑块调节范围 **0–30**，步长 **0.5**。
- 设为 **0** 时，仅选中与点击处完全一致的颜色。
- 调高容差可将深浅过渡相近的色块一并纳入，若背景或相邻图案色差较近也会同时进入选区。
- 再次点击同一颜色可切换对应范围的选中状态。

容差仅影响选区范围，不会直接改变画面颜色；建议先确认画面上的选区轮廓，再执行换色。

## 设置目标颜色 B

可通过输入六位 HEX 色值（如 `#ff8800`）、打开系统取色器，或直接点选下方列出的图中已有颜色来设定**目标颜色 B**。传统 LUT 模式会检索与 B 最接近的 LUT 可打印色；耗材档案模式则以 B 为目标，由当前材料组合求解实际叠层配方。

确认选区与最接近的可打印色后，点击**把选区替换成这个颜色**即可更新预览，并对照周边未选中区域核对改色边界。

<img src={require('./assets/02-target-color.webp').default} alt="输入目标颜色 B，核对最接近的可打印颜色并替换当前选区" />

## 使用吸管从图中取色

点击输入框右侧的吸管图标（**从图中取色**），再点击左侧 2D 预览图中的任意位置，即可将该像素当前显示的打印色填入目标颜色 B，且不会打断已有选区。按 `Esc` 或收起卡片可退出取色模式。

## 挑选相似配方

在**相似配方**栏可切换**按选区颜色**或**按目标颜色 B**排序；若当前选区包含多种颜色，可点击其中一种作为参考色。每条候选配方旁会标注来源标签：

- **实测：** 来自当前 LUT 的实测色卡条目。
- **预测：** 由内置正向预测模型估算得出。
- **图中已有：** 当前预览图像中已使用该颜色。

每行下方的叠层小色块从左至右依次代表**观察面 → 底部**。核对色差 ΔE 与逐层材料后，点击右侧的**替换**即可应用。在耗材档案模式下，相似配方列表展示当前图像内已使用的颜色及其叠层；如需搜索更大范围的材料组合，请配合下方的耗材可达色面板。

## 检查与保存

替换完成后，2D 与 3D 预览会同步刷新；如需回退可点击顶部的**撤销**。若套用新配方后选区边界发生变化，请重新点选目标区域再继续微调。生成 3MF 前建议逐层核对改色区域，并及时[保存项目](../../../knowledge/share-card-json/share-card-json.mdx)。

若相似配方列表为空，通常表示当前颜色来源下暂无可用候选；若提示加载异常，请重新运行预览后再试。更换耗材组合或颜色来源后，请重新核对候选配方。
