# 3D 高精度颜色预览

**3D 高精度颜色预览**用于放宽浏览器 3D 预览保留的颜色网格数量上限，让高色数图像在 3D 画布中呈现更细致的局部过渡。此项默认关闭，仅影响浏览器中的 3D 预览显示，不改变 2D 颜色预览与 3MF 中的实际打印配方。

## 控件位置

1. 进入**图像转换**。
2. 展开**核心设置**下的**高级设置**。
3. 找到**3D 高精度颜色预览**。

## 默认预览上限

常规 3D 预览最多保留 **128** 个颜色网格。当画面颜色数超过 128 时，系统会按像素占比保留主要高频颜色，并将低频颜色归并到色彩空间中最接近的高频颜色，以控制浏览器需要渲染的网格规模。

## 开启后的上限

开启后，当[量化颜色数](../../converter-basic/quantize-colors/quantize-colors.mdx)高于 128 时，3D 预览的颜色网格上限会同步提升至当前量化颜色数：

| 当前量化颜色数 | 常规预览上限 | 开启高精度预览后 |
| ---: | ---: | ---: |
| 64 | 128 | 128（显示效果不变） |
| 128 | 128 | 128 |
| 256 | 128 | 256 |
| 512 | 128 | 512 |

像素建模模式默认直接按当前量化颜色数生成预览，在该模式下切换此开关不会改变网格数量。

## 性能与导出说明

保留的颜色网格越多，生成的 GLB 体积越大，轮廓提取、网格构建、数据传输与 Three.js 实时渲染耗时也会相应增加。同时开启高量化颜色数与 3D 高精度颜色预览时，内存和显存占用会明显上升。

切换此开关后，需重新运行预览或生成以刷新 3D 模型；检查最终可打印结构请以切片软件预览为准。该开关状态会随 Lumina 配方卡一并保存。
