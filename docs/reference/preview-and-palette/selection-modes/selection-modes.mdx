# 选择模式、调色板与自由色

调色板只列出当前预览实际出现的颜色。每个色块下方的百分比是该匹配色在画面中的像素占比；选中后，顶部会
依次显示量化色、匹配色和已替换色。

## 当前选择工具

| 模式 | 点击 2D 预览后的目标 | 适合操作 |
| --- | --- | --- |
| 同颜色全选 | 切换该颜色在整张图中的全部色块 | 将同一颜色统一处理 |
| 相近颜色 | 切换与点击颜色的色差不超过容差的可见色块 | 一起修改接近的深浅色 |
| 点选色块 | 逐次选择或取消独立色块 | 修改一个或几个独立图形 |
| 选区画笔 | 选择画笔碰到的整个色块 | 一次选择多处色块 |

当前工具使用统一选区。“当前”“多选”“局部区域”是较早版本的入口名称，
新界面按上表操作。实际更改范围应以画面里的选区边缘为准。

相近颜色的容差默认 6，范围 0–30；0 只选相同颜色。画笔大小范围 2–160 px，用来调整一次划过的宽度。
选区工具及目标色的完整说明见[快速换色与相似配方](../quick-recolor/quick-recolor.mdx)。

## 替换、撤销和清空

在右侧选择目标色后，工作站先显示“源色 → 目标色”，只有确认后才重新生成预览。多色或多区域会合并为
一次批处理，避免每个区域重复重建 3D 模型。

- **撤销：** 返回可用的上一编辑状态，操作后检查颜色与选区是否符合预期；
- **清空替换：** 清除全局与区域替换，并让后端从原始匹配结果重建 2D/3D 预览；
- **取消：** 只放弃尚未确认的目标色。

## 自由色

选中一个颜色后，“标记为自由色”会让生成器把该颜色的全部实体体素提取为一个独立对象，名称类似
`Free_FFFFFF`。这适合在切片软件中单独分配耗材或继续处理，不代表系统会自动找到一种新的真实耗材。

自由色改变 3MF 的对象结构，因此标记或清除后需要重新生成。它不会改变当前 2D 预览的颜色。
