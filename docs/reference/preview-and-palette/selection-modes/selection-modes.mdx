# 选择模式、调色板与自由色

中间栏下方的调色板仅列出当前预览实际使用到的颜色。每个色块下方的百分比表示该匹配色在画面中的像素面积占比；选中色块后，栏位顶部会依次展示原图量化色、当前匹配色与替换目标色。

## 四种选择工具

| 工具 | 点击 2D 预览后的作用 | 适用场景 |
| --- | --- | --- |
| 同颜色全选 | 选中或取消该颜色在全图中的全部色块 | 将同一种颜色全局统一替换 |
| 相近颜色 | 选中或取消色差在容差范围内的可见色块 | 合并处理深浅相近的过渡色块 |
| 点选色块 | 逐个添加或取消独立的连通色块 | 单独修改一处或几处局部图案 |
| 选区画笔 | 选中画笔涂抹经过的完整色块 | 连贯扫选相邻的多块区域 |

四种工具共用同一套活动选区（涵盖早期界面的“全选 / 当前 / 多选 / 局部区域”操作），实际改动范围以 2D 预览中的高亮选区轮廓为准。

**相近颜色**容差默认为 **6**，调节范围 **0–30**（设为 **0** 时仅匹配完全相同的颜色）；**选区画笔**直径范围为 **2–160 px**。选区组合与局部换色流程详见[快速换色与相似配方](../quick-recolor/quick-recolor.mdx)。

## 确认替换、撤销与清空

在右侧选定目标色后，中间栏顶部会先展示“源色 → 目标色”预览，点击确认后才会重建图像预览。同时修改多种颜色或多个区域时，系统会自动合并为单次批处理，避免逐块重复生成 3D 模型。

- **撤销：** 回退到上一步已确认的编辑状态，回退后可同步核对画面颜色与当前选区。
- **清空替换：** 清除全部全局与局部换色记录，按初始匹配结果重新生成 2D 与 3D 预览。
- **取消：** 仅放弃当前尚未确认的待选目标色。

## 自由色

选中任一颜色后点击**标记为自由色**，生成 3MF 时会将该匹配色的全部实体体素拆分为独立模型对象（命名格式如 `Free_FFFFFF`），便于导入切片软件后单独指定 AMS 耗材槽位或自定义局部打印参数。

标记或点击**清除自由色**会改变最终 3MF 的对象拆分结构，修改后需重新点击**生成**以导出新模型；该标记不会改变当前 2D 预览的显示颜色。
