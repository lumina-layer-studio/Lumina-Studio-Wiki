# 3D 查看器、截图、性能统计与诊断

完成**预览**或**生成**后，3D 查看器会将模型放置在当前所选机型的热床网格上，用于直观检查模型朝向、外轮廓、结构附件与整体尺寸比例；最终打印走线与逐层路径请以切片软件预览为准。

## 视角操控

- **旋转：** 在画布上按住鼠标左键拖动，围绕模型旋转观察视角。
- **缩放：** 滚动鼠标滚轮拉近或推远镜头。
- **平滑阻尼：** 视角转动带有惯性阻尼，松手后平滑停稳。
- **退出磁铁选中：** 处于磁铁槽编辑模式时，点击模型外部的空白画布可取消当前选中的磁铁槽。

相机支持大范围远近缩放；若模型在热床网格上显得过小，请先核对目标尺寸与预览尺寸参数。

## 右下角工具栏

画布右下角从左至右依次提供四个按钮：

1. **性能统计**
2. **3D 诊断**
3. **全屏**
4. **截图**

**全屏**按钮在支持 Fullscreen API 的浏览器中自动显示，退出全屏后直接回到原工作区。**截图**会直接捕获当前 WebGL 3D 画布并下载为 `lumina-3d-screenshot-时间戳.png` 纯图像文件；如需同时保存可恢复的参数与配方，请使用**导出分享卡**或项目导出功能。

## 性能统计

<img
  src={require('./assets/viewer-performance.webp').default}
  alt="Lumina Studio 3D 查看器性能统计，显示真实预览请求的各阶段耗时"
/>

性能统计面板展示最近一次**预览**或**生成**各阶段的实际耗时：

| 指标 | 含义 |
| --- | --- |
| 总耗时 | 本次预览或生成从发起到完成的总用时 |
| 上传处理 | 接收并预处理输入图像素材的用时 |
| 核心计算 | 执行图像色彩转换与三维几何建模的用时 |
| 缓存读取 | 读取已保存中间数据的用时 |
| 预览 GLB | 构建 3D 查看器分段网格模型的用时 |
| 调色板 | 汇总预览颜色占比与配方数据的用时 |
| 调度开销 | 总耗时中除核心计算外的任务准备与传输用时 |

面板仅列出当前任务实际执行的计时项。**性能统计**与**3D 诊断**面板互斥，打开其中一个会自动收起另一个。

## 3D 诊断

<img
  src={require('./assets/viewer-diagnostics.webp').default}
  alt="Lumina Studio 3D 诊断面板，显示来源、FPS、内存、三角面、调用数、纹理和画布"
/>

| 指标 | 含义 |
| --- | --- |
| 来源 | 当前画布加载的数据源（预览 GLB、生成模型、批量预览或空闲画布） |
| FPS / 帧时间 | 浏览器实时刷新帧率及单帧渲染耗时 |
| JS 堆 | 浏览器开放内存接口时，显示已用与总计 JavaScript 堆内存 |
| 三角面 | 当前场景提交渲染的三角形总数 |
| 调用数 | 单帧 WebGL 绘制调用（Draw Calls）次数 |
| 纹理 | 当前渲染器驻留的纹理数量 |
| 画布 | WebGL 画布物理像素尺寸与设备像素比（DPR） |

**3D 诊断**用于区分“模型计算耗时长”与“本地浏览器渲染卡顿”。若出现帧率偏低、三角面或绘制调用数过高的情况，可先关闭暂不需要的复杂 3D 结构附件、降低预览精度，并检查浏览器是否已开启硬件加速。

## 与高精度颜色预览的关系

**3D 高精度颜色预览**决定模型表面保留的颜色网格上限，而本页的**性能统计**与**3D 诊断**用于实时观测画布负载。有关颜色网格合并规则与显存占用的详细说明，请参阅[3D 高精度颜色预览](../high-precision-3d-preview/high-precision-3d-preview.mdx)。
