# 3D 查看器、截图、性能统计与诊断

完成预览或生成后，3D 查看器把模型放在当前机器的热床网格上。它用于检查朝向、轮廓、结构附件和大致比例，
不是切片器的走线预览。

## 视角操作

- 在画布上按住并拖动，围绕模型旋转视角；
- 滚动鼠标滚轮，拉近或拉远；
- 视角移动带有阻尼，松手后会平滑停止；
- 点击模型外的画布时，磁铁槽编辑模式会取消当前磁铁选择。

查看器允许相机在较大的距离范围内移动，但模型太小时应先核对目标尺寸和预览尺寸，不要只靠无限放大判断
能否打印。

## 右下角四个按钮

从左到右依次为：

1. **性能统计；**
2. **3D 诊断；**
3. **全屏；**
4. **截图。**

全屏按钮只在浏览器支持 Fullscreen API 时显示。退出全屏后回到同一工作区。截图直接读取当前 WebGL 画布，
下载名为 `lumina-3d-screenshot-时间戳.png`；它只包含 3D 画布，不等于分享卡，也不包含可恢复配方。

## 性能统计

<img
  src={require('./assets/viewer-performance.webp').default}
  alt="Lumina Studio 3D 查看器性能统计，显示真实预览请求的各阶段耗时"
/>

性能统计来自最近一次预览和生成响应：

| 项目 | 含义 |
| --- | --- |
| 总耗时 | 当前阶段从请求到完成的总时间 |
| 上传处理 | 接收和准备输入素材的时间 |
| 核心计算 | 后端工作进程执行转换的时间 |
| 缓存读取 | 读取已有中间数据的时间 |
| 预览 GLB | 建立供 3D 查看器显示的分段模型时间 |
| 调色板 | 整理预览颜色和配方信息的时间 |
| 调度开销 | 生成总耗时中未计入核心工作进程的部分 |

只有后端返回了相应计时字段，面板才显示该段数据。性能统计和 3D 诊断互斥；打开一个会关闭另一个。

## 3D 诊断

<img
  src={require('./assets/viewer-diagnostics.webp').default}
  alt="Lumina Studio 3D 诊断面板，显示来源、FPS、内存、三角面、调用数、纹理和画布"
/>

| 项目 | 含义 |
| --- | --- |
| 来源 | 当前显示来自预览 GLB、生成模型、批量预览或空闲画布 |
| FPS / 帧时间 | 浏览器实际刷新速度及单帧估算时间 |
| JS 堆 | 浏览器可提供时，显示已用和总 JavaScript 堆内存 |
| 三角面 | 当前渲染器提交的三角形数量 |
| 调用数 | 当前帧的绘制调用数量 |
| 纹理 | 当前渲染器使用的纹理数量 |
| 画布 | WebGL 画布像素尺寸与设备像素比 |

诊断面板用于区分“后端生成慢”和“模型已经生成，但本机浏览器显示慢”。FPS 低、三角面或调用数很高时，
先关闭不需要的高级 3D 结构、减小预览复杂度，并确认浏览器硬件加速正常。它不判断打印质量，也不会修改
模型参数。

## 与高精度颜色预览的关系

“3D 高精度颜色预览”改变模型表面的颜色显示策略；本页的性能与诊断按钮只负责观察当前 3D 画布。颜色预览
