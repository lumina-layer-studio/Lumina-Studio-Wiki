# 自定义配方

自定义配方允许为选中的空间区域直接指定每一层使用的颜色。先在 2D 预览中选中至少一个区域，再点击
“自定义配方”。

## 编辑层序

编辑器按照当前 LUT 的层序显示配方。可以逐层换色、添加层、删除层或上下移动。顶部“层色搜索”支持快速
输入：

- 字母使用颜色英文名首字母，例如 `W`、`B`、`C`、`M`、`Y`、`R`、`G`；
- `?` 保留当前层；
- `-` 可以作为分隔符。

软件会根据当前调色板解释字母；无法唯一对应时应检查每一层的实际色块，不要只依赖字母。

## 预测颜色

“预测颜色”使用当前 LUT 自带的正向模型，给出 RGB 与 Lab 预览。没有正向模型时仍可手动编辑和应用，
但不能计算可信的预测色，界面会明确提示。

预测结果是模型估算，不包含实际耗材批次、打印板纹理、光源和相机白平衡造成的偏差。

## 应用到选区

“应用到选区”把配方写入当前一个或多个区域，并重建预览。新配方层数高于当前预览时，整张图必须按新的
光学层数重新出图；编辑器会要求再次确认。

配方可以引用当前 LUT 原有材料，也可以携带在本次编辑中产生的虚拟材料。生成 3MF 时，这些材料声明会和
区域配方一起传入建模流程，避免预览存在而 3MF 缺少对象。

每次成功应用都会生成一个历史快照。之后选择其他区域时，可从“历史配方”一键复用同一层序；“撤销编辑”
只撤销编辑器内尚未应用的修改，工作站顶部的“撤销”负责已确认的颜色替换。
