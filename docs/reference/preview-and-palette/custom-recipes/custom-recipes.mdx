# 自定义配方

自定义配方可为选中的空间区域逐层指定耗材颜色。先在 2D 预览中选中至少一个区域，再点击**自定义配方**打开编辑器。

## 编辑层序

编辑器按当前 LUT 记录的光学层序展示各层材料，支持逐层换色、添加层、删除层或上下调整顺序。顶部的**层色搜索**支持简写快速填充：

- 使用颜色英文名首字母指定材料，例如 `W`、`B`、`C`、`M`、`Y`、`R`、`G`；
- 使用 `?` 保留该层当前颜色；
- 使用 `-` 作为可选分隔符。

简写字母会按当前调色板匹配对应材料；当调色板中存在首字母相同的颜色时，请在填充后核对每一层的实际色块。

## 预测颜色

点击**预测颜色**可调用当前 LUT 内置的正向模型，计算该层序对应的 RGB 与 Lab 估算值。若当前 LUT 不含正向模型，界面会提示无法生成预测色，但仍可正常编辑并应用配方。

预测色基于光学模型估算，实际打印效果还会受耗材批次、打印板纹理、环境光源与相机白平衡影响。

## 应用到选区

点击**应用到选区**会将当前配方写入所选的一个或多个区域，并重新生成预览。若新配方的层数高于当前预览层数，整张图需按更高的光学层数重新渲染，编辑器会在执行前弹出二次确认。

配方既可使用当前 LUT 的原有材料，也可包含本次编辑新增的虚拟材料。生成 3MF 时，相关材料信息会随区域配方一并写入模型，确保预览中的每种颜色都能生成对应实体对象。

每次成功应用的配方都会自动存入**历史配方**，切换到其他区域后可一键复用同一层序。编辑器底部的**撤销编辑**仅撤回当前窗口内尚未应用的改动；已确认生效的颜色替换请使用工作站顶部的**撤销**。
