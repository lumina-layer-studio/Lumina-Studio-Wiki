# 孤立像素清理

“孤立像素清理”用于消除颜色匹配后残留的严格单像素杂点。只有当某个像素的整套材料堆叠与周围所有相邻像素均不同时，系统才会将其判定为孤立点并替换为周围最常见的材料配方，不会模糊整体画面或磨平正常边缘。

此项默认开启。

## 控件位置

依次打开“图像转换 → 核心设置 → 高级设置”，即可找到“孤立像素清理”。

## 清理规则

清理在像素完成材料配方匹配之后执行。系统会逐像素检查周围最多 8 个相邻像素（图像边缘与四角按实际存在的邻居计算）：

1. 按整套**材料层堆叠配方**进行比对，而非仅比较屏幕显示的 RGB 颜色。
2. 仅当当前像素的材料堆叠与周围所有有效邻居均不相同，才将其标记为孤立点。
3. 统计周围邻居中出现频次最高的材料堆叠。
4. 直接复制该常见邻居的材料堆叠与匹配颜色完成替换。

由于替换配方直接取自相邻像素，清理过程始终复用调色板内已有的合法配方，不会生成调色板之外的新颜色。

## 保留范围与成片碎点排查

以下结构不属于严格单像素孤立点，清理时会完整保留：

- 两个及以上相连且同配方的像素块；
- 至少与一个相邻像素共用同一材料堆叠的细线、轮廓与微小色块。

若开启后画面仍存在成片噪点或细碎色块，建议结合[量化颜色数](../../converter-basic/quantize-colors/quantize-colors.mdx)、原图降噪以及目标打印尺寸一并调整。

## 生效范围

传统 LUT、预测匹配与耗材档案的位图像素流程均采用这套邻居配方清理规则；原生 SVG 矢量路径直接按图形对象匹配颜色，不经过单像素清理。

切换开关后，此前生成的预览与 3MF 文件将失效，请重新生成预览和模型以查看变化。Lumina 配方卡会保存该开关状态。
