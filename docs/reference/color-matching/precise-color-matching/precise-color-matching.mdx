# 高精度颜色匹配

“高精度颜色匹配（实验性功能）”会在图像颜色量化阶段，直接将聚类中心约束在当前 LUT 实际可达的颜色集合内。常规量化先在全 RGB 空间生成自由聚类中心，随后再查表映射到打印配方；高精度颜色匹配则让每个聚类中心从一开始就落在当前打印系统真正印得出的颜色上。

此项默认关闭。

## 控件位置

依次打开“图像转换 → 核心设置 → 高级设置”，即可找到“高精度颜色匹配（实验性功能）”。

<img
  src={require('./assets/01-precise-color-matching-location.webp').default}
  alt="Lumina Studio 高级设置中的高精度颜色匹配开关"
/>

## 匹配流程

当所选颜色来源具备完整的 LUT 色表与颜色空间索引时，开启此项后按以下步骤量化：

1. 根据原图像素分布建立初始颜色聚类。
2. 在迭代过程中，将每个聚类中心持续约束到 LUT 中真实存在的可达颜色上。
3. 输出不超过当前[量化颜色数](../../converter-basic/quantize-colors/quantize-colors.mdx)上限的颜色集合。
4. 直接调用这些可达颜色对应的材料配方生成预览与 3MF 模型。

若当前 LUT 缺少约束量化所需的完整索引数据，系统会自动回退至常规量化，不会中断转换流程。“耗材档案”采用独立的配方求解器，不受此开关影响。

## 与色相保护的关系

开启“高精度颜色匹配”后，[色相保护](../hue-protection/hue-protection.mdx)开关会自动置灰停用，避免两套候选筛选规则互相干扰。

<img
  src={require('../hue-protection/assets/03-disabled-by-precise-matching.webp').default}
  alt="开启高精度颜色匹配后色相保护被禁用"
/>

如需重新测试“色相保护”，请先关闭“高精度颜色匹配”。

## 效果与性能权衡

当常规转换出现“原图聚类颜色看似接近，查表后却跳到另一色系配方”的现象时，开启高精度颜色匹配往往能获得更稳定的色块划分。由于聚类迭代需反复检索 LUT 可达颜色集合，处理耗时会比常规 K-Means 略长。最终可呈现的色彩依然取决于当前 LUT、量化颜色数、原图内容与材料层数。

切换开关后请重新生成预览和模型。Lumina 配方卡不保存此实验性开关，导入配方卡后如需使用请再次勾选。
