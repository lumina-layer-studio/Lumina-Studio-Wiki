# 暗色彩度门槛

“暗色彩度门槛”是[色相保护](../hue-protection/hue-protection.mdx)的附属参数。它决定哪些暗色像素进入
“无彩暗色候选”匹配，以减少黑色描边、深灰阴影被匹配成深红、深蓝等有彩暗色的情况。

它比较的是颜色的**彩度**，不会改变软件判断“暗色”的亮度分界，也不是整幅图的饱和度调节。

## 控件位置

1. 进入“图像转换”，打开“核心设置”。
2. 展开右侧的“高级设置”。
3. 打开“色相保护”。
4. “暗色彩度门槛”会显示在开关下方。

  alt="Lumina Studio 高级设置中打开色相保护后显示暗色彩度门槛"
/>

当前控件范围为 **0–50**，步长为 **1**，默认值为 **15**。打开“高精度颜色匹配”后，
“色相保护”由该模式接管，“暗色彩度门槛”也会随之隐藏。

## 彩度门槛比较的是什么

软件先把输入颜色换算到 CIELAB/LCh 颜色空间：

- **L\*** 表示亮度，数值越低，颜色越暗；
- **C** 表示彩度，数值越低，颜色越接近黑、白、灰，数值越高，颜色倾向越明显。

“暗色彩度门槛”只与 **C** 比较。例如门槛为 15 时，处于暗色亮度范围、并且彩度
**C ≤ 15** 的像素可以进入暗色保护分支；彩度 **C > 15** 的像素继续使用常规色相优先匹配。

:::note

这里的彩度 C 是软件在 LCh 颜色空间中计算的数值，不等同于图片编辑软件中的 HSV/HSL
“饱和度”百分比。

:::

## 当前匹配逻辑

色相保护会先从当前 LUT 中建立一组“无彩暗色候选”：候选颜色的亮度约低于
**L\* 60**，彩度 **C ≤ 8**。暗色彩度门槛随后判断输入像素是否可以优先从这组候选中匹配。

<img
  src={require('./assets/02-dark-chroma-gate-logic.webp').default}
  alt="暗色彩度门槛在当前颜色匹配流程中的判断逻辑示意图"
/>

当前实现按输入像素的亮度分为三个区间：

| 输入亮度 | 门槛参与方式 |
| --- | --- |
| 约 **L\* < 50** | 符合彩度门槛时，强制从无彩暗色候选中选择 |
| 约 **L\* 50–70** | 符合彩度门槛时，在无彩暗色候选与常规候选之间逐渐过渡 |
| 约 **L\* ≥ 70** | 不进入暗色保护分支，继续常规色相优先匹配 |

这些亮度分界由当前匹配算法固定，拖动“暗色彩度门槛”不会移动它们。

## 数值如何影响结果

| 设置 | 实际含义 | 可能出现的结果 |
| --- | --- | --- |
| **0** | 特殊值：所有处于暗色亮度范围的颜色都可以进入暗色保护分支 | 黑灰描边保护最强；深红、深蓝等有彩暗部也更容易被匹配成黑或灰 |
| **低于 15** | 只有更接近无彩色的暗色进入保护分支 | 更容易保留有彩暗部；黑灰区域可能重新带上邻近耗材的色偏 |
| **15** | 软件默认值 | 适合作为比较起点，但不是所有图片和 LUT 的固定最佳值 |
| **高于 15** | 更宽的暗色彩度范围进入保护分支 | 可减少黑灰描边中的杂色，也可能让深色阴影失去原有色相 |
| **50** | 当前可设置的最大值 | 覆盖范围最宽，适合用于确认问题是否来自暗色分支，不代表推荐长期使用 |

因此，数值越高并不表示“只保护更暗的阴影”。它表示**允许彩度更高的暗色进入保护分支**。

## 调整方法

先保持图片、LUT、耗材和其他颜色设置不变，只调整这一项：

- 黑色或灰色描边出现红、蓝、绿等杂色时，可以小幅调高门槛；
- 深红、深蓝、深绿等暗部被压成黑色或灰色时，应调低门槛；
- 调整后等待预览重新计算，并始终比较画面中的同一位置；
- 确认预览后重新生成 3MF，再到切片软件中检查底面和分层预览。

如果需要完全停用这套暗色保护逻辑，应关闭“色相保护”。不要把门槛设为 0 当作关闭；
在当前实现中，0 恰好具有相反含义。

## 生效范围

“暗色彩度门槛”当前由使用 LUT 色表的常规色相保护匹配读取，包括相应的位图和原生 SVG
颜色匹配流程。

下列情况不会应用这一参数：

- “色相保护”关闭；
- “高精度颜色匹配”开启；
- 使用耗材档案直接预测叠层颜色，而不是使用 LUT 色表匹配；
- 当前处理流程使用的预测匹配器没有读取暗色彩度门槛。

在后两种来源中，界面有时仍可能显示该滑块，但修改数值不会改变匹配结果。这是当前版本的实现限制，
不是门槛失效或预览缓存错误。

## 常见问题

### 调整后为什么看不出变化？

先确认“色相保护”已经开启，并等待预览重新计算。图片中没有低亮度区域、当前 LUT 没有合适的无彩暗色候选，
或者当前颜色来源不读取这一参数时，结果都可能不变。

### 为什么调高后，彩色阴影变灰了？

调高门槛会让彩度更高的暗色进入无彩暗色候选匹配。降低门槛，直到深色区域恢复需要保留的红、蓝或绿色相。

### 0 是不是关闭暗色保护？

不是。当前代码把 0 作为特殊值处理：所有处于暗色亮度范围的颜色都可以进入暗色保护分支。
要关闭它，应直接关闭“色相保护”。

### 默认值 15 一定最好吗？

不是。15 是稳定的比较起点；实际结果仍取决于原图、当前 LUT、耗材组合和你希望保留的暗色细节。
