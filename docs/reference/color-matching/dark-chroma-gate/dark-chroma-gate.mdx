# 暗色彩度门槛

“暗色彩度门槛”是[色相保护](../hue-protection/hue-protection.mdx)的附属参数，用于控制哪些暗部像素进入“无彩暗色候选”分支，减少黑色描边或深灰阴影被匹配成深红、深蓝等彩色暗部的情况。

该参数仅按像素的**彩度（Chroma）**进行筛选，不改变暗部判定的亮度分界，也不会调整整幅图像的饱和度。

## 控件位置

1. 进入“图像转换 → 核心设置”，展开右侧“高级设置”。
2. 开启“色相保护”，“暗色彩度门槛”滑块即会显示在其下方。

/>

取值范围为 **0–50**，步长为 **1**，默认值为 **15**。开启“高精度颜色匹配”后，“色相保护”自动停用，“暗色彩度门槛”也会随之隐藏。

## 彩度筛选原理

匹配前，Lumina Studio 会将原图像素转换至 CIELAB/LCh 颜色空间：

- **L\*** 表示亮度，数值越低颜色越暗；
- **C** 表示彩度，数值越低越接近黑、白、灰，数值越高色彩倾向越鲜明。

“暗色彩度门槛”直接与像素的彩度 **C** 比较。以默认值 **15** 为例：位于暗部亮度区间且满足 **C ≤ 15** 的像素会进入暗色保护分支；**C > 15** 的像素则继续按常规色相优先规则匹配。

:::note[彩度与饱和度的区别]
此处的彩度 C 在 CIELAB/LCh 颜色空间中计算，不同于修图软件常见的 HSV/HSL“饱和度”百分比。
:::

## 亮度分段与匹配逻辑

开启色相保护后，系统会先从当前 LUT 中筛选出一组“无彩暗色候选”（亮度约低于 **L\* 60**、彩度 **C ≤ 8**），再结合原图像素的亮度区间决定匹配方式：

<img
  src={require('./assets/02-dark-chroma-gate-logic.webp').default}
  alt="暗色彩度门槛在当前颜色匹配流程中的判断逻辑示意图"
/>

| 原图像素亮度 | 满足彩度门槛时的匹配方式 |
| --- | --- |
| 约 **L\* < 50** | 直接从无彩暗色候选中择优匹配 |
| 约 **L\* 50–70** | 在无彩暗色候选与常规候选之间平滑过渡 |
| 约 **L\* ≥ 70** | 不进入暗色保护分支，保持常规色相优先匹配 |

上述亮度分界固定不变，拖动“暗色彩度门槛”只改变允许进入暗色保护分支的彩度上限。

## 数值方向与效果对比

数值越大，允许进入无彩暗色保护分支的暗部彩度越宽（但 `0` 为全开特殊值）：

| 设置值 | 作用规则 | 画面表现 |
| --- | --- | --- |
| **0** | 特殊值：暗部亮度区间内的所有像素均进入暗色保护分支 | 黑灰描边最干净，但深红、深蓝等有彩暗部也容易被压成黑灰 |
| **低于 15** | 仅极低彩度的近黑灰像素进入暗色保护分支 | 有彩暗部保留更完整，但黑灰区域可能重新混入邻近耗材色偏 |
| **15** | 默认值 | 兼顾黑灰纯净度与暗部色彩，适合作为调节起点 |
| **高于 15** | 允许带一定色彩倾向的暗部也进入无彩暗色匹配 | 进一步抑制黑灰描边杂色，但较深的彩色阴影可能变灰 |
| **50** | 最大常规门槛 | 覆盖高彩度暗部，适合排查杂色是否源自暗部匹配分支 |

## 调节建议

对比参数时，建议保持原图、LUT、耗材组合及其他颜色设置不变，仅微调此滑块：

- **黑灰线条或阴影混入红、蓝、绿杂色**：逐步调高门槛，直至杂色消退；
- **深红、深蓝、深绿等暗部失去原有色相而发灰**：从 15 往下调低门槛；
- **完全停用暗色保护**：请直接关闭“色相保护”开关（切勿将门槛设为 **0**，设为 **0** 会对全部暗色启用最强无彩保护）；
- **确认产出**：每次修改后等待预览刷新并对比同一局部，满意后重新生成 3MF，在切片软件中核对分层结果。

## 生效范围

“暗色彩度门槛”在使用 LUT 色表的常规色相保护流程中生效（含位图与原生 SVG 颜色匹配）。

以下场景不应用该参数：

- 未开启“色相保护”；
- 已开启“高精度颜色匹配”；
- 使用“耗材档案”直接求解叠层配方，或使用未接入该门槛的预测匹配流程（此类场景下即使界面仍显示滑块，调整数值也不会改变匹配结果）。

## 常见问题

### 调整数值后预览为什么没有变化？

请先确认“色相保护”处于开启状态并已重新生成预览。若原图本身缺少暗部区域、当前 LUT 中没有符合条件的无彩暗色候选，或当前颜色来源为耗材档案，调整滑块均不会改变画面。

### 为什么调高数值后彩色阴影变灰了？

门槛调高后，原本带有色相的深色像素也被归入无彩暗色候选池。将门槛逐步调低，即可恢复深红、深蓝或深绿暗部。

### 设为 0 可以关闭暗色保护吗？

不可以。**0** 是“所有暗部像素均进入暗色保护分支”的特殊值；如需关闭暗色保护，请直接关闭“色相保护”。
