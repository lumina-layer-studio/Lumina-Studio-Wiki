# 色相保护

“色相保护”用于抑制颜色匹配时的明显跨色相偏移。常规匹配以整体色差最小为优先，有时会把蓝色匹配成综合色差更接近的偏紫色，或把正红匹配成偏橙色；开启色相保护后，Lumina Studio 会加大色相偏离的惩罚权重，让匹配结果优先留在原本的色相范围内。

该选项仅调整候选颜色的排序权重，不会增减可用耗材、改变模型几何结构或修改切片参数。

## 开启方式

1. 进入“图像转换 → 核心设置”，展开右侧“高级设置”。
2. 打开“色相保护”。
3. 重新生成预览以应用更改。

<img
  src={require('./assets/01-enable-hue-protection.webp').default}
  alt="Lumina Studio 高级设置中的色相保护开关位置"
/>

开启后，下方会显示附属滑块[暗色彩度门槛](../dark-chroma-gate/dark-chroma-gate.mdx)，用于筛选进入无彩暗色候选池的暗部像素。其默认值为 **15**；特殊值 **0** 表示允许所有暗部像素进入无彩保护分支（而非关闭）。首次对比色相保护效果时，建议保持默认值 **15**，每次只改变一个变量。

## 匹配规则变化

未开启色相保护时，系统主要按整体 CIELAB 色差挑选最近候选；开启后，系统在兼顾亮度与彩度的同时大幅提高色相角偏差的代价，优先选用同色系或邻近色相的配方。

<img
  src={require('./assets/02-how-hue-protection-matches.webp').default}
  alt="普通颜色匹配与开启色相保护后的候选颜色选择示意"
/>

上图展示了同一目标色在开启前后的候选选择倾向。实际打印颜色仍取决于当前 LUT、耗材档案与可用叠色配方；若调色板中本身缺少相近的蓝色系配方，软件仍只能从现有可达颜色中选取最接近的结果。

## 适用场景

当画面出现以下情况时，建议开启色相保护并对比预览：

- 主体色相特征鲜明，但常规匹配出现了明显的红偏橙、蓝偏紫或绿偏黄；
- 画面包含多组相近色块，保持色相准确比细微的明暗过渡更重要；
- 当前 LUT 或耗材档案中明明存在同色系颜色，但常规匹配未将其选中。

对于黑白灰图像、极低彩度画面，或当前耗材组合本就缺少目标色相的情况，开启前后的差异通常不大。

## 对比与导出检查

建议在开启前后各生成一次预览，同时观察主体色块与高光、阴影及渐变过渡区域，确认色相归正的同时没有引入明显的明暗断层。

确认预览无误后，请重新生成并下载 3MF 文件，再导入切片软件检查分层预览（此前导出的旧 3MF 文件不会随网页开关自动更新）。

## 与高精度颜色匹配的关系

“色相保护”与[高精度颜色匹配](../precise-color-matching/precise-color-matching.mdx)互斥。开启“高精度颜色匹配”后，“色相保护”开关会自动置灰停用，由约束量化接管颜色选择。

<img
  src={require('./assets/03-disabled-by-precise-matching.webp').default}
  alt="开启高精度颜色匹配后，色相保护开关自动变灰"
/>

如需对比两者的效果，请保持图像、LUT 及其他参数不变，按以下两组设置分别生成预览：

1. 关闭“高精度颜色匹配”，开启“色相保护”；
2. 关闭“色相保护”，开启“高精度颜色匹配”。

## 常见问题

### 开启后为什么画面没有变化？

请先确认已重新生成预览。若原图以黑白灰或低彩度色彩为主、常规匹配本就选中了同色相候选，或当前 LUT 与耗材档案中没有更接近目标色相的配方，结果都会保持不变。

### 开启后色相准了，但明暗略有变化，正常吗？

正常。在有限的耗材叠层候选下，优先锁定色相有时需要牺牲少许亮度或彩度匹配度。若画面整体对明暗层次更敏感，可关闭色相保护回到常规匹配。
