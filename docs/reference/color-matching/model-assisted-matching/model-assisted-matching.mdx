# 模型辅助匹配

“模型辅助匹配”仅在内置了预测模型的[反推 LUT](../../converter-basic/inferred-lut-source/inferred-lut-source.mdx) 品牌包中显示，用于根据目标颜色预测逐层耗材叠色配方，补充实测数据库尚未覆盖的颜色区间。该功能只参与材料配方求解，不会改动原图内容。

## 模型辅助匹配

开启后，Lumina Studio 会同时计算颜色数据库中的最近实测候选与预测模型候选。仅当同时满足以下两个条件时，系统才会采用预测模型结果替换数据库结果：

1. 数据库最近候选的色差距离超出模型触发阈值；
2. 预测模型的色差距离加上安全边距后，依然小于数据库色差距离。

因此，实测数据库中已有的高匹配度颜色仍会优先保留，预测模型只负责填补数据库覆盖薄弱且模型把握更高的颜色区域。

## 仅模型匹配

开启“仅模型匹配”后，系统会跳过实测数据库基线，全部颜色均直接采用预测模型求解。该模式便于单独评估预测模型自身的色彩覆盖表现；实际打印通常建议优先使用“模型辅助匹配”，以兼顾实测数据的准确性。若所选品牌包未包含可用预测模型，这两项开关均不会显示。

## 阈值、安全边距与对比方法

面板不单独展示阈值与安全边距输入框，默认直接读取品牌包内置的运行参数（配置文件中仍支持指定非负覆盖值以复现特定实验配置）。

切换任一开关都会清空既有预览与 3MF 输出。对比不同模式的效果时，请保持品牌包、颜色数据库、打印层数、成品尺寸及其他颜色选项不变，分别重新生成预览后再作比较。
