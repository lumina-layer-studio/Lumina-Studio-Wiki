# 模型辅助匹配

模型辅助匹配只会出现在包含可用预测模型的“反推 LUT”品牌包中。它不是图像识别模型，也不会修改原图；
它根据目标颜色预测逐层耗材配方。

## 模型辅助匹配

打开后，软件仍先计算颜色数据库中的最近候选，并同时计算模型候选。只有同时满足以下条件时，模型结果
才会替换数据库结果：

1. 数据库候选距离大于模型阈值；
2. 模型距离加上安全边距后，仍小于数据库距离。

因此，开关不是“所有颜色都改用模型”。数据库已有可靠实测颜色时仍保留数据库结果，模型只处理数据库
覆盖较差且自身明显更优的颜色。

## 仅模型匹配

打开“仅模型匹配”后，跳过数据库基线，直接使用模型结果。它适合检查预测模型自身的覆盖情况，不代表
一定比数据库优。若品牌包没有可用预测运行时，界面不会显示这些开关。

## 阈值和边距

当前界面不直接显示阈值与边距输入框；空值使用品牌包中预测运行时的默认值。代码仍支持显式传入非负
覆盖值，主要供配置和复现使用。

切换任一开关都会清除旧预览和 3MF。比较时保持品牌、数据库、层数、图片尺寸和其他颜色选项不变，
分别生成预览再判断。
