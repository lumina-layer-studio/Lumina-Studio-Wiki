# 解锁量化颜色数

“解锁量化颜色数”用于将[量化颜色数](../../converter-basic/quantize-colors/quantize-colors.mdx)滑块的调节上限从 **256** 扩展至 **8192**。开启开关本身不会立即重新量化图像，也不会自动改动当前已设定的颜色数。

此项默认关闭。

## 控件位置

依次打开“图像转换 → 核心设置 → 高级设置”，即可找到“解锁量化颜色数”。

## 取值范围变化

| 开关状态 | 量化颜色数范围 | 步长 |
| --- | ---: | ---: |
| 关闭 | 8–256 | 8 |
| 开启 | 8–8192 | 8 |

量化颜色数的默认值为 **48**。开启解锁后，只有手动将滑块拖到 **256** 以上，实际颜色预算才会随之增加；再次关闭解锁时，若当前数值高于 **256**，系统会自动将其回调至 **256**。

## 适用场景与性能开销

将量化颜色数调高至数百乃至数千时，下列计算与渲染开销会显著上升：

- K-Means 聚类与颜色映射耗时；
- 运行内存占用；
- 待求解的材料配方数量；
- 3D 预览生成的颜色网格数量、GLB 体积与浏览器渲染时间。

成品实际能够呈现的细节同时取决于原图有效色彩、打印尺寸、喷嘴线宽及可用耗材配方。仅当处理高分辨率照片或平滑长渐变画面，且常规 **256** 上限仍出现可见色阶断层时，才建议开启解锁并逐步上调。

## 与 3D 预览的配合

标准 3D 预览默认最多合并渲染 **128** 个颜色网格。当量化颜色数超过 **128** 且需要在 3D 视口中完整观察低频过渡色时，请同时开启[3D 高精度颜色预览](../../preview-and-palette/high-precision-3d-preview/high-precision-3d-preview.mdx)。

修改开关或调整量化颜色数后，请重新生成预览和模型。Lumina 配方卡会记录具体的量化颜色数，但不单独保存“解锁量化颜色数”开关状态。
