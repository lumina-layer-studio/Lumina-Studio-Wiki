# 自动动态范围

“自动动态范围（实验性功能）”在颜色量化和配方匹配之前，先把原图亮度压缩到当前 LUT 或耗材档案
能够覆盖的亮度范围。它主要处理“原图比耗材系统更亮或更暗”的情况。

此项默认关闭。

## 控件位置

1. 进入“图像转换”。
2. 打开“核心设置”中的“高级设置”。
3. 找到“自动动态范围（实验性功能）”。

  src={require('./assets/01-auto-dynamic-range-location.webp').default}
  alt="Lumina Studio 高级设置中的自动动态范围开关"
/>

## 处理顺序

开启后，软件会：

1. 从当前 LUT 或耗材调色板中读取最低和最高 CIELAB L*。
2. 计算原图实际使用的 L* 范围。
3. 仅在目标亮度范围确实比原图窄时执行压缩。
4. 对阴影和高光使用平滑的缓入、缓出曲线；中间调在轻度压缩时保持原有斜率。
5. 保留 a*、b* 色度通道，再进入后续量化和颜色匹配。

这不是简单地把整张图线性拉灰。轻度压缩主要收拢两端；压缩幅度较大时，中间调对比度也会随目标范围
一同降低。

## 自动跳过

以下情况不会修改图像：

- 当前颜色来源无法提供有效的可达亮度范围。
- 可达范围与原图相同或更宽。
- 原图亮度跨度小于 1 L*，接近单一亮度。
- 目标亮度范围无效或没有实际压缩空间。

因此，开关开启但两次预览看起来相同，并不一定是故障。

## 观察结果

重点比较原图中接近纯白的高光和接近纯黑的阴影。开启后，这些区域可能更容易落入当前耗材能区分的颜色，
但整体明暗对比也可能变弱。它不会增加 LUT 的颜色数量，也不会改变材料层高。

切换后需要重新生成预览和模型。当前 Lumina 配方卡不会保存这一实验性开关。
