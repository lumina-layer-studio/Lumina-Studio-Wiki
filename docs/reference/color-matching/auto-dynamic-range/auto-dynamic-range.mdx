# 自动动态范围

“自动动态范围（实验性功能）”会在颜色量化和配方匹配之前，将原图亮度压缩到当前 LUT 或耗材档案可表达的亮度区间内，适合原图明暗跨度超出耗材实际表现范围的场景。

此项默认关闭。

## 控件位置

依次打开“图像转换 → 核心设置 → 高级设置”，即可找到“自动动态范围（实验性功能）”。

## 处理流程

开启后，Lumina Studio 按以下顺序处理图像亮度：

1. 读取当前 LUT 或耗材调色板的最低与最高 CIELAB L\* 值。
2. 统计原图实际分布的 L\* 亮度范围。
3. 仅当目标可达范围窄于原图亮度范围时执行压缩。
4. 对暗部与高光应用平滑的缓入、缓出曲线，轻度压缩时保持中间调斜率不变。
5. 保持 a\*、b\* 色度通道不变，随后进入颜色量化与配方匹配。

该压缩采用柔和的曲线过渡：轻度压缩主要收拢暗部与高光两端；当目标亮度范围明显收窄时，中间调对比度也会相应降低，以换取两端细节不丢失。

## 自动跳过条件

遇到以下任一情况时，软件会直接跳过压缩并保持原图亮度不变：

- 当前颜色来源未提供有效的可达亮度范围；
- 耗材可达亮度范围等于或宽于原图亮度范围；
- 原图整体亮度跨度小于 1 L\*（接近纯平单色亮度）；
- 目标亮度区间无需进一步压缩。

满足上述条件时，开启该开关前后的预览效果会保持一致。

## 效果评估与注意事项

建议重点对比原图中接近纯白的高光与接近纯黑的阴影区域：开启后通常能让耗材在这些极端明暗区域拉开层次，但整体明暗反差可能略微柔和。该选项不会改变 LUT 的颜色数量，也不会影响模型材料层高。

切换开关后需重新生成预览和模型。Lumina 配方卡不包含此实验性开关的状态。
