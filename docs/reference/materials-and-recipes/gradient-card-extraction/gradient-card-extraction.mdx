# 梯度卡提取

梯度卡提取根据同一种耗材在白色基底与黑色基底上的实拍梯度卡照片，拟合光学透射与吸收参数，并保存为可供叠层颜色预测使用的耗材档案。

<img
  src={require('./assets/01-gradient-card-inputs.webp').default}
  alt="梯度卡提取的 ZIP、名称和图片入口"
/>

## 准备文件

提取前需准备三项文件：

1. 在[梯度卡生成](../gradient-card-generation/gradient-card-generation.mdx)页面下载的 Kit ZIP 配置包；
2. 白色基底梯度卡的完整实拍照片；
3. 黑色基底梯度卡的完整实拍照片。

支持常见图片格式（如 PNG、JPG）及系统可直接解码的相机照片格式；若当前系统不支持读取 HEIC/HEIF，请先转换为 PNG 或 JPG。拍摄两张照片时，请固定使用同一台相机、相同曝光参数、白平衡与校色设置，并避开表面反光、高光过曝或遮挡色块的阴影。

## 图像来源与 ColorChecker

默认直接按相机或扫描仪原图提取。开启“ColorChecker 校色”后，需分别校正并确认白底图与黑底图；确认后的图像会在档案中标记为 ColorChecker 校色来源。

对同一份耗材执行多次复验并合并结果时，图像来源类型必须一致——原图样本与 ColorChecker 校色样本分开记录，不支持混合合并。

## 旋转、角点和纯色块位置

上传照片后，可按需顺时针或逆时针旋转 90°，然后按以下顺序依次点击梯度卡的四个角点：

1. 左上
2. 右上
3. 右下
4. 左下

<img
  src={require('./assets/02-corner-controls.webp').default}
  alt="纯色块位置和角点微调控件"
/>

“纯白色块位置”和“纯黑色块位置”用于确定色块采样方向。一般保持“自动检测（推荐）”即可；当自动识别方向不准时，再手动指定照片中纯基底色块所在的角。

放置四个角点后，可选中第 1–4 个角点，在 `1–10` 像素范围内设置步长并用方向按钮微调位置。请将角点紧贴梯度卡有效区域边缘，避开桌面、手指或卡外背景。

## 提取与保存

<img
  src={require('./assets/03-extract-action.webp').default}
  alt="黑底梯度卡与提取耗材按钮"
/>

上传 Kit ZIP、白底图与黑底图并标定好两组四角后，“提取耗材”按钮即可点击。提取完成后，结果区会展示：

- 透视校正结果与各色块的实际采样框；
- 估算耗材颜色（RGB / HEX）；
- 平均 ΔE 与最大 ΔE；
- 线性及分通道 RMSE；
- 白底卡与黑底卡的识别方向及方向置信度；
- 光学拟合参数与材料诊断摘要。

填写耗材名称后即可保存档案；品牌可从已有品牌中选择，也可直接输入新品牌名称，系统会按品牌与名称创建档案目录。展开结果详情还可下载 `stage_A_parameters.json`，用于留存本次拟合参数与诊断记录。

若从已有档案发起复验，保存时可在三种操作中选择（详见[编辑与复验耗材](../material-edit-and-verification/material-edit-and-verification.mdx)）：

- **合并结果**：将本次有效样本并入同一图像来源的历史数据共同重拟合。
- **覆盖结果**：用本次拟合结果替换档案当前的数据。
- **取消复验**：退出当前复验模式，耗材库中原有的档案保持不变。

保存完成后，可在[耗材库](../material-library/material-library.mdx)中查看档案，并前往[耗材配方查询](../material-recipe-query/material-recipe-query.mdx)验证叠层混色预测效果。
