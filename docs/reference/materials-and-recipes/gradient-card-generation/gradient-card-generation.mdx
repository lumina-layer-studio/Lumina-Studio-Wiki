# 梯度卡生成

梯度卡用于测量单种耗材在不同叠层厚度及黑白基底上的透射与吸收特性。本页面会同时生成供切片打印的模型文件，以及后续提取阶段所需的配置包（Kit ZIP）。

  src={require('./assets/01-gradient-card-generation.webp').default}
  alt="梯度卡生成页面"
/>

## 层高

支持选择 `0.04 mm`、`0.08 mm` 和 `0.10 mm` 三种标定层高。所选层高会写入打印文件、提取配置及最终生成的耗材档案。后续提取直接读取 Kit ZIP 中记录的层高参数，请在生成前确认所选数值与实际切片层高一致。

## 生成配置文件包

点击“生成配置文件包”后，Lumina 会打包生成以下内容：

- 可直接打印的 3MF 模型文件；
- 梯度卡色块布局与层序配置；
- 提取阶段定位与匹配各色块所需的参数；
- 打印与拍摄说明。

生成完成后请及时下载并保存该 ZIP 文件。即使直接下载 MakerWorld 上的同款在线 3MF 模型进行打印，后续在提取页面仍需上传此处生成的 Kit ZIP 配置包。

## 打印要求

每种待测耗材均需打印两张梯度卡：

1. 白色基底梯度卡一张；
2. 黑色基底梯度卡一张。

两张色卡请使用同一卷待测耗材、相同层高、同一套打印参数及摆放方向完成打印。页面同时提供与本地几何尺寸一致的在线梯度卡模型及参数化收纳盒链接：

- [Lumina 2.0 梯形校色色卡（0.08 mm 层高）](https://makerworld.com.cn/zh/models/2394753-lumina2-0-ti-xing-xiao-se-se-qia-0-08ceng-gao-15ce#profileId-2721317)
- [参数化 Lumina 2.0 梯度色卡收纳盒](https://makerworld.com.cn/zh/models/2400920-can-shu-hua-lumina-2-0ti-du-se-qia-zi-ding-yi-shou#profileId-2729620)

打印并拍摄完成后，前往[梯度卡提取](../gradient-card-extraction/gradient-card-extraction.mdx)拟合并保存档案；保存后的耗材会显示在[耗材库](../material-library/material-library.mdx)中。
