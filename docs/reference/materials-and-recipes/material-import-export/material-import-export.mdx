# 导入与导出耗材

在“耗材库”中可将多份耗材档案批量打包为单个 ZIP 文件导出，也可在其他 Lumina 环境中重新导入。导出的压缩包完整保留了材料配置、光学拟合参数与校验清单，导入后可直接用于叠层颜色预测与图像转换。

## 导出

1. 在耗材库中勾选需要备份的档案，或点击“全选耗材”。
2. 点击“导出所选耗材”。
3. 下载并保存生成的 `lumina_materials_<数量>_<时间>.zip`。

单个 ZIP 可同时包含多份耗材，内含导出清单、材料包清单，以及每份耗材对应的 `material.json`、拟合参数与附属档案文件。导出文件生成后请及时下载保存。

## 导入

点击“导入耗材 ZIP”支持一次选择多个 ZIP 文件。导入时系统会自动校验压缩包结构与数据完整性：

- 校验压缩包内路径、清单文件及耗材目录是否完整有效；
- 校验 `material.json` 与拟合参数是否为合法的 UTF-8 JSON，且 Stage A 光学参数符合求解要求；
- 对于带有版本清单的材料包，核对文件大小与内容摘要（Hash）是否匹配。

若本地已存在同名目录，系统会自动为新导入的目录追加时间戳后缀，保留原有档案不被覆盖。导入成功后，新导入的档案会自动处于选中状态，方便当场核对。

一次导入多个 ZIP 时，若其中任一文件校验失败，本次已写入的内容会自动全部回滚，确保本地耗材库保持整洁一致。

## 适用场景

- 更换电脑、迁移运行环境或重装 Lumina 前备份本地耗材库；
- 在团队成员之间共享已完成标定的耗材档案；
- 从 NAS 或离线存储恢复备份档案；
- 将某次实验用到的整套耗材打包归档，便于后续复现结果。

导入完成后，建议先在[耗材库](../material-library/material-library.mdx)核对品牌、目录名、标定层高与验证次数，再用于[耗材配方查询](../material-recipe-query/material-recipe-query.mdx)或图像转换。
