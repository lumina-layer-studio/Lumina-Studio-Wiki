# 社区账号、收藏与投稿

社区账号用于同步公开资源的点赞、收藏与投稿记录。桌面打包版无需绑定社区账号，也能使用本地耗材、LUT 和离线功能；登录不是本地创作的前置步骤。

## 连接账号

1. 在“设置 → 常规”的“社区账号”入口，或耗材／LUT 库中点击“连接社区账号”。
2. 打开耗材库登录网页，用自己的邮箱验证码或页面提供的其他方式登录。
3. 核对网页与 Studio 显示的十位连接码，确认账号正确后允许连接。
4. 回到 Studio，等待状态变为“已连接社区账号”。

连接码有效期为 10 分钟，只能确认一次；过期后重新发起连接。已有账号但尚未验证邮箱时，先用原来的登录方式进入，再验证邮箱，原来的投稿和收藏会保留。

桌面端能安全记住账号时，下次启动会自动连接；使用浏览器或环境不支持安全存储时，界面会提示“重启软件后需要重新登录”。可通过“管理邮箱与设备”查看和撤销已连接设备。

## 点赞、收藏与本机常用

公开资源的点赞、收藏和下载人数可以直接查看。登录后点击点赞或收藏，状态会归到当前社区账号；耗材库、LUT 库和转换选择器中的相应入口共用这些记录。

在桌面版中，收藏只记录想保留的条目，不会自动下载全部收藏。需要使用尚未安装的资源时，再从云端选择并下载。纯本地档案仍可设为“本机常用”，它与账号收藏是两种记录。在线站使用预装资源，见下方[在线预览站与桌面版](#在线预览站与桌面版)。

| 操作或显示 | 含义 |
| --- | --- |
| 取消收藏 | 取消当前账号的收藏，不删除本地文件或当前配色选择 |
| 切换或断开账号 | 当前个人状态随账号切换，本地已安装资料保留 |
| 下载人数 | 成功下载的不同账号数，同一账号重复下载不重复计数 |
| 数量显示“—” | 统计尚未取得或资源未能对应，不能当作零人使用 |

## 提交自己的耗材或 LUT

1. 在桌面版的本地资源详情中点击“贡献到公共库”。梯度卡保存后也可直接进入；LUT 提取页可选择“保存到本地并贡献”。
2. 核对当前投稿账号、名称、品牌、材质、系列、色号与校准资料。LUT 要逐个通道核对耗材，不能只填一卷。
3. 根据实际情况填写本人原创、改编或代传的来源。改编和代传需补原作者、来源及授权说明。
4. 核对使用许可和公开署名，主动确认后提交审核。
5. 在“我的投稿”查看状态和审核意见；待审条目可先撤回再修改，已公开资源可提交新修订。

提交不是立即公开。资料修订审核期间，已公开的旧版仍可使用。填写商品名或购买链接不会改变 LUT 配方数据，也不会使投稿账号自动获得品牌官方身份。

## 自动贡献默认关闭

希望持续分享自己的校准结果时，可在“我的投稿”中单独阅读并确认自动贡献设置。开启后，今后新保存的校准会进入提交队列；普通浏览、下载、导入和已有历史文件不会因此自动上传。

资料不全时，队列会停在“本机待提交”，补齐后再继续。断网时保留待提交内容；关闭自动贡献或断开账号会暂停未开始的任务，重新开启不会擅自恢复旧任务。

## 在线预览站与桌面版

[在线预览站](https://test.luminastudio.com.cn/)免登录即可试用，每天可导出 3 张不同原图。通过右下角“登录 Lumina 账号 · 再享 +3 张/天”或耗材／LUT 库的社区账号入口连接后，可同步个人点赞与收藏，并额外获得每天 3 张新图的导出额度，合计每天 6 张。具体连接步骤与计数方式见[在线预览与导出额度](../../../getting-started/online-preview/online-preview.mdx)。

在线站已预装公开耗材与 LUT 库，可在选择器中按点赞或收藏筛选这些资源，无需逐条下载安装。按需下载到私人库、管理个人耗材与 LUT，以及“贡献到公共库”和“我的投稿”管理，请在桌面版完成；在线站的投稿入口会引导前往桌面版。

上述每日额度属于在线站；桌面打包版的离线和本地使用不要求连接社区账号。
