# 耗材配方查询

耗材配方查询使用保存档案中的 Beer–Lambert 正向模型预测叠层颜色，不依赖传统 LUT，也不把配方限制为五层。

<img
  src={require('./assets/01-recipe-result.webp').default}
  alt="四层耗材配方的预测结果"
/>

## 基底与层厚

“白色基底 / 黑色基底”决定模型最后看到的基底颜色。层厚可选 `0.04`、`0.08` 或 `0.10 mm`，应与实际切片层高一致。

改变基底或层厚会使当前预测失效，需要重新计算。

## 添加配方层

耗材库按品牌分组，可按耗材名、品牌或目录搜索。点击耗材会把一层追加到**靠近基底的一侧**。

页面中的顺序始终是：

`观赏面 → …… → 基底侧`

“撤销最后一层”删除最靠近基底的最后一次追加；单独的 × 可移除任意层；“反序”翻转全部层序；“清空”移除当前配方。

## 计算混色

“计算混色”会把界面层序转换为求解器使用的基底优先顺序，再逐层执行正向模型。结果包括预测 HEX、RGB、层数、层厚、基底和每一层之后的估算颜色。

这是标定模型的预测，不等同于显示器色块。打印机、耗材批次、表面纹理和拍摄光线都会造成差异，应使用实体色块确认。

## 配方队列与验证色块

<img
  src={require('./assets/02-recipe-queue.webp').default}
  alt="已加入一个配方后的配方队列"
/>

计算完成后可“添加到队列”；完全相同的结果不会重复加入。队列内每个配方保存自己的层序、层厚和基底，可以
单独移除，也可以用“清空队列”全部移除。生成验证色块时可设置：

- **色块尺寸**：`5–50 mm`；
- **间距**：`0.5–10 mm`；
- **列数**：`0–20`，`0` 表示自动排列；
- **结构模式**：单面或双面。

生成时还会读取“设置”中的打印机、切片软件、喷嘴和设备配置，以制作对应的 3MF。预览图用于识别色块位置；
生成成功后“下载 3MF”才会出现，获取文件后仍可保留队列继续调整布局并重新生成。
