# 耗材配方查询

耗材配方查询基于耗材档案中的 Beer–Lambert 光学正向模型计算任意层数的叠层混色效果，无需依赖传统五色 LUT，也不受固定五层层数限制。

<img
  src={require('./assets/01-recipe-result.webp').default}
  alt="四层耗材配方的预测结果"
/>

## 基底与层厚

“白色基底 / 黑色基底”用于指定叠层最底部的衬底颜色。单层厚度可选 `0.04`、`0.08` 或 `0.10 mm`，请与实际切片层高保持一致。

调整基底或单层厚度后，需重新点击“计算混色”以更新预测结果。

## 添加配方层

耗材列表按品牌分组，支持按耗材名称、品牌或目录名搜索。点击任一耗材，即可在**靠近基底的一侧**追加一层。

页面中的配方层始终按从外到内的顺序展示：

`观赏面 → …… → 基底侧`

- **撤销最后一层**：移除最近一次追加在基底侧的那一层。
- **×**：单独移除指定层。
- **反序**：将当前全部层序首尾翻转。
- **清空**：清空当前配方中的所有层。

## 计算混色

点击“计算混色”后，系统会从基底侧向观赏面逐层推算光学混色结果，并展示最终预测的 HEX 与 RGB 色值、总层数、单层厚度、基底类型，以及逐层叠加后的过渡颜色预览。

界面色块反映标定模型的理论预测值；由于最终实物成色还会受到打印机挤出状态、耗材批次、表面纹理及观察光源影响，关键配色建议打印实体色块加以确认。

## 配方队列与验证色块

<img
  src={require('./assets/02-recipe-queue.webp').default}
  alt="已加入一个配方后的配方队列"
/>

计算完成后点击“添加到队列”，即可保存当前配方的层序、层厚与基底设置（完全相同的配方不会重复入队）。队列中的条目支持逐条移除，也可点击“清空队列”全部清空。生成验证色块 3MF 时可配置以下参数：

- **色块尺寸**：`5–50 mm`
- **间距**：`0.5–10 mm`
- **列数**：`0–20`，设为 `0` 时自动排列
- **结构模式**：单面或双面

生成时会自动读取“设置”中配置的打印机、切片软件、喷嘴与设备参数以构建对应的 3MF 文件，并生成位置对照预览图。构建完成后即可点击“下载 3MF”保存模型；下载后队列仍会保留，方便调整排列参数并重新生成。
