# 色域覆盖与各耗材的贡献

“色域覆盖”用于比较一组耗材能表现的颜色范围，以及每卷耗材在这组配色中的作用。它使用耗材档案预测叠层颜色，不需要先生成模型或打印测试件。

## 选择组合并计算

1. 打开“耗材管理 → 色域覆盖”，选择至少一种耗材。
2. 设置层高与固定层数，或开启动态层数并填写最小、最大层数及底板耗材。
3. 核对模拟使用的白底或黑底，点击“计算覆盖率”。
4. 查看覆盖率、匹配误差、亮度范围、颜色分布和各耗材的贡献。

从转换页点击“查看色域”会带入当前配色，也可以点击“使用转换器当前选择”重新带入。在工作台中试换耗材或层数不会改动转换页的设置。参数改变后，旧结果会标记为之前组合的结果，需要重新计算再比较。

## 覆盖率和匹配误差有什么区别

| 指标 | 表示什么 | 怎样比较 |
| --- | --- | --- |
| sRGB 覆盖率 | 这组耗材触达了参考颜色范围中的多少个色彩单元 | 数值越高，覆盖范围越广；不表示每种颜色都更准确 |
| 匹配误差估计 | 参考颜色与邻近可打印颜色之间的平均 ΔE00 色差 | 同一颜色组内越小越接近，可分别查看灰黑白、暗色、肤色、鲜艳色等 |
| 亮度范围 | 预测颜色中从暗到亮的范围 | 配合暗部细节、灰阶或高光需求观察 |
| 候选完整 / 候选近似 | 计算是否保留全部叠层候选颜色 | 近似结果可能遗漏可达颜色，比较时要留意候选来源 |

覆盖率默认将 Lab 颜色空间划分为边长 5 ΔE 的小格，统计预测颜色触达了多少个包含 sRGB 颜色的格子。匹配误差则在每个参考色的八个邻近候选中计算最小 ΔE00，再按颜色组取平均。因此，“候选完整”也不表示匹配误差已经求得全局最小值。

## “各耗材的贡献”怎样读

第一行是完整组合的基线，后续每一行表示**移除该卷耗材**后的变化，而不是该卷耗材单独打印的效果。

- 某颜色组的色差增加得越多，说明这卷耗材对该组颜色越重要。
- 最暗亮度升高，说明移除后暗色能力减弱。
- 覆盖率下降，说明组合少了一部分可表达的颜色范围。
- 显示没有明显变化时，表示当前组合与计算条件下差别较小，不代表这卷耗材在其他作品里没有用途。

例如，某卷耗材移除后肤色色差明显增加，而鲜艳色变化很小，它对这组配色的肤色更有帮助。是否保留仍取决于作品中的颜色、可用料槽与实际打印要求，不宜只按总覆盖率排名。

逐卷比较采用同一个固定层数和 100 万候选预算。动态模式按**最大层数**进行这项比较，因此贡献表的基线与动态范围的总覆盖率可能不同。

## 动态层数与缓存

动态模式还会展示不同有效层数上限的累计覆盖率。首次计算需要建立逐层候选和合并目录，保存后可供后续转换复用。固定层数、动态范围或耗材组合改变后，对应的可用缓存也会不同，详见[求解缓存](../material-solver-cache/material-solver-cache.mdx)。

计算依据是所选档案的测量与拟合数据。它适合在一致的层高、底色和候选条件下比较组合；实际打印仍会受到耗材批次、温度与测量条件的影响。
