# 求解缓存

求解缓存保存一组耗材已经算过的叠层候选，便于之后的配色与转换复用。它是计算结果，不是耗材原始档案；删除缓存不会删除耗材库中的测量数据。

## 打开缓存概览

在“耗材管理 → 求解缓存”中选择耗材组合与层数设置，或从转换页点击“管理缓存”带入当前选择。缓存概览读取已有状态，不会因为打开页面就自动开始一次完整构建。

这里与“色域覆盖”共用工作台的耗材及层数选择。工作台里的改动不会替换转换页的当前参数。转换使用白底条件，缓存页面也按白底管理，不显示色域分析中的黑底切换。

## 固定层数

固定层数下可以查看、建立或删除穷举缓存与智能缓存。选择改变后，状态对应新的耗材组合、层数与层高；看到其他组合已有缓存，不表示当前组合也已准备好。

固定层数的穷举缓存最多支持 10 层，更深的叠层使用智能缓存。界面默认的固定层数上限为 10，开启高级层数设置后可到 30；扩大层数范围不意味着穷举缓存也能超过 10 层。

## 动态层数

动态模式可选择 5–30 层，默认范围为 5–10 层，并指定参与补位的底板耗材。点击“预构建”后，软件会保存范围内的逐层候选，再建立转换使用的合并目录。

| 状态 | 含义 |
| --- | --- |
| 已就绪 | 当前组合与范围的目录可以复用 |
| 部分层数可复用 | 一部分逐层候选已经存在，仍需准备其余部分或合并目录 |
| 未准备 | 当前设置没有可直接复用的预构建结果 |
| 查询失败 | 读取状态未完成，可根据提示重试；不等于耗材档案已损坏 |

动态计算可以复用兼容的手动智能缓存。选择更宽的层数范围时，每层分配的候选预算也可能变化，所以不能仅看层数相同就判断所有缓存都通用。

## 删除后会怎样

“删除预构建缓存”移除当前组合与范围对应的合并目录和预构建逐层候选，不删除已有的手动智能缓存。只有手动缓存可复用时，不显示预构建删除操作。

删除后，下次需要这些候选时可以重新计算。想回收计算文件的空间时使用此入口；想备份或移走耗材档案时，使用[导入与导出耗材](../material-import-export/material-import-export.mdx)。系统设置中的[缓存管理](../../settings-import-export/cache-maintenance/cache-maintenance.mdx)主要处理临时文件和转换会话，是另一个入口。
