# 编辑与复验耗材

耗材卡片提供编辑信息、再次验证、验证历史和删除耗材四项操作，分别用于调整界面展示属性、追加实测样本、排查拟合质量以及清理本地档案。

## 编辑信息

<img
  src={require('./assets/01-edit-material.webp').default}
  alt="编辑耗材名称、品牌和显示颜色的窗口"
/>

点击“编辑信息”可修改以下属性：

- **显示名称**
- **品牌**
- **显示颜色**：支持通过取色器选取，或直接输入 `#RGB` / `#RRGGBB` 色值。

显示颜色仅调整材料选择器中的预览色块，方便快速辨认，已拟合的 E、k 与基底光学参数保持不变。修改名称或品牌时底层目录名固定不变，已有工程或配方对该档案的引用不受影响。

## 再次验证

点击“再次验证”会跳转至“梯度卡提取”页面，并将当前耗材目录设为复验目标。完成新一组白底、黑底梯度卡照片提取后，可选择：

- **合并结果**：保留原有验证记录，将本次有效样本与历史样本一并重新拟合。
- **覆盖结果**：清空原有验证记录，以本次拟合结果替换档案数据。
- **取消复验**：退出复验模式，原档案保持不变。

相机原图与 ColorChecker 校正图属于不同图像来源，不支持直接合并。若与原档案的图像来源不同，请改用相同校色方式重新处理图像，或直接选择覆盖结果。

## 验证历史

<img
  src={require('./assets/02-verification-history.webp').default}
  alt="耗材档案的验证历史窗口"
/>

展开验证历史可查看历次测量的诊断摘要，包括估算颜色、平均 ΔE、线性 RMSE、白底与黑底识别方向，以及 E、k、白底 C0、黑底 C0 参数；执行过合并重拟合时，还会列出各次历史测量被采纳或剔除的情况。

通过验证历史可以直观检查：

- 同一耗材多次拍摄与打印的一致性；
- 是否存在曝光偏移、白平衡漂移或色卡方向识别异常；
- 新测得的数据适合并入历史样本，还是直接覆盖旧档案。

## 删除

点击“删除耗材”会永久移除当前环境中的这份本地档案目录，操作不可撤销；云端目录中的版本或其他设备上的副本不受影响。如需留存备份，请在删除前通过[导入与导出耗材](../material-import-export/material-import-export.mdx)导出 ZIP 包。

复验的完整拍摄与提取步骤见[梯度卡提取](../gradient-card-extraction/gradient-card-extraction.mdx)。
