# 云端耗材库

云端耗材库收录已公开的单卷耗材档案。先核对料盘上的品牌、系列、材质和色号，再选择与计划打印层高相符的档案。浏览目录不需要先下载整个库。

## 找到并添加耗材

1. 在耗材选择器中点击“去云端找耗材”，或打开“耗材管理 → 云端耗材库”。
2. 输入品牌、系列、商品名称或色号，结合安装状态筛选。
3. 点开条目，查看梯度卡、校准层高、原始档案名、作者与说明。
4. 确认符合手头线材后，点击“下载到本地”。
5. 返回本地选择器，勾选刚添加的档案，再确认用于当前配色。

下载与选用是两个动作：查看详情、翻页或下载都不会自动替换当前配色。来回切换本地、云端和离线包时，查找用的搜索词会保留。

## 目录和预览怎样加载

软件先读取名称、颜色模式等轻量目录，目录完整加载后可搜索全部条目。列表按页面读取色板，不会在打开时安装所有耗材；访问过的预览会复用缓存。目录尚未读完时，暂时没有结果不代表整个库都没有对应耗材。

耗材预览将白底、黑底梯度卡并列展示，便于比较不同厚度的显色。旧档案缺少的采样位置留空；只有代表色时会标明“代表色示意”。缩略图和显示色用于辨认，选择时仍需核对具体商品与校准层高。

| 状态 | 含义与操作 |
| --- | --- |
| 未安装 | 尚未加入本地，按需下载 |
| 已安装 | 本地已有当前修订，可以返回选择器使用 |
| 有新版本 / 本地已有版本 | 同一资源存在不同修订，核对说明后再更新 |
| 本地文件缺失 | 安装记录仍在，但文件不完整，重新下载对应条目 |

刷新云端目录只更新目录与安装状态，不会删除自测档案。不同来源中名字相同的条目也不一定是同一份数据。

## 中国大陆与国际包装名称

打开“设置 → 常规 → 耗材包装名称”，可选择“跟随界面语言”“中国大陆包装”或“国际包装”。同一商品在不同地区可能使用不同名称，切换后列表显示相应名称，详情仍保留原始档案名。

已核实的地区名称、品牌中英文名、原名和色号都可以用于搜索。没有对应地区名称时继续显示原名；品牌标志只在已有授权与对应资料时显示。切换名称不修改校准数据，也不改变当前选择的耗材。

## 断网时从离线包挑选

打包版提供离线包入口。有可用资源包时，点击“从离线包挑选”，查看条目后再“添加到本地”。打开软件、搜索或预览不会把整包全部装入本地；重复添加同一修订会沿用已有记录。

离线包是固定版本，不会凭空获得后来新增的档案。联网恢复后，可继续到云端查找更新。没有离线包时，已经安装的耗材仍可使用，也可以[导入耗材 ZIP](../material-import-export/material-import-export.mdx)或自行[制作梯度卡档案](../../../tutorials/gradient-card-extract-profile/gradient-card-extract-profile.mdx)。

## 收藏和投稿

公开目录可以直接浏览。连接社区账号后可点赞、收藏资源，收藏会随账号同步；收藏本身不会自动下载整库。自己的实测档案可从详情中的“贡献到公共库”提交审核，步骤见[社区账号、收藏与投稿](../community-resources/community-resources.mdx)。
