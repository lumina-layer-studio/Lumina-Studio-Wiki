# 云端耗材库

云端耗材库是可选的材料目录。没有配置云端地址时，本地耗材库仍可离线使用。

  alt="未配置云端目录时的云端耗材库"
/>

## 状态栏

顶部显示云端条目数、本地已安装数、可更新数、索引状态和最近同步时间。“刷新云端目录”会重新读取目录与安装状态，不会删除本地耗材。

没有配置目录时会显示提示，而不是把本地耗材判定为失效。

## 搜索与筛选

搜索会匹配品牌、名称、材料 ID、版本、目录、频道和可见性。筛选项包括：

- **全部**；
- **未安装**，也包含本地文件缺失的条目；
- **可更新**；
- **已安装**。

目录采用每页 50 条的增量加载；有更多数据时可继续加载一页或加载全部。

## 安装状态

每张云端卡片会显示品牌、名称、颜色、目录、包体积、内容指纹和状态：

- **未安装**：可下载到本地；
- **已安装**：本地版本与目录当前版本一致；
- **有新版本**：可更新到目录中的版本；
- **本地已有版本**：相同内容已经存在，但安装记录来自另一条本地映射；
- **本地文件缺失**：安装记录存在，但材料文件不完整，需要重新下载。

“官方”标记来自云端频道。安装前仍应核对材料名称、品牌和适用条件。

## 版本回滚

只有本地仍保留可用历史版本时，页面才显示回滚入口。回滚会切换当前安装版本，不会改写云端目录。

云端安装后的档案会出现在[耗材库](../material-library/material-library.mdx)，也可以用[导入与导出耗材](../material-import-export/material-import-export.mdx)离线备份。
