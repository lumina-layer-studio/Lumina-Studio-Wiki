# 云端耗材库

云端耗材库提供在线耗材档案目录，方便直接浏览、下载和更新已标定的耗材数据。未配置云端地址时，本地耗材库仍可正常离线使用。

## 状态栏

顶部状态栏汇总显示云端条目数、本地已安装数、可更新数、索引状态及最近同步时间。点击“刷新云端目录”会重新读取在线目录与本地安装状态，本地已有的耗材档案保持不变；未配置云端地址时，页面会提示当前未接入云端目录。

## 搜索与筛选

搜索框支持匹配品牌、名称、材料 ID、版本、目录、频道与可见性。状态筛选包含四项：

- **全部**：显示目录中的所有条目。
- **未安装**：显示尚未下载或本地文件缺失的条目。
- **可更新**：显示云端有新版本的已安装条目。
- **已安装**：显示本地已安装的条目。

目录按每页 50 条增量加载；条目较多时，可选择继续加载一页或一次加载全部。

## 安装状态

每张云端耗材卡片均展示品牌、名称、颜色、目录名、包体积、内容指纹及当前状态：

- **未安装**：可直接下载安装到本地。
- **已安装**：本地版本与云端当前版本一致。
- **有新版本**：云端发布了更新版本，可执行升级。
- **本地已有版本**：本地其他安装映射中已存在内容完全相同的档案。
- **本地文件缺失**：本地保留了安装记录，但档案文件不完整，需重新下载。

带有“官方”标记的条目来自官方发布频道。安装前请核对耗材品牌、名称及标定层高等适用条件。

## 版本回滚

当本地仍保留可用的历史版本时，卡片会显示回滚入口。执行回滚会将本地当前生效的档案切换回指定历史版本，云端目录本身不受影响。

从云端安装的档案会自动加入[耗材库](../material-library/material-library.mdx)，也可通过[导入与导出耗材](../material-import-export/material-import-export.mdx)打包为离线备份。
