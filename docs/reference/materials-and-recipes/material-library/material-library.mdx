# 耗材库

耗材库用于集中查看和管理已完成梯度卡标定的本地耗材档案。每份档案同时保存界面预览颜色与叠层混色预测所需的光学拟合参数及标定层高。

## 品牌分组与同名耗材

耗材默认按品牌折叠展示，未设置品牌的档案归入“未分组”。点击品牌标题栏即可展开或收起对应分组。

当多份档案的品牌与显示名称相同、但底层目录或实测数据不同时，列表会标记“同名 N 份”。每份档案均以各自的磁盘目录名作为唯一标识，彼此独立保存。

从官方云端频道安装的档案带有“官方”标记，用于说明档案来源；由于实际打印成色还会受到具体打印机、喷嘴状态与线材批次影响，建议根据实际机器情况搭配自测档案选用。

## 卡片字段

- **显示颜色**：由梯度卡拟合估算出的 RGB 预览色，可在编辑窗口中手动调整。
- **创建时间 / 最近更新**：档案首次创建及最近一次写入更新的时间。
- **品牌 / 目录名**：用于分组归类与唯一定位档案的标识信息。
- **拟合误差**：当前拟合结果的平均 ΔE，用于评估该档案自身的采样与拟合质量（受不同颜色透光特性影响，不宜用于跨颜色横向排名）。
- **验证次数**：已并入当前档案的有效实测次数。
- **使用次数**：该档案在各颜色模式中被实际调用的次数；若有记录，还会一并显示最近使用时间。
- **层高**：打印并拟合该梯度卡时采用的标定层高，后续叠层颜色预测会沿用此项标定条件。

## 顶部操作

顶部工具栏中，“全选耗材”用于快速勾选当前列表中的档案以便批量导出；“刷新耗材库”用于重新读取本地存储中的最新档案列表。

批量备份与跨机迁移见[导入与导出耗材](../material-import-export/material-import-export.mdx)。单份档案的“编辑信息”“再次验证”“展开验证历史”与“删除耗材”操作说明见[编辑与复验耗材](../material-edit-and-verification/material-edit-and-verification.mdx)。
