# 色彩数据来源

**色彩数据来源**决定 Lumina Studio 依据哪类色彩数据，将图片颜色转换为可打印的逐层耗材配方。切换来源不会改动原图，但会同步切换下方可配置的耗材组合或品牌 LUT、叠色层数及底板耗材选项。

## 两种来源对比

| 选项 | 使用的数据 | 适用场景 |
| --- | --- | --- |
| 耗材档案 | 从梯度卡实测提取并保存在耗材库中的单卷耗材档案 | 自由组合已实测耗材，由求解器实时计算逐层叠色配方 |
| 经典 LUT | 预先生成或实测校准的“颜色—配方”查找表 | 直接选用内置 LUT、组合多个兼容 LUT，或导入自定义 LUT 文件 |

同一张图片在不同来源下会得到不同的候选色域与配方结果。首次使用且未保存偏好时，默认选中**耗材档案**；已有使用记录时则自动保留上次选定的来源。

早期版本曾提供“反推 LUT”入口，现已从该开关中移除，历史背景可参阅[旧版说明](../inferred-lut-source/inferred-lut-source.mdx)。

## 切换来源后的变化

切换色彩数据来源后，软件会自动清空当前预览、已生成的 3MF 及下载链接，并重置仅适用于原来源的设置项。切换完成后，请重新确认目标耗材组合或 LUT，再重新生成预览与模型。

## 选择来源后继续设置

- [经典 LUT](../legacy-lut-source/legacy-lut-source.mdx)
- [耗材档案](../material-archive-source/material-archive-source.mdx)

若你使用的是通过梯度卡实测并保存在耗材库中的单卷耗材数据，请选择**耗材档案**并直接从耗材库调用；**经典 LUT** 仅用于加载预生成的查找表文件。
