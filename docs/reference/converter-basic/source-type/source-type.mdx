# 来源类型

“来源类型”决定 Lumina Studio 用哪一套颜色数据，把图片颜色转换成可以打印的逐层耗材配方。
它不会改变原图，但会改变后续可选择的品牌、数据库、层数和底板耗材。

## 三种来源

| 选项 | 使用的数据 | 适合的情况 |
| --- | --- | --- |
| 传统 LUT | 已经生成好的颜色—配方查找表 | 使用旧版 LUT、多个兼容 LUT，或导入自己的 LUT 文件 |
| 反推 LUT | 品牌包中的颜色数据库与可选预测模型 | 使用已经提供原生品牌包、层数模式和数据库的耗材组合 |
| 耗材档案 | 从梯度卡提取并保存在耗材库中的单卷耗材档案 | 自由组合已实测耗材，并由求解器计算逐层配方 |

三种来源不是同一数据的三个显示方式。相同图片在不同来源下可能得到不同候选颜色和配方。

## 切换时会发生什么

切换来源后，软件会清除旧预览、3MF 和下载链接，避免继续使用上一套颜色数据。不同来源还会处理各自
不再适用的设置：

- 切换到传统 LUT 时，会清除反推 LUT 的品牌、数据库、动态层数和模型辅助匹配状态；
- 切换到耗材档案时，会停用模型辅助匹配；
- 切换到反推 LUT 时，会选中当前品牌可用的数据库与受支持层数组合。

因此，切换来源后需要重新确认该来源下的选择，再生成预览。旧的 3MF 不会自动转换成新来源。
