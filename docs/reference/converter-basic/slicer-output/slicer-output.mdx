# 切片软件与下载

Lumina Studio 会自动检测本机已安装的切片软件，并默认选中“设置”里指定的首选切片软件。主输出按钮的具体动作取决于本机是否检测到可用切片软件、当前是否已生成 3MF，以及是否启用了大画幅或独立背板。

## 主按钮动作

| 当前状态 | 点击主按钮后的动作 |
| --- | --- |
| 已检测到切片软件，尚未生成 3MF | 先生成 3MF，随后在所选切片软件中打开 |
| 已检测到切片软件，已有现成 3MF | 直接将当前 3MF 发送至所选切片软件打开 |
| 未检测到切片软件 | 生成并下载 3MF（已有现成文件时直接下载） |
| 大画幅模式 | 生成或下载包含多块分片 3MF 的 ZIP 压缩包，不自动拉起切片软件 |
| 独立背板工程 | 下载包含主体模型与背板两个独立 3MF 的 ZIP 压缩包，解压后分别导入切片软件 |

你也可以随时展开按钮右侧的下拉菜单，选择**生成并下载 3MF**将文件保存到本地（若尚未生成 3MF，软件会先完成生成再下载）。若“设置”中指定的首选切片软件未在本机安装，界面会弹出提示，方便你改选其他已安装软件或直接下载 3MF。

生成前若弹出耗材预设或打印板尺寸确认窗口，请先完成对应选择。修改原图、配色或结构设置后，需重新生成并导出最新 3MF。桌面版支持在“设置”中指定默认保存目录：保存对话框会默认定位到该目录，单次导出时仍可手动改选其他文件夹。

## 导入切片软件后的检查项

3MF 文件内已写入模型几何与材料信息，但最终上机打印的参数仍由切片软件决定。正式切片前建议逐项确认：

1. 打印机型号与喷嘴直径；
2. 每个对象映射的实际耗材槽位；
3. 模型是否平整贴合在打印板上；
4. 首层朝向与显色面方向；
5. 逐层切片预览中的细线条、孔洞与附加结构是否完整保留。
