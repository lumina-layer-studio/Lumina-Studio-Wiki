# 切片软件与下载

Lumina Studio 会检测本机可调用的切片软件，并优先使用“设置”中选择的软件。输出按钮的动作取决于是否
检测到切片器、当前是否已有文件，以及是否启用大画幅。

<img
  src={require('./assets/01-slicer-list.webp').default}

/>

## 主按钮的实际动作

| 当前状态 | 点击后的动作 |
| --- | --- |
| 已检测到切片器，尚未生成 | 先生成 3MF，再在所选切片器中打开 |
| 已检测到切片器，已有 3MF | 直接把当前产物交给所选切片器 |
| 未检测到切片器 | 生成并下载 3MF，或直接下载已有文件 |
| 大画幅模式 | 生成或下载包含多片 3MF 的 ZIP，不自动在切片器中打开 |

下拉列表只显示已经检测到的切片软件，并提供独立“下载 3MF”入口。设置中的首选软件未安装时，界面会提示
不匹配，而不是假装打开成功。

## 为什么必须在切片器中再检查

3MF 包含模型对象和材料信息，但实际机器、喷嘴、打印板、层高和耗材映射由切片器最终决定。打开后至少
检查：

1. 打印机型号和喷嘴尺寸；
2. 每个对象对应的真实耗材；
3. 模型是否位于打印板上方；
4. 首层和显色面方向；
5. 逐层路径中是否保留细线、孔洞和附加结构。

相关教程：[切片软件中的耗材映射](../../../tutorials/slicer-material-mapping/slicer-material-mapping.mdx)。
