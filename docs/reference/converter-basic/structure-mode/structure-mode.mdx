# 结构模式

**结构模式**决定彩色图案层生成在底板的单侧还是双侧。

<img
  src={require('./assets/01-structure-mode.webp').default}
  alt="Lumina Studio 的双面和单面结构模式"
/>

## 双面

在底板正反两侧对称建立彩色叠层，适合吊牌、挂件、双面钥匙扣等正反两面都需要展示图案的作品。开启双面结构会相应增加模型总厚度、耗材用量与切片层数。

## 单面

仅在正面建立彩色叠层，背面保留平整底板。常规摆件、画框插片，以及浮雕、冰箱贴等依赖背面结构的功能均采用单面结构。

## 模式联动与限制

- 开启**浮雕**或**冰箱贴**时，结构模式会被锁定为**单面**；
- 启用**五色扩展模式**时不支持双面，若原本处于双面会自动切回**单面**；
- 切换结构模式会清空已生成的 3MF 与下载文件，需重新生成模型。

导出 3MF 并导入切片软件后，建议旋转视角同时检查顶面与底面，确认显色面朝向、底板贴合面及背面附加结构均符合预期。
