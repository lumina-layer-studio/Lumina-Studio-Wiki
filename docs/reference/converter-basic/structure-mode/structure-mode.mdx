# 结构模式

结构模式决定彩色层出现在底板的一面还是两面。

<img
  src={require('./assets/01-structure-mode.webp').default}
  alt="Lumina Studio 的双面和单面结构模式"
/>

## 双面

双面结构在底板两侧建立对应的彩色层，适合需要正反都能看到图案的吊牌、挂牌等作品。它会增加模型
高度、耗材和切片层数。

## 单面

单面结构只在一侧保留彩色层，另一侧为底板。浮雕、冰箱贴和依赖背面结构的功能使用单面路径。

## 自动限制

- 开启浮雕或冰箱贴时，结构模式会被禁用或强制为单面；
- 五色扩展模式不允许选择双面，若原来是双面会自动切回单面；
- 修改结构模式会清除旧 3MF 和下载结果。

这里控制的是模型几何，不是切片软件中的“打印顺序”或“逐对象打印”。生成后仍应在切片软件中翻转到
底面，确认可见面、底板和附加结构符合预期。
