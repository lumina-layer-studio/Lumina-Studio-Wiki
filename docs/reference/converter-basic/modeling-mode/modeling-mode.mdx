# 建模模式

建模模式决定 Lumina Studio 如何把原图变成颜色网格和模型几何。它不同于颜色来源：来源决定有哪些
可打印配方，建模模式决定怎样读取图片与保留边缘。

## 高保真

位图按约 10 px/mm 建立处理网格，先做边缘保持处理，再按“量化颜色数”聚类和匹配。适合照片、插画、
渐变和包含细小轮廓的普通图片。

## 像素艺术

按喷嘴线宽建立像素尺度，使用最近邻缩放，不先平滑硬边。可见颜色没有超过量化预算时会保留原色板；
超过预算才直接量化。适合像素画和希望每个色块对应稳定打印单元的图像。

## 矢量模式

只在上传 SVG 时可选。位图上传时控件会变灰，存储层也拒绝把位图强制切到矢量模式。矢量路径按形状、
填充和描边生成几何；相关参数见矢量与轮廓页面。

## 验证色卡

用于根据当前配方生成校验色块，不应按普通图片细节理解。生成接口会把它转为专用色卡路径。

## 如何选择

高保真和像素艺术没有固定“谁更清晰”。结果取决于图像风格、成品尺寸、喷嘴线宽和需要保留的边缘。
可先参考[位图与矢量图的区别](../../../knowledge/bitmap-vs-vector/bitmap-vs-vector.mdx)与
[模式选择](../../../knowledge/image-mode-selection/image-mode-selection.mdx)，再用同一尺寸分别预览。

切换模式会清除旧 3MF 和下载结果；必须重新预览和生成。
