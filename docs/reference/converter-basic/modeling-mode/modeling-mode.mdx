# 建模模式

**建模模式**决定 Lumina Studio 如何采样原图、处理边缘并生成三维模型几何。它与“色彩数据来源”分工不同：色彩数据来源提供可用的叠色配方，建模模式决定如何将画面结构转换为色块与模型实体。

## 高保真

位图按约 10 px/mm 建立采样网格，先执行保边平滑处理，再按“量化颜色数”聚类并匹配叠色配方。适合照片、插画、自然渐变以及带有细小轮廓的常规图片。

## 像素艺术

按喷嘴线宽建立像素网格，采用最近邻缩放以完整保留硬朗边缘，不做平滑过渡。当可见颜色数未超过“量化颜色数”上限时，直接保留原有色板；超出上限时再对像素颜色做量化归并。适合像素画、点阵图标以及需要每个色块对应清晰打印单元的图像。

## 矢量模式

仅上传 SVG 时可选；上传位图时该项不可用。软件直接依据 SVG 中的路径形状、填充和描边生成三维几何，相关细节可在矢量与轮廓设置中调整。

## 验证色卡

根据当前选定的色彩配方直接生成标准校验色块模型，供你在正式打印作品前实打核对耗材的真实显色效果。

## 如何选择

照片、插画和柔和渐变优先选**高保真**；硬边像素画或小尺寸色块图优先选**像素艺术**。实际清晰度同时受原图风格、成品尺寸与喷嘴线宽影响，可在相同目标尺寸下分别预览对比，或参阅[位图与矢量图的区别](../../../knowledge/bitmap-vs-vector/bitmap-vs-vector.mdx)与[模式选择](../../../knowledge/image-mode-selection/image-mode-selection.mdx)。

切换建模模式后，已生成的 3MF 将失效，需重新预览并生成模型。
