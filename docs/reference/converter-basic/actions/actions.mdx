# 预览、生成与导出

转换页面底部的操作栏集中了色彩预览、分层检查、3MF 生成和配方导出功能。调整参数后先运行预览，即可在生成可打印模型前确认配色与几何结构。

## 预览

点击**预览**会根据当前图片、色彩数据来源和各项设置计算匹配结果，并同步生成：

- 当前匹配结果的 2D 效果预览；
- 供 3D 查看器展示的模型预览；
- 调色板、分层图与颜色工作站所需的颜色数据。

尚未导入图片或色彩数据来源未配置完整时，**预览**按钮保持禁用，并提示缺少的条件。修改任何影响输出效果的参数后，请重新点击**预览**以刷新模型与分层图。

## 下载 3MF 或打开切片软件

确认预览效果理想后，可通过主导出按钮一步完成模型生成与交付，无需先寻找单独的“生成”按钮。按钮文案会随本机检测到的切片软件和文件状态自动切换（例如**生成并在 Bambu Studio 中打开**、**生成并下载 3MF**或**下载 3MF**），点击右侧下拉箭头可切换执行方式。未检测到本地切片软件时，仍可直接生成并下载 3MF 文件。

开启拼图或大画幅等模式时，该按钮会走对应模式的专属生成流程。修改参数不会更新此前已下载的文件；调整设置后请先检查新预览，再重新生成导出。

## 查看分层

点击**查看分层**可生成当前配色方案中每一光学显色层的分布图，点击缩略图即可放大查看细节。将鼠标悬停在主预览图上时，颜色检查器会同步显示该位置的表面颜色及下方各层的叠色配方，方便在进入切片软件分配实体耗材前核对叠层顺序。

## 分享卡与 JSON

完成图片导入与预览后，可将当前转换配方导出保存：

- **导出分享卡：** 将作品封面图与可复现配方打包在同一文件中，适合直接分享给其他 Lumina 用户。
- **导出 JSON：** 仅导出独立的 JSON 配方文件，便于备份归档、版本管理或自动化处理。

这两种文件记录的是可再次导入编辑的 Lumina 转换参数。详细结构与导入方式见[分享卡与 JSON](../../../knowledge/share-card-json/share-card-json.mdx)。

## 热床尺寸

操作栏会显示系统设置中当前所选打印机的热床尺寸，用于在 2D/3D 预览中提供比例参照与边界提示。在切片软件中打开 3MF 后，请再次确认目标机型、喷嘴直径和打印板配置。
