# 预览、生成与导出

操作栏把同一组参数的检查、建模和交付分成不同阶段。先预览再生成，可以在下载 3MF 前发现图片、颜色和
结构设置的问题。

## 预览

“预览”读取当前图片、颜色来源和全部设置，建立一个新的预览会话。成功后会得到：

- 当前匹配结果的 2D 预览；
- 供 3D 查看器使用的模型预览；
- 调色板、分层图和颜色工作站所需的数据；
- 后续生成 3MF 所需的会话状态。

图片或颜色来源尚未准备好时，按钮会禁用并显示缺少的条件。修改会影响结果的参数后，应重新预览；旧的
分层图不会混用到新会话。

## 生成

“生成”只在当前预览会话有效时可用。它把当前参数变成可打印 3MF；拼图、大画幅等模式会进入各自的专用
生成流程。生成完成前，之前下载的文件不会自动获得新参数。

底部的主按钮可以把“生成”和“打开切片软件”合并为一步。它仍会先完成生成，再把产物交给检测到的切片
软件。

## 查看分层

“查看分层”从当前会话生成每一光学层的图片。缩略图可点击放大；在主预览上悬停时，颜色检查器会读取同一
位置的表面颜色与各层颜色。它用于核对配方，不代表切片软件已经采用了对应耗材。

## 分享卡与 JSON

- **导出分享卡：** 把封面图和可复现配方放在同一分享文件中，适合交给另一位 Lumina 用户；
- **导出 JSON：** 只导出配方侧车文件，便于版本管理、检查和自动化。

两种导出都要求已经有图片和预览。它们保存的是 Lumina 参数，不是切片后的 G-code。详细格式见
[分享卡与 JSON](../../../knowledge/share-card-json/share-card-json.mdx)。

## 热床尺寸

操作栏显示设置中当前打印机的热床尺寸。它用于 2D/3D 预览比例和边界判断，不会替代切片软件中的打印机
配置。最终仍要在切片器里确认机器、喷嘴和打印板。
