# 大画幅模式

**大画幅模式**可将超出单块热床幅面或不便单次打印的作品切分为多块子板，每块独立生成 3MF 文件，并统一打包为 ZIP 压缩包下载。

## 成品尺寸与切片尺寸

开启大画幅模式后，作品成品宽高的上限会从 `400 mm` 扩展至 **9999 mm**。**切片宽度**与**切片高度**可在 **50–500 mm** 范围内调节，步长为 **10 mm**。

分片网格按以下规则计算：

- **列数** = 成品宽度 ÷ 切片宽度（向上取整）；
- **行数** = 成品高度 ÷ 切片高度（向上取整）；
- **总片数** = 行数 × 列数；
- 最右侧一列与最下方一行仅保留实际剩余尺寸，不会补入空白边框凑满整片。

面板底部显示的 `列×行 = 总片数` 即根据上述规则实时计算；若边缘分片小于标准切片宽高，括号内会标明边缘片的实际尺寸。

## 输出与切片注意事项

在大画幅模式下点击生成会直接下载一个 ZIP 压缩包，内部每个 3MF 文件均带有原图名称与行列坐标后缀，打印完成后按编号顺序拼接即可。设置切片宽高时，请使其小于打印机的实际可打印面积，为裙边（Skirt/Brim）、擦料塔或耗材清理区以及热床禁印边界预留余量。

上传原生 SVG 时，结构规整的文件会直接按矢量几何路径分片；若遇到难以直接矢量裁切的复杂 SVG 特性，软件会自动回退为按像素预算光栅化后再分片，并在界面显示提示。回退不会改变成品的物理拼接尺寸，但极细微边缘的锐利度可能略受影响。

## 模式互斥与兼容

**拼图**模式与**冰箱贴**磁铁槽均与大画幅模式互斥，启用其中任一功能时会自动关闭大画幅模式。普通**浮雕**、**外轮廓**和**透明镀层**均支持随大画幅一同分片生成，打印前建议在预览或切片软件中检查相邻分片接缝处的边缘过渡是否连续。
