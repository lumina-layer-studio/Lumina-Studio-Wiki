# 大画幅模式

大画幅模式把超出单块热床或不便一次打印的作品切成多片，每片生成独立 3MF，最后打包为 ZIP 下载。

## 成品尺寸与切片尺寸

开启后，成品宽高上限从 400 mm 提高到 **9999 mm**。切片宽度和高度可设置为 **50–500 mm**，
步进为 **10 mm**。

界面按以下方式预估网格：

- 列数 = 成品宽度 ÷ 切片宽度，向上取整；
- 行数 = 成品高度 ÷ 切片高度，向上取整；
- 总片数 = 行数 × 列数；
- 最右列和最下行只保留实际剩余尺寸，不会用空白补足到整片大小。

因此面板中的 `列×行 = 总片数` 是当前参数的直接结果；括号内尺寸表示最后一片与标准切片尺寸不同。

## 输出与切片

大画幅生成按钮会下载 ZIP，而不是只打开一个 3MF。每片的文件名包含来源名称和位置标签，打印后需要按
行列位置拼接。切片宽高应小于实际可用热床范围，并为裙边、耗材清理区和机器边界留出空间。

原生 SVG 在结构允许时使用矢量分片；遇到不适合安全切割的 SVG 时会回退为受像素预算限制的栅格分片，
界面会显示警告。回退不会改变成品物理尺寸，但可能影响小细节。

## 不能同时开启的模式

拼图和冰箱贴磁铁槽会禁用大画幅；开启其中任意模式时，大画幅状态自动关闭。普通浮雕、外轮廓和透明
镀层可以随分片生成，但应检查每片边缘是否连续。
