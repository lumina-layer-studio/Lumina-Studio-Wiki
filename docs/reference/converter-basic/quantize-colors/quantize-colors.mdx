# 量化颜色数

**量化颜色数**用于设定图像在匹配叠色配方前最多保留多少种聚类颜色。默认值为 **48**；未解锁上限时可在 **8–256** 之间调整，步长为 **8**。

该数值作用于图像色彩聚类阶段，与打印机装载的耗材卷数及最终 3MF 中的对象数量相互独立：同一种聚类颜色会映射为一套多层耗材叠色配方，几种相近的聚类颜色也可能匹配到同一套配方。

## 控件位置

依次打开**图像转换 → 核心设置 → 基础设置**，在**建模模式**下方即可找到**量化颜色数**。

## 数值的作用机制

在高保真位图模式下，软件先按目标物理尺寸缩放图像，再通过 K-Means 将相近像素归并到不超过设定值的颜色中心。调高数值可保留更多局部色差与渐变层次；调低数值则会收拢相近色块，并加快处理速度。

该数值为上限值：若缩放后的画面本身只包含少量有效颜色，软件会按实际颜色数保留，不会额外拆分出新颜色。完成颜色量化后，软件再依据当前选定的 LUT 或耗材档案将各聚类颜色匹配为可打印配方。

## 不同模式下的生效范围

| 当前路径 | 实际作用 |
| --- | --- |
| 高保真位图 | 作为全图 K-Means 聚类的最大颜色数 |
| 像素艺术 | 控制像素颜色归并上限；若画面可见颜色数未超过上限，直接保留原色板 |
| 原生 SVG 矢量 | 直接按 SVG 图形的填充与描边颜色处理，不执行全图 K-Means 量化 |
| SVG + 耗材档案渐变 | 限制渐变区域的离散色带数量，内部有效范围收敛在 16–32 |
| 验证色卡 | 直接按色卡布局和当前配方生成标准色块，不执行图像颜色量化 |

在矢量模式下，纯色形状与描边始终保留原始颜色；仅当 SVG 包含渐变且搭配“耗材档案”来源时，软件才会参考该数值切分渐变色带（自动限制在 16–32 之间）。

## 自动计算

上传图片后点击**自动计算**，软件会结合当前成品宽度分析画面复杂度，并将建议值写回滑块（未上传图片时该按钮不可用）。分析过程综合五项特征：

1. 按约 5 px/mm（5 像素/mm）缩放到打印尺寸对应的分析图，最长边不超过 600 像素；
2. 统计粗量化后的独特颜色数量；
3. 统计显著色相分布与有色像素占比；
4. 评估主色调的集中程度；
5. 计算边缘密度，并按目标宽度的平方根修正建议值。

最终建议值会自动对齐到 8、16、24、32、48、64、96、128、160、192 或 256；目标宽度越大，建议值相应提高（宽度系数范围为 0.8–2.5）。

自动计算基于原图复杂度给出初始建议值，不预设具体 LUT 或耗材档案的可达色域，建议在生成预览后按画面效果微调。

## 调整建议

- **边缘或渐变被明显合并**：逐步调高数值后重新生成预览观察过渡。
- **画面出现大量单像素杂色**：先检查原图噪点与成品尺寸；继续调高量化颜色数往往会保留更多细碎杂色，可配合孤立像素清理优化。
- **数值已调高，但 3D 预览颜色仍偏少**：检查是否开启了[3D 高精度颜色预览](../../preview-and-palette/high-precision-3d-preview/high-precision-3d-preview.mdx)。
- **需要超过 256 的上限**：开启[解锁量化颜色数](../../color-matching/unlock-quantize-ceiling/unlock-quantize-ceiling.mdx)，开启后再手动上调滑块数值。

修改量化颜色数后，已生成的 3MF 将失效，需重新生成预览或模型。导出的 Lumina 配方卡会一并记录当前的量化颜色数。
