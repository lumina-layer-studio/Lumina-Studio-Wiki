# 经典 LUT

**经典 LUT** 是预先计算或实测生成的颜色查找表，表中每个可打印颜色都对应一组固定的逐层耗材叠色配方。预览图片时，Lumina Studio 会在查找表中检索与原图各区域最接近的颜色条目。

## 选择 LUT

<img
  src={require('./assets/02-lut-picker.webp').default}
  alt="经典 LUT 选择窗口中的品牌列表、搜索框和确认按钮"
/>

1. 在**色彩数据来源**中选择**经典 LUT**，打开 LUT 选择窗口。
2. 通过搜索框或品牌分类浏览列表，勾选所需的 LUT（支持跨品牌选择）。
3. 点击确认返回基础设置，运行**预览**并检查主体色、灰阶过渡与暗部层次。

你可以同时勾选多张互相兼容的 LUT。多选时以列表中的第一项为主 LUT，所有已选查找表会在内存中合并为同一组候选颜色参与匹配，磁盘上的原始 LUT 文件保持不变。合并多张 LUT 时，请确保它们的叠色层数、层高及耗材通道彼此兼容。

## 刷新与上传

在本地目录新增或替换 LUT 文件后，点击选择窗口内的刷新按钮即可重新加载列表。

点击**上传**可导入 `.npy`、`.json`、`.npz` 和 `.msgpack` 格式的查找表文件，导入完成后请在列表中确认已勾选目标条目。若预览色彩表现异常，可打开 LUT 详情核对其颜色模式、叠色层数、层高及配方元数据是否完整。

## 动态层数

仅当所选 LUT 的元数据声明支持动态层数（`supports_dynamic_layer_count`）时，基础设置中才会显示**叠色层数**与**叠色层高**控件。此时层数可在 **1–20** 之间调节，层高可在 **0.04–0.20 mm** 之间调节；修改任一参数都会清空旧的预览与生成结果。

常规固定层数的经典 LUT 直接采用文件内记录的层数与层高，界面隐藏上述两项控件时仍按原表配方正常生成。
