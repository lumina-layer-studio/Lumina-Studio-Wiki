# 底板厚度

**底板厚度**用于设置彩色显色层下方结构底板的高度，默认值为 **1.20 mm**。

<img
  src={require('./assets/01-backing-thickness.webp').default}
  alt="Lumina Studio 基础设置中的底板厚度滑块"
/>

*图中旧版滑块现已统一命名为“底板厚度”。*

滑块调节范围为 **0.24–10.00 mm**，步长为 **0.08 mm**，便于与常用打印层高保持整数倍对齐（导入外部参数时有效范围为 **0.20–10.00 mm**）。

## 对模型结构与高度的影响

底板厚度仅代表底层支撑结构本身，不包含彩色显色层、浮雕起伏高度或透明镀层。估算成品总厚度时，需要将以上各部分的高度相加。

部分结构功能会自动约束或抬高实际底板厚度：

- **浮雕：** 开启后，软件会自动确保浮雕起伏高度不低于当前底板与显色层所需的最小安全厚度。
- **冰箱贴：** 开启后，若磁铁槽深度加上保底壁厚超过当前设定的底板厚度，实际生效厚度会自动抬高以容纳磁铁孔；关闭冰箱贴后会恢复原先保存的底板厚度。

较薄的底板适合小尺寸摆件并能节省打印时间；大幅面作品或带有挂孔、支架槽的模型建议适当加厚底板，以保证结构刚性与边缘强度。调整底板厚度后请重新生成 3MF，切勿在切片软件中直接缩放模型的 Z 轴高度，否则会同时拉厚光学显色层并改变透光配色效果。

底板厚度还会决定[底板填充率](../backing-infill/backing-infill.mdx)是否生成稀疏填充：靠近观赏面的 3 mm 保护区始终保持实心，底板超过该厚度后深层区域才会应用稀疏填充。
