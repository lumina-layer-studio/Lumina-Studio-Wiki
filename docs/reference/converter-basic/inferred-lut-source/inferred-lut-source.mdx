# 反推 LUT

:::warning[旧版资料]
新版“色彩数据来源”已移除“反推 LUT”选项，本页内容保留供旧版用户参考。
:::

与直接选用单张固定查找表的经典 LUT 不同，**反推 LUT** 会读取耗材品牌包中的颜色数据库、受支持的叠层组合及可选预测模型：先选定品牌，再指定参与匹配的数据库与层数模式。

## 品牌与数据库

选定品牌后，界面仅列出该品牌包声明的数据库。复选框决定哪些实测或计算数据库参与配色匹配，至少需要勾选一个数据库才能开始预览。

切换品牌时，原先勾选的数据库会清空并恢复为新品牌包的默认勾选组合，原有的预览和已生成的 3MF 也会同步失效。

## 层数

调整层数滑块时，软件会在品牌包的 `supported_modes` 中匹配可用的叠层方案：

- 若所选层数下存在与当前层高完全一致的组合，直接启用该组合；
- 若所选层数包含多种层高但无完全一致项，自动选用最接近当前层高的一项；
- 若品牌包未提供所选层数，则保持上一次的有效组合不变。

控件下方的**支持模式**列出了该品牌包实际可用的全部“层数 @ 层高”组合，预览与生成均按匹配到的组合执行。

## 模型辅助匹配

仅当所选品牌包内置可用的预测模型时，界面才会显示**模型辅助匹配**与**仅模型匹配**选项。默认情况下仍以实测颜色数据库为基准；开启模型辅助后，当数据库匹配色差较大而模型预测结果明显更优时，软件会采用模型候选方案。详细判定逻辑见[模型辅助匹配](../../color-matching/model-assisted-matching/model-assisted-matching.mdx)。
