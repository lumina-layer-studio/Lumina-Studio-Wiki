# 耗材档案来源

耗材档案模式使用梯度卡实测并保存在耗材库中的单卷耗材数据。你可以自由组合多卷耗材，再让 Lumina
Studio 计算各层配方，而不是从一张固定 LUT 中取现成结果。

## 选择耗材

“选择耗材”会打开耗材库。确认后，列表顺序就是后续配方中的材料槽顺序；更换、删除或重排耗材都会
使旧预览失效。软件会尝试把旧目录名迁移到耗材库当前名称，但找不到的档案不会静默替换成其他耗材。

## 叠色层数

界面允许 5–10 层，生成接口可接受 1–20 层。这里的数字是每个像素配方可以使用的打印层数，不是所选
耗材卷数。五卷耗材也可以计算十层配方，因为同一耗材可以在多层重复出现。

层数增加会扩大候选组合数量，也会提高模型高度和求解成本。修改后需要重新预览。

## 层高

当前界面提供 0.04、0.08 和 0.10 mm。层高决定每层透色贡献及整套实测数据的适用条件。不要把
0.08 mm 梯度卡档案直接当成 0.04 mm 数据理解；实际可用范围以档案和求解器校验为准。

## 底板耗材

“底板耗材”只能从已选耗材中选择。生成请求保存的是该耗材在当前列表中的索引；若原选择被移除，
软件会重新推断一个默认底板耗材。未明确分离底板颜色时，底板、轮廓等基础结构会沿用这项选择。

## 穷举缓存

“穷举缓存…”在选择至少一种耗材后可用。它会为当前组合建立一个持久化的精确配方库。缓存身份同时包含：

- 耗材及其排列顺序；
- 叠色层数；
- 层高；
- 基底类型；
- 设置页选择的 Lab 网格精度。

其中任何一项改变，界面都会查询另一份缓存，而不是继续沿用旧结果。

缓存就绪后，详情会显示构建时间、文件大小、有效格数、平均与最大 ΔE，以及构建耗时。“查看色彩分布图”
会读取这份缓存的 Lab / RGB 分布；“重新构建”覆盖同一组合的现有缓存，“删除缓存”只删除当前组合和当前
网格精度对应的文件。

精确穷举缓存不存在时，当前转换流程会按从大到小的顺序查找已保存的智能配方缓存；仍未找到时，会临时建立
一份最多约 100 万条候选的运行时缓存。它能继续完成预览，但候选覆盖不等同于完整穷举。

## 智能配方缓存

智能配方缓存面向完整组合数过大的耗材集合。它使用固定候选预算保存一组覆盖范围较广的配方，而不是承诺枚举
所有可能排列。界面提供约 100 万、400 万、800 万、3200 万和 6400 万条五个档位，默认档位为 3200 万条。

缓存规模越大，候选覆盖通常越广，构建时间、磁盘占用和构建期内存也会增加。状态区会显示实际保存的配方数、
候选预算、文件大小、构建时间及反推精修状态；“查看配方覆盖图”用于检查这组候选在颜色空间中的分布。

穷举缓存与智能配方缓存互不覆盖。转换时，匹配当前组合的穷举缓存优先；没有穷举缓存时才使用智能配方缓存。
两类缓存都不会修正不准确的耗材测量，也不会改变层序和光学计算规则。
