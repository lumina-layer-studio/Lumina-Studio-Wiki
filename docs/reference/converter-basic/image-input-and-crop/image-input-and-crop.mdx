# 图片上传、批量选择、裁剪与旋转

导入图片是图像转换的第一步，后续的预览、颜色匹配与模型几何轮廓都基于此处载入的素材。你可以点击上传区选择文件，也可以直接将文件拖入上传区；载入图片后上传区会收起为单行，点击文件名区域即可重新展开。

## 支持的文件格式

转换入口支持导入以下类型的文件：

- JPEG、PNG、SVG 和 WebP；
- HEIC 与 HEIF；
- DNG、CR2、CR3、NEF、ARW、ORF、RW2、RAF、PEF、SRW 及通用 RAW 格式；
- Lumina 的 `.lumina.json` 项目文件。

RAW、HEIC 和 HEIF 的直接读取取决于当前运行环境的解码支持；若环境不支持直接解码，软件会提示先将其转换为 PNG 或 JPEG。上传 SVG 时按矢量图形处理，即使开启了“上传后裁剪”，也不会自动弹出位图裁剪窗口。

## 单图、追加与批量模式

载入单张普通图片时，上传区会展示当前图片预览，并提供两项操作：

- **更换当前图片：** 替换当前任务所使用的图片；
- **添加更多图片：** 追加文件并切换为批量转换任务。

进入批量模式后，上传区会展示文件列表，支持继续追加或逐个移除文件。列表最多直接列出 **40** 个文件名，超出部分以剩余文件数汇总显示。批量模式下不提供单图裁剪开关，请在加入队列前预先调整好每张图片的方向与构图。

当一次仅选择单个 `.lumina.json` 文件或带有 Lumina 配方的 PNG 分享卡时，软件会自动按项目文件导入并恢复对应参数；不含有效配方数据的普通 PNG 仍按常规图片导入。完整恢复流程详见[分享卡与 JSON：导出、导入和继续编辑](../../../knowledge/share-card-json/share-card-json.mdx)。

## 上传后裁剪

开启**上传后裁剪**后，每次新选入单张位图都会自动打开裁剪窗口。关闭该开关仅对后续新选入的图片生效，当前已完成裁剪的图片保持不变。

裁剪窗口提供以下控制项：

- 自由比例；
- `1:1`、`4:3`、`3:2`、`16:9`、`9:16` 和 `3:4` 固定比例；
- 原图尺寸与当前选区像素尺寸显示；
- `X`、`Y`、宽度与高度的精确像素输入框；
- **向左旋转 90°**、**向右旋转 90°**、**取消**和**应用更改**按钮。

拖动画面选框与手动输入像素数值会实时同步，且选区自动限制在原图边界之内。点击**应用更改**后，当前任务的图片、预览和宽高比会一并更新为裁剪结果；按 `Esc`、关闭窗口或点击**取消**则会放弃本次改动。

上传单张图片后，点击**裁切与旋转**打开编辑窗口，选择**向左旋转 90°**或**向右旋转 90°**（连续点击两次可旋转 180°），最后点击**应用更改**保存。

确认旋转后，软件会更新当前工作图片及其宽高比，后续的 2D/3D 预览、颜色匹配、分享卡、JSON 导出与 3MF 模型均采用旋转后的方向。SVG 文件同样可在此窗口旋转方向并完整保留矢量路径，不会执行位图化裁剪。

## 修改图片后的检查

更换、裁剪或旋转图片后，原先的预览已不再反映最新素材。请重新点击**预览**，核对模型外轮廓、方向、透明镂空区域、分层图与目标物理尺寸。完整操作步骤见[上传、裁剪与旋转图片](../../../knowledge/image-upload-crop-rotate/image-upload-crop-rotate.mdx)。
