# 预设

**预设**用于保存一组常用的转换参数。处理同类图片时，从下拉菜单中选择已保存的预设即可一键套用配置，省去逐项重复设置的步骤。该控件位于**图像转换 → 核心设置 → 图像导入和基础设置**中，介于图片上传区与色彩数据来源之间。

## 保存预设

<img
  src={require('./assets/01-save-preset.webp').default}
  alt="保存参数预设窗口中的名称、保存内容和可选设置"
/>

1. 先在基础设置中配好色彩数据来源、耗材或 LUT、目标尺寸、叠色层数、层高及单面／双面模式。
2. 点击**保存为预设**，输入 **1–40** 个字符的唯一名称（不可与已有预设重名）。
3. 在**保存内容**中核对参数摘要，并按需勾选**高级设置**、**外轮廓**或**透明镀层**（这三组默认不勾选）。
4. 点击**保存预设**完成创建。

预设中的尺寸按图片的**长边**记录。例如保存长边为 `100 mm` 的预设后，无论套用到横图还是竖图，都会自动将新图片的长边设为 `100 mm`，并按原图宽高比计算短边尺寸。

## 套用与管理预设

在**预设**下拉菜单中点击预设名称即可套用；预设中未勾选保存的可选参数组会保留界面当前值。套用后请核对耗材与尺寸设置并重新点击**预览**；此前已导出的 3MF 文件不会自动更新。

套用预设后若手动改动了参数，状态会显示为**已修改**，原预设不会被自动覆盖；如需将新参数写回该预设，请点击**更新预设**。此外，还可在下拉菜单中对选中预设执行重命名或删除操作，删除预设不会清空当前面板上正在使用的参数。

菜单中的**上次使用**可恢复上一次转换时保存的设置；导入外部项目后，菜单中还会提供**当前项目参数**选项。

## 预设与项目文件的区别

预设保存的是通用转换参数以及对所选耗材档案或 LUT 的引用，不包含原图、预览结果或局部颜色替换记录。跨设备使用同一预设时，请先确认目标设备上已安装对应的耗材档案或 LUT。若需完整备份或向他人分享某件具体作品，请连同原图一起保存，并使用[分享卡与 JSON：导出、导入和继续编辑](../../../knowledge/share-card-json/share-card-json.mdx)。
