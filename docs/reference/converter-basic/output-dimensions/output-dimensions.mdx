# 成品宽度与高度

“宽度”和“高度”表示打印成品在 XY 平面的目标尺寸，单位为毫米。它们不是上传图片的像素尺寸。

## 比例联动

图片上传后，软件记录原图宽高比。修改宽度时，会按该比例重新计算高度；修改高度时，也会反向计算宽度。
联动结果取整到毫米，并限制在当前模式允许的范围内。

普通模式下宽高范围为 10–400 mm；开启大画幅后上限扩展到 9999 mm。能输入该尺寸不代表单台打印机
可以一次打印，仍要检查热床尺寸，或使用[大画幅模式](../../../knowledge/large-format/large-format.mdx)
拆分成多个板件。

## 尺寸会影响什么

- 决定最终模型的 XY 尺寸；
- 决定图像处理阶段使用的目标采样网格；
- 影响量化颜色自动建议值；
- 影响钥匙扣、磁铁孔、轮廓等附加结构相对于主体的位置。

高保真位图通常按 10 px/mm 建立处理网格；像素模式按喷嘴线宽建立像素尺度。SVG 高保真路径使用设置
中的 SVG 光栅化密度。详情见[建模模式](../modeling-mode/modeling-mode.mdx)。

修改尺寸后，已有 3MF 和下载链接会失效。重新预览后再判断细节是否足够，不要用浏览器把旧预览拉大
来代替重新计算。
