# 成品宽度与高度

**宽度**和**高度**用于设定打印成品在 XY 平面上的实际物理尺寸，单位为 mm。

## 比例联动与尺寸范围

上传图片后，软件会自动锁定原图宽高比：修改**宽度**时自动按比例换算**高度**，修改**高度**时也会同步换算**宽度**。联动计算结果取整到毫米，并自动限制在当前模式允许的尺寸范围内。

普通模式下宽高可调范围为 10–400 mm；开启大画幅后上限扩展至 9999 mm。若目标尺寸超出单台打印机的热床幅面，请先核对热床尺寸，或启用[大画幅模式](../../../knowledge/large-format/large-format.mdx)将作品拆分为多块板件分别打印。

## 尺寸会影响什么

修改成品宽高不仅改变模型外形大小，还会同步更新以下计算：

- 最终三维模型的 XY 物理尺寸；
- 图像处理阶段的目标采样网格（高保真位图约按 10 px/mm 采样，像素艺术按喷嘴线宽采样，SVG 高保真路径则使用设置中的 SVG 光栅化密度，详见[建模模式](../modeling-mode/modeling-mode.mdx)）；
- “量化颜色数”的自动计算建议值；
- 钥匙扣挂孔、磁铁孔、轮廓等附加结构相对于主体的位置比例。

修改任一尺寸后，已生成的 3MF 与下载文件都会失效。由于采样网格随目标物理尺寸重新计算，调整尺寸后请重新生成预览，以确认新尺寸下的细节表现。
