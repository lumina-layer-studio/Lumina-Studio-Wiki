# ColorChecker 校色

开启 ColorChecker 校色后，上传的校准板照片会先进入色卡校正对话框。确认后的全分辨率校色结果再交给 LUT 提取器，
避免只对界面缩略图校色。

## 基准与定位

先选择内置或自定义基准。基准包含色块 Lab 数值、白点和内容哈希；上传 `.xlsx` 可建立会话内的自定义基准。
基准未准备完成时，自动定位和校色按钮不会启用。

“自动定位色卡”会返回四个角点和置信度；也可以手动放置、拖动角点。色卡方向支持正常、旋转 180°、水平翻转和
垂直翻转。生成拉正预览后，应确认色块顺序与基准一致。

## 采样与算法

- **采样方式：** 均值或中位数；
- **采样半径：** 控制每个色块中心取样范围；
- **输出柔化：** 对校正输出施加可选模糊；
- **灰阶归一化：** 自动、强制启用或回退模式；
- **校色算法：** 3×3 矩阵、3×4 矩阵、根多项式或自动选择。

较大的采样范围不是越好：范围触及色块边缘、反光或阴影时，会把污染数据带入拟合。

## 确认结果

结果页显示平均、中位数、P95 和最大 ΔE00、最差色块及灰阶检查。被排除色块、灰阶偏差或参考数据风险会以警告显示。
“确认使用”把校色图交给 LUT 提取；“重新校色”返回参数阶段，不会把未确认结果写入提取流程。

ColorChecker 校色只能减少拍摄与光照偏差，不能修复过曝、严重反光、失焦或错误打印的校准板。
