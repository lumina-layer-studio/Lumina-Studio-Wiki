# ColorChecker 校色

在 LUT 提取器中开启 **ColorChecker 校色**后，上传校准板照片会先打开色卡校正对话框，对全分辨率原图进行色彩还原，确认后再将结果送入 LUT 提取流程。

## 基准与定位

首先选择内置基准，或上传 `.xlsx` 文件建立当前会话的自定义基准（包含各色块 Lab 参考值、白点和内容哈希）。基准加载就绪后，自动定位与校色按钮随即启用。

点击**自动定位色卡**会自动识别四个角点并返回置信度，也可在画布上手动点击或拖动角点。色卡方向支持正常、旋转 180°、水平翻转和垂直翻转；生成拉正预览后，请核对色块排列顺序是否与所选基准一致。

## 采样与算法

- **采样方式**：可选均值或中位数。色块表面有细微灰尘或局部噪点时，中位数更具抗干扰性。
- **采样半径**：控制每个色块中心的取样范围。适当调大可平滑表面纹理；若色块边缘存在阴影、反光或边框干扰，建议调小半径以避开边缘区域。
- **输出柔化**：对校正输出图像施加可选模糊，用于平抑高频噪点。
- **灰阶归一化**：支持自动、强制启用或回退模式，用于稳定中性灰阶的明度与白平衡基准。
- **校色算法**：支持 3×3 矩阵、3×4 矩阵、根多项式或自动选择。

## 确认结果

结果页会列出平均、中位数、P95 和最大 ΔE00、最差色块以及灰阶检查结果；若存在被排除色块、灰阶偏差或参考数据风险，页面会显示相应警告。点击**确认使用**会将校色后的图像交由 LUT 提取器继续处理；点击**重新校色**则返回参数阶段重新调整。

:::tip[拍摄质量要求]
ColorChecker 校色用于消除相机色彩倾向与环境光源色偏。拍摄校准板与色卡时，请确保对焦清晰、布光均匀，避免高光过曝或表面强反光。
:::
