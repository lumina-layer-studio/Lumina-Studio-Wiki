# LUT 详情与色域图

LUT 详情用于检查一个 LUT 实际声明的材料、颜色模式、打印参数、能力和颜色覆盖，而不是只看文件名判断是否适用。

/>

## 摘要与元数据

- **颜色数**是可绘制的 LUT 记录数，不等于基础耗材数量。
- **来源类型**区分传统查表、预测模型等数据来源。
- **层高、线宽、最大颜色层数、底层数和层顺序**描述建立该 LUT 时的结构。
- **基础通道**指出配方中作为基底的通道索引。
- **能力**用于判断是否支持预测匹配、动态层高、动态层数或自定义配方。
- **支持模式**列出该 LUT 明确声明的层数与层高组合。

原始元数据区域保留文件中的附加字段，用于排查旧格式或迁移问题；正常选择 LUT 时应优先阅读结构化字段。

## 调色板

调色板把通道编号、颜色名称、材料和 HEX 色值对应起来。打印时应按通道顺序装载实际耗材，不能只凭颜色外观猜测
槽位。

  src={require('./assets/02-color-charts.webp').default}

/>

## 颜色图

- **Lab 图：** 2D 显示 a*/b* 平面；3D 加入 L* 亮度，并可查看参考切片。
- **RGB 图：** 显示记录在 RGB 立方体中的覆盖。
- **色相—亮度：** 检查不同色相可达到的相对明暗范围。
- **色相—彩度：** 检查不同色相可达到的相对饱和范围。

中性色没有稳定色相，会从依赖色相的图中省略，但仍保留在 LUT 和 Lab/RGB 统计中。

需要判断两批耗材或两次校准差异时，使用 [LUT 对比](../lut-compare/lut-compare.mdx)。
