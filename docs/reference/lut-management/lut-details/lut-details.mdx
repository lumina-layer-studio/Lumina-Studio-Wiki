# LUT 详情与色域图

在 **LUT 详情**中加载任意 LUT，即可查看其完整声明的耗材类型、色彩模式、打印结构参数、功能特性及色域覆盖分布，便于在建模与打印前确认匹配关系。

## 摘要与元数据

- **颜色数**：当前 LUT 包含的可打印叠色记录总数（区别于基础耗材色数）。
- **来源类型**：标识数据来源类型，如传统查表（`legacy_lookup`）或预测模型。
- **层高、线宽、最大颜色层数、底层数和层顺序**：描述建立该 LUT 时所依据的切片与叠色打印结构。
- **基础通道**：指出配方中用作底色基底的通道索引。
- **能力**：标明该 LUT 是否支持预测匹配、动态层高、动态层数或自定义配方。
- **支持模式**：列出该 LUT 明确声明支持的层数与层高组合。

日常选型时直接参考上方的**摘要**与**类型化元数据**即可；底部的原始元数据完整保留了源文件附加字段，主要用于排查旧格式或数据迁移问题。

## 调色板

**调色板**将各通道编号、颜色名称、耗材类型和 HEX 色值一一对应。实际装机打印时，请严格按照通道编号顺序将对应耗材装入供料槽位。

## 色域分布图

- **Lab 图**：2D 视图展示 `a*/b*` 色度平面分布；3D 视图加入 `L*` 明度轴，并支持叠加参考切片。
- **RGB 图**：展示全部颜色记录在 RGB 立方体空间内的覆盖范围。
- **色相—亮度**：查看不同色相下可达到的相对明暗区间。
- **色相—彩度**：查看不同色相下可达到的相对饱和度上限。

黑、白、灰等中性色没有稳定色相角，因此不在依赖色相角的图表中绘制，但仍完整保留在 LUT 记录及 Lab/RGB 分布统计中。

如需比较两批耗材或两次校准之间的色差变化，请前往 [LUT 对比](../lut-compare/lut-compare.mdx)。
