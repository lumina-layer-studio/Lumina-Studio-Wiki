# LUT 库

LUT 库按制造商分组展示本地可用的全部传统查色表（LUT），涵盖软件内置预设、手动导入的自定义文件以及从云端安装的版本。

## 卡片信息

每张 LUT 卡片展示以下关键字段：

- **名称与材料类型**：LUT 方案名称及适用耗材（如 `PLA`、`Basic`）。
- **颜色模式**：如 4 色、6 色或 8 色模式。
- **来源类型**：如传统查表（`legacy_lookup`）。
- **路径与指纹**：库内相对引用路径及文件内容哈希指纹。
- **来源标记**：区分**预设**、**自定义**或**云端**来源。

**指纹**根据文件内容计算生成，同名但数据不同的 LUT 会显示不同指纹；**路径**仅展示便携的库内相对引用，不包含本机磁盘目录。

## 搜索与筛选

搜索框会同时匹配名称、制造商、材料、颜色模式、来源类型、路径和别名。输入多个以空格分隔的关键词时，条目需同时命中全部关键词（每个词至少匹配任一字段）才会显示。

## 导入与刷新

点击**导入 LUT 文件**可上传 `.npy`、`.json`、`.npz` 或 `.msgpack` 文件；上传完成后条目会归入自定义类别并自动更新列表。导入外部或早期格式的 LUT 后，建议点击卡片上的**查看详情**跳转至 [LUT 详情](../lut-details/lut-details.mdx)，核对颜色模式、调色板、层顺序与基础通道信息。

点击**刷新本地库**会重新扫描本地存储目录以加载新增或变更的文件；若需拉取远程目录更新，请前往云端 LUT 库刷新。
