# LUT 对比

LUT 对比将**基准 LUT** 与**对比 LUT** 按相同配方键逐条关联，并计算两者颜色之间的 ΔE00 色差，适用于评估耗材批次波动、复测校准一致性以及验证校准更新前后的色彩变化。

## 统计指标

- **共享配方**：两份 LUT 中可按相同配方键配对的记录数量。
- **RGB 完全一致**：共享配方中两侧 RGB 数值完全相同的条目数。
- **平均 / P95 / 最大 ΔE00**：共享配方的整体平均色差、尾部色差与极值色差。
- **A / B 覆盖率**：共享配方分别占基准 LUT 与对比 LUT 可比较记录数的百分比。

其中 **P95 ΔE00** 表示 95% 的共享配方色差均不超过该数值，比单一极值更能稳定反映整体一致性；**最大 ΔE00** 则便于快速定位偏差最显著的个别配方。

## 兼容性提示与差异明细

当两份 LUT 的颜色模式、层数、层高、线宽、Schema、预测能力或动态能力不一致时，结果顶部会显示兼容性警告。对比始终按实际配方键匹配；若两份 LUT 不存在共享配方，系统会提示无法进行逐配方比较。

下方的**最大差异配方**列表并排展示两侧色块、完整叠色层序、HEX 色值及 ΔE00，方便回溯核查对应校准板照片或耗材批次。整个对比过程为只读分析，不会修改、合并或覆盖任何 LUT 文件。
