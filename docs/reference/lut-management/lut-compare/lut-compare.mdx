# LUT 对比

LUT 对比按相同配方连接两份 LUT，并计算它们预测颜色之间的 ΔE00。它适合检查耗材批次变化、重复校准一致性或
更新前后的差异。

## 统计值

- **匹配配方数：** 两份 LUT 中能够按配方键对应的记录数；
- **完全相同颜色数：** 对应记录中 RGB 完全一致的数量；
- **平均 / P95 / 最大 ΔE00：** 共享配方的整体与尾部色差；
- **覆盖率 A / B：** 共享配方分别占两份 LUT 可比较记录的比例。

P95 表示 95% 的共享配方差异不超过该值，比单独看最大值更能反映整体稳定性。最大值仍用于定位最异常的配方。

## 兼容性警告

颜色模式、层数、层高、线宽、Schema、预测能力或动态能力不同，会在结果上方显示警告。没有共享配方时，不能把
两份 LUT 的行号直接当作相同配方比较。

“最大差异配方”同时显示两侧颜色、配方和 ΔE00，便于回到校准照片或耗材批次中核对。对比不会修改、合并或覆盖
任何 LUT。
