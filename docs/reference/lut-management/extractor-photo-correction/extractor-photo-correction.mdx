# 照片校正与角点定位

照片校正用于让校准板的网格边界与提取模板对齐。它只作用于当前上传的照片，不会修改磁盘中的原图。

## 校正参数

| 控件 | 范围 | 作用 |
| --- | --- | --- |
| 水平偏移 | `-30–30` | 沿 X 方向移动采样模板 |
| 垂直偏移 | `-30–30` | 沿 Y 方向移动采样模板 |
| 缩放 | `0.80–1.20` | 同时放大或缩小采样区域 |
| 畸变校正 | `-0.20–0.20` | 补偿镜头造成的桶形或枕形偏差 |
| 暗角校正 | 开/关 | 补偿画面边缘亮度下降 |
| 自动白平衡 | 开/关 | 为当前照片生成白平衡预览 |

参数用于修正系统性偏差。只有个别角点偏离时，优先拖动角点或使用微调，不要用全局偏移去迁就一个角。

## 四个角点

在画布上依次放置四个角点后，选择一个角点作为当前目标。微调步长为 `1–10 px`，方向按钮和键盘方向键都会按该
步长移动当前角点。“清除角点”只删除定位点，不会删除上传照片。

角点应落在校准板规定的外框位置，而不是凭视觉选择最接近的色块中心。拉正预览中的网格仍然歪斜时，先检查角点
顺序，再调整畸变。
