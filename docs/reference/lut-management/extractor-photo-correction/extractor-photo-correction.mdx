# 照片校正与角点定位

照片校正用于将实拍校准板的色块网格与提取采样模板精确对齐。所有调整仅作用于当前会话上传的图像，不会修改磁盘上的原始照片。

## 校正参数

| 控件 | 范围 | 作用 |
| --- | --- | --- |
| 水平偏移 | `-30–30` | 沿 X 方向整体平移采样模板 |
| 垂直偏移 | `-30–30` | 沿 Y 方向整体平移采样模板 |
| 缩放 | `0.80–1.20` | 等比例放大或缩小每个色块的采样区域 |
| 畸变校正 | `-0.20–0.20` | 补偿镜头产生的桶形或枕形畸变 |
| 暗角校正 | 开/关 | 补偿画面四角与边缘的亮度衰减 |
| 自动白平衡 | 开/关 | 为当前照片生成自动白平衡预览 |

上述参数适合修正整张画面的系统性偏移或镜头畸变；若仅有个别角点未对齐，直接拖动该角点或使用下方的像素微调更为精准。

## 角点定位与微调

在画布上按顺序点击放置四个角点后，可选中任一角点进行精细调节。**微调步长**范围为 `1–10 px`，点击面板方向按钮或按键盘方向键即可按设定步长移动当前角点。点击**清除角点**仅移除画布上的定位点，已上传的照片仍会保留。

放置角点时，请对准校准板四周的定位外框角，确保采样网格与每个色块中心严格对应。若拉正预览中的网格出现整体倾斜或翻转，请先核对四角点击顺序，再调整**畸变校正**。
