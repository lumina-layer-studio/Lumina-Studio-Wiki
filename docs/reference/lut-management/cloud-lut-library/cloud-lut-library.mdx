# 云端 LUT 库

云端 LUT 库读取管理员配置的远程目录，并把选中的版本安装到本地 LUT 库。它是可选功能；远程目录未配置或暂时
不可用时，本地 LUT 仍可离线使用。

## 目录状态

顶部显示远程项目总数、已安装数量、启用的频道和已加载条目数。目录每次最多读取 100 项；还有剩余内容时，
“加载更多”会从当前偏移继续追加，并按 LUT ID 与修订 ID 去重。

卡片有三种本地状态：

- **未安装：** 本地没有该项目；
- **已安装：** 当前修订已经安装；
- **本地已有版本：** 本地存在同一 LUT，但不是目录中的当前修订。

安装操作会下载卡片标明的修订并刷新本地状态。云端项目随后也会出现在 [LUT 库](../lut-library/lut-library.mdx)。

## 搜索范围

搜索会检查 LUT ID、修订 ID、内容哈希、频道、显示名称、制造商和兼容颜色模式。搜索只过滤已经加载的目录页；
尚未加载的后续页面不会提前出现在结果中。

:::note[页面提示“云端 LUT 注册表未配置”时，不是本地 LUT 故障。该实例没有设置远程目录地址，继续使用本地库即可。]
:::
