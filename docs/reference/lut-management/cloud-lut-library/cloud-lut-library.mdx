# 云端 LUT 库

云端 LUT 库提供已校准的多色配方表。使用前核对颜色模式、各通道对应的真实耗材、层数和层高；显示颜色相近不能代替耗材型号相符。

## 查找与下载

1. 在经典 LUT 选择器点击“去云端找 LUT”，或打开“LUT 管理 → 云端 LUT 库”。
2. 按品牌、名称或颜色模式筛选，点开条目查看色卡与配套资料。
3. 点击“下载到本地”，等待当前修订安装完成。
4. 回到本地 LUT 选择器，确认使用这份 LUT。

目录先读取轻量条目信息，完整加载后可搜索全部条目。列表以每页 24 项为基准，并按实际列数补齐整行；色板只为当前页加载，返回浏览过的页面会复用缓存。搜索不再局限于手动点击“加载更多”之后的条目。

## 怎样阅读色卡预览

预览按文件记录的打印顺序排列配方色，保留校准板的空格与定位角标。五色基础板和扩展板分别为 32 × 32 格、38 × 38 格；常用八色 A、B 板各为 37 × 37 格。外形相同不表示配方数量相同。

多板 LUT 在列表中以错开的卡片表示。打开详情后，直接点击色卡切换下一张，也可使用触屏或 Enter／空格键；名称附近会显示当前板名与配方数。仅包含单板的文件只显示已有的那一张。合并或自定义 LUT 以“配方色表”展示。

“暂无色板数据”表示条目未提供预览，不等于本地文件损坏。读取失败时可在原处重试。浏览、换板和刷新都不安装 LUT，点击下载才将选定版本加入本地库。

## 本地版本与离线包

“已安装”表示本地已有当前修订；“本地已有版本”表示本地保存的是同一 LUT 的另一个修订。更新与个人文件冲突时，软件保留原件，新版本另行保存。旧工程缺少原来的 LUT 时，需要明确获取或替换，不会自动套用一个名字相近的文件。

有离线资源包时，可通过“从离线包挑选”预览并按项添加。离线目录与云端目录使用相同的资源身份；从离线包添加不需要把所有 LUT 都装入本地。

## 名称、收藏与投稿

包装地区设置、品牌标志和原始名称的规则与[云端耗材库](../../materials-and-recipes/cloud-material-library/cloud-material-library.mdx)一致。LUT 可以包含不同品牌的通道，请逐个核对实际线材。

连接社区账号后可以点赞、收藏，并在不同入口使用同一份收藏记录。自己的校准结果可通过“贡献到公共库”送审；投稿 LUT 时需要填写各通道的耗材信息，见[社区账号、收藏与投稿](../../materials-and-recipes/community-resources/community-resources.mdx)。
