# 云端 LUT 库

云端 LUT 库用于浏览远程目录，并将选定的 LUT 版本下载安装到本地库。该功能为可选扩展；未配置远程目录或处于离线环境时，本地 LUT 仍可正常使用。

## 目录状态

顶部状态栏显示云端条目总数、已安装数量、远端配置或启用频道以及当前已加载条目数，右侧可点击**刷新云端目录**重新拉取。目录单次最多加载 100 项；仍有剩余条目时，点击**加载更多**即可继续读取后续内容，并自动按 LUT ID 与修订 ID 去重。

每张卡片对应三种本地状态：

- **未安装**：本地尚未安装该 LUT。
- **已安装**：本地已安装当前展示的修订版本。
- **本地已有版本**：本地已存在同一 LUT，但版本与目录当前展示的修订不同。

点击安装后会下载对应修订并刷新本地状态，安装完成的项目也会同步出现在本地 [LUT 库](../lut-library/lut-library.mdx) 中。

## 搜索范围

搜索框可匹配显示名称、制造商、兼容颜色模式、频道、LUT ID、修订 ID 及内容哈希。搜索仅筛选当前已加载的目录条目；如需在更大目录中检索后续内容，请先点击**加载更多**再执行搜索。

:::note[离线说明]
若页面顶部提示“尚未配置云端 LUT 库”（或云端 LUT 注册表未配置），说明当前环境未设置 `LUMINA_LUT_REGISTRY_URL` 远端目录地址，直接使用本地 LUT 库即可。
:::
