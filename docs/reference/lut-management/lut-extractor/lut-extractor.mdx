# LUT 提取流程

LUT 提取器用于从打印完成的校准板实拍照片中采样全部色块，生成包含实测颜色、叠色配方与调色板元数据的 LUT 文件。

<img
  src={require('./assets/01-lut-extractor.webp').default}
  alt="等待上传校准板照片的 LUT 提取器"
/>

## 操作步骤

1. 选择与生成校准板时一致的**颜色模式**（多页模式下同时选择对应页码）。
2. 上传校准板照片，支持常见图像格式以及 `DNG`、`CR2/CR3`、`NEF`、`ARW`、`ORF`、`RW2`、`RAF`、`PEF`、`SRW`、`RAW` 等相机原始格式。
3. 按画布提示顺序依次点击校准板外框四角，必要时配合照片校正与像素级角点微调完成对齐。
4. 点击**提取颜色**，检查拉正预览、色块采样结果以及异常标记单元格。
5. 若为多页模式，按页码依次完成每页提取后执行合并。
6. 填写制造商、耗材类型及各基础通道的颜色名称与色值，确认调色板信息。
7. 下载生成的 LUT 文件。

更换照片、旋转图像或切换颜色模式时，系统会自动清空当前角点与未完成的提取缓存，以便按新画面重新定位。

## 多页模式合并

5 色扩展与标准 8 色模式使用多页校准板；开启 8 色全量导出时包含更多分页。页面列表会实时标示各页的提取状态，待同一校准方案所需的全部页面均提取完毕后，即可合并生成完整 LUT。

## 手动修正色块

若提取预览中个别色块受局部灰尘或反光影响出现采样偏差，可直接点击对应单元格手动修正色值。手动修改会保存在当前提取会话中，并在确认调色板后一并写入最终导出的 LUT。
