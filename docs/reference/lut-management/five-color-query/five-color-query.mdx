# 五色配方查询

五色配方查询用于检索支持 5 层或 6 层叠色配方的 LUT，既可按基础颜色堆叠顺序正向查询呈色结果，也可输入目标 HEX 色值反向匹配最接近的可用配方。

## 按层顺序查询

在**基础色板**中选择目标 LUT 后，颜色卡片会根据当前已选层序实时筛选下一层可选颜色；若当前前缀之后不存在包含某颜色的有效配方，对应卡片会自动置灰。

选满 5 层或 6 层有效顺序后，可通过**操作**面板执行以下动作：

- **查询**：返回当前层序对应的合成颜色及 LUT 记录行。
- **撤销**：移除最后选入的一层。
- **反序**：将完整层序首尾翻转并重新查询。
- **清除**：清空当前层序重新开始。

透光叠色效果取决于从**底面**到**观赏面**的实际堆叠顺序；即使耗材组合相同，改变层序也会产生不同的最终颜色。

## 按目标色值匹配

在**按色值查询**中输入 `#RRGGBB` 并点击**匹配配方**，系统会在当前 LUT 中查找最接近的颜色记录，并展示目标色、匹配色、ΔE00 色差、色卡坐标和具体层序；同时可通过相邻候选网格直观对比周边的相近配方。

## 配方收藏与打印色卡

可将查询结果加入收藏列表（相同配方会自动去重），支持逐条移除或点击**清空收藏**一键清除。确认收藏列表后，可设置色块尺寸 `5–50 mm`、间距 `0.5–10 mm`、列数 `0–20`（设为 `0` 时自动排布行列）以及单面或双面结构，直接生成并下载可打印的 3MF 实体色卡。

切换至另一份 LUT 时，系统会自动清空当前收藏列表，确保同一张色卡中的配方始终来自同一 LUT。
