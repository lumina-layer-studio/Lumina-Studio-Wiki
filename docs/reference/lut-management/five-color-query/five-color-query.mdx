# 五色配方查询

五色配方查询用于检查支持 5 或 6 层配方的 LUT。它既能按基础颜色顺序查询结果，也能输入目标 HEX 查找最接近的
可用配方。

## 按层顺序查询

选择 LUT 后，基础颜色卡片会按当前已选前缀筛选“下一层仍然有效”的颜色。灰掉的颜色不是界面故障，而是没有任何
合法配方能接在当前顺序之后。

完成 5 层或 6 层有效顺序后：

- “查询”返回该配方的结果颜色和 LUT 行；
- “撤销”移除最后一层；
- “反序”翻转完整层序后重新查询；
- “清除”重新开始。

层序会影响叠色结果，相同耗材集合的不同排列不能视为同一配方。

## 按目标色匹配

输入 `#RRGGBB` 后，系统在当前 LUT 中寻找最接近的结果，并显示目标色、匹配色、ΔE00、色卡位置和层序。
附近网格用于观察相邻候选，不代表这些颜色都具有同一配方。

## 配方集合与打印色卡

查询结果可加入集合；同一配方不会重复加入。每一项都可以单独移除，也可以用“清空收藏”一次清除。集合中的
配方可以设置色块尺寸 `5–50 mm`、间距 `0.5–10 mm`、列数 `0–20` 以及单面或双面结构，然后生成并下载
3MF 色卡。列数为 `0` 时由生成器自动排布。

切换到另一份 LUT 会清空当前集合，避免把不同 LUT 的行和配方混在同一张色卡中。
