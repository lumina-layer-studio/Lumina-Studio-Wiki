# 生成 LUT 校准板

校准板将选定颜色模式下的叠色配方排布为实体打印色块。完成打印与实拍后，可通过 LUT 提取器读取色块实测值并生成专属 LUT。

## 参数

- **颜色模式**：决定叠色配方集合与校准板页数，支持黑白、4 色、5 色扩展、6 色和 8 色模式。
- **色块尺寸**：`3–10 mm`，步进 `0.5 mm`（默认 `5.00 mm`）。调大尺寸便于相机对焦与中心采样，同时会增大整板面积；打印幅面受限时可适当调小。
- **色块间距**：`0.4–2.0 mm`，步进 `0.01 mm`（默认 `0.84 mm`）。用于分隔相邻色块并保留网格定位边界，调大可减少邻块溢色或边缘阴影干扰。
- **底板厚度**：`0.4–3.5 mm`，步进 `0.08 mm`（默认 `1.20 mm`）。调厚底板可提升板件刚性并减少透光影响。

选择 8 色模式时，面板会显示**全量导出**开关。5 色扩展与 8 色模式包含的配方数量较多，校准板会自动拆分为多页，并以配置包形式输出。

## 生成结果

生成完成后，右侧预览区会展示整板效果与逐层分布图；点击任意逐层缩略图即可放大检查单层细节。底部切片操作（如**生成并在 Bambu Studio 中打开**）会调用系统设置中已配置的打印机、喷嘴和切片软件参数。

拍摄校准板时请完整保留四周定位边界。后续在 LUT 提取器中上传照片时，请选择与生成时一致的颜色模式与对应页码，并在同一提取会话中仅处理同一模式的校准板照片。
