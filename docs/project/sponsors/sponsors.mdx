# 赞助支持

如果您希望通过资金支持开源项目的持续开发，欢迎自愿通过[爱发电](https://ifdian.net/a/MMMINNN)或 [Patreon](https://www.patreon.com/cw/Lumina_studio) 赞助我们。

如果您代表耗材品牌、打印机厂商、配件厂商或高校机构，希望提供耗材样品、硬件或色卡合作支持，欢迎通过社交平台或 QQ 联系开发组：

:::info[合作联系]
QQ：`6550671`（大胖肥猫） · QQ：`374612153`（Evan76）
:::

> **合作声明**：外部赞助与样品支持仅代表合作方对开源项目的鼓励，不干预 Lumina 的技术路线与开源协议。耗材赞助仅用于实拍制作对应色卡预设，Lumina 不捆绑销售或指定任何品牌耗材，也不对具体产品的品控作商业背书；部分渠道推广产生的佣金全部用于社区抽奖福利与后续研发。
