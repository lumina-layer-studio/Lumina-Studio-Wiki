# 内容许可与知识产权

除页面或素材另有说明外，Lumina Studio 对本 Wiki 中享有著作权的原创公开内容采用[知识共享署名—非商业性使用—相同方式共享 4.0 国际许可协议（CC BY-NC-SA 4.0）](https://creativecommons.org/licenses/by-nc-sa/4.0/)授权。你也可以查看 Creative Commons 官方提供的[简体中文许可摘要](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)。

## 适用范围

本声明适用于本 Wiki 已发布与后续发布的原创公开内容，涵盖 Lumina Studio 享有相应权利的原创文字、表格、示意图、标注与媒体素材。

若具体页面、图片或视频附有单独的署名、许可或“仅授权本 Wiki 使用”等标注，以该特别说明为准。Lumina Studio 仅对自身拥有著作权或获准再许可的内容授予许可。

## 你可以做什么

在遵守许可条件的前提下，你可以：

- 复制并分享许可范围内的内容；
- 翻译、改写、重新排版或制作衍生改编版本；
- 将内容用于个人学习、教学、社区交流及其他非商业用途。

## 使用条件

1. **署名**：注明“Lumina Studio Wiki”，附上原页面与许可协议链接，并说明是否作了修改。
2. **非商业性使用**：不得将许可内容用于商业用途。
3. **相同方式共享**：分发改编版本时，须继续采用 CC BY-NC-SA 4.0 协议。
4. **不得增加额外限制**：不得附加法律条款或技术限制，妨碍他人行使本许可授予的权利。

推荐署名格式：

> 来源：Lumina Studio Wiki；原文链接：`<URL>`；许可协议：CC BY-NC-SA 4.0；修改说明：`<说明修改内容或注明未修改>`。

## 不适用本许可的内容

以下内容不因出现在本 Wiki 中而适用 CC BY-NC-SA 4.0：

- Lumina Studio 及其他项目的源代码、构建部署脚本与基础设施配置；
- 第三方软件界面截图、Logo、商标、字体、模型设计、角色形象及品牌资产；
- 由用户、测试者或合作方提供并标注为单独许可或“仅限本 Wiki 使用”的照片、视频与文件；
- 外部链接、嵌入视频及引用的第三方图文素材；
- 知识共享著作权许可未涵盖的专利权、商标权、肖像权与隐私权等其他权利。

上述内容仍归各自权利人所有并受其相应条款约束；引用或转载前请先核实具体权利声明。

## 软件代码许可

CC BY-NC-SA 4.0 仅适用于本 Wiki 的原创文档内容，不适用于 Lumina Studio 软件代码。复用软件源码、站点组件或第三方依赖时，请分别遵循对应代码仓库与依赖项的开源许可证。

## 社区投稿与素材授权

投稿者保留其原创内容的著作权。向本 Wiki 提交原创文字、表格、示意图或标注时，请确认有权按本页协议公开发布；提交照片、视频、模型等素材时，可选择采用 CC BY-NC-SA 4.0、其他开源许可，或仅授权 Lumina Studio Wiki 展示使用。

如发现署名遗漏或授权边界疑问，请通过 Wiki 反馈渠道联系我们，并附上对应页面链接与权利说明。
