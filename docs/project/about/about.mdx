## 开发组介绍

我们是一群分散在全国各地的 3D 打印爱好者。聚在一起的初衷很简单：做一款免费、好上手的多色版画与浮雕生成工具。随着项目不断打磨和演进，我们也希望把这套工作流带给全球 3D 打印社区，为大家提供一种新的多色创作方案。

无论未来 Lumina 走向何方，感谢每一位使用和支持过我们的朋友！
