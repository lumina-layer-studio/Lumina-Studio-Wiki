# Wiki 反馈与建议

本页专门收集对 Lumina Studio Wiki 的反馈。无论是某句话看不懂、缺少操作图片，还是没有找到需要的教程，都可以告诉我们。

请直接在本页底部的评论区留言。你不需要了解 Markdown、代码仓库或 Wiki 的文件结构，也不需要先写好完整的修改稿。

## 可以反馈哪些问题

- 某段解释过于专业，术语没有说清楚；
- 缺少控件位置、操作步骤、前后对比或实际打印图片；
- 操作步骤与当前版本不一致，或者结论不准确；
- 页面中的链接、图片或视频无法打开；
- 内容存在，但导航和搜索很难找到；
- 中文或英文表达不自然、翻译不准确；
- 希望新增某个功能、工作流或常见问题的教程；
- 其他影响阅读和使用 Wiki 的问题。

## 怎样让反馈更容易处理

留言时尽量包含以下信息：

1. 受影响的页面标题或公开链接；
2. 看不懂或有问题的段落、图片、步骤；
3. 你遇到的具体困难，或者认为哪里不准确；
4. 希望补充解释、截图、对比、案例还是重新组织内容。

你不需要自己写出正确答案。只要说明“哪里不好理解”和“希望看见什么”，就已经很有帮助。

## 可复制的留言模板

```text
受影响的页面：
反馈类型：看不懂 / 缺少图片或对比 / 内容不准确或过时 / 链接或媒体失效 / 导航或搜索 / 翻译 / 希望新增内容 / 其他
具体位置：
遇到的问题：
希望改进的方向：
```

## 示例

> 受影响的页面：色相保护<br />
> 反馈类型：缺少图片或对比<br />
> 具体位置：“匹配会发生什么变化”<br />
> 遇到的问题：文字解释了开启后的匹配逻辑，但我看不出实际画面会发生什么变化。<br />
> 希望改进的方向：增加同一张图片关闭和开启色相保护后的并排预览，并标出最明显的颜色区域。

本页只收集 Wiki 内容、结构和阅读体验方面的建议。如果 Lumina Studio 出现报错、生成失败、下载失败或功能异常，请参考[软件内错误报告与可复现信息](../../reference/workspace-and-navigation/bug-report/bug-report.mdx)，通过软件内的反馈入口提交。

## 留言前请检查隐私

评论是公开内容。请勿提交账号、邮箱、密码、访问令牌、私有链接、本机路径、服务器地址、设备标识，或其他个人与保密信息。需要举例时，可以隐藏无关内容，只保留理解问题所需的画面。

## 反馈会怎样处理

维护者会整理反馈、确认当前版本的实际行为，并把适合的建议纳入后续 Wiki 修订。相似问题可能合并处理；留言不代表一定采用，也不承诺固定回复或更新时间。
