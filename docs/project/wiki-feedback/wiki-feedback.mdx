# Wiki 反馈与建议

如果你在阅读 Lumina Studio Wiki 时遇到表述晦涩、步骤有误、缺少配图对比或找不到所需主题，欢迎随时告诉我们。

请直接使用本页底部的反馈表单提交，无需了解 Markdown 语法或文档目录结构。

## 可以反馈哪些内容

- 概念或参数解释过于晦涩，缺少直观说明
- 操作步骤与当前软件界面不一致，或结论有误
- 缺少控件位置截图、调整前后对比图或实拍打印样例
- 页面链接、图片或嵌入视频无法正常加载
- 中英文表述生硬或翻译不准确
- 希望补充某个功能、工作流或排障场景的教程

## 建议提供的信息

提交时附上以下信息，能帮助我们更快定位并修订：

1. 受影响的页面标题或链接
2. 具体段落、步骤或图片位置
3. 哪里不好理解，或与实际操作不一致的地方
4. 你希望看到的改进方式（如补充对比图、拆细步骤或调整目录位置）

## 反馈参考模板

```text
受影响的页面：
反馈类型：表述不清 / 缺少配图或对比 / 内容有误或过时 / 链接或媒体失效 / 导航与搜索 / 翻译问题 / 建议新增主题 / 其他
具体位置：
遇到的问题：
希望改进的方向：
```

### 填写示例

> 受影响的页面：色相保护<br />
> 反馈类型：缺少配图或对比<br />
> 具体位置：“匹配会发生什么变化”<br />
> 遇到的问题：文字说明了色相权重变化，但看不出画面实际会有什么差别。<br />
> 希望改进的方向：补充同一张图片开启色相保护前后的并排预览对比，标出变化最明显的区域。

## 软件故障请通过软件内入口提交

本页仅收集针对 Wiki 文档的意见。如果遇到 Lumina Studio 报错、生成失败或功能异常，请参考[软件内错误报告与可复现信息](../../reference/workspace-and-navigation/bug-report/bug-report.mdx)，直接在软件内提交问题反馈。

## 隐私提醒

反馈内容仅发送给 Wiki 维护团队，不会在页面上公开展示。提交时请避免填入账号密码、访问令牌、订单凭证或其他个人敏感信息。
