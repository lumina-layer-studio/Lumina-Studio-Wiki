# 如何添加挂件环？尺寸、位置和切片检查

“添加挂件环”会在模型边缘生成一个可以穿钥匙环、挂绳或连接件的结构。它不是只显示在预览图上的标记，而是最终 3MF 中需要被真实切片和打印的几何结构。

因此，看到挂件环出现在 Lumina Studio 预览中还不够。生成模型后，还要在切片软件中确认它与主体相连、内孔没有消失，并且切片路径连续。

## 本篇会完成什么

本文会依次完成：

1. 在 Lumina Studio 中开启挂件环；
2. 理解环宽度、环长度和环孔直径；
3. 调整角度与 X、Y 位置；
4. 重新生成 3MF；
5. 在切片软件中检查连接、孔径和实际耗材。

下面是一件已经安装连接环的实物作品。挂件环的尺寸和位置没有唯一答案，应根据作品大小、连接件、喷嘴、耗材和使用场景调整。

## 开始前需要准备什么

- 已经上传图片并完成基础预览；
- 已经确定作品的大致成品尺寸和结构模式；
- 准备使用的钥匙环、挂绳或连接件；
- Bambu Studio、OrcaSlicer，或能够完整打开 Lumina 3MF 的兼容切片软件；
- 与实际打印机、喷嘴和耗材相符的切片配置。

如果连接件已经在手边，建议先量一下需要穿过挂件环的最宽位置。不要只按钥匙圈金属丝的直径估算，也要考虑连接扣、开口和装配时需要的余量。

## 第一步：开启挂件环

先完成图片、耗材档案、成品尺寸和基础结构设置，然后打开“高级功能”中的“挂件环设置”。

1. 开启“添加挂件环”；
2. 暂时保留默认参数；
3. 重新生成一次预览；
4. 确认挂件环已经出现在模型边缘。

<img
  src={require('./assets/01-enable-keychain-loop.webp').default}
  alt="在 Lumina Studio 的高级功能中开启添加挂件环"
/>

默认参数只是方便第一次看到结构的起点，并不代表适合所有作品。看到挂件环后，再根据实际连接件和模型外形调整会更直观。

:::note
如果“添加挂件环”无法开启，请先检查是否启用了“冰箱贴磁铁槽”或“拼图设置”。当前版本会阻止这些互相冲突的结构同时开启。
:::

## 第二步：理解三个尺寸参数

挂件环最重要的三个尺寸是：

| 参数 | 控制什么 | 调整时看什么 |
| --- | --- | --- |
| 环宽度 | 挂件环的水平外形宽度 | 是否过窄、是否挤到画面主体、与模型边缘的连接是否充足 |
| 环长度 | 挂件环向外伸出的长度 | 连接件是否有装配空间、挂件环是否显得过长 |
| 环孔直径 | 中间真正可以穿过配件的孔径 | 钥匙环、挂绳或连接扣能否顺利穿过 |

/>

当前界面提供的范围是：

- 环宽度：2–10 mm；
- 环长度：4–15 mm；
- 环孔直径：1–5 mm。

这些范围是软件允许输入的范围，不是打印建议。实际能否稳定打印，还会受到喷嘴线宽、材料、模型尺寸、挂件环与主体的连接面积以及切片参数影响。

### 应该先调哪个参数？

建议按下面的顺序调整：

1. 先让“环孔直径”能够容纳真实连接件；
2. 再调整“环宽度”和“环长度”，让孔周围保留可连续切片的结构；
3. 最后调整位置与角度，让挂件环与主体有足够的实际连接。

如果环孔在切片后消失，不要只看 Lumina Studio 的预览。先确认切片软件使用的喷嘴和线宽，再适当增大孔径或外形尺寸，并重新切片检查。

## 第三步：调整角度和位置

尺寸合适后，再调整：

- **旋转角度**：0° 表示竖直向上，正值按顺时针方向旋转；
- **X 偏移**：正值向右，负值向左；
- **Y 偏移**：正值向上，负值向下。

建议一次只改一个参数，每次修改后都重新预览。这样更容易判断是哪一个变化让挂件环离开主体、遮住画面，或移动到不合适的位置。

调整位置时重点看两件事：

1. 挂件环不能只在视觉上“碰到”主体，而要与主体形成明确的重叠连接；
2. 挂件环周围不要压住作品中必须保留的细节。

如果挂件环已经离开主体，先减小偏移量，把它向作品内部移动；如果只剩一个很窄的连接点，也应继续向内移动或适当增加外形尺寸。

## 第四步：重新生成新的 3MF

修改挂件环后，需要重新预览并重新生成模型。

以前下载的 3MF 不会随着网页设置自动变化。即使文件名称相同，也要确认切片软件中打开的是刚刚生成的新文件。

建议使用“打开项目”或等效方式载入完整 3MF，不要把它当作普通 STL 或单个几何对象导入。完整项目能够保留 Lumina 写入的对象和材料信息。

## 第五步：在切片软件中做真实检查

打开新的 3MF 后，不要立即开始打印。先完成下面的检查。

### 1. 检查对象和耗材

- 挂件环应随模型一起出现；
- 对象列表中不应出现与本次设置无关的额外结构；
- 项目耗材应与真实线盘和料槽对应；
- 如果挂件环使用了与主体不同的对象或耗材编号，要确认映射没有错位。

不了解 3MF 的正确打开方式时，请先阅读：[把 Lumina 3MF 正确导入切片器](../3mf-slicer-material-mapping/)。

### 2. 检查连接

切片后逐层观察挂件环与主体相交的位置：

- 两者之间应有连续的打印路径；
- 不应出现完全分离的悬空小岛；
- 连接处不应只剩一条很细、随后又中断的路径；
- 环孔四周应形成连续闭合的轮廓。

“准备”页面里看起来连在一起，不代表切片后一定相连。最终以切片预览中的真实路径为准。

### 3. 检查环孔

把预览移动到包含环孔的层，确认：

- 内孔没有被切片器自动填满；
- 孔边没有因为线宽和尺寸过小而合并；
- 孔径能容纳准备使用的连接件；
- 安装连接件时不会必须强行掰开薄弱结构。

### 4. 第一次先打印小样

挂件会在日常使用中承受拉扯、摆动和碰撞。第一次使用新的尺寸、材料或连接件时，建议先打印一个较小样品，实际装配并轻拉检查，再决定是否批量打印。

## 哪些功能不能同时开启？

当前版本中，“冰箱贴磁铁槽”和“拼图设置”会禁用挂件环。如果导入的配方同时包含冲突状态，Lumina Studio 也可能自动关闭挂件环以保持设置有效。

其他高级结构即使界面允许同时开启，也不代表所有模型都一定适合直接组合。请先阅读：[哪些功能可以一起用？](../../knowledge/feature-compatibility/)，再以实际预览和切片路径为准。

## 常见问题

### 为什么“添加挂件环”是灰色的？

先检查是否开启了冰箱贴磁铁槽或拼图模式。关闭冲突功能后，再回到挂件环设置。

### 为什么网页里能看到挂件环，切片后却没有？

最常见的原因是仍然打开着旧 3MF。修改参数后必须重新生成、重新下载，并在切片软件中打开新文件。

### 为什么挂件环与主体分开了？

角度或偏移量可能把挂件环移得太远。将它向主体内部移动，重新预览并重新切片，直到连接处出现连续路径。

### 为什么环孔在切片后消失了？

环孔或周围结构可能小于当前喷嘴、线宽和切片参数能够稳定表达的尺寸。根据实际硬件调整孔径或挂件环外形，然后重新切片检查。

### 默认的 4 mm、8 mm 和 2.5 mm 必须照抄吗？

不需要。它们只是当前界面中的默认起点。连接件尺寸、模型大小、喷嘴、材料和使用强度不同，最终尺寸也应不同。

### 改完参数后，已经下载的文件会自动更新吗？

不会。必须重新生成并下载新的 3MF。

## 打印前检查清单

- 已确认没有开启冰箱贴磁铁槽或拼图模式；
- 环孔能够容纳真实连接件；
- 挂件环没有遮住必须保留的画面细节；
- 挂件环与主体形成明确重叠，而不是刚好接触；
- 修改设置后已经重新生成并下载新 3MF；
- 切片后连接位置存在连续路径；
- 环孔没有消失或被自动填满；
- 实际线盘、项目耗材和打印机料槽对应正确；
- 新尺寸第一次使用前已经安排小样验证。

Lumina Studio 与切片软件仍会持续更新，个别按钮名称和位置可能略有变化。最终请以真实切片路径、实际连接件和小样打印结果为准。
