# 在模型平面上添加图案

“模型贴图”可将多色图案嵌合到 STL 或 OBJ 模型的指定平面上，在保留底模原有外形尺寸的同时生成多色打印工程。该功能适用于铭牌、盒盖等带有平整表面的模型，不支持在曲面上包裹纹理。

## 准备底模和图案

准备带有平整表面的 STL 或 OBJ 底模，以及用作图案的位图或 SVG 文件。导入前请确认底模尺寸正确且为封闭实体；存在破面、法线反置或非流形几何的模型会导致布尔开槽与生成失败。

在图像转换页面选定颜色来源与实际打印耗材。使用耗材档案时，底模会自动采用所选的底色材料（三维预览中的底模显示色仅作示意，实际材料以耗材配置为准）。

## 导入模型

展开并启用“模型贴图”面板，点击上传区选择 STL 或 OBJ 文件，也可直接将模型拖入工作区。图案仍通过图像上传入口导入；若将模型与图片同时拖入，软件会按文件类型自动分别载入。

导入后核对模型文件名与外形尺寸，待状态就绪后即可选面。启用模型贴图后固定采用单面结构，基础设置中的常规底板选项会自动隐藏。

## 选择贴图平面

使用选面工具在 3D 预览中点击目标平面。默认开启“共面组”模式，可一次选中组成同一平面的全部三角面；“三角面”模式则适合检查局部细小面片。

选中后确认高亮区域的范围与尺寸；若底模带有安装孔或镂空，请检查孔位边界是否完整保留。若选错平面，重新点选确认后再调整图案。

可通过视图立方体、适配视图及正反面切换调整观察视角。“旋转模型”用于改变整个底模在空间中的朝向；调整图案自身的位置与角度时，直接使用平面贴图变换工具即可。

## 调整图案

| 操作 | 作用 |
| --- | --- |
| 移动贴图 | 在选中平面内平移图案 |
| 旋转贴图 | 在选中平面内旋转图案，保持底模朝向不变 |
| 缩放贴图 | 调整图案覆盖尺寸，不改变底模外形 |
| 铺满 | 按选中平面的外边界自动铺放图案（带孔模型请留意孔位避让） |
| 内缩 | 按毫米（mm）设置图案距平面边缘的留白距离 |
| 旋转模型 | 改变整个底模在三维空间中的摆放朝向 |

建议先点击“铺满”对齐边界，再微调位置、角度与缩放比例。对齐孔洞、文字和边缘时，可结合 2D 图案视图与 3D 选中平面对照观察。源图中的透明区域不会生成彩色填充；需要留空或避让孔位处，请在源图中保留透明通道。

## 预览、生成与切片

1. 完成图案排布与耗材设置后，点击生成预览。
2. 切换观察面与背面，检查图案朝向、孔位避让、边缘留白及底模尺寸。
3. 导出 3MF 并在所选切片软件中打开。
4. 核对底模与各图案对象的耗材映射，逐层检查嵌入式开槽、显色层与底模实体是否完整。
5. 确认模型与擦料塔均在热床可打印范围内，执行切片预览无误后再发起打印。

3D 预览默认将贴图面朝向镜头以便检查，导出 3MF 时的模型朝向则由打印面设置决定（例如顶面贴图设为底面打印时会翻转朝向热床）。在切片软件中若初始视角未看到图案，可翻转到底面或展开对象列表与分层路径查看。若生成阶段提示选面、实体几何或开槽报错，请先修复底模网格或重选平面后再重新生成。

## 文件留档

分享卡与 JSON 项目文件暂不包含外部底模及选面信息，启用模型贴图期间也不支持导出配方。需要留档复用时，请将原始底模（STL / OBJ）、源图案、导出的 3MF 以及贴图定位参数一并保存。
