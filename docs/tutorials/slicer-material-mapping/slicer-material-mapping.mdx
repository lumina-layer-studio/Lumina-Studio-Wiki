# 把 Lumina 3MF 正确导入切片器：对象、颜色和 AMS 料槽怎么对应

将 Lumina Studio 生成的 3MF 导入切片软件后，各区域的实际打印材料由切片器耗材列表、对象耗材编号、机器内实际装载的线盘及多料槽位共同决定，不能仅凭三维视图中的表面显示色判断。

本教程以 Bambu Studio 和 OrcaSlicer 为例，演示如何将 Lumina 3MF 作为完整项目打开、逐项核对对象与耗材映射，并在切片预览中确认显色面无错色、缺层或细节丢失。

如果 Lumina 未检测到切片软件、点击一键打开无响应，或下载的 3MF 无法正常打开，请先参阅[切片器没检测到，或者 3MF 打不开怎么办？](pathname:///zh/docs/knowledge/slicer-path-and-open-troubleshooting/)，按“文件生成”“自动启动”和“项目导入”三个环节分别排查。

## 开始前需要准备什么

请先准备好：

- Lumina Studio 生成并下载的完整 3MF 文件；
- 实际使用的打印机与已安装的喷嘴；
- 作品所需的全部实物耗材线盘；
- 使用 AMS、ACE、MMU 等多料系统时，记录每卷耗材当前所在的物理槽位。

若使用他人分享的 3MF，建议先确认对方生成时所用的 Lumina 版本、耗材档案与工艺设置；单独导出的 STL 网格不包含多色对象分组与耗材对应关系。

:::note[参数说明]
本文聚焦 3MF 项目打开、耗材映射与切片预览检查；层高、线宽、流量和打印速度请根据实际机型、喷嘴孔径与线材特性设置。
:::

## 第一步：把 3MF 作为完整项目打开

打开 Bambu Studio 或 OrcaSlicer，选择“打开项目”载入 Lumina 生成的 3MF（也可直接双击 3MF 文件并用常用切片软件打开）。

若弹窗询问“作为项目打开”还是“仅导入模型 / 几何数据”，请选择**作为完整项目打开**。仅导入几何数据会丢失原有的打印盘布局、对象颜色分组、耗材编号及工艺参数。

项目载入后，先确认界面中能看到以下完整结构：

- 一个或多个打印盘；
- 左侧对象面板中可展开的模型、对象与子零件；
- 带编号的项目耗材列表；
- 打印板上的完整模型外形。

若打开后仅显示一个合并的单一网格，无法在对象列表中展开各颜色零件，请关闭当前窗口，重新通过“打开项目”载入原始 3MF。

## 第二步：核对打印机和喷嘴

在切片器左上角的打印机区域，确认当前机型与实际机器一致，并确认喷嘴直径与当前安装的喷嘴规格一致。

若切片器提示项目与当前机型或喷嘴不兼容，请先核查原因，避免直接覆盖全部预设：

1. Lumina“设置”中的打印机或喷嘴是否选错；
2. 本地切片器是否尚未添加对应的机型预设；
3. 该 3MF 是否原本为其他机型配置生成。

如果是生成前在 Lumina 中选错了设备规格，直接返回 Lumina Studio 修正切片软件、打印机和喷嘴后重新导出 3MF，比在切片器中逐项手动补齐参数更稳妥。若是有意将项目迁移至其他兼容机型，切换机型后请重新核对耗材列表、层高、可打印范围与切片预览。

## 第三步：区分四层耗材信息

修改颜色与槽位前，先区分以下四项信息：

| 信息层级 | 含义 | 查看位置 |
| --- | --- | --- |
| 项目耗材 | 3MF 内记录的耗材编号、界面显示色与材料预设 | 切片器左侧耗材列表 |
| 对象耗材分配 | 某个几何对象或零件所绑定的项目耗材编号 | 对象列表右侧的编号或色块 |
| 真实耗材 | 实际准备上机打印的物理线盘（含材质、品牌与颜色） | 实物线盘及标签 |
| 实际料槽 | 真实线盘当前装在 AMS、多料系统或外置料架的具体位置 | 设备料仓状态与装料记录 |

例如，对象列表中显示编号 `3`，代表该零件使用“项目耗材 3”，并不强制要求把线盘塞进 AMS 的 3 号物理槽位——发送打印时可将项目耗材 3 映射到任意实际装有对应线盘的槽位。同理，切片器中的红、蓝、白色块仅用于界面识别，实际打印颜色由所映射槽位中的物理线盘决定。

## 第四步：核对项目耗材列表

逐项检查切片器的项目耗材列表，确认每个编号的材料类型与显示色同 Lumina 中所选的耗材档案一致：

- 同时核对材料类型（如 PLA、PETG）与颜色，不同材质或不同光学档案的同色线材不宜直接混用；
- 项目耗材的排列顺序无需与 AMS 物理槽位顺序一致；
- 若切片器自动替换了本地缺失的材料预设，请确认替换后的材料类型与打印温度同实物线盘匹配。

若某项项目耗材有误，先将其改为实际使用的材料预设与识别色（此步骤修改的是项目级耗材定义，尚未改动零件绑定或物理料槽映射）。

## 第五步：逐个检查对象和零件的耗材分配

展开对象列表中的打印盘、模型、对象与子零件。不同作品的几何拆分方式不同：同一种画面颜色可能包含多个独立零件，底板、描边、挂环、磁铁槽等结构也会各自生成独立对象。因此，以下四个数量通常并不相等：

- 原图肉眼可见的颜色数量；
- Lumina 生成所用的项目耗材数量；
- 切片器对象列表中的对象与零件总数；
- 打印机单次可同时供料的物理槽位数量。

逐一选中对象或零件，检查右侧耗材列中的编号是否指向目标项目耗材；若有偏差，点击该编号或色块重新指定。

核对时请以**该区域实际应由哪卷线材打印**为准，零件名称仅作辅助参考。例如历史项目中的底板零件原名可能仍含 `White`，但实际耗材已改为黑色，最终打印结果始终取决于耗材分配与切片路径。修改单个零件后，请留意模型表面与对象列表高亮范围，避免误改整个组合模型或其他零件。

## 第六步：把项目耗材对应到真实料槽

确认所有对象的项目耗材分配无误后，再将项目耗材逐一对应到机器上的物理料槽：

1. 材质类型完全一致；
2. 线盘实物颜色符合本次作品需求；
3. 线盘已装入目标物理槽位；
4. 使用外置料架时，未误选为自动料仓槽位。

你可以手动指定映射关系，也可在设备在线且料仓识别准确时点击切片器的“同步”按钮。同步仅从设备读取当前槽位的材质与色标，同步完成后请再次复查“对象 → 项目耗材 → 物理槽位”两级对应关系是否被意外改动。

:::warning[槽位对应原则]
无需为了让编号外观一致而反复调换 AMS 中的物理线盘；只要将每个项目耗材准确映射到实际装有对应线盘的物理槽位即可。
:::

## 第七步：执行切片并查看预览

完成映射后点击切片，待计算结束后进入**预览**页面，将配色方案切换为按**耗材（Filament）**显示并逐项确认：

- 画面各主要色块均使用了预期耗材；
- 底板、描边与辅助结构未分到错误颜色；
- 切片器未自动将某种材料合并或替换到其他槽位；
- 无悬空路径、无法切片或超出打印边界警告。

若屏幕预览色与线盘实物略有色差，先区分是界面色标近似显示还是映射指向了错误槽位：单纯的屏幕色标色差不影响实际出料，映射槽位错误则需在打印前修正。

## 第八步：翻到显色面并逐层检查

将视角转到作品最终用于观赏的显色面：底面显色作品翻转到底视图查看，顶面显色作品则在顶视图查看。

切片预览中的层号按热床自下而上的实际喷嘴路径编号；而 Lumina 分层预览的第 1 层始终从观赏面算起，详细读法见[怎样读懂 Lumina 分层预览？](pathname:///zh/docs/knowledge/layer-preview-guide/)。

<img
  src={require('./assets/04-check-sliced-display-surface.webp').default}
  alt="切片后翻到显色面并拖动层滑块逐层检查"
/>

拖动右侧层滑块，从显色面第 1 层起逐层核查：

1. 首层出现的轮廓与颜色是否准确；
2. 层间换色是否发生在预期高度；
3. 小字、细线或微小色块是否在切片后被过滤消失；
4. 底板与背板是否完整闭合，有无意外孔洞或缺层；
5. 擦拭塔、支撑等辅助结构使用的耗材是否合理。

“准备”视图展示的是原始三维网格，唯有“预览”中的切片刀路才代表喷嘴实际执行的打印路径。若细小文字或线条在切片后消失，说明细节尺寸小于当前喷嘴与线宽的成型下限，可放大成品尺寸、更换更细喷嘴、调整生成模式或简化原图细节后重新生成。

## 常见问题

### 打开 3MF 后，原来的参数和颜色分组都不见了怎么办？

请检查打开时是否误选了“仅导入模型 / 几何数据”。关闭当前窗口，重新用“打开项目”载入原始 3MF。若该 3MF 原本针对其他打印机或喷嘴生成，建议返回 Lumina 修改设备设置后重新导出。若切片软件本身无法唤醒或报错，请按[切片器检测与 3MF 打开排障](pathname:///zh/docs/knowledge/slicer-path-and-open-troubleshooting/)逐项排查。

### 为什么切片器自动把项目耗材替换成了错误材料？

通常是因为本地缺少原项目的材料预设，或点击同步后切片器按当前料仓槽位自动重排了材料。请依次检查项目耗材定义、对象耗材编号与打印时的物理槽位映射三处设置。

### 为什么画面只有几种颜色，对象列表里却有更多对象？

对象代表几何零件而非颜色种类：同一种颜色可能拆分为多个不相连零件，底板、描边、挂环、磁铁槽等结构也会单独成组。按零件逐一核对耗材编号即可。

### 切片器预览颜色和真实线盘不完全一样，会打印错吗？

只要“对象 → 项目耗材 → 真实线盘与物理槽位”链路对应准确，界面色标的显示色差不会影响实际打印出料；若槽位映射有误，则需修正后再发起打印。

### 为什么准备页面能看到的小字或细线，切片后消失了？

“准备”页面显示三维几何网格，“预览”页面显示实际挤出路径。当局部特征小于当前喷嘴直径与线宽所能稳定成型的尺寸时，切片引擎会自动过滤或合并细碎路径。可通过增大成品尺寸、改用更小口径喷嘴（如 `0.2 mm`）或开启可变线宽（Arachne）来改善细节表现。

## 完成后的下一步

确认切片预览与物理料槽映射全部准确后，即可正常发起打印。首次尝试新组合时，建议先打印小尺寸测试件，并随手记录所用的 Lumina 耗材档案、项目耗材顺序及物理槽位，便于后续复现或排查色差。

若切片路径与槽位均无误，但打出的实物仍明显偏色，可依次排查耗材光学档案、同款线材批次差异、首层挤出饱满度以及观察环境光源色温。
