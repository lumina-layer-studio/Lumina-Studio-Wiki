# 生成并打印梯度色卡

本教程带你从 Lumina Studio 生成梯度卡配置文件包，并在切片软件中准备同一卷待测试耗材的白底色卡与黑底色卡。

打印完成后，你将得到一张白底梯度色卡和一张黑底梯度色卡。请将本次下载的完整 ZIP 包一并保留，下一篇“拍摄并提取梯度卡”教程会用到它。

## 本篇会完成什么

<img
  src={require('./assets/07-white-black-card-photo.webp').default}
  alt="打印完成的白底与黑底梯度色卡"
/>

每一种待测试耗材都需要打印一张白底色卡和一张黑底色卡。两张色卡的底板颜色不同，但上方的阶梯梯度色块必须使用同一卷待测试耗材。

## 开始前需要准备什么

<img
  src={require('./assets/00-settings-check.webp').default}
  alt="在设置中确认切片软件、打印机和喷嘴"
/>

先在 Lumina Studio 的“设置”中确认已选定实际使用的切片软件、打印机型号和喷嘴尺寸。

准备三卷耗材：

- 白色耗材，用于第一张色卡的底板；
- 黑色耗材，用于第二张色卡的底板；
- 本次待测试的耗材，用于两张色卡上方的梯度色块（本教程以红色耗材为例）。

同时准备好常用的切片软件。首次制作建议先单独跑通一卷耗材的全流程，以免多卷耗材的照片与配置包混淆。

## 第一步：打开梯度卡生成

<img
  src={require('./assets/01-open-gradient-generator.webp').default}
  alt="打开耗材管理中的梯度卡生成"
/>

打开 Lumina Studio，在顶部导航栏点击“耗材管理”，再点击第二排标签中的“梯度卡生成”。页面左侧为“生成设置”，右侧为“使用须知与线上模型”。

每种待测试耗材都需打印白底与黑底两张色卡；缺少其中任意一张，后续提取的光学数据将不完整。

## 第二步：选择层高

<img
  src={require('./assets/02-choose-layer-height.webp').default}
  alt="选择与打印设置一致的层高"
/>

在“生成设置”中打开“层高”下拉菜单，可选 0.04 mm、0.08 mm 或 0.10 mm。

首次制作梯度卡建议使用默认的 **0.08 mm**；0.04 mm 对首层稳定性、拍摄精度与后续提取的要求更高，可在熟悉流程后再尝试。

选定的层高需与切片软件中的实际打印层高保持一致。本教程以 0.08 mm 为例。

## 第三步：生成并保存 ZIP

<img
  src={require('./assets/03-download-zip.webp').default}
  alt="生成并下载完整配置文件包"
/>

确认层高后点击“生成配置文件包”，等待页面下方出现成功提示与“下载结果”区域，再点击“下载配置文件包 (.zip)”将压缩包保存到固定目录。建议按“耗材名称 + 层高 + 日期”命名归档文件夹（例如 `红色 PLA_0.08_2026-07-19`），便于后续查找。

<img
  src={require('./assets/03b-actual-zip.webp').default}
  alt="Finder 中实际下载的完整 ZIP"
/>

该 ZIP 包除 3MF 模型外，还包含后续“梯度卡提取”所需的配置文件与目录模板。即使打算直接使用右侧的 MakerWorld 在线模型打印，也必须在此生成并保留对应的 ZIP 包。

如需直接使用 MakerWorld 在线模型，可访问以下链接：

- [梯度卡在线模型（当前为 0.08 mm 层高）](https://makerworld.com.cn/zh/models/2394753-lumina2-0-ti-xing-xiao-se-se-qia-0-08ceng-gao-15ce#profileId-2721317)
- [梯度卡收纳盒在线模型](https://makerworld.com.cn/zh/models/2400920-can-shu-hua-lumina-2-0ti-du-se-qia-zi-ding-yi-shou#profileId-2729620)

<img
  src={require('./assets/03c-makerworld-page.webp').default}
  alt="实际打开的 MakerWorld 梯度卡页面"
/>

通过上述在线模型链接下载可为 Lumina 团队累积 MakerWorld 积分，相关积分将用于社区抽奖福利。

使用在线模型时，请确认模型层高与生成配置包时所选层高一致。当前在线梯度卡对应 0.08 mm；若选择了其他层高，请使用本地 ZIP 包内的 3MF 文件打印。

## 第四步：找到并打开 3MF

<img
  src={require('./assets/04-zip-contents.webp').default}
  alt="解压后保留 3MF、清单、说明和数据目录"
/>

解压下载好的 ZIP 包，在根目录找到扩展名为 `.3mf` 的打印项目文件。目录内同时包含 `manifest`、说明文件和数据目录模板，请保持原有文件完整，切勿删除或改名。

双击 `.3mf` 文件，或在 Bambu Studio / OrcaSlicer 中通过“打开项目”载入，即可看到由多个阶梯方格组成的梯度卡模型。

<img
  src={require('./assets/04-open-in-bambu-studio.webp').default}
  alt="在 Bambu Studio 中打开实际生成的 3MF"
/>

展开对象列表后，模型包含两个零件：“Base - White”为底板，“Step - Sample”为上方的梯度色块。

若切片软件提示打印机、喷嘴或配置不兼容，请返回 Lumina Studio 的“设置”核对切片软件、打印机型号和喷嘴尺寸，重新生成配置文件包后再打开。

## 第五步：准备白底和黑底两张色卡

<img
  src={require('./assets/05-material-mapping.webp').default}
  alt="白底、黑底和红色样本层的对象映射"
/>

默认配置包中包含一张完整的梯度卡模型。先展开对象列表确认包含“Base - White”和“Step - Sample”，再将整张色卡复制一份，使同一打印盘上并排放置两张梯度卡：

- **白底卡（第一张）**：将“Base - White”分配为白色耗材，“Step - Sample”分配为待测试的红色耗材。
- **黑底卡（第二张）**：将底板对象分配为黑色耗材，“Step - Sample”同样分配为同一卷红色耗材（底板对象原名仍显示“Base - White”，实际打印颜色以所选耗材槽为准）。

映射完成后检查确认：一张为白底配红阶梯层，另一张为黑底配红阶梯层。请保持模型原始尺寸与高度不变，切勿缩放模型或将底板与样本层分到同一种耗材。

## 第六步：切片检查与打印

<img
  src={require('./assets/06-bottom-preview.webp').default}
  alt="翻到底面并逐层检查切片结果"
/>

切片前，确认当前打印机、喷嘴及工艺层高与 Lumina 生成设置一致（本例为 0.08 mm），并复查白色、黑色与红色耗材槽位未被自动替换。

点击切片后进入“预览”，将视角翻到底面并拖动右侧层滑块逐层查看，确认白底和黑底上的红色梯度方格均完整清晰，无缺层、悬空或异常换色后再发起打印。打印完成后立即将两张色卡归拢，并标注耗材名称。

## 打印后要保留什么

请将以下三项成套保存：

- 白底梯度卡；
- 黑底梯度卡；
- 本次从 Lumina 下载的完整 ZIP。

仅保留解压出的 3MF 无法完成后续提取；请勿混放不同层高或不同批次生成的配置包，确保实物色卡与生成时的 ZIP 一一对应。

## 常见问题

### 可以只打印白底卡或黑底卡吗？

不可以。每种待测耗材都必须成对打印白底卡与黑底卡。

### 从 MakerWorld 下载了在线模型，还要生成 ZIP 吗？

需要。在线模型可替代本地 3MF 用于打印，但后续提取耗材档案仍需读取本地生成的 ZIP 配置文件包。

### 第一次应该选哪个层高？

建议从 0.08 mm 开始；熟练掌握打印、拍摄和提取流程后再尝试 0.04 mm。

### 打开 3MF 后，打印机或喷嘴不匹配怎么办？

返回 Lumina Studio 的“设置”核对切片软件、打印机型号和喷嘴尺寸，重新生成配置文件包后再打开，避免直接覆盖全部项目设置导致参数偏差。

### 对象名称里的“Base - White”为什么在第二张黑底卡上没有变？

“Base - White”只是模型零件的初始名称，实际打印哪种底色完全取决于切片软件中分配给该零件的耗材槽位。
