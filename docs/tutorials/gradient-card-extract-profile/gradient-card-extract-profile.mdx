# 拍摄并提取梯度卡：创建耗材档案

上一篇教程中，我们已经为同一卷待测试耗材打印了一张白底梯度卡和一张黑底梯度卡，并保留了 Lumina Studio 生成的完整 ZIP。

本篇继续完成拍摄、导入、四角标记、数据提取和耗材档案保存。保存后，这卷耗材会出现在 Lumina Studio 的“耗材库”中，后续进行图像转换时可直接选用。

尚未准备色卡时，请先阅读：[生成并打印梯度色卡](../gradient-card-generate-print/gradient-card-generate-print.mdx)。

## 开始前需要准备什么

<img
  src={require('./assets/07-white-black-card-photo.webp').default}
  alt="同一卷耗材对应的白底与黑底梯度色卡"
/>

请准备好以下三项：

- 白底梯度卡；
- 黑底梯度卡；
- 打印这对色卡时从 Lumina Studio 下载的完整 Kit ZIP。

三者必须来自同一卷待测试耗材和同一次梯度卡生成任务；上传时需使用完整 Kit ZIP，而非单独解压出的 3MF 文件。

拍摄可使用手机、相机或扫描仪。基础流程无需标准 24 色卡；如果手头已有 ColorChecker 并熟悉校色流程，可启用页面中的可选校色功能。

## 第一步：拍摄白底卡和黑底卡

选择稳定、均匀的中性光源，避免阳光直射、彩色环境光、局部反光或画面一侧亮一侧暗。

固定手机或相机位置，使镜头正对梯度卡。整片梯度色块与四个外角必须完整入镜，请勿让 ColorChecker、尺子或其他物体遮挡色卡边缘。

先拍白底卡，再将黑底卡放在同一位置拍摄第二张。两张照片需保持同一设备、同一镜头，以及相同的拍摄距离、曝光、白平衡和校色设置，拍摄期间关闭滤镜、美颜、AI 增强等会改变色彩的效果。

拍完后放大检查两张照片：

- 色块边界清晰分明；
- 亮部不过曝死白，暗部不死黑成片；
- 无明显高光反射、阴影、虚焦或严重透视畸变。

照片格式建议使用 PNG 或 JPG。若手机拍摄的 HEIC / HEIF 文件无法直接识别，请先转换为 PNG 或 JPG。

## 第二步：打开梯度卡提取

打开 Lumina Studio，在顶部导航栏点击“耗材管理”，再点击第二排标签中的“梯度卡提取”，进入包含“导入生成的梯度卡ZIP”“耗材名称”“白底梯度卡图片”和“黑底梯度卡图片”的页面。

## 第三步：导入 ZIP 并上传两张照片

<img
  src={require('./assets/snipaste_2026-04-19_16-19-05.png').default}
  alt="导入完整 ZIP，并分别上传白底与黑底照片"
/>

在“导入生成的梯度卡ZIP”区域点击“选择数据集 ZIP”，选择打印这对白底卡和黑底卡时保留的完整 Kit ZIP。

此处需导入梯度卡生成阶段的 Kit ZIP；从耗材库导出的档案 ZIP 请在“耗材库”页面导入。两者的区别见[梯度卡 ZIP 和耗材档案 ZIP](../../knowledge/material-library-management/material-library-management.mdx#梯度卡-zip-和耗材档案-zip-有什么区别)。

随后分别上传白底梯度卡照片和黑底梯度卡照片。若照片朝向不便点选四角，可点击“逆时针 90°”或“顺时针 90°”旋转调整。

首次提取时，“纯白色块位置”和“纯黑色块位置”保持“自动检测（推荐）”即可。这两项对应照片中未覆盖待测试耗材的纯白或纯黑基底色块；仅当自动方向检测置信度低或识别有误时，再按该色块在原图中的实际角落手动指定。

:::tip[可选校色卡]
截图中的照片包含 ColorChecker，但基础提取无需标准色卡。没有色卡时，保持 ColorChecker 校色关闭，直接上传相机或扫描仪原图即可。
:::

## 第四步：按顺序标记四个角

<img
  src={require('./assets/snipaste_2026-04-19_16-33-56-转换自-png.webp').default}
  alt="白底和黑底照片都按同一顺序标记四角"
/>

在白底梯度卡预览图中，按以下顺序依次点击整片梯度色块区域的四个外角：

1. 左上；
2. 右上；
3. 右下；
4. 左下。

完成白底图后，按相同顺序标记黑底图的四个外角，两张图共点击八次。

请点选整片梯度色块区域的外边界四角，而非单个小色块、照片边缘或 ColorChecker 的四角。

若角点略有偏移，可在“角点位置微调”中选中对应角点，用方向按钮或键盘方向键微调；若点选顺序有误，点击“清除角点”后重新按序标记。

当白底图和黑底图均提示四角标记完成时，“提取耗材”按钮变为可用状态。

## 第五步：提取并检查方向

<img
  src={require('./assets/snipaste_2026-04-19_16-37-14.webp').default}
  alt="自动方向不可靠时，可以手动指定纯白和纯黑色块位置"
/>

点击“提取耗材”，等待软件完成透视校正、色块取样与光学参数拟合。

若提示方向检测不可靠，先核对照片旋转方向与四角点选顺序。若仍无法准确识别，请在“纯白色块位置”或“纯黑色块位置”中按纯色块在**原照片**中所在的实际角落手动选择（而非校正后的目标位置），再重新点击“提取耗材”。

## 第六步：检查透视校正预览

<img
  src={require('./assets/snipaste_2026-04-19_16-37-38.webp').default}
  alt="透视校正后，取样框应完整落在各个色块内部"
/>

提取完成后，先查看“透视校正预览”。白底卡和黑底卡均应被拉正，且所有取样方框完整落在对应小色块内部，不压缝隙、边框或超出画面。

若取样框明显偏移或压线，请检查四角位置与点选顺序，修正后重新提取。

## 第七步：评估提取结果

<img
  src={require('./assets/snipaste_2026-04-19_16-40-34.png').default}
  alt="同时查看耗材颜色、平均 ΔE、方向检测和页面警告"
/>

“计算出的耗材颜色”用于标识该档案，正常情况下与待测试耗材实物颜色接近（受显示器显色影响，仅供参考）。

“平均 ΔE”反映本次拟合的平均色差，数值越小表示拟合越紧密。确认结果是否可用时，请结合以下三项综合判断：

- 透视校正预览中的取样框全部准确落在色块内部；
- “方向检测”状态显示可靠；
- 页面未出现提取警告。

若系统提示平均 ΔE 大于 3、白底过亮或过暗、基底信号过弱或方向置信度低，请先排查光线、曝光、照片方向、四角位置及纯色块设置，必要时重拍后再重新提取。

“最大 ΔE”“线性 RMSE”和“通道 RMSE”用于进阶误差分析；常规提取只需确保取样区域准确、方向检测可靠且无警告提示。

## 第八步：填写信息并保存耗材档案

<img
  src={require('./assets/snipaste_2026-04-19_16-41-14.png').default}
  alt="填写耗材名称和可选品牌后保存档案"
/>

确认提取结果无误后，填写“耗材名称”，建议包含材质、系列和颜色以便区分。“品牌”为选填项，填写后软件会按品牌分组展示，留空则归入未分组列表。

点击“保存耗材档案”，页面提示“耗材保存成功”即表示档案已保存到 Lumina Studio 本地，无需另行下载 `material.json` 等底层参数文件。

切换到“耗材库”即可看到刚保存的耗材档案。后续如需改名、复验、查看历史或跨设备迁移，请参阅[管理耗材档案：编辑、复验、历史、导入和导出](pathname:///zh/docs/knowledge/material-library-management/)。

## 完成后的建议

新建耗材档案后，建议先选一张色彩层次与细节清晰的小尺寸测试图转换试打，对照 Lumina 预览、切片器底面预览与实际打印件效果，确认表现符合预期后再制作大尺寸作品。

## 常见问题

### 只用手机拍照可以吗？

可以。只要两张照片使用同一台设备与同一颗镜头、保持相同的曝光和白平衡，并在均匀光线下清晰拍全整张梯度卡即可。

### 必须购买标准 24 色卡吗？

不需要。基础提取流程直接使用相机或扫描仪原图即可；若启用可选的 ColorChecker 校色，两张照片需采用一致的校色流程。

### 可以只拍白底卡或黑底卡吗？

不可以。白底卡、黑底卡与对应的完整 Kit ZIP 必须成套使用。

### 为什么“提取耗材”按钮是灰色的？

请检查 Kit ZIP、白底照片和黑底照片是否已全部上传，并确认两张照片均已标满四个角点。

### 为什么“保存耗材档案”按钮是灰色的？

需先完成一次有效提取并填写“耗材名称”。若修改输入后原提取结果已失效，请重新提取后再保存。

### 自动方向检测显示“置信度低”怎么办？

先核对四角点选顺序和照片旋转方向。若仍无法自动判定，请按原照片中纯白或纯黑色块所在的实际角落手动指定“纯白色块位置”或“纯黑色块位置”，再重新提取。

### 平均 ΔE 多少才算可用？

请结合取样框位置、方向检测状态和页面警告一并判断。若系统提示平均 ΔE 大于 3，说明本次拟合误差偏大，请修正拍摄条件或角点标记后重新提取。

### 保存后还需要手动下载参数文件吗？

不需要。档案已自动保存在软件本地并显示在“耗材库”中；底层参数导出仅用于跨设备备份或问题排查。
