# 切片教程

:::warning[旧版资料]
本页记录早期版本的梯度卡手动切片参数与顶面显色玩法，仅供项目参数丢失或特殊打法时参考，无需套用到所有常规模型。常规 3MF 导入、对象耗材核对与实际料槽映射，请阅读新版教程：[把 Lumina 3MF 正确导入切片器](/zh/docs/tutorials/slicer-material-mapping/)。
:::

较新版本的 Lumina Studio 已兼容主流切片软件与机型配置，下载的 3MF 通常可直接在切片软件中作为项目打开。若导入后工艺参数意外丢失，可参照以下步骤手动恢复 0.08 mm 梯度卡参数。

## Bambu Studio

### 1. 选择机型与 0.08 mm 工艺预设

打开 Bambu Studio，先选择实际使用的打印机型号，再将工艺参数切换为 `0.08 mm` 预设。

<img
  src={require('./assets/p2s01.png').default}
  alt="p2s01.png"
/>

### 2. 设置层高与首层线宽

在“质量”设置中修改：

- **层高**：`0.08`（mm）
- **首层层高**：`0.08`（mm）
- **首层线宽**：`0.42`（mm，以 `0.4 mm` 喷嘴为例）

:::warning[其他尺寸喷嘴]
若使用 `0.2`、`0.6` 或 `0.8` 喷嘴，只需将“层高”和“首层层高”固定为 `0.08`，线宽随喷嘴孔径相应调整，其余参数保持不变。
:::

<img
  src={require('./assets/p2s02.png').default}
  alt="p2s02.png"
/>

### 3. 关闭象脚补偿并启用可变线宽

将**象脚补偿**设为 `0`（避免第二层颜色渗透到显色面；若对此不敏感可保持默认），并将**墙生成器**切换为**可变线宽（Arachne）**。

<img
  src={require('./assets/p2s03.png').default}
  alt="p2s03.png"
/>

### 4. 调整首层流量比与首层单层墙

将**首层流量比**设为 `1.1`（可根据机器与耗材状态自行微调），并勾选**首层单层墙**。

:::info[开发者模式]
若界面中未显示“首层流量比”，请点击切片软件左上角菜单打开“偏好设置”，勾选“开发者模式”。
:::

<img
  src={require('./assets/p2s04.png').default}
  alt="p2s04.png"
/>

### 5. 设置墙层数与壳体表面图案

在“强度”设置中调整：

- **墙层数**：`1`
- **顶部壳体层数**：`0`（可选，设为 `0` 可避免顶面走线交叉留下网格折痕）
- **底部壳体层数**：`1`
- **顶面 / 底面图案**：`单调线`

<img
  src={require('./assets/0001.png').default}
  alt="0001.png"
/>

### 6. 设置填充参数

继续在“强度”中设置：

- **稀疏填充密度**：`100%`
- **稀疏填充图案**：`直线排列`（也可设为`直线`）
- **填充方向**：`0`（`0°`，也可设为 `45°`）
- 取消勾选**识别狭窄内部实心填充**

<img
  src={require('./assets/p2s06.png').default}
  alt="p2s06.png"
/>

### 7. 降低打印速度

在“速度”设置中，建议适当降低打印速度以提高细小色块成型质量。图中各项速度以 `50`（mm/s）为推荐起始值，确认打印稳定后可按需提高。

<img
  src={require('./assets/p2s07.png').default}
  alt="p2s07.png"
/>

### 8. 调整擦拭塔形状

在“其他”页面的“擦拭塔”区域，可先关闭**斜肋外墙**，再将擦拭塔**宽度**调大。切片后擦料塔会变为细长条状，有助于节省热床空间。

<img
  src={require('./assets/p2s08.png').default}
  alt="p2s08.png"
/>

### 9. 检查并修正耗材映射

先检查耗材列表是否包含生成时所选模式对应的颜色。若下方对象列表中的颜色映射有误（常见于仅导入几何模型而非打开完整项目），可逐个选中对象手动修改对应的耗材编号。

:::info[预设对象命名]
使用四色或六色预设时，请留意所选模式是 CMYW（青、品红、黄、白）还是 RYBW（红、黄、蓝、白）。在这两种模式下，**红色与品红色共用同一对象名**，**蓝色与青色共用同一对象名**。例如使用 RYBW 预设时，生成的对象名若显示为“品红”或“青”，直接将其分配给红色和蓝色耗材即可。
:::

<img
  src={require('./assets/p2s09.png').default}
  alt="p2s09.png"
/>

完成以上全部设置并核对耗材映射后，即可执行切片与打印。

## OrcaSlicer / ElegooSlicer / Snapmaker Orca / AnycubicSlicer Next

上述参数同样适用于 OrcaSlicer 及各衍生切片软件，按对应分类修改参数并在切片预览中核对分层效果即可。

## 进阶玩法：显色面为顶面

使用 PEI 纹理热床打印板时，底面纹路可能印在色卡或版画表面。若希望避开热床底纹，可将模型翻转 180° 使显色面朝上打印，并配合高度范围修改器加快背板打印速度：

1. 以背板厚度 `1.6 mm` 的色卡模型为例，翻转后 `0–1.6 mm` 高度范围为白色背板。先在全局参数中将**首层层高**设为 `0.2`（mm）：

<img
  src={require('./assets/p2s10.png').default}
  alt="p2s10.png"
/>

2. 右键点击模型，选择**添加高度范围修改器**，将高度范围设为 `0–1.6 mm`，并将该范围内的**层高**设为 `0.2`（mm）：

<img
  src={require('./assets/p2s11.png').default}
  alt="p2s11.png"
/>

3. 切片后检查最顶部的显色层：正常情况下最上方应恰好为 `5` 层颜色层；若变成 `4` 层或 `6` 层，请重新核对首层层高与修改器高度范围。

<img
  src={require('./assets/p2s12.png').default}
  alt="p2s12.png"
/>

:::tip[换算背板厚度]
日常打印其他版画模型时，只需按实际生成的背板厚度设置高度范围即可。例如生成时将背板厚度设为 `1 mm`，则首层层高设为 `0.2 mm`，高度范围修改器设为 `0–1 mm`、层高 `0.2 mm`，即可在不影响顶部 `5` 层显色层的前提下快速打完背板。
:::
