# 本地预览与提交前检查

本站基于 Docusaurus 构建，使用 `yarn` 管理依赖。修改文档后，请先在本地完成预览与构建检查，再提交 Pull Request。

## 一、环境准备

### 1. Git 与源码仓库

本地预览与提交前检查均会读取仓库的 `.git` 历史记录。请使用 `git clone` 克隆仓库，切勿直接下载源码 ZIP 解压运行（普通解压目录缺少 `.git` 记录，会导致预览与构建报错）。

1. 安装 Git 并确认命令可用：

```bash
git --version
```

2. 克隆源码仓库并进入目录：

```bash
git clone https://github.com/lumina-layer-studio/Lumina-Studio-Wiki.git
cd Lumina-Studio-Wiki
```

### 2. Node.js 与 Corepack

需要 Node.js 20 及以上版本与 Corepack。Node.js 14.19.0 至 24.x 自带 Corepack；从 Node.js 25 起不再默认附带。

若系统提示找不到 `corepack`（如使用 Node.js 25 及以上版本），请先手动安装全局 Corepack，详见 [Corepack 官方安装说明](https://github.com/nodejs/corepack#how-to-install)：

```bash
npm install -g corepack
```

已内置或安装完成后，启用 Corepack：

```bash
corepack enable
```

随后安装项目依赖：

```bash
yarn install --immutable
```

项目固定使用 `package.json` 中声明的 Yarn 4 版本。

## 二、本地预览

`yarn start` 默认仅启动中文站点预览：

```bash
yarn start
```

预览英文站点需显式指定语言参数：

```bash
yarn start --locale en
```

中英文站点分别独立构建，且默认占用同一端口，因此**同一时间只能运行一种语言的预览服务**。切换语言前，请先按 `Ctrl+C` 停止当前服务，再执行另一条启动命令。

## 三、提交前检查

提交前请依次执行类型检查与完整构建：

```bash
yarn typecheck
yarn build
```

## 四、目录与文件约定

- 中文文档位于 `docs/`，英文文档位于 `i18n/en/docusaurus-plugin-content-docs/current/`。
- 每篇教程使用独立目录，MDX 文件与所在目录同名，配图统一存放在该目录下的 `assets/` 文件夹中。

示例：

```
docs/tutorials/example/example.mdx
docs/tutorials/example/assets/step-01.webp
```

## 五、写法约定

- 正文仅使用 Docusaurus 原生支持的 Markdown/MDX 语法，不引入自定义图片或路径组件。
- MDX 正文中不添加 `import` 语句。
- 图片统一使用页面目录内的相对路径引用：

```jsx
<img src={require('./assets/step-01.webp').default} alt="步骤一" />
```
