# Wiki Feedback and Suggestions

If a page in the Lumina Studio Wiki is hard to follow, out of date, missing visual examples, or difficult to locate, let us know.

Please use the feedback form at the bottom of this page—no Markdown or repository knowledge required.

## What to report

- Unclear explanations or unexplained technical terms
- Steps or parameter descriptions that do not match the software
- Missing control screenshots, before-and-after comparisons, or print examples
- Broken links, images, or embedded videos
- Awkward phrasing or translation errors
- Requests for new tutorials, workflows, or troubleshooting guides

## Helpful details to include



1. The affected page title or URL
2. The specific section, step, or image
3. What felt confusing or inaccurate
4. What would make the page clearer (for example, a side-by-side comparison, extra screenshot, or clearer steps)

## Copyable feedback template

```text
Affected page:
Feedback type: unclear / missing image or comparison / inaccurate or outdated / broken link or media / navigation or search / translation / missing topic / other
Location on the page:
Problem or experience:
Suggested direction:
```

### Example

> Affected page: Hue Protection<br />
> Feedback type: missing image or comparison<br />
> Location on the page: "How matching changes"<br />
> Problem or experience: The text describes the hue penalty, but it is hard to picture the visual difference.<br />
> Suggested direction: Add side-by-side previews of the same image with Hue Protection off and on, highlighting the clearest color shift.

## Report software bugs inside Lumina Studio

This form is for documentation feedback only. If Lumina Studio crashes, fails to generate a 3MF, or behaves unexpectedly, see [In-app Bug Reports and Reproducible Information](../../reference/workspace-and-navigation/bug-report/bug-report.mdx) to send a report from inside the app.

## Privacy note

Submissions go privately to the Wiki maintainers and are not published on this page. Even so, do not include passwords, access tokens, order references, or confidential personal data.
