# ColorChecker Calibration

When **ColorChecker Calibration** is enabled in LUT Extractor, uploading a calibration-board photo opens the calibration dialog first. Lumina Studio calibrates the full-resolution photograph and passes the confirmed image into the LUT extraction workflow.

## Reference and placement

Start by selecting a built-in reference or uploading an `.xlsx` file to create a custom reference for the current session (containing patch Lab values, white point, and content hash). Once a valid reference is ready, auto-detection and calibration controls become active.

Click **Auto Locate** to detect the four chart corners and view the confidence score, or place and drag the corners manually. Patch orientation supports normal, 180° rotation, horizontal flip, and vertical flip—check the rectified preview to verify that the patch order matches the selected reference.

## Sampling and fitting

- **Sampling method:** Choose mean or median. Median is more resistant to minor dust or surface speckle inside a patch.
- **Sample radius:** Controls the center region sampled within each patch. Increasing it averages out print or paper texture, while reducing it keeps sampling clear of patch borders, glare, or edge shadows.
- **Output blur:** Applies optional smoothing to the calibrated output to suppress high-frequency noise.
- **Gray normalization:** Supports automatic, enabled, or fallback modes to stabilize neutral-gray balance.
- **Calibration algorithm:** Supports 3×3 matrix, 3×4 matrix, root polynomial, or automatic selection.

## Confirming the result

The results screen reports mean, median, P95, and maximum ΔE00, along with the highest-error patch and gray-balance checks. Warnings highlight excluded patches or elevated neutral-reference deviations. Click **Accept** to pass the calibrated image to extraction, or **Retry** to return to the parameter settings and adjust the fit.

:::tip[Photo quality]
ColorChecker calibration compensates for camera response and ambient lighting casts. For accurate results, capture a sharply focused, evenly lit photograph without clipped highlights or specular glare.
:::
