# Five-Color Recipe Query

Five-Color Recipe Query inspects LUTs built around five- or six-layer recipes. You can step through an explicit base-color stacking order to preview its resulting color, or enter a target HEX value to find the closest available recipe.

## Query by layer order

After selecting a LUT under **Base Palette**, the color cards filter dynamically based on the layers chosen so far. Any color that cannot form a valid recipe after the current sequence appears dimmed.

Once you complete a valid five- or six-layer sequence, use **Actions** to inspect or adjust it:

- **Query:** Returns the resulting color and its LUT row.
- **Undo:** Removes the last selected layer.
- **Reverse:** Flips a complete layer sequence end-to-end and queries it again.
- **Clear:** Resets the current sequence.

Because light transmission depends on the stacking order from **Bottom** to **Viewing Face**, using the same filaments in a different order produces a distinct optical recipe.

## Match a target color

Under **Match by color value**, enter a `#RRGGBB` value and click **Match recipe** to find the nearest entry in the active LUT. The result shows the target and matched colors, ΔE00 difference, swatch coordinates, and layer sequence, alongside neighboring candidate cells for comparing nearby alternatives.

## Collection and printable swatch

Save queried recipes to your collection (duplicate recipes are ignored automatically). You can remove items individually or click **Clear collection** to empty the list. Configure patch size (`5–50 mm`), gap (`0.5–10 mm`), columns (`0–20`, where `0` lets the generator arrange columns automatically), and single- or double-sided structure, then generate and download a printable 3MF swatch.

Switching to another LUT clears the active collection so every swatch card stays tied to a single LUT.
