# Photo Correction and Corner Placement

Photo correction aligns the photographed board grid with the extraction sampling template. Adjustments apply only to the current upload in memory and leave the original file on disk untouched.

  src={require('./assets/01-photo-correction.webp').default}

/>

## Correction controls

| Control | Range | Effect |
| --- | --- | --- |
| Horizontal Offset | `-30–30` | Shifts the sampling template along X |
| Vertical Offset | `-30–30` | Shifts the sampling template along Y |
| Zoom | `0.80–1.20` | Scales the patch sampling area uniformly |
| Distortion Correction | `-0.20–0.20` | Compensates for lens barrel or pincushion distortion |
| Vignette Correction | On/off | Compensates for brightness falloff near image edges |
| Auto White Balance | On/off | Generates a white-balanced preview for the active photo |

Use these controls to correct systematic shifts or lens distortion across the entire image. When only one corner is slightly displaced, move that corner directly rather than shifting the whole template.

## Corner placement and fine-tuning

After placing four corners on the canvas, select a corner to make it active. **Step (px)** accepts `1–10 px`; both the on-screen arrow buttons and your keyboard arrow keys nudge the active corner by that step size. **Clear Corners** removes the placed points while keeping the uploaded photo loaded.

Align the four points with the outer border corners of the calibration board so the sampling grid registers cleanly over every block center. If the rectified grid still appears skewed or flipped, verify the corner placement order first, then adjust **Distortion Correction**.
