# Cloud LUT Library

Cloud LUT Library browses a configured remote catalog and installs selected LUT revisions into your local library. It is optional—when no remote catalog is configured or your machine is offline, local LUTs remain available as usual.

## Catalog state

The header displays **Cloud Items**, **Installed** count, **Remote** status or active channels, and loaded entry count, with **Refresh Catalog** on the right. Each request loads up to 100 items; when more items are available, **Load More** fetches the next batch and deduplicates entries by LUT ID and revision ID.

Each card reflects one of three local states:

- **Not installed:** No local copy of this LUT exists.
- **Installed:** The displayed revision is already installed locally.
- **Local revision available:** Another revision of the same LUT is installed locally.

Clicking **Install** downloads the listed revision, updates the card status, and adds the item to [LUT Library](../lut-library/lut-library.mdx).

## Search

Search matches display name, manufacturer, compatible color mode, channel, LUT ID, revision ID, and content hash across the catalog pages already loaded on screen. Load additional pages with **Load More** before searching if you need to look further down a large catalog.

:::note[Offline use]
A “Cloud LUT registry is not configured” banner indicates that no `LUMINA_LUT_REGISTRY_URL` remote catalog URL has been set for this instance. You can continue working directly with your local LUT Library.
:::
