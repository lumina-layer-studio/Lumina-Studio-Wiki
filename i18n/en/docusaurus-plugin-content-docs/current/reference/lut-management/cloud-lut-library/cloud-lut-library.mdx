# Cloud LUT Library

The cloud LUT library provides calibrated multi-color recipe tables. Before using one, check its color mode, the actual filament assigned to every channel, layer count and layer height. Similar-looking preview colors do not establish a filament match.

## Find and download a LUT

1. Select the cloud-library shortcut in the classic LUT picker, or open the cloud LUT library under LUT management.
2. Filter by brand, name or color mode, then open an entry to inspect its boards and supporting information.
3. Select **Download to local** and wait for the selected revision to finish installing.
4. Return to the local LUT picker and confirm this LUT for use.

The catalog first loads lightweight entries. Once loaded, search covers the full catalog. Pages use a baseline of 24 entries, adjusted to fill complete rows. Only the current page requests preview boards, and previously visited pages reuse cached previews. Search no longer depends on manually loading additional batches of entries.

## Read the board preview

Previews arrange recipe colors in the file's print order, retaining empty cells and orientation markers. The five-color base and extension boards contain 32 × 32 and 38 × 38 cells respectively; the usual eight-color A and B boards each contain 37 × 37 cells. Matching outer dimensions do not imply matching recipe counts.

Multi-board LUTs appear as overlapping cards in the list. In the detail view, click the board itself to switch to the next one, or use touch, Enter or Space. The current board name and recipe count appear near the title. A file containing only one board shows only that board. Merged and custom LUTs display a recipe color table.

**No board preview data** means the entry has no supplied preview, not that a local file is corrupt. Failed preview requests can be retried in place. Browsing, switching boards and refreshing do not install a LUT; downloading adds the selected revision to the local library.

## Local revisions and offline packs

**Installed** means the current revision is available locally. **Local version exists** means another revision of the same LUT is present. If an update conflicts with a personal file, Studio keeps the original and saves the new revision separately. When an older project is missing its original LUT, explicitly obtain or replace it; Studio does not substitute a similarly named file.

With an offline resource pack available, select **Browse offline pack** to preview and add individual entries. Offline and cloud catalogs share resource identities. Adding a LUT from a pack does not install every LUT in it.

## Names, saved resources and submissions

Naming regions, brand logos and original names follow the same rules as the [Cloud Material Library](../../materials-and-recipes/cloud-material-library/cloud-material-library.mdx). A LUT may use different brands across its channels, so check each filament separately.

Connect a community account to like and save resources, with the same saved list available across entry points. Submit your own calibration through **Share to public library**. LUT submissions require filament information for every channel; see [Community account, saved resources and submissions](../../materials-and-recipes/community-resources/community-resources.mdx).
