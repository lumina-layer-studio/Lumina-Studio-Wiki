# LUT Extraction Workflow

LUT Extractor samples every color block in a photographed calibration board and builds a LUT containing measured colors, layering recipes, and palette metadata.

<img
  src={require('./assets/01-lut-extractor.webp').default}
  alt="LUT Extractor waiting for a calibration-board photograph"
/>

## Workflow

1. Select the exact **Color Mode** (and page number, for multi-page boards) used to generate the printed board.
2. Upload the board photograph. Standard image formats as well as `DNG`, `CR2/CR3`, `NEF`, `ARW`, `ORF`, `RW2`, `RAF`, `PEF`, `SRW`, and `RAW` camera files are supported.
3. Place the four outer corners in the prompted order, then apply photo correction or pixel-level corner fine-tuning as needed.
4. Click **Extract Colors** and review the rectified board, sampled swatch grid, and any flagged cells.
5. For multi-page modes, extract each required page in turn and then merge the set.
6. Enter the manufacturer, material type, and each base color's name and HEX value, then confirm the palette.
7. Download the resulting LUT file.

Replacing or rotating the photo—or switching **Color Mode**—clears current corners and in-progress results so you can align the new image cleanly.

## Multi-page modes

5-color Extended and standard 8-color modes use multi-page calibration sets, with additional pages when full 8-color export is enabled. The page checklist tracks extraction progress for each required page and unlocks **Merge** once every page in that calibration set is complete.

## Manual patch correction

If an individual block is misread due to dust or localized glare, click that cell in the extraction preview to override its color manually. Edits stay in the active session and are written into the exported LUT once you confirm the palette.
