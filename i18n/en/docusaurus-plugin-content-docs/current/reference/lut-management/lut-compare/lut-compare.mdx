# LUT Compare

LUT Compare joins a **Baseline LUT** and a **Comparison LUT** by matching recipe keys and calculates the ΔE00 color difference for each pair. Use it to evaluate filament batch drift, check repeat-calibration consistency, or review color shifts before and after an update.

## Statistics

- **Shared Recipes:** Number of records paired across both LUTs by identical recipe key.
- **Exact RGB Matches:** Paired records whose RGB values match identically.
- **Mean / P95 / Max ΔE00:** Average, 95th-percentile, and worst-case color differences across shared recipes.
- **A / B Coverage:** Shared recipes expressed as a percentage of each LUT's comparable records.

**P95 ΔE00** indicates that 95% of shared recipes fall at or below that threshold, offering a steadier measure of overall agreement than a single outlier, while **Max ΔE00** pinpoints the largest individual shift.

## Compatibility warnings and largest differences

If the two LUTs differ in color mode, layer count, layer height, line width, schema, predictive capability, or dynamic capability, compatibility warnings appear above the summary. Records are always paired by recipe key rather than table row index; if two LUTs share no recipes, no recipe-level ΔE00 comparison is generated.

**Largest Recipe Diffs** lists the widest shifts side by side—showing both swatches, the layer sequence, HEX values, and ΔE00—so you can trace anomalies back to a calibration photo or filament spool. Comparing LUTs is strictly read-only and leaves both files unchanged.
