# LUT Details and Gamut Charts

Load any LUT in **LUT Details** to inspect its declared materials, color mode, print structure, capabilities, and color-gamut coverage before selecting it for modeling or printing.

/>

## Summary and typed metadata

- **Color count:** Total number of printable recipe records in the LUT (distinct from the number of base filaments).
- **Source kind:** Distinguishes traditional lookup tables (`legacy_lookup`) from predictive data sources.
- **Layer height, line width, maximum color layers, base layers, and layer order:** Define the physical print structure used to build the LUT.
- **Base channel:** Identifies the substrate channel index used at the base of recipes.
- **Capabilities:** Indicates support for predictive matching, dynamic layer height, dynamic layer count, or custom recipes.
- **Supported modes:** Lists explicitly supported combinations of layer count and layer height.

Use **Summary** and **Typed Metadata** when choosing a LUT for everyday projects; the raw metadata section preserves underlying file fields for format or migration diagnostics.

## Palette

The palette maps each channel index to its color name, material type, and HEX value. When loading filaments on the printer, match physical spools to the listed channel order.

## Gamut charts

- **Lab:** 2D plots the `a*/b*` chromaticity plane; 3D adds lightness (`L*`) with optional reference slices.
- **RGB:** Plots all LUT records inside the RGB color cube.
- **Hue–lightness:** Shows the relative lightness range achievable across hues.
- **Hue–chroma:** Shows the relative saturation reach across hues.

Neutral colors lack a stable hue angle, so hue-based plots omit them while keeping them in the LUT data and in the Lab/RGB views.

To analyze differences between two filament batches or calibration runs, use [LUT Compare](../lut-compare/lut-compare.mdx).
