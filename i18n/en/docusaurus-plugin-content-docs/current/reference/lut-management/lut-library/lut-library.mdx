# LUT Library

LUT Library displays all locally available traditional lookup tables (LUTs) grouped by manufacturer, including built-in presets, user-imported files, and revisions installed from the cloud catalog.

## Card fields

Each LUT card summarizes:

- **Name and material:** LUT profile name and filament type (such as `PLA` or `Basic`).
- **Color Mode:** Supported multi-color configuration (such as 4-Color, 6-Color, or 8-Color Max).
- **Source Kind:** Underlying LUT type, such as `legacy_lookup`.
- **Path and Fingerprint:** Portable library-relative reference and content hash.
- **Origin badge:** Marks whether the item comes from **Preset**, **Custom**, or **Cloud**.

**Fingerprint** is derived from the file contents, so two LUTs with the same name but different data carry distinct fingerprints. **Path** shows only the portable library reference rather than a machine-specific disk path.

## Search

Search matches name, manufacturer, material, color mode, source kind, path, and aliases simultaneously. When you enter multiple space-separated terms, every term must match at least one field on the card.

## Import and refresh

Click **Import LUT File** to upload `.npy`, `.json`, `.npz`, or `.msgpack` files; imported LUTs appear under the **Custom** count once the library refreshes. After importing an external or older LUT file, click **View Details** to open it in [LUT Details](../lut-details/lut-details.mdx) and verify its color mode, palette, layer order, and base channel.

**Refresh Library** rescans local storage for newly added or updated LUT files (use Cloud LUT Library when you want to fetch remote catalog updates).
