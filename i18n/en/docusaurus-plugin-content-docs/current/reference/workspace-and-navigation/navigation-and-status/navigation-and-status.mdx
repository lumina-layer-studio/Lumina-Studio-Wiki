# Navigation, Language, Theme, and Connection Status

The top bar houses the app identity, workspace navigation, and global status controls. Switching pages preserves your current form values and editing state without automatically triggering Preview, Generate, or Save.

## Primary pages

| Page | Purpose |
| --- | --- |
| Converter | Import artwork, choose a color source and structure, preview, and export 3MF |
| LUT Management | Manage LUTs, generate calibration boards, extract LUTs from photos, and inspect or compare LUTs |
| Material Management | Manage material archives, generate or extract gradient cards, and query layer recipes |
| Vectorizer | Convert bitmaps into editable SVGs or send them directly to Converter |
| Creative Workshop | Browse and launch creative modules |
| Settings | Configure your printer, nozzle, and slicer, and manage compute, cache, and interface options |

**LUT Management** and **Material Management** each include secondary subpages. Returning to either workspace restores the last valid subpage you visited, or falls back to that workspace's default view.

## Converter secondary pages

- **Core Settings:** Artwork upload, color source, physical dimensions, backing, mode, common advanced options, and **Actions**.
- **Color Adjustment:** 2D Preview, selection tools, color replacement, layer recipes, and color groups.
- **Creative Center:** Relief, Outline, Transparent Coating, Keychain Loop, Fridge Magnet, Puzzle, and related structure features (the Cloisonné entry is currently hidden).

**Core Settings** and **Creative Center** use movable panels, whereas **Color Adjustment** opens a full-screen color workspace—so **Panel Controls** in the header lists only the panels active on the current view. For layout details, see [Show, Collapse, Move, and Reset Panels](../panel-layout/panel-layout.mdx).

## Language and theme

Switch between Simplified Chinese and English under **Settings → General → Language / 界面语言**.

Open **More options** at the top right and toggle **Dark mode** to switch between light and dark themes without affecting your image, recipe, mesh, or exported files. On narrower windows, text labels compact into icons and navigation bars scroll horizontally.

## Backend connection status

Open **More options** at the top right to check communication between the interface and the local Lumina backend:

- **Green:** Latest health check succeeded.
- **Red:** Latest check failed or the backend is unreachable.
- **Checking:** Waiting for the initial check result after page load.

Lumina checks the connection on startup and every five seconds afterward. When communication drops, a red badge appears on the menu button—confirm that the Lumina backend service is running before retrying your task.

## Update announcements

When unread release notes are available at startup, Lumina displays recent update highlights. Closing the dialog or clicking **Later** dismisses it for the current session; clicking **Got it** saves the latest read version in local browser storage so the prompt stays dismissed until the next update.

## What page switches preserve

Moving between pages preserves active control values, selected subpages, and panel layouts, while device settings sync to the backend automatically. Temporary previews, download links, and session files still expire when a session ends—export share cards, JSON recipes, 3MF files, source artwork, and your LUT or material archive whenever you want a permanent backup.
