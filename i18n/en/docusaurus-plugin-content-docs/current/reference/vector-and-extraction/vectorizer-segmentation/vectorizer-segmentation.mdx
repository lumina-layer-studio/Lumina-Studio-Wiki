# Superpixel Segmentation and Antialiasing

During multicolor vectorization, the engine divides the image into SLIC superpixels and refines their labels using local color and edge gradients. These controls govern how accurately color boundaries snap to edges and how antialiased transition pixels are handled.

## SLIC Region Size

Ranges from `5–100`, with a default of `20`. Sets the target size for initial SLIC superpixels:

- **Smaller values** generate denser superpixels that capture finer local features.
- **Larger values** generate fewer, broader superpixels for faster processing and cleaner generalization.

Subsequent color merging, boundary refinement, and region filtering continue to reshape regions, so this setting does not lock final SVG shapes to a fixed size.

## Edge Sensitivity

Ranges from `0–1`, with a default of `0.8`. Controls how strongly SLIC relaxes spatial regularity when it encounters a color edge:

- **Higher values** snap region boundaries tightly along color transitions.
- **Lower values** favor uniform spatial cells and smoother, more regular boundaries.

## Refine Passes

Ranges from `0–20`, with a default of `6`. Each pass refines boundary labels against neighboring pixels—adding passes aligns boundaries more tightly to intricate edges at the cost of extra processing time, while `0` skips boundary refinement altogether.

## Antialiasing Detection and AA Tolerance

Enabling **Antialiasing Detection** identifies blended transition pixels along the border between two colors so antialiased halos are merged cleanly instead of becoming thin, stray color bands.

- **Turn on** for smooth-edged illustrations, icons, logos, and typography.
- **Turn off** for pixel art when you want crisp, stair-stepped pixel edges preserved intact.

**AA Tolerance** ranges from `1–50`, defaults to `10`, and is measured in LAB ΔE. Higher values allow a wider color difference to qualify as a blended edge pixel.
