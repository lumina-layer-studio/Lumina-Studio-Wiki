# Image Vectorizer

**Image Vectorizer** converts PNG, JPEG, WebP, and BMP raster images into clean SVGs built from closed paths and a compact color palette. It shines on icons, logos, pixel art, flat illustrations, and artwork with crisp edges; photographs also convert cleanly, typically yielding higher color and shape counts.

## Basic workflow

1. Choose a supported raster image in the upload area.
2. Start with the default settings and click **Start Vectorization**.
3. Pan and zoom the synchronized original and SVG views to inspect contours, fine lines, and color transitions.
4. Click **Download SVG** to save the vector file locally, or **Send to Image Converter** to build a 3D print model right away.

While running, the action button changes to **Vectorizing…**—click it again to cancel the active job. Uploading a new image clears the previous output.

## Processing pipeline and result summary

Each conversion runs sequentially through resolution scaling and Mean Shift smoothing, color segmentation, boundary extraction, contour assembly, Bézier curve fitting, contour tracing, and SVG export. Every parameter group in the sidebar controls a dedicated stage of this pipeline.

When vectorization finishes, the result summary displays:

- **Shapes**: total closed paths in the final SVG;
- **Colors**: final palette size after automatic detection or manual selection;
- **Width × height**: original pixel dimensions of the source image;
- **Palette**: up to 16 color swatches shown inline, with any additional colors summarized as `+N`.

Higher shape counts preserve smaller color details while producing denser SVG geometry. Zoom in to inspect edge fidelity and color cleanliness directly so you can balance fine detail against clean paths.

## Download or continue in Image Converter

<img
  src={require('./assets/03-result-actions.webp').default}
  alt="Send to Image Converter and Download SVG actions"
/>

Clicking **Send to Image Converter** loads the generated SVG directly into **Image Converter** as a native vector source and switches tabs automatically, preserving Lumina's vectorization metadata for downstream 3D modeling.

Generated SVGs are held at a temporary download URL for 20 minutes, and navigating away from **Image Vectorizer** clears the current session preview—download any SVG you plan to keep.
