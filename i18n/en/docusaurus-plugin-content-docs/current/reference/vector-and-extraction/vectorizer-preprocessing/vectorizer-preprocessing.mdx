# Image Preprocessing

**Image Preprocessing** runs before color segmentation, capping the internal working resolution and applying Mean Shift smoothing to suppress compression artifacts and pixel noise.

  src={require('./assets/01-preprocessing.webp').default}
  alt="Image Vectorizer preprocessing controls"
/>

## Spatial Smoothing

Ranges from `0–50`, with a default of `15`. Sets the spatial neighborhood radius used by Mean Shift filtering:

- **Higher values** smooth out grain and noise across a wider pixel radius.
- **Excessive values** can blur closely spaced fine lines and tiny details together.

## Color Smoothing

Ranges from `0–80`, with a default of `25`. Controls how far apart two pixel colors can be and still merge within a Mean Shift pass:

- **Higher values** consolidate similar shades into cleaner blocks and cut down fragmentation.
- **Excessive values** can merge neighboring tones that you want to keep distinct.

**Spatial Smoothing** sets *how far* the filter reaches across the canvas, while **Color Smoothing** sets *how similar* colors must be to group together.

## Max Working Pixels

Ranges from `100,000–10,000,000`, with a default of `3,000,000`. When an uploaded image exceeds this total pixel count, the engine downscales it proportionally before segmentation:

- **Lower limits** reduce memory footprint and speed up large images.
- **Higher limits** preserve finer micro-detail on high-resolution artwork at the cost of longer processing time.

Images already below this pixel limit stay at their native resolution and are never upscaled. The result summary always reports the original source dimensions.
