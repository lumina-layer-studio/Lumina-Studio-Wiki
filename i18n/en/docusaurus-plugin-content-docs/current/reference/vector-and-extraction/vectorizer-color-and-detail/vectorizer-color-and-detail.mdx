# Colors, Smoothness, and Detail

The basic parameters control how many colors remain in the palette and how closely vectorized paths follow fine source details versus clean, simplified curves.

  src={require('./assets/01-basic-parameters.webp').default}
  alt="Basic Image Vectorizer parameters"
/>

## Number of Colors

In **Auto** mode (value `0`), the vectorizer estimates an appropriate palette size from the image and displays the final color count in the result summary.

Switch to **Manual** to specify `2–256` colors. This sets the K-Means palette size for color segmentation (because multiple separate shapes can share one color, this differs from the total SVG shape count):

- **Lower values** merge similar shades into cleaner, more uniform regions.
- **Higher values** preserve subtle gradients and local tonal shifts, though they can also introduce more small fragments.

For icons, logos, or pixel art with a known palette, set **Manual** to the exact color count; otherwise, start with **Auto**.

## Smoothness

Ranges from `0–1`, with a default of `0.5`. **Smoothness** controls contour point decimation and curve smoothing:

- **Near `0`**: preserves crisp corners and small edge variations using more path nodes.
- **Near `1`**: produces smoother, cleaner curves with fewer nodes, softening sharp corners and tiny bumps.

To clean up scattered color speckles rather than contour roughness, pair this control with [Image Preprocessing](../vectorizer-preprocessing/vectorizer-preprocessing.mdx) and [Curve Fitting and Region Filtering](../vectorizer-curve-and-filtering/vectorizer-curve-and-filtering.mdx).

## Detail Level

**Detail Level** is off by default (value `-1`), allowing every advanced setting below it to act independently.

When enabled, it ranges from `0–1` and starts at `0.5`, acting as a master slider that coordinates multiple segmentation and fitting thresholds at once:

- **Lower values** favor broader regions and cleaner, simpler paths.
- **Higher values** retain finer edges and small structural details.

Adjusting **Detail Level** leaves **Number of Colors** unchanged and does not overwrite the numbers shown in the advanced panels. Turn **Detail Level** off whenever you want direct, reproducible control over individual advanced parameters.
