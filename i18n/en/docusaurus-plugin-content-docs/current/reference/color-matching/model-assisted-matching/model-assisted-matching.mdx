# Model-Assisted Matching

**Model-Assisted Matching** appears when you select an [Inferred LUT](../../converter-basic/inferred-lut-source/inferred-lut-source.mdx) brand package that includes a predictive color model. It predicts layer-by-layer filament recipes for target colors where measured data is sparse, without altering your source image.

## Model-Assisted Matching

When enabled, Lumina Studio evaluates both the nearest measured database candidate and the predictive model candidate. The model result replaces the database match only when both conditions are met:

1. The database candidate's color distance exceeds the model threshold; and
2. The model's color distance plus its safety margin is still smaller than the database distance.

Colors already well covered by measured swatches keep their verified database recipes, while the predictive model fills in under-sampled color regions where it offers a clearly closer match.

## Model only

**Model only** bypasses the measured database baseline and uses predictive model recipes across the entire image. Use it when you want to inspect the model's standalone color coverage; for everyday prints, **Model-Assisted Matching** is usually preferable so measured matches stay anchored. Neither toggle is shown if the active brand package has no predictive model.

## Threshold, safety margin, and comparison tips

Threshold and safety margin are not exposed as separate input fields in the panel—Lumina Studio uses the runtime defaults bundled with the brand package (non-negative overrides remain supported in configuration files for reproducible testing).

Changing either switch clears the current preview and 3MF output. When comparing modes, keep the brand package, active databases, layer count, print dimensions, and other color controls identical across runs.
