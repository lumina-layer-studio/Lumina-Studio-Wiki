# Dark Chroma Gate

**Dark Chroma Gate** is a sub-setting of [Hue Protection](../hue-protection/hue-protection.mdx) that controls which dark pixels are matched against neutral (achromatic) dark candidates. Use it to prevent black outlines and dark gray shadows from picking up unwanted red, blue, or green color casts.

This slider evaluates **chroma** only—it does not shift the lightness cutoff that defines a dark pixel, nor does it adjust overall image saturation.

## Location

1. Open **Converter → Core Settings → Advanced Settings**.
2. Enable **Hue Protection** to reveal the **Dark Chroma Gate** slider directly underneath.

/>

The range is **0–50** in steps of **1**, with a default of **15**. Turning on **Precise Color Matching** takes over candidate selection, disables **Hue Protection**, and hides this slider.

## How chroma filtering works

Lumina Studio converts each source color into the CIELAB/LCh color space:

- **L\*** measures lightness (lower values are darker).
- **C** measures chroma (lower values are closer to neutral black, white, or gray; higher values carry stronger color).

At the default value of **15**, dark pixels with **C ≤ 15** enter the neutral-dark protection branch, while pixels with **C > 15** continue through standard hue-priority matching.

:::note[Chroma vs. Saturation]
Chroma (C) is calculated in CIELAB/LCh color space and differs from the HSV or HSL saturation percentage shown in image editors.
:::

## Lightness bands and matching behavior

Hue Protection first collects neutral dark candidates from the active LUT—colors below roughly **L\* 60** with **C ≤ 8**—and applies the gate across three fixed lightness bands:

| Source lightness | Behavior when passing the chroma gate |
| --- | --- |
| Approx. **L\* < 50** | Matches exclusively against neutral-dark candidates |
| Approx. **L\* 50–70** | Blends smoothly between neutral-dark and standard candidates |
| Approx. **L\* ≥ 70** | Bypasses the dark branch and uses standard hue-priority matching |

Adjusting **Dark Chroma Gate** changes the maximum chroma eligible for this branch without moving the lightness cutoffs above.

## Adjusting the value

| Value | Behavior | Visual effect |
| --- | --- | --- |
| **0** | Special value: routes all pixels in the dark lightness range into the neutral-dark branch | Strongest protection for black and gray linework, but pushes dark reds, blues, and greens toward black or gray |
| **Below 15** | Restricts the branch to nearly neutral dark pixels | Preserves rich colored shadows, though black or gray areas may pick up slight color casts |
| **15** | Default baseline | Balanced starting point for most illustrations and photos |
| **Above 15** | Admits dark pixels with higher chroma into the neutral-dark branch | Cleans up colored speckles in dark linework, at the risk of desaturating deep colored shadows |
| **50** | Widest threshold | Useful for testing whether unwanted casts originate in the dark-matching branch |

Raise the slider slightly if black or gray details show colored speckles; lower it below **15** if intentional dark reds, blues, or greens lose their hue. To turn off dark protection entirely, disable **Hue Protection**—do not set the gate to **0**, which routes every dark pixel into the neutral branch.

## Supported color sources

**Dark Chroma Gate** takes effect during standard LUT color-table matching for both raster images and native SVGs.

It is not used when:

- **Hue Protection** is off;
- **Precise Color Matching** is enabled;
- Matching runs through a **Material Archive** solver or a predictive matcher that does not reference this gate (even if the slider remains visible in the panel, changing its value will leave those previews unchanged).
