# Unlock Quantize Ceiling

**Unlock Quantize Ceiling** raises the upper limit of the [Quantize Colors](../../converter-basic/quantize-colors/quantize-colors.mdx) slider from **256** to **8192**. Flipping the toggle does not re-quantize the image or change your current slider value until you move the slider above **256**.

This option is off by default.

## Location

Open **Converter → Core Settings → Advanced Settings**, then locate **Unlock quantize ceiling**.

## Slider range

| Toggle state | Quantize Colors range | Step |
| --- | ---: | ---: |
| Off | 8–256 | 8 |
| On | 8–8192 | 8 |

The default **Quantize Colors** value is **48**. If you raise the slider past **256** and later turn **Unlock quantize ceiling** off, Lumina Studio immediately clamps the value back to **256**.

## When to use it and performance impact

Raising the color budget into the hundreds or thousands noticeably increases:

- Clustering and color-mapping time;
- Memory usage;
- The number of material recipes solved;
- Color mesh count, GLB generation time, and browser rendering load in the 3D preview.

Physical print detail is still bounded by the source image's distinct colors, final print dimensions, nozzle line width, and available filament recipes. In most cases, unlock the ceiling only for high-resolution photos or smooth, wide gradients that still show visible banding at **256** colors.

## Pairing with 3D preview

Standard 3D preview caps color meshes at **128** by default. When **Quantize Colors** is set above **128** and you want low-frequency transition colors rendered accurately in the 3D viewport, enable [High-precision 3D Color Preview](../../preview-and-palette/high-precision-3d-preview/high-precision-3d-preview.mdx) as well.

Rebuild the preview and model after changing either control. Lumina recipe cards save the numeric **Quantize Colors** value, but not the separate unlock toggle.
