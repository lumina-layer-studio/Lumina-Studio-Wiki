# Precise Color Matching

**Precise Color Matching (Experimental)** constrains color quantization centers directly to colors available in the active LUT. While standard quantization forms free RGB cluster centers first and maps them to printable recipes afterward, constrained quantization ensures every cluster center is a physically reachable print color from the start.

This option is off by default.

## Location

Open **Converter → Core Settings → Advanced Settings**, then locate **Precise Color Matching (Experimental)**.

<img
  src={require('./assets/01-precise-color-matching-location.webp').default}
  alt="Precise Color Matching in Lumina Studio Advanced Settings"
/>

## Matching workflow

When the active color source provides valid LUT color samples and a spatial color index, enabling this switch runs constrained quantization:

1. Builds initial color clusters from the source image pixels.
2. Snaps and refines each cluster center within the set of reachable colors recorded in the LUT.
3. Outputs up to the configured [Quantize Colors](../../converter-basic/quantize-colors/quantize-colors.mdx) budget.
4. Generates the preview and 3MF model directly from the recipes tied to those LUT colors.

If the active LUT lacks the index data needed for constrained clustering, Lumina Studio automatically falls back to standard quantization without interrupting conversion. **Material Archives** use their own recipe solver and are unaffected by this switch.

## Relationship with Hue Protection

Turning on **Precise Color Matching** disables [Hue Protection](../hue-protection/hue-protection.mdx) so two different candidate-selection rules never conflict.

<img
  src={require('./assets/02-precise-disables-hue.webp').default}
  alt="Precise Color Matching enabled while Hue Protection is disabled"
/>

Turn **Precise Color Matching** off first whenever you want to test **Hue Protection** again.

## Quality and performance trade-offs

Constrained quantization helps prevent situations where an unconstrained RGB cluster looks accurate on screen yet snaps to an unexpected recipe during lookup. Because each iteration runs repeated nearest-neighbor searches against the LUT's reachable colors, processing takes longer than standard K-Means quantization. Final color fidelity remains bounded by your active LUT, **Quantize Colors** limit, source artwork, and layer count.

Rebuild the preview and model after toggling this switch. Lumina recipe cards do not save this experimental setting, so re-enable it manually if needed after importing a card.
