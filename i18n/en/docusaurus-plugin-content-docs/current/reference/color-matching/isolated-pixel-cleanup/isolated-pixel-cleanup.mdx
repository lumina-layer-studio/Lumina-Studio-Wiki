# Isolated Pixel Cleanup

**Isolated Pixel Cleanup** removes strict single-pixel recipe outliers after color matching. Instead of blurring the image or softening edges, it replaces a pixel only when its complete material stack differs from every surrounding neighbor.

This option is enabled by default.

## Location

Open **Converter → Core Settings → Advanced Settings**, then locate **Isolated Pixel Cleanup**.

## How cleanup works

Cleanup runs after pixels have been matched to printable material recipes. For each pixel, Lumina Studio inspects up to eight surrounding neighbors (edge and corner pixels are checked against their existing neighbors):

1. Compares the complete **material layer stack**, not just the on-screen RGB color.
2. Marks the pixel as isolated only if its stack differs from every valid neighbor.
3. Identifies the most frequent material stack among those neighbors.
4. Copies both the material stack and the matched color from a neighbor with that winning stack.

Because replacements are copied directly from neighboring pixels, cleanup always reuses valid recipes already present in the image and never introduces out-of-palette colors.

## What stays untouched

- Clusters of two or more connected pixels sharing the same stack are preserved.
- Fine lines, outlines, and small details remain intact whenever at least one adjacent pixel shares the same stack.

If noticeable speckling or color chatter remains, check [Quantize Colors](../../converter-basic/quantize-colors/quantize-colors.mdx), source image noise, and your target print dimensions.

## Supported workflows

Standard LUT, predictive matching, and Material Archive pixel pipelines all apply this neighbor-copy rule. Native SVG vector shapes are matched per vector object and bypass single-pixel cleanup.

Toggling this option clears any previously generated preview and 3MF output—rebuild both to compare results. Lumina recipe cards save this setting.
