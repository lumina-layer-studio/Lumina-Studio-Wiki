# Selection Modes, Palette, and Free Colors

The palette lists every color currently used in the active preview, with the percentage below each swatch showing its pixel coverage across the image. Selecting a swatch displays its quantized source color, matched color, and replacement color in order at the top of the column.

## Selection tools

| Tool | Action on the 2D preview | Typical use |
| --- | --- | --- |
| Same color | Toggles every region using the clicked color | Replace a color globally across the artwork |
| Similar colors | Toggles visible regions within the ΔE00 tolerance | Group and adjust nearby shades together |
| Pick blocks | Selects or deselects individual connected regions | Edit one or several isolated shapes |
| Selection brush | Selects whole connected blocks touched by the brush | Sweep across multiple neighboring regions quickly |

All four tools operate on a shared selection (superseding the earlier **All**, **Current**, **Multi**, and **Region** mode switches); check the highlighted outline on the 2D preview to verify the exact edit area.

**Similar colors** tolerance defaults to **6** and ranges from **0** to **30** (at **0**, only identical colors match). **Selection brush** size ranges from **2** to **160 px**. For step-by-step recoloring workflows, see [Quick recolor & similar recipes](../quick-recolor/quick-recolor.mdx).

## Replace, Undo, and Clear Remaps

Picking a target color stages a `source → target` preview first, rebuilding the 2D and 3D views only after you click **Confirm Replace**. Multi-color and multi-region edits are processed together in a single batch so the 3D preview rebuilds only once.

- **Undo:** Steps back to the previous confirmed edit state; check both the colors and active selection afterward.
- **Clear Remaps:** Removes all global and regional color replacements and rebuilds the 2D and 3D previews from the initial match.
- **Cancel:** Discards only the currently staged, unconfirmed target color.

## Free Color

Select a palette color and click **Mark as Free Color** to extract all solid voxels of that matched color into a standalone object (named like `Free_FFFFFF`) when generating the 3MF. In your slicer, you can then assign that object to any filament slot or apply dedicated print settings independently.

Because **Mark as Free Color** and **Clear Free Colors** change how objects are split inside the 3MF, run **Generate** again after updating them. Marking a Free Color leaves the 2D preview colors unchanged.
