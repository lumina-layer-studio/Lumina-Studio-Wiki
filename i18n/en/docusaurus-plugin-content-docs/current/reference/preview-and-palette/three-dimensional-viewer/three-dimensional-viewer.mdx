# 3D Viewer, Screenshot, Performance, and Diagnostics

After running **Preview** or **Generate**, the 3D Viewer places your model on the active printer's build-plate grid so you can inspect orientation, silhouette, structural attachments, and overall scale. Check your slicer preview to inspect final toolpaths and printable layers.

/>

## Camera controls

- **Orbit:** Click and drag on the canvas to rotate around the model.
- **Zoom:** Scroll the mouse wheel to move closer or farther away.
- **Smooth damping:** Camera motion decelerates smoothly when you release the pointer.
- **Deselect magnet:** While editing Fridge Magnet slots, clicking empty space outside the model clears the active magnet selection.

The camera supports a wide zoom range; if your model looks tiny on the build plate, verify your target and preview dimensions first.

## Bottom-right toolbar

From left to right, the four buttons in the lower-right corner open:

1. **Performance**
2. **Diagnostics**
3. **Fullscreen**
4. **Screenshot**

**Fullscreen** appears automatically in browsers that support the Fullscreen API, and exiting returns directly to the same workspace. **Screenshot** captures the current WebGL viewport as `lumina-3d-screenshot-<timestamp>.png`. To save recoverable settings and filament recipes alongside an image, use **Export Share Card** or **Export JSON** instead.

## Performance

<img
  src={require('./assets/viewer-performance.webp').default}
  alt="Lumina Studio Performance panel showing timing from a real Preview request"
/>

The **Performance** panel breaks down execution time from your latest **Preview** or **Generate** run:

| Metric | Meaning |
| --- | --- |
| Total | End-to-end duration for the completed stage |
| Upload processing | Time spent receiving and preparing the source image |
| Worker | Core color conversion and 3D geometry computation time |
| Cache load | Time spent reading cached intermediate data |
| Preview GLB | Time spent building the segmented GLB mesh for the 3D Viewer |
| Palette | Time spent assembling preview color coverage and recipe data |
| Overhead | Request handling and transfer time outside core computation |

Only stages involved in the latest run are displayed. **Performance** and **Diagnostics** are mutually exclusive—opening one closes the other.

## Diagnostics

<img
  src={require('./assets/viewer-diagnostics.webp').default}
  alt="Lumina Studio Diagnostics panel showing source, FPS, heap, triangles, calls, textures, and canvas"
/>

| Metric | Meaning |
| --- | --- |
| Source | Active viewport content: preview GLB, generated model, batch preview, or idle canvas |
| FPS / frame time | Live browser frame rate and estimated render time per frame |
| JS heap | Used and total JavaScript heap memory (when exposed by the browser) |
| Triangles | Total triangles submitted in the current frame |
| Calls | WebGL draw calls per frame |
| Textures | Active textures held by the renderer |
| Canvas | WebGL canvas pixel dimensions and device pixel ratio |

Use **Diagnostics** to tell whether a delay comes from model generation or from local WebGL rendering. If FPS drops alongside high triangle or draw-call counts, turn off unneeded 3D attachments, lower preview complexity, and check that browser hardware acceleration is enabled.

## Relationship to High-precision 3D Color Preview

**High-precision 3D Color Preview** controls how many color meshes are retained on the preview surface, while **Performance** and **Diagnostics** monitor live viewport load. For details on mesh budgets and memory impact, see [High-precision 3D Color Preview](../high-precision-3d-preview/high-precision-3d-preview.mdx).
