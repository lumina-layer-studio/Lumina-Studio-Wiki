# Color Workstation

After generating a preview, open **Color Adjustment** to enter Color Workstation. The 2D preview, palette, and target-color panels all share the active preview session, and confirmed edits write directly back to that session.

<img
  src={require('./assets/01-workstation.webp').default}
  alt="Color Workstation opened with real preview data"
/>

## Layout

- **2D preview:** Inspect the color result and click a pixel or connected region to select what you want to edit.
- **Palette:** View every color used in the active preview, its pixel coverage, selection tools, and edit history.
- **Target colors:** Legacy LUT mode loads the LUT color library; Material Archive mode shows candidate colors achievable with the active material set.

If an image is uploaded without a preview, opening the workstation runs a preview automatically. If the image, color source, or required settings are incomplete, the workspace stays blank until ready.

## How edits are applied and saved

Confirming a color replacement immediately updates the active 2D and 3D previews, and **Generate** applies those edits when building the 3MF. Closing the workstation or pressing `Esc` returns to the 3D viewer while keeping all confirmed replacements. Recheck the palette after changing the image or color source.

Confirmed local recoloring, regional recipes, and selections are saved and restored with your project, and remain intact when you run **Preview** again. For saving options and legacy file behavior, see [Save projects and share cards](../../../knowledge/share-card-json/share-card-json.mdx).

Use [Quick recolor & similar recipes](../quick-recolor/quick-recolor.mdx) in the right column to set a target color for the active selection, sample a color from the image, or apply a similar material stack.
