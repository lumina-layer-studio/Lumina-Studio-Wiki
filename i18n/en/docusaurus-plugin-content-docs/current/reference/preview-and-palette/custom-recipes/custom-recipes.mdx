# Custom Recipes

**Custom Recipe** lets you specify the exact filament color on each optical layer of a selected spatial region. Select at least one region in the 2D preview, then click **Custom Recipe** to open the editor.

## Editing the layer stack

Layers are listed in the order defined by the active LUT. You can recolor any layer, **Add Layer**, **Remove Layer**, or reorder layers with **Move Up** and **Move Down**. Use the pattern search field at the top for quick shorthand entry:

- Enter the first letter of a color's English name, such as `W`, `B`, `C`, `M`, `Y`, `R`, or `G`.
- Use `?` to keep the layer's current color.
- Use `-` as an optional separator.

Shorthand letters match against the active palette. When two palette colors share the same initial, inspect each layer swatch after clicking **Apply Pattern**.

## Predict Color

**Predict Color** uses the forward model bundled with the active LUT to estimate the resulting RGB and Lab values. If the LUT has no forward model, the editor notes that prediction is unavailable, while manual stack editing and application continue to work normally.

Predicted values reflect the optical model; physical prints also vary with filament batch, build-plate texture, lighting, and camera white balance.

## Apply to Selection

**Apply to Selection** saves the layer stack to one or more selected regions and rebuilds the preview. When your custom stack uses more layers than the current preview, the full image re-renders at the higher optical-layer count after a confirmation prompt.

A custom recipe can use both existing LUT materials and virtual materials introduced during editing. Both are passed into 3MF generation alongside regional overrides so every previewed color produces its corresponding 3MF object.

Each applied stack is saved to **Recipe History** for one-click reuse on other regions. **Undo edit** inside the dialog reverts only unapplied changes in the editor, whereas **Undo** in the workstation toolbar reverts confirmed replacements.
