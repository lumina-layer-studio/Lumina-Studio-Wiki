# High-precision 3D Color Preview

**High-precision 3D Color Preview** raises the maximum number of color meshes retained in the browser's GLB preview so high-color conversions show finer tonal detail on the 3D canvas. Disabled by default, it affects only the in-browser 3D display while leaving the 2D color preview and exported 3MF material recipes unchanged.

## Location

Open **Converter → Core Settings → Advanced Settings**, then locate **High-precision 3D color preview**.

## Default preview limit

Standard 3D previews retain up to **128** color meshes. When a conversion contains more than 128 colors, Lumina keeps the most frequent colors by pixel coverage and merges lower-frequency shades into their nearest retained color in color space to keep browser rendering responsive.

## Limit when enabled

When [Quantize Colors](../../converter-basic/quantize-colors/quantize-colors.mdx) is set above 128, enabling this option raises the GLB mesh limit to match your active **Quantize Colors** setting:

| Quantize Colors | Standard preview limit | High-precision preview |
| ---: | ---: | ---: |
| 64 | 128 | 128 (unchanged) |
| 128 | 128 | 128 |
| 256 | 128 | 256 |
| 512 | 128 | 512 |

Pixel Art mode already uses the current **Quantize Colors** value as its preview limit, so toggling this option has no extra effect in that mode.

## Performance and export behavior

Retaining more color meshes increases GLB file size as well as contour extraction, mesh building, transfer time, and Three.js rendering load. Combining a high **Quantize Colors** setting with **High-precision 3D Color Preview** increases both RAM and GPU memory usage.

After toggling this option, re-run **Preview** or **Generate** to rebuild the 3D view. Always check your slicer preview to verify the final printable structure. Lumina recipe cards save this setting automatically.
