# High-Fidelity SVG Sampling Density

In High-Fidelity mode, Lumina rasterizes SVG files at their target physical dimensions before running color matching and 3D modeling. **High-Fidelity SVG Sampling Density** sets how many pixels are generated per millimeter.

<img
  src={require('./assets/01-svg-density.webp').default}
  alt="High-Fidelity SVG sampling-density slider"
/>

## Range

- Default: `10.0 px/mm`
- Minimum: `2.0 px/mm`
- Maximum: `50.0 px/mm`
- Step: `0.1 px/mm`

For example, a 100 mm-wide SVG rasterizes to roughly 1000 pixels wide at the `10.0 px/mm` default. Higher values preserve sharper edges and tiny details at the cost of extra processing time and memory; lower values speed up computation while making fine strokes or narrow gaps coarser.

## When it applies

This setting takes effect only when both conditions are met:

- The input file is an SVG.
- Image Mode is set to **High-Fidelity**.

Native **Vector** mode processes SVG paths directly without rasterizing, so it ignores this value. Standard raster formats such as PNG and JPG are also unaffected.

After changing the sampling density, run Preview and Generate again to rebuild with the updated resolution. **Reset default** restores `10.0 px/mm`.
