# Auto Gradient Replacement

When a material profile maps a smooth gradient onto a finite set of filament recipes, subtle transitions can split into stepped color bands. **Auto Gradient Replacement** detects those band groups after preview and merges each group into the single color that covers the most pixels.

<img
  src={require('./assets/01-auto-gradient.webp').default}
  alt="Auto gradient replacement in System Settings"
/>

## Processing order

1. Complete standard image processing and material color matching.
2. Analyze gradient-band groups in the preview.
3. Pick the color with the highest pixel count in each group.
4. Apply the replacements as a batch and refresh the 2D and 3D previews.

Because artwork with heavy gradients runs this extra pass right after matching, the final preview may take a moment longer to appear.

## Default behavior and manual refinement

This option is off by default, keeping the raw matched palette intact so you can inspect detected groups in Color Workstation and merge only the ones you choose. Automatic and manual merges share the same grouping engine, and every change can still be undone or refined individually.

Merging bands smooths stepped transitions within detected gradient groups while leaving total color capacity and unrelated regions untouched.
