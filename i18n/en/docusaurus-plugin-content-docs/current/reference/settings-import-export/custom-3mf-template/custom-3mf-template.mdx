# Custom 3MF project templates

Custom templates let you reuse filament and global process settings already tuned in your slicer. Save a single-plate 3MF project with the same slicer, printer model, and nozzle size selected in Lumina.

## Import and select a template

1. Verify the printer, nozzle, build plate, filaments, and process settings in your slicer, then save a single-plate 3MF project.
2. Open Lumina Settings and locate **3MF Project Templates**.
3. Choose the 3MF file, optionally enter a descriptive name, and import it.
4. Select the imported template in the list, then return to Converter to generate your model.

Review the detected device summary and filament-slot count in the list. During export, Lumina also verifies that the template matches your active device and workflow.

## Retained and overridden settings

| Setting category | How Lumina handles it |
| --- | --- |
| Speed, acceleration, temperature, flow, retraction, cooling | Reuses the template's process settings |
| Material slots | Retained or trimmed to fit the export workflow; verify mapping in your slicer |
| Layer height, line width, walls, top/bottom shells, infill | Overridden to meet Lumina's color-modeling requirements |
| Wipe tower | Handled according to **Automatic wipe-tower placement** |
| Existing 3D meshes, per-object settings, modifiers | Omitted from the new project |

Templates carry over global filament and process tuning only—original models and local modifiers are excluded, while geometry-critical settings such as layer height, line width, shells, and infill are managed by Lumina.

## Supported workflows

Templates are supported for standard image, vector, material-archive, large-format tiled, and Model texture exports. Batch, puzzle, calibration, and swatch workflows use built-in configurations.

If Lumina reports a mismatch with the selected printer, nozzle, or slicer, update your device selection or import a template saved for that hardware.

## Switch back to a built-in configuration

Select a built-in configuration at any time to stop using a custom template. Back up your original 3MF file before deleting a stored template; if a previously selected template is missing, pick another valid template or return to a built-in configuration.

After opening the generated file in your slicer, check the assigned filaments, build plate, color layers, and wipe-tower placement, then run a full slice before printing.
