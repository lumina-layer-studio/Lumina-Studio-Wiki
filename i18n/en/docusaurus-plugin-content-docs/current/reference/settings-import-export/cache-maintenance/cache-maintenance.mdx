# Cache Management

**Clear Cache** deletes temporary runtime files, preview meshes, and conversion sessions, then reports the number of files removed and the disk space reclaimed.

<img
  src={require('./assets/01-cache.webp').default}
  alt="Cache Management in System Settings"
/>

## What is cleared

Lumina Studio removes:

- Temporary files tracked by the file registry.
- Active conversion sessions and their associated temporary files.
- Runtime files inside the output `temp` and `models` directories.
- Cleanable 3MF, GLB, PNG, JPG, and TXT files at the root of the output directory.

Protected statistics and cached LUT data are preserved, along with your material libraries, imported source LUTs, and application settings.

## After clearing

Active preview sessions are reset, so existing preview and download links on the page expire. Re-upload or run Preview again before generating a new download.

Because clearing the cache discards your active working session, run it when reclaiming disk space after long sessions, resetting a stuck session state, or following a specific troubleshooting step.

See [Web Generation and Download Troubleshooting](../../../knowledge/web-generation-troubleshooting/web-generation-troubleshooting.mdx) for standard troubleshooting steps.
