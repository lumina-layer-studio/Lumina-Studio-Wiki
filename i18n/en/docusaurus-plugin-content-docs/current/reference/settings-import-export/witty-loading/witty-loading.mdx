# Loading Witty Messages

When **Loading Witty Messages** is enabled, preview and generation screens rotate through playful short prompts while tasks run. Turning it off keeps the standard loading indicator without the extra copy.

<img
  src={require('./assets/01-witty-loading.webp').default}
  alt="Loading Witty Messages switch"
/>

This switch affects waiting-screen text only—image processing, color matching, generated geometry, computation speed, progress indicators, and error alerts all remain unchanged.

Your preference is saved in local browser storage across page reloads. Set it again if you switch browsers, clear site data, or move to another device.
