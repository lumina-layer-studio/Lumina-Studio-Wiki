# Loading Witty Messages

When Loading Witty Messages is enabled, preview and generation screens rotate through short status messages while a task
is running. Disabling it keeps the normal loading state but removes the extra copy.

<img
  src={require('./assets/01-witty-loading.webp').default}
  alt="Loading Witty Messages switch"
/>

The switch changes display text only:

- it does not change image-processing algorithms;
- it does not change model or colour output;
- it does not change computation speed;
- it does not hide progress or error messages.

The preference is stored in the current browser's local settings and survives a page reload. Set it again after changing
browsers, clearing site data, or moving to another device.
