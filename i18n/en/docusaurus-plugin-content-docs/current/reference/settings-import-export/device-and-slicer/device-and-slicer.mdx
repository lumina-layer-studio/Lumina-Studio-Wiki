# Device and Slicer

Device settings determine how Lumina Studio structures exported 3MF files and which slicer opens them after generation. Select the slicer, printer model, and installed nozzle size that match your actual hardware setup.

## How the settings work together

1. **Slicer Software** sets the compatible printer list and 3MF output adapter.
2. **Printer Model** defines build volume, machine capabilities, and available device profiles.
3. **Nozzle Size** drives model resolution, line width, and variable layer-height calculations.
4. **Device Profile** selects specific hardware or toolhead variants of the same printer.
5. **Build Plate** writes a native plate type supported by the active slicer and printer into the exported project.

Switching slicers immediately filters the printer list. If a previously selected printer, nozzle, or profile is unavailable under the new slicer, Lumina Studio automatically selects a valid option from the updated list.

After changing any device setting, run Preview and Generate again to export a 3MF configured for the new hardware.

## Manual slicer path

On macOS, you can specify an application path such as `/Applications/Bambu Studio.app`. Click **Validate & Save** to verify and store the path; once validated, Lumina uses it first when opening a generated 3MF in your slicer.

Because the manual path only chooses which app launches the file, keep **Slicer Software** set to the matching slicer family so Lumina exports the right 3MF format.

:::note[Device list]
The local machine registry supplies the device list. If the list is temporarily empty, Lumina retries automatically; if it remains unavailable, check that the local backend service is running.
:::

## Filament presets and build-plate compatibility

Before generation, Lumina checks native filament presets against the selected build plate. When a material matches multiple native presets, pick the specific preset you plan to print with; if a plate-compatibility warning appears, switch to a compatible build plate or filament type before continuing.

Select presets that match the physical filaments loaded on your printer so nozzle temperatures, flow rates, and bed temperatures slice accurately. Preferences are saved per device and nozzle, and exported projects record the selected filament presets.

## Custom templates and wipe-tower placement

To reuse process tuning from your slicer, import a [custom 3MF project template](../custom-3mf-template/custom-3mf-template.mdx) saved for the same slicer, printer, and nozzle.

**Automatic wipe-tower placement** is enabled by default so Lumina positions the model and wipe tower for your active build plate; turn it off to keep the template's wipe-tower coordinates for manual arrangement in your slicer. Whenever Lumina flags a layout warning, check the object, brim, and wipe-tower clearance in your slicer before printing.

Integrations such as QIDI Studio, PrusaSlicer, and Flash Studio each support specific printer models, nozzle sizes, and multicolor channel limits—select a slicer to view its supported hardware in the dropdown menus.
