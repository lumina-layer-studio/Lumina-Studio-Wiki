# Base-plate Layer-height Modifier

**Base-plate Layer-height Modifier** writes variable layer-height ranges into the exported 3MF so the plain backing prints with coarser layers to save time, while the colored artwork above retains its fine layer height.

## Layer-height rules

The base-plate layer height equals half the nozzle diameter:

| Nozzle | Base-plate layer height |
| --- | --- |
| 0.2 mm | 0.1 mm |
| 0.4 mm | 0.2 mm |

Lumina Studio writes this range into the 3MF `layer_config_ranges` metadata, allowing compatible slicers to apply separate layer heights to the backing and color layers within the same object.

## Scope

- Supported for Bambu-family slicer output only; hidden when another slicer is selected.
- Automatically skipped on double-sided models, which require symmetric layer sequencing across both faces.
- Regenerate the 3MF after toggling this option or changing the nozzle size.

Inspect the sliced layer-height preview before printing to confirm smooth transitions between the backing and color layers.

See [Why Base-color Layer Height Must Match](../../../knowledge/base-color-layer-height/base-color-layer-height.mdx) for details on how first layers, color layers, and backing thickness work together.
