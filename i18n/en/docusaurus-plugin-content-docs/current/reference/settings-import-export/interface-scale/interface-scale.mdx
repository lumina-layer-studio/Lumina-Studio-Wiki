# Interface scale

The desktop **Interface scale** setting changes the displayed size of text, buttons and panels. It does not change the
physical dimensions of a model or exported 3MF.

Open **Settings → General** and select 80%, 90%, 100%, 110%, 125%, 150% or 175% under **Interface scale**. At 100%,
the interface follows your operating system's display scale. Choose a larger value if the interface is too small, or a
smaller one if it is too large. The selection is saved for the next desktop launch.

/>

You can also change scale one step at a time with `Ctrl` plus `+` or `-` on Windows and Linux. Press `Ctrl + 0` to return
to 100%. On macOS, use `Command` in place of `Ctrl`.

This setting appears only in desktop versions that support it. In a browser, use the browser's own page zoom instead;
browser zoom and the desktop setting are stored separately.
