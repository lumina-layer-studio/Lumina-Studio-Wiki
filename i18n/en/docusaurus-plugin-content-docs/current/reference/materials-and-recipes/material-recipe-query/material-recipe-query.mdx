# Material Recipe Query

Material Recipe Query predicts stacked filament colors of arbitrary layer counts using the Beer–Lambert forward optical model stored in your material archives, with no five-layer cap or traditional LUT requirement.

<img
  src={require('./assets/01-recipe-result.webp').default}
  alt="Predicted result for a four-layer material recipe"
/>

## Substrate and layer height

Choose **White** or **Black** to set the underlying substrate color. Set the layer height to `0.04`, `0.08`, or `0.10 mm` to match your actual slicer layer height.

After changing either the substrate or the layer height, click **Compute Color** again to refresh the prediction.

## Build the stack

Materials are grouped by brand and searchable by material name, brand, or directory. Clicking a material appends one layer on the **substrate side** of the stack.

The stack is always displayed from outside to inside:

`viewing face → … → substrate`

- **Undo Last Layer**: Removes the most recently appended layer on the substrate side.
- **×**: Removes any individual layer from the stack.
- **Reverse**: Flips the entire layer sequence end to end.
- **Clear**: Removes all layers from the current recipe.

## Compute Color

Clicking **Compute Color** evaluates the forward optical model layer by layer from the substrate up to the viewing face. The output displays the predicted HEX and RGB values, total layer count, layer height, substrate, and intermediate color previews after each layer.

Screen swatches show the calibrated model prediction; because physical appearance also varies with extrusion behavior, filament batch, surface texture, and viewing illumination, print a verification swatch to confirm critical colors.

## Queue and verification swatch

<img
  src={require('./assets/02-recipe-queue.webp').default}
  alt="Recipe queue after adding one prediction"
/>

Click **Add to Queue** to save the current layer order, layer height, and substrate to the batch queue (identical recipes are skipped automatically). You can remove queued recipes individually or clear the entire queue at once. When generating verification swatches, configure:

- **Block size**: `5–50 mm`
- **Gap**: `0.5–10 mm`
- **Columns**: `0–20` (`0` arranges columns automatically)
- **Structure mode**: **Single-sided** or **Double-sided**

Swatch generation uses the printer, slicer, nozzle, and device profile configured in **Settings** to build a ready-to-slice 3MF alongside a layout legend preview. Once generation finishes, click **Download 3MF** to save the file; your queued recipes remain in place so you can adjust layout settings and generate again if needed.
