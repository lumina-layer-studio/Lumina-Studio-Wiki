# Gradient Card Generation

Gradient cards measure how one material transmits and absorbs colour at different stack thicknesses and over different
substrates. This page creates both the printable model and the Kit ZIP required by extraction.

<img
  src={require('./assets/01-gradient-card-generation.webp').default}
  alt="Gradient Card Generation page"
/>

Available layer heights are `0.04 mm`, `0.08 mm`, and `0.10 mm`. The selected value is written into the print jobs,
extraction configuration, and resulting material archive. Do not change it after printing; extraction follows the Kit
ZIP.

Generate Configuration Package creates the printable 3MF, card layout and layer-order configuration, extraction
parameters, and instructions. Download the ZIP promptly.

Even when you obtain the identical 3MF from MakerWorld, extraction still requires the configuration package generated
here.

Print two cards for every material under test:

1. one over a white substrate;
2. one over a black substrate.

Use the same test material, layer height, print profile, and orientation for both. The linked online model has the same
geometry as the local model; the page also links to a parametric storage box.
