# Editing and Re-Verification

Each material card provides four actions—**Edit Details**, **Re-Verify**, **Verification History**, and **Delete Material**—to manage display metadata, append new calibration measurements, inspect fit diagnostics, or remove a local archive.

## Edit Details

<img
  src={require('./assets/01-edit-material.webp').default}
  alt="Dialog for editing material name, brand, and display colour"
/>

**Edit Details** updates an archive's display metadata:

- **Display name**
- **Brand**
- **Display color**: Choose a swatch from the picker or enter a `#RGB` / `#RRGGBB` hex value.

Changing the display color updates only the preview swatch shown in material selectors; the fitted E, k, and substrate optical parameters remain unchanged. Because the underlying directory name stays fixed, renaming a material or changing its brand keeps existing project and recipe references intact.

## Re-Verify

Clicking **Re-Verify** opens **Gradient Extractor** with the current material directory targeted for re-verification. After extracting a new pair of white- and black-substrate card photos, choose how to handle the result:

- **Merge Result**: Keeps prior verification runs and jointly refits all valid historical and new samples.
- **Override**: Discards prior verification history and replaces the archive with the new fit.
- **Cancel Re-Verification**: Exits re-verification mode without modifying the archive.

Uncalibrated captures and ColorChecker-corrected images belong to separate source classes and cannot be merged together. To update an archive when switching calibration workflows, either process the images with matching source settings or select **Override**.

## Verification History

<img
  src={require('./assets/02-verification-history.webp').default}
  alt="Verification History dialog for a material archive"
/>

Each recorded run in **Verification History** lists the estimated color, mean ΔE, linear RMSE, detected white/black card orientations, and the fitted E, k, white C0, and black C0 parameters. When runs have been merged, merge diagnostics also indicate which historical measurements were included or excluded.

Reviewing these diagnostics helps you:

- Check consistency across repeated prints and photo sessions for the same filament
- Spot exposure shifts, white-balance drift, or card orientation errors
- Decide whether a new measurement should be merged into history or used to override the archive

## Delete Material

**Delete Material** permanently deletes this local archive directory from the current installation and cannot be undone. Cloud catalog revisions and copies stored on other machines are unaffected. To keep a backup before deleting, export the archive first via [Material Import and Export](../material-import-export/material-import-export.mdx).

For the full photography and extraction workflow, see [Gradient Card Extraction](../gradient-card-extraction/gradient-card-extraction.mdx).
