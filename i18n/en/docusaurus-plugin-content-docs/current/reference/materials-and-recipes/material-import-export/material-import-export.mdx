# Material Import and Export

You can export multiple material archives from the Material Library into a single ZIP package and import them into another Lumina installation. Each exported ZIP preserves the complete material metadata, optical fit parameters, and manifests needed for layer-stack prediction and image conversion.

  alt="Selection, import, and export controls in the Material Library"
/>

## Export

1. Check the materials you want to back up, or click **Select All**.
2. Click **Export Selected**.
3. Download and save the generated `lumina_materials_<count>_<time>.zip`.

A single ZIP can bundle multiple materials, including an export manifest, a package manifest, and each archive's `material.json`, fitted parameters, and supporting files. Download and save the generated package promptly.

## Import

**Import Material ZIP** lets you select multiple ZIP files at once. Before installing any archive, Lumina validates the package structure and contents:

- Archive paths, manifests, and material directory layouts are complete and valid
- `material.json` and fitted parameter files contain valid UTF-8 JSON with usable Stage A optical parameters
- For packages that include a versioned manifest, file sizes and content hashes match the recorded values

If a matching directory name already exists locally, Lumina appends a timestamp suffix to create a separate directory rather than overwriting the existing archive. Newly imported materials are automatically selected so you can review them right away.

When importing multiple ZIP files in one batch, if any file fails validation, all changes from that batch are rolled back automatically to keep your library consistent.

## Common use cases

- Backing up your local library before switching computers, migrating environments, or reinstalling Lumina
- Sharing calibrated material archives across a team
- Restoring archived materials from a NAS or offline backup
- Archiving the exact set of materials used in a project for reproducible results

After importing, review the brand, directory, layer height, and verification run count in the [Material Library](../material-library/material-library.mdx) before using the archives in [Material Recipe Query](../material-recipe-query/material-recipe-query.mdx) or image conversion.
