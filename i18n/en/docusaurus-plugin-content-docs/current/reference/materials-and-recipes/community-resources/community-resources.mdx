# Community Account, Saved Resources and Submissions

A community account syncs likes, saved resources and submission records. The packaged desktop edition can use local materials, LUTs and offline features without an account. Signing in is not a prerequisite for local work.

## Connect your account

1. Select **Connect account** under **Settings → General → Community account**, or from the material or LUT library.
2. Open the library sign-in page and use your email verification code or another offered sign-in method.
3. Check that the ten-character connection code matches the one in Studio, confirm the account and allow the connection.
4. Return to Studio and wait for **Community account connected**.

The connection code is valid for 10 minutes and can be confirmed only once. Start again if it expires. If an existing account has no verified email, sign in using its original method before verifying the email, preserving its submissions and saved resources.

When secure account storage is available on desktop, Studio reconnects on the next launch. Browser sessions and environments without secure storage display **Valid until Studio restarts**. Use **Account & devices** to view or revoke connected devices.

## Likes, saved resources and local favorites

Public resources display like, save and download counts without requiring sign-in. Once connected, likes and saves belong to the current community account. The corresponding material library, LUT library and converter pickers use the same records.

Saving records an entry you want to keep; it does not download all saved resources. Select and download an uninstalled item when you need it. Purely local profiles can still be marked as local favorites, separately from account-saved resources.

| Action or display | Meaning |
| --- | --- |
| Unsave | Removes the account's saved entry without deleting local files or changing the current palette |
| Switch or disconnect an account | Personal state follows the account; installed local resources remain |
| Download count | Distinct accounts that downloaded successfully; repeated downloads by one account count once |
| A count shown as “—” | Statistics are unavailable or the resource could not be matched; this is not a count of zero |

## Submit your own material profile or LUT

1. Open a local resource's details and choose **Share to public library**. This is also available after saving a gradient-card profile; LUT extraction offers a save-and-share action.
2. Check the submitting account, name, brand, material, series, color code and calibration information. For a LUT, check the filament in every channel, not just one spool.
3. State whether the data is your original work, an adaptation or a redistribution. Adapted and redistributed data need the original author, source and permission details.
4. Check the license and public attribution, then explicitly confirm and submit for review.
5. Open **My submissions** to follow status and reviewer feedback. Pending entries can be withdrawn for editing; published resources can receive a new revision.

Submitting does not publish immediately. A published revision remains available while an update is reviewed. Editing product names or purchase links does not alter a LUT's recipe data, and submitting does not confer official brand status on an account.

## Automatic contributions are off by default

To keep sharing your own calibrations, separately read and confirm the automatic-contribution setting in **My submissions**. Once enabled, newly saved calibrations enter the submission queue. Browsing, downloading, importing and existing historical files do not trigger uploads.

Incomplete entries wait locally for the missing information. Offline submissions remain queued. Disabling automatic contributions or disconnecting pauses tasks that have not started; enabling it again does not silently resume old tasks.

## Online preview and desktop use

The [online preview site](https://test.luminastudio.com.cn/) can be used without signing in, with exports for 3 distinct source images per day. Connecting a community account syncs saved resources and grants 3 additional new-image exports daily. See [Online preview and export allowance](../../../getting-started/online-preview/online-preview.mdx) for the workflow and counting rules.

These daily allowances belong to the online site. Local and offline use of the packaged desktop edition does not require a community account.
