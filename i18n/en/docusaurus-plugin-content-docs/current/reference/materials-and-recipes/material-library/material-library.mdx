# Material Library

The Material Library stores and organizes locally calibrated filament archives. Alongside a preview swatch for the interface, each archive holds the fitted optical parameters and calibration layer height required for layer-stack color prediction.

## Brand groups and duplicate names

Materials are grouped by brand and collapsed by default, with unbranded archives listed under **Unassigned**. Click any brand header to expand or collapse its group.

An **N copies** indicator appears when multiple archives share the same brand and display name while differing in directory name or measured data. Each archive uses its directory name as a unique identifier and remains stored separately.

Archives installed from the official cloud channel display an **Official** badge to indicate their source. Because printed color also depends on your specific printer, nozzle condition, and filament batch, choose between official archives and your own calibrated profiles based on your setup.

## Card fields

- **Display color**: The estimated RGB swatch from the gradient-card fit, which can be customized in the edit dialog.
- **Created / Last Updated**: Timestamps for when the archive was first saved and most recently updated.
- **Brand / Directory**: Brand grouping metadata and the archive's unique directory identifier.
- **Fit Error**: Mean ΔE of the current fit, useful for evaluating sampling and fit quality for that material (because optical behavior varies by pigment, compare values across runs of the same filament rather than ranking different colors against one another).
- **Verification Runs**: Number of valid calibration runs incorporated into the archive.
- **Usage Count**: How many times color modes have used this archive, along with its most recent use timestamp when recorded.
- **Layer Height**: The calibration layer height used when printing and fitting the gradient cards.

## Top toolbar

In the top toolbar, **Select All** selects every archive in the list for batch export, and **Refresh Library** reloads the latest archives from local storage.

For batch backups and transfers, see [Material Import and Export](../material-import-export/material-import-export.mdx).
