# Cloud Material Library

The cloud material library contains published profiles for individual filaments. Check the brand, series, material and color code on your spool, then choose a profile calibrated at the layer height you plan to print. You do not need to download the entire library to browse it.

## Find and add a filament

1. Select the cloud-library shortcut in the material picker, or open the cloud material library under material management.
2. Search by brand, series, product name or color code, and filter by installation status.
3. Open an entry to inspect its gradient cards, calibration layer height, original profile name, author and notes.
4. Once it matches your filament, select **Download to local**.
5. Return to the local picker, select the added profile and confirm it for your palette.

Downloading and selecting are separate actions: opening details, changing pages or downloading does not replace the current palette. Your search term is retained when moving between local profiles, the cloud and the offline pack.

## How the catalog and previews load

Studio first loads lightweight catalog details such as names and color modes. Once the catalog is complete, search covers all entries. Preview boards load by page, without installing every filament, and previously viewed previews are cached. While the catalog is still loading, an empty result does not mean the full library has no matching profile.

Filament previews place the white-base and black-base gradient cards side by side to show color at different thicknesses. Missing samples in older profiles are left blank; entries with only a representative color are labeled accordingly. Thumbnails and display colors help identify a profile, but the exact product and calibration layer height still need to match.

| Status | Meaning and action |
| --- | --- |
| Not installed | Not yet in the local library; download when needed |
| Installed | The current revision is available locally and can be selected |
| Update available / Local version exists | Another revision of the same resource exists; check its notes before updating |
| Local files missing | An installation record exists, but its files are incomplete; download that entry again |

Refreshing the cloud catalog updates the catalog and installation status without deleting your own calibrations. Identically named entries from different sources are not necessarily the same data.

## Mainland China and international product names

Open **Settings → General → Filament naming region** and choose **Match UI language**, **Mainland China** or **International**. A product may have different names in different markets. The list uses the selected market's name while details retain the original profile name.

Search accepts verified regional names, Chinese and English brand names, original names and color codes. Profiles without a regional name keep their original name; brand logos appear only when the corresponding authorized asset is available. Changing the naming region does not alter calibration data or the selected materials.

## Choose from an offline pack

Packaged editions provide an offline-pack entry. When a resource pack is available, select **Browse offline pack**, inspect an entry and choose **Add to local**. Starting Studio, searching and previewing do not install the entire pack; adding the same revision again reuses its existing record.

An offline pack is a fixed snapshot and does not include profiles published later. Check the cloud for updates when back online. Without an offline pack, installed profiles remain usable; you can also [import a material ZIP](../material-import-export/material-import-export.mdx) or [create a gradient-card profile](../../../tutorials/gradient-card-extract-profile/gradient-card-extract-profile.mdx).

## Save resources and contribute

The public catalog can be browsed without connecting an account. Connect a community account to like and save resources across devices; saving does not download the library. To submit your own measured profile for review, choose **Share to public library** in its details. See [Community account, saved resources and submissions](../community-resources/community-resources.mdx).
