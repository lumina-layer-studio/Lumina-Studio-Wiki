# Cloud Material Library

The Cloud Material Library provides an optional online catalog for browsing, downloading, and updating calibrated material archives. When no cloud registry is configured, the local Material Library remains fully functional offline.

  alt="Cloud Material Library with no registry configured"
/>

## Status bar

The top summary displays total catalog entries, locally installed materials, available updates, index status, and the last sync time. Clicking **Refresh Cloud Catalog** reloads the remote catalog and checks local installation status while keeping existing local archives intact. When no registry URL is configured, the page displays an unconfigured notice.

## Search and filters

Search matches brand, material name, material ID, revision, directory, channel, and visibility. You can filter entries by status:

- **All**: Shows every entry in the catalog.
- **Not Installed**: Shows materials not yet downloaded, as well as entries with missing local files.
- **Updates**: Shows installed materials that have a newer revision in the catalog.
- **Installed**: Shows materials currently installed locally.

Catalog entries load in pages of 50; when additional entries are available, you can load the next page or load all remaining items at once.

## Install states

Each material card displays its brand, name, color, local directory, package size, content fingerprint, and current state:

- **Not installed**: Ready to download locally.
- **Installed**: The local revision matches the latest catalog revision.
- **Update available**: A newer revision is available in the catalog.
- **Local revision available**: Identical archive content already exists locally under another mapping.
- **Local files missing**: An installation record exists locally, but its archive files are incomplete and need to be downloaded again.

Entries published through the official channel carry an **Official** badge. Verify the brand, material name, and calibration conditions before installing.

## Version rollback

Rollback controls appear on a card whenever a usable historical revision is still stored locally. Rolling back switches your active local version to that earlier revision without modifying the cloud catalog.

Installed archives appear in the [Material Library](../material-library/material-library.mdx) and can be backed up offline using [Material Import and Export](../material-import-export/material-import-export.mdx).
