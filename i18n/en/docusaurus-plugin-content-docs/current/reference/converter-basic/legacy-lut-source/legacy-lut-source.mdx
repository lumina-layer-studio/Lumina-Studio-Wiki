# Classic LUT

A **Classic LUT** is a precomputed color lookup table in which each printable color maps to a fixed layer-by-layer filament recipe. During preview, Lumina Studio matches each area of your artwork to the closest entry in the table.

## Select LUTs

<img
  src={require('./assets/02-lut-picker.webp').default}
  alt="Classic LUT picker with the brand list, search field and Confirm button"
/>

1. Under **Color Data Source**, choose **Classic LUT** and open the LUT selection dialog.
2. Search or browse by brand and check the LUTs you want to use—compatible LUTs from different brands can be combined.
3. Confirm your selection, click **Preview**, and inspect key colors, neutral grays, and shadow detail.

When multiple compatible LUTs are selected together, the first item serves as the primary LUT while all selected tables merge in memory into a single candidate color pool without creating a new file on disk. Only combine LUTs that share compatible layer counts, layer heights, and filament channels.

## Refresh and upload

After adding or replacing LUT files on disk, click the refresh button inside the picker to reload the list.

**Upload** accepts `.npy`, `.json`, `.npz`, and `.msgpack` files. After uploading a file, verify in the list that the intended LUT is checked. If a preview produces unexpected colors, open **LUT Details** to check that its color mode, layer count, layer height, and recipe metadata are complete.

## Dynamic layers

**Color Layers** and **Layer Height** appear in basic settings only when the selected LUT declares `supports_dynamic_layer_count` in its metadata. Layer count can be adjusted from **1–20** and layer height from **0.04–0.20 mm**; changing either clears any previous preview and generated output.

Standard Classic LUTs use the fixed layer count and layer height stored inside the LUT file itself, so these two controls stay hidden during normal use.
