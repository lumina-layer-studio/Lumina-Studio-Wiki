# Base Plate Infill

**Base plate infill** controls the sparse infill density deep inside thick base plates. Lowering this value reduces filament usage and print time on thick bases, while **100%** keeps the entire base solid. Color layers always print solid, and base plate thickness itself remains unchanged.

Find **Base plate infill** in the Converter's basic settings directly below **Base plate thickness**. It ranges from **5%–100%** with a default of **100%**. Drag the slider in **5%** steps, or type any whole number within that range into the input box on the right.

## Why does a lower setting still produce a solid base?

To prevent internal infill patterns from showing through the viewing surface, Lumina keeps a **3 mm solid protection zone** inside the base plate, measured inward from the boundary between the color layers and the base. Double-sided prints reserve a 3 mm solid zone behind each face, and the color layers themselves remain solid as well.

Because of this protection zone, a single-sided base **3 mm** or thinner lies completely inside the solid region. Likewise, a double-sided base **6 mm** or thinner has touching or overlapping protection zones and stays solid throughout. At those thicknesses, the exported 3MF uses 100% infill for the base regardless of a lower slider setting.

For example, with **Base plate infill** set to **20%**:

| Artwork | Generated base thickness | Exported infill behavior |
| --- | --- | --- |
| Single-sided | 1.20 mm | Entire base stays solid |
| Single-sided | 4.00 mm | 3 mm next to the color layers stays solid; deeper section uses 20% sparse infill |
| Double-sided | 6.00 mm | Protection zones meet, so the entire base stays solid |
| Double-sided | 8.00 mm | 3 mm on each side stays solid; center core uses 20% sparse infill |

This threshold is based on the **layer-aligned base thickness** generated for the model, excluding the height of the color layers. When your base thickness is close to the 3 mm or 6 mm boundary, scrub through the layers in your slicer preview to verify where sparse infill begins.

### Slicing comparison

When exporting a 20 × 20 mm single-sided test block from Lumina at 20% and 100% infill and slicing both in Bambu Studio, a 2 mm base produces identical filament estimates because the entire base falls within the 3 mm solid zone. Increasing the base to 6 mm introduces sparse internal paths in the 20% project, reducing both estimated filament usage and print time. Exact savings vary with print area, base thickness, wall count, and top/bottom shell settings.

## Check the result in your slicer

1. Set [Base-Plate Thickness](../backing-thickness/backing-thickness.mdx) and **Base plate infill** for your print, then generate a new 3MF.
2. Open the 3MF **as a complete project** in a compatible slicer—importing raw geometry alone skips 3MF infill modifiers.
3. Slice the project and drag the layer slider down into the base to inspect the internal toolpaths beneath the solid shells.
4. To compare infill values directly, keep all other parameters identical, export and slice separate 3MF projects, and compare internal paths, material estimates, and print times.

Top shells, bottom shells, and perimeter walls in your slicer also occupy solid volume, and third-party slicers vary in how they interpret 3MF modifier settings. Use the layer-by-layer preview after slicing to confirm the internal infill layout.

## When is the control unavailable?

**Base plate infill** is disabled when **Model Texture** (also labeled “Model Surface” in some tooltips) or **Relief** is enabled; flat puzzles remain adjustable. Note that **Base plate infill** adjusts infill density rather than layer thickness—to print thick bases faster with taller layers, see [Backing, Color Layers, and Layer-Height Modifiers](../../../knowledge/base-color-layer-height/base-color-layer-height.mdx).
