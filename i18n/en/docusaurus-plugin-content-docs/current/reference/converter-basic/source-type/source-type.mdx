# Color Data Source

Color Data Source determines which colour data Lumina Studio uses to turn image colours into printable, layer-by-layer material
recipes. It does not alter the source image, but it changes the brands, databases, layer modes, and backing materials available
later in the workflow.

## The two sources

| Option | Data used | Typical use |
| --- | --- | --- |
| Material Archive | Individual filament profiles extracted from gradient cards | Freely combining measured materials and solving recipes for that set |
| Classic LUT | A precomputed colour-to-recipe lookup table | Existing LUTs, compatible multi-LUT sets, or a LUT file you import |

The same image can produce different candidates and recipes under each source. Material Archive is selected by default if no
preference has been saved; an existing source preference is retained.

Older versions also offered Inferred LUT. The current source selector does not expose that option; its
[older documentation](../inferred-lut-source/inferred-lut-source.mdx) is retained for reference.

## What switching resets

Switching sources invalidates the current preview, 3MF, and download URL so results from the previous data source cannot be
reused accidentally.

Confirm the selected materials or LUT and generate a fresh preview after every switch. A previously downloaded 3MF is not
updated to use the new source.
