# Color Data Source

**Color Data Source** selects which color data Lumina Studio uses to convert image colors into printable, layer-by-layer filament recipes. Changing the source leaves your artwork untouched while updating the material library, brand LUT, layer count, and base plate options shown below it.

## Comparing the Two Sources

| Option | Data used | When to use |
| --- | --- | --- |
| Material Archive | Individual filament profiles measured from gradient cards and saved in your material library | Freely combining measured spools and letting the solver calculate recipes for that set |
| Classic LUT | A precomputed color-to-recipe lookup table | Using built-in LUTs, combining compatible multi-LUT sets, or importing your own LUT file |

The same image can produce different candidate palettes and layer recipes under each source. **Material Archive** is selected by default when no preference has been saved; afterward, Lumina Studio remembers your last selection.

Earlier versions also included an Inferred LUT option, which is no longer part of this selector; see its [older documentation](../inferred-lut-source/inferred-lut-source.mdx) for background.

## Switching Sources

Switching **Color Data Source** clears the active preview, generated 3MF, and download link, and resets settings specific to the previous source. After switching, confirm your chosen materials or LUT and generate a fresh preview and model.
