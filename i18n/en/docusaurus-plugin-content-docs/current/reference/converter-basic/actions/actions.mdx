# Preview, Generate, and Export

Actions separates inspection, model generation, and delivery for the same parameter set. Previewing first catches image,
colour, and geometry issues before a printable 3MF is created.

## Preview

Preview reads the current image, colour source, and settings and creates a new preview session. A successful run supplies:

- the matched 2D result;
- the model used by the 3D viewer;
- palette, layer-image, and Color Workstation data;
- session state required by Generate.

The button is disabled until both an image and a complete colour source are available. Re-preview after changing a setting
that affects output; layer images from an old session are not reused for the new one.

## Download 3MF or open the slicer

Once the preview looks right, generate and download a 3MF or open it in a detected slicer. The button label depends on the
detected slicer and file state, for example **Generate & open in Bambu Studio**, **Generate & Download 3MF**, or
**Download 3MF**. Use the adjacent arrow to choose an action. If no slicer is detected, you can still generate and download
the file; there is no separate Generate control to press first.

Puzzle and Large Format use their own generation paths. A previously downloaded file does not change when settings are
edited; check the new preview and generate again.

## View Layers

View Layers creates one image for each optical layer in the current session. Thumbnails open at a larger size. Hover
inspection reads the surface colour and the colours at the same point in every layer. This verifies the recipe; it does not
prove that the slicer has assigned the intended physical filaments.

## Share Card and JSON

- **Export Share Card** packages a cover image with a reproducible Lumina recipe.
- **Export JSON** saves the recipe sidecar alone for inspection, automation, or version control.

Both need an image and completed preview. They contain Lumina parameters rather than sliced G-code. See
[Share Card and JSON](../../../knowledge/share-card-json/share-card-json.mdx).

Bed Size comes from the selected printer in Settings and is used for preview scale and bounds. Confirm the real printer,
nozzle, and plate again in the slicer.
