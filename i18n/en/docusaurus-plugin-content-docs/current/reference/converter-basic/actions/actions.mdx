# Preview, Generate, and Export

The action bar at the bottom of the Converter brings together color preview, layer inspection, 3MF export, and recipe sharing. Running a preview first lets you verify color matching and model geometry before generating a printable 3MF file.

## Preview

Clicking **Preview** processes the current image, color source, and settings to generate:

- The matched 2D preview;
- The 3D model shown in the 3D viewer;
- Palette data, layer images, and **Color Workstation** color assignments.

**Preview** stays disabled until both an image and a complete color source are ready, and indicates what is missing. After changing any setting that affects the output, run **Preview** again to refresh the model and layer images.

## Download 3MF or open the slicer

Once the preview looks right, use the primary export button to generate and deliver your 3MF in one step—there is no separate **Generate** button to press first. The button label updates automatically based on detected slicers and file status, such as **Generate & open in Bambu Studio**, **Generate & Download 3MF**, or **Download 3MF**. Use the dropdown arrow next to the button to switch actions. If no slicer is detected on your system, you can still generate and download the 3MF file directly.

**Puzzle** and **Large Format** modes use their own dedicated export workflows. Editing settings does not modify a previously downloaded 3MF; inspect the updated preview and export a new file after making changes.

## View Layers

**View Layers** renders an image for each optical color layer in the current preview. Click any thumbnail to inspect it at a larger size, or hover over the main preview to read both the finished surface color and the layer-by-layer color stack at that exact point. Use this view to verify the optical recipe before confirming physical filament assignments in your slicer.

## Share Card and JSON

Once an image has been imported and previewed, you can export the current conversion recipe in two formats:

- **Export Share Card:** Packages a cover image with a reproducible Lumina recipe in a single file for sharing with other Lumina users.
- **Export JSON:** Saves the standalone JSON recipe file for backups, version control, or automation workflows.

Both formats store editable Lumina conversion parameters that can be re-imported later. For details on file contents and import behavior, see [Share Card and JSON](../../../knowledge/share-card-json/share-card-json.mdx).

## Bed Size

**Bed Size** displays the build-plate dimensions of the printer selected in **Settings**, providing scale and boundary references in the 2D and 3D previews. When preparing the print in your slicer, confirm that the target printer, nozzle, and build plate match your hardware.
