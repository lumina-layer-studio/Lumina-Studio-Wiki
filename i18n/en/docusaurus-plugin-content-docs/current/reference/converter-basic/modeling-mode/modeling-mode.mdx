# Modeling Mode

**Modeling Mode** controls how Lumina Studio samples your artwork, handles edges, and builds 3D geometry. It works alongside **Color Data Source**: the data source supplies printable filament recipes, while the modeling mode determines how image structure becomes color regions and mesh geometry.

  alt="The four Modeling Mode options in Lumina Studio"
/>

## High-Fidelity

Samples raster images at roughly 10 px/mm, applies edge-preserving smoothing, and clusters colors within your **Quantize Colors** budget before matching recipes. Best suited for photographs, illustrations, smooth gradients, and detailed everyday artwork.

## Pixel Art

Scales the grid to the nozzle width and uses nearest-neighbor resizing to keep crisp, unsmoothed pixel edges. When the visible palette already fits within **Quantize Colors**, original colors are preserved as-is; otherwise pixels are quantized directly without High-Fidelity smoothing. Ideal for pixel art, sprites, and graphics with sharp block boundaries.

## Vector

Available only when an SVG is uploaded; unavailable for raster images. Lumina Studio builds 3D geometry directly from the SVG shapes, fills, and strokes.

## Color Card

Generates a calibration swatch model from the active color recipes so you can test-print and verify actual filament colors before printing full artwork.

## Choosing a Mode

Choose **High-Fidelity** for photos, illustrations, and smooth transitions, or **Pixel Art** for crisp pixel graphics where hard edges should remain intact. Because final detail depends on artwork style, target dimensions, and nozzle width, preview both modes at the same output size when in doubt. For further guidance, see [Bitmap vs vector](../../../knowledge/bitmap-vs-vector/bitmap-vs-vector.mdx) and [Choosing an image mode](../../../knowledge/image-mode-selection/image-mode-selection.mdx).

Switching Modeling Mode clears any previously generated 3MF, so generate a fresh preview and model afterward.
