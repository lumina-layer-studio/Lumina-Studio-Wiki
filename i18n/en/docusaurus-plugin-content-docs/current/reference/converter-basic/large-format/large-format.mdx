# Large Format Mode

**Large Format** splits artwork that exceeds a single build plate into a grid of separate 3MF tiles and packages them together as a downloadable ZIP archive.

## Finished size and tile size

Enabling **Large Format** raises the maximum finished width and height from `400 mm` to **9999 mm**. **Tile Width** and **Tile Height** can each be set from **50–500 mm** in **10 mm** steps.

Lumina calculates the tile grid as follows:

- **Columns** = finished width ÷ tile width, rounded up;
- **Rows** = finished height ÷ tile height, rounded up;
- **Total tiles** = rows × columns;
- Edge tiles along the last column and bottom row keep only their actual remaining dimensions rather than adding blank padding.

The `columns × rows = total` summary reflects these exact calculations, with dimensions in parentheses indicating smaller edge tiles.

## Output and slicing

Generating in **Large Format** mode downloads a ZIP archive containing individual 3MF files named with the source artwork title and row/column coordinates for straightforward assembly after printing. Set **Tile Width** and **Tile Height** slightly smaller than your printer's nominal bed size to leave clearance for skirts, brims, prime/purge regions, and bed keep-out boundaries.

Native SVG artwork is split directly as vector geometry whenever possible. If an SVG contains structures that cannot be cleanly split as vectors, Lumina falls back to resolution-bounded raster tiling and displays a warning. Finished physical dimensions remain unchanged, though tiny edge details may be rasterized.

## Mode compatibility

**Puzzle** and **Fridge Magnet** modes cannot be combined with **Large Format**—enabling either automatically turns **Large Format** off. **Relief**, **Outline**, and **Transparent Coating** can all be tiled, though you should inspect adjacent tile boundaries in the preview or slicer to verify clean seam continuity before printing.
