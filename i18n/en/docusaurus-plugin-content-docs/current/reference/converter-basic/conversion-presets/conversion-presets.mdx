# Preset

**Preset** saves your commonly used conversion settings so you can apply them to future images in a single click. Find **Preset** under **Converter → Core Settings → Image Import and Basic Settings**, located between the image upload area and the color source selector.

## Save a preset

<img
  src={require('./assets/01-save-preset.webp').default}
  alt="Save parameter preset dialog with its name, summary and optional setting groups"
/>

1. Configure your color source, filament profiles or LUTs, dimensions, layer count, layer height, and single- or double-sided mode.
2. Click **Save as preset** and enter a unique name between **1–40** characters.
3. Review **Settings to save**. **Advanced settings**, **Outline**, and **Coating** are optional and unchecked by default—check any group you want included.
4. Click **Save preset**.

Preset dimensions are stored using the image's **long edge**. For example, a `100 mm` preset sets the long edge to `100 mm` on both landscape and portrait images, calculating the shorter edge automatically from each image's aspect ratio.

## Apply and manage presets

Select any preset from the **Preset** dropdown menu to apply it. Optional setting groups omitted from that preset keep their current values. After applying a preset, verify your filaments and dimensions, then run **Preview** again—previously exported 3MF files are not updated automatically.

Editing any setting after selecting a preset displays **Modified** without overwriting the saved preset; click **Update preset** to save your changes back to it. You can also rename or delete the selected preset from the dropdown menu without clearing the parameters currently active on screen.

Choose **Last used** to restore the settings from your previous conversion session. When an external project is imported, the menu also includes **Current project settings**.

## Preset vs. project file

A preset stores reusable conversion parameters and references to selected filament profiles or LUTs—it does not embed source artwork, previews, or local color edits. When using a preset on another computer, make sure the referenced filament profiles or LUTs are available there. To archive or share a specific piece of artwork with its exact recipe, keep the source image or export a project file as described in [Share Card and JSON](../../../knowledge/share-card-json/share-card-json.mdx).
