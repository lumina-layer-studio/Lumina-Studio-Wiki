# Image Import, Batch Selection, Crop, and Rotation

Importing an image is the first step in Converter—subsequent previews, color matching, and model geometry all build on the artwork loaded here. Click the upload area to choose files or drag and drop them directly onto it. Once an image is loaded, the upload area collapses to a single row; click the filename row at any time to expand it again.

## Accepted file formats

Converter accepts the following input formats:

- JPEG, PNG, SVG, and WebP;
- HEIC and HEIF;
- DNG, CR2, CR3, NEF, ARW, ORF, RW2, RAF, PEF, SRW, and generic RAW formats;
- Lumina `.lumina.json` project files.

RAW, HEIC, and HEIF support depends on the decoders available in your system environment; if a file cannot be decoded directly, Lumina prompts you to convert it to PNG or JPEG first. SVG files are processed as vector artwork and do not automatically open the bitmap crop dialog when **Crop after upload** is enabled.

## Single image, add more, and batch mode

When a single standard image is loaded, the uploader displays the current image and provides two actions:

- **Replace current image:** Replaces the artwork in the current task.
- **Add more images:** Appends additional files and switches to batch mode.

Batch mode lists queued files and lets you add more or remove individual items. Up to **40** filenames are listed directly, with any additional files summarized by count. Because the single-image crop toggle is hidden in batch mode, prepare each image's framing and orientation before adding it to a batch.

When you select a single `.lumina.json` file or a PNG share card containing an embedded Lumina recipe, Lumina imports it as a project and restores its saved parameters. Standard PNGs without valid recipe data are imported as regular images. For the full workflow, see [Share Card and JSON: Export, Import, and Continue Editing](../../../knowledge/share-card-json/share-card-json.mdx).

## Crop after upload

When **Crop after upload** is turned on, selecting a new single bitmap automatically opens the crop dialog. Turning the toggle off applies only to future uploads and leaves your currently cropped image intact.

The crop dialog includes:

- Free aspect ratio;
- `1:1`, `4:3`, `3:2`, `16:9`, `9:16`, and `3:4` aspect presets;
- Original image dimensions and current selection dimensions in pixels;
- Numeric pixel inputs for `X`, `Y`, width, and height;
- **Rotate left 90°**, **Rotate right 90°**, **Cancel**, and **Apply Changes**.

Dragging the crop box and typing pixel coordinates stay synchronized in real time, and the selection stays constrained within the image bounds. Clicking **Apply Changes** updates the working image, preview, and aspect ratio to the cropped result. Pressing `Esc`, closing the dialog, or clicking **Cancel** discards uncommitted edits.

With a single image loaded, click **Crop & Rotate**, then use **Rotate left 90°** or **Rotate right 90°** (click twice for 180°) and click **Apply Changes** to confirm.

Applying rotation writes an updated working image and refreshes its aspect ratio, so all subsequent 2D and 3D previews, color matching, share cards, JSON exports, and 3MF models use the new orientation. Consecutive rotations build directly on the current working image. SVG files can also be rotated here while preserving vector paths, without bitmap cropping.

## Check after changing the image

Replacing, cropping, or rotating an image makes the previous preview outdated. Click **Preview** again to verify the updated outline, orientation, transparent cutouts, layer images, and physical dimensions. For a step-by-step walkthrough, see [Upload, Crop, and Rotate an Image](../../../knowledge/image-upload-crop-rotate/image-upload-crop-rotate.mdx).
