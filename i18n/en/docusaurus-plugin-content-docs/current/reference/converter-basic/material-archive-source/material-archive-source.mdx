# Material Archive Source

Material Archive mode uses individual filament profiles measured from gradient cards and saved in your material library. You can freely combine measured spools and let Lumina Studio calculate layer-by-layer color recipes directly, without relying on a fixed preset LUT.

## Select Materials

Click **Select Materials** to pick filaments from your material library. Once confirmed, the list order defines the material-slot order used in generated recipes. Adding, removing, replacing, or reordering materials clears the current preview so you can regenerate it with the updated set. If a material folder was renamed in the library, Lumina Studio automatically links to the updated name; missing profiles are never silently replaced with unrelated filaments.

## Color Layers

Sets how many printed color layers each pixel recipe stacks, adjustable from **5–10** layers (default **5**). Because the same filament can appear on multiple layers, the layer count is independent of how many spools you select—for example, a 5-spool set can still generate 10-layer recipes.

Increasing **Color Layers** expands the pool of achievable colors while also increasing model height and solve time. Regenerate the preview after changing this value.

## Layer Height

Offers **0.04**, **0.08**, and **0.10 mm**. Layer height determines the light transmission and color contribution of each printed layer. Because optical behavior changes with thickness, match this setting to the layer height used when measuring your gradient cards (for instance, pair a profile calibrated at 0.08 mm with a 0.08 mm layer height) for accurate color reproduction.

## Base Plate Material

Chooses which of the currently selected materials forms the base plate. Unless you assign separate structure colors elsewhere, the base plate, outlines, and other foundational geometry use this filament. If you later remove that filament from the selected list, Lumina Studio automatically assigns a new default from the remaining materials.

## Exhaustive Cache

**Exhaustive cache…** becomes available once at least one material is selected. It builds and saves a complete, exact recipe library on disk for the active setup. Each cache file is keyed to five parameters:

- Selected materials and their exact order;
- **Color Layers** count;
- **Layer Height**;
- Substrate type;
- Lab-grid density configured in Settings.

Changing any of these parameters switches Lumina Studio to the cache file matching the new configuration.

Once built, the panel displays the build timestamp, file size, occupied grid cells, mean and maximum ΔE, and build duration. **View color charts** inspects the Lab and RGB coverage of the cache, **Rebuild** overwrites the cache for the current parameter set, and **Delete cache** removes only the file for the active combination and grid density.

When no exhaustive cache exists for the active setup, conversion checks saved Smart Recipe Caches from the largest budget downward. If none is found, Lumina Studio builds a temporary runtime cache of up to roughly 1M candidates so you can still preview right away, though with narrower color coverage than a full exhaustive build.

## Smart Recipe Cache

Smart Recipe Cache is designed for larger filament sets or higher layer counts where enumerating every permutation would be impractical. It samples and stores a broadly distributed set of recipes within a fixed candidate budget: **1M**, **4M**, **8M**, **32M** (default), or **64M** candidates.

Higher budgets cover more of the color space at the cost of longer build times, larger cache files, and higher peak memory during construction. The status panel shows the saved recipe count, candidate budget, file size, build timestamp, and inverse-refinement status. Click **View recipe coverage** to inspect how the saved candidates are distributed in color space.

Exhaustive and smart caches are stored separately and never overwrite each other. During conversion, a matching Exhaustive Cache always takes priority; Smart Recipe Cache is used when no exhaustive cache is available.
