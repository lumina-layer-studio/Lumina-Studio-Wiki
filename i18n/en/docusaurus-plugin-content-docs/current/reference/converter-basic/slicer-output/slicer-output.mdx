# Slicer and downloads

Lumina Studio detects compatible slicers installed on your computer and prioritizes the preferred application configured in Settings. What the primary output button does depends on whether a slicer is available, whether a 3MF is already built, and whether Large Format or separate backing is enabled.

## Primary Button Actions

| Current state | Action when clicked |
| --- | --- |
| Slicer detected, 3MF not yet built | Generates the 3MF and opens it in the selected slicer |
| Slicer detected, 3MF ready | Opens the current 3MF directly in the selected slicer |
| No slicer detected | Generates and downloads the 3MF (or downloads the ready file) |
| Large Format enabled | Generates or downloads a ZIP archive of tiled 3MF files without auto-opening a slicer |
| Separate backing project | Downloads a ZIP archive containing separate model and backing 3MFs to unpack and open individually |

You can also open the dropdown menu next to the button and select **Generate & Download 3MF** at any time—if no 3MF exists yet, Lumina Studio builds it first and saves it without launching a slicer. If the preferred slicer set in Settings is not installed, Lumina Studio notifies you so you can pick another detected slicer or download the file directly.

If a filament-preset or build-plate prompt appears before generation, confirm those choices first. Whenever you edit the artwork, color assignments, or structure settings, generate a fresh 3MF so your exported file reflects the latest changes. In the desktop app, you can configure a default save folder in Settings; save dialogs open there first while still letting you pick another folder per download.

## Checks in Your Slicer

A 3MF carries mesh geometry and material metadata, while your slicer controls the final machine-specific settings. Before sending a print job, verify:

1. Printer model and nozzle diameter;
2. Physical filament slot assigned to each object;
3. Flat contact between the model and the build plate;
4. First-layer orientation and display-face direction;
5. Fine lines, holes, and attached geometry in the layer-by-layer slice preview.
