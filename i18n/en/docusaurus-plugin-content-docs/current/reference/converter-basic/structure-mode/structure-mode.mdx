# Structure Mode

**Structure Mode** controls whether color layers are built on one side or both sides of the base plate.

<img
  src={require('./assets/01-structure-mode.webp').default}
  alt="Double-sided and Single-sided Structure Mode options"
/>

## Double-sided

Builds color layers on both sides of the base plate, making it ideal for hanging tags, charms, and keychains viewed from either side. Double-sided geometry increases overall model thickness, filament usage, and total sliced layers.

## Single-sided

Builds color layers on one face while leaving the opposite face as the base plate. Standard plaques as well as back-side features such as Relief and Fridge Magnet use single-sided geometry.

## Mode Restrictions

- Enabling **Relief** or **Fridge Magnet** locks Structure Mode to **Single-sided**.
- **5-Color Extended** supports **Single-sided** only and automatically switches an active **Double-sided** selection back to **Single-sided**.
- Changing Structure Mode clears any previously generated 3MF and download, so regenerate the model before slicing.

After opening the 3MF in your slicer, inspect both the top face and the underside to verify display-face orientation, build-plate contact, and any back-side features.
