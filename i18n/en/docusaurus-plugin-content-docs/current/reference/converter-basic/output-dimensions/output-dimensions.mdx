# Output Width and Height

**Width** and **Height** set the physical XY size of the finished print in millimeters (`mm`).

## Aspect-Ratio Locking and Size Limits

Once an image is uploaded, Lumina Studio locks its source aspect ratio: changing **Width** recalculates **Height**, and changing **Height** recalculates **Width**. Linked values are rounded to whole millimeters within the active size range.

Standard mode supports **10–400 mm**, while Large Format raises the upper limit to **9999 mm**. When your target dimensions exceed a single printer's build plate, check your plate limits or enable [Large Format](../../../knowledge/large-format/large-format.mdx) to tile the artwork across multiple plates.

## What Dimensions Affect

Adjusting Width or Height updates more than the outer footprint:

- Final XY dimensions of the 3D model;
- Image sampling resolution—**High-Fidelity** raster images sample at roughly 10 px/mm, **Pixel Art** scales by nozzle width, and **High-Fidelity** SVGs use the SVG raster density in Settings (see [Modeling Mode](../modeling-mode/modeling-mode.mdx));
- The suggested value from **Auto Detect** under **Quantize Colors**;
- Placement of loops, magnet pockets, outlines, and other attached structures relative to the main body.

Changing either dimension clears any previously generated 3MF. Because sampling density scales with physical size, generate a fresh preview after resizing to verify fine details.
