# Quantize Colors

**Quantize Colors** sets the maximum number of color clusters retained from your image before Lumina Studio matches printable recipes. The default is **48**, adjustable from **8–256** in steps of **8** under the standard ceiling.

This setting controls image color clustering and is independent of both your physical filament count and the object count in the final 3MF: a single quantized color maps to a multilayer filament recipe, and multiple quantized colors can match the same recipe.

## Location

Go to **Converter → Core Settings → Basic Settings**. **Quantize Colors** is located directly below **Modeling Mode**.

## How It Works

In High-Fidelity raster mode, Lumina Studio first scales the artwork to your target dimensions, then uses K-Means clustering to group similar pixels into no more than the selected number of color centers. Higher values preserve subtler local shading and smoother gradients; lower values consolidate color regions and speed up processing.

The number acts as an upper limit. If a resized image already contains fewer distinct colors than the slider value, Lumina Studio keeps the actual palette as-is without inventing extra clusters. Once quantization completes, each cluster is matched to a printable recipe using the active LUT or Material Archive set.

## Behavior by Conversion Path

| Conversion path | How the value is used |
| --- | --- |
| High-Fidelity raster | Maximum number of whole-image K-Means clusters |
| Pixel Art | Pixel-color reduction limit; preserves the original palette untouched when visible colors already fit within the limit |
| Native SVG Vector | Uses SVG fills and strokes directly without running whole-image K-Means |
| SVG + Material Archive gradients | Caps the number of discrete gradient bands, clamped internally to 16–32 |
| Color Card | Builds calibration swatches directly from active recipes without image quantization |

In Vector mode, solid SVG shapes and strokes always retain their source colors; **Quantize Colors** comes into play only when discretizing SVG gradients under Material Archive (clamped to 16–32).

## Auto Detect

Once an image is uploaded, click **Auto Detect** to analyze the artwork at the current target width and populate the slider with a suggested value (the button is disabled until an image is loaded). The analyzer evaluates five factors:

1. Resizes the image to roughly 5 px/mm (capped at a 600-pixel analysis width);
2. Counts coarsely quantized unique colors;
3. Measures significant hue groups and the ratio of colored pixels;
4. Evaluates how concentrated the dominant colors are;
5. Measures edge density and scales the estimate by the square root of the target width.

The suggested value snaps to 8, 16, 24, 32, 48, 64, 96, 128, 160, 192, or 256, with the width multiplier bounded between 0.8 and 2.5.

**Auto Detect** estimates image complexity to give you a practical starting point without factoring in the gamut of a specific LUT or filament set—fine-tune the slider after checking your preview.

## Tuning Tips

- **Merged edges or banded gradients**: Increase the value step by step and regenerate the preview.
- **Single-pixel speckles**: Check source image noise and target dimensions first; raising the budget further often preserves more stray speckles. Pair with Isolated Pixel Cleanup if needed.
- **High value still looks simplified in 3D**: Check whether [High-Precision 3D Color Preview](../../preview-and-palette/high-precision-3d-preview/high-precision-3d-preview.mdx) is enabled.
- **Need more than 256 colors**: Enable [Unlock Quantize Ceiling](../../color-matching/unlock-quantize-ceiling/unlock-quantize-ceiling.mdx), then raise the slider manually.

Changing **Quantize Colors** clears any generated 3MF, so regenerate your preview or model afterward. Exported Lumina recipe cards record the active quantize value.
