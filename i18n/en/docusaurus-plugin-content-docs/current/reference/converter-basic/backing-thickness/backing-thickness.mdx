# Base-Plate Thickness

**Base plate thickness** sets the height of the structural foundation beneath the optical color layers. The default value is **1.20 mm**.

<img
  src={require('./assets/01-backing-thickness.webp').default}
  alt="Base-plate Thickness slider in Lumina Studio"
/>

*Screenshot from an earlier release; this setting is labeled “Base plate thickness”.*

The slider ranges from **0.24–10.00 mm** in **0.08 mm** steps so the base stays aligned with standard print layer heights (imported recipes accept **0.20–10.00 mm**).

## Impact on model height and features

Base thickness measures only the structural base—it does not include color layers, extra relief height, or a transparent coating. Add those components separately when calculating the total height of the finished print.

Certain geometry modes automatically adjust or clamp height values when active:

- **Relief:** Ensures extra relief height meets at least the minimum required by the current base and color layers.
- **Fridge Magnet:** Automatically increases the effective base thickness if needed to maintain wall thickness around the magnet pocket; turning **Fridge Magnet** off restores your saved base thickness.

Thinner bases print faster for compact pieces, while larger prints or designs with hanging holes benefit from extra thickness for stiffness and durability. After changing **Base plate thickness**, generate a fresh 3MF rather than scaling Z height in your slicer—scaling Z in the slicer also stretches the color layers and shifts optical color mixing.

Base thickness also determines whether [Base Plate Infill](../backing-infill/backing-infill.mdx) produces sparse internal infill, because the 3 mm zone behind each viewing surface always remains solid.
