# Inferred LUT

:::warning[Older versions]
Newer releases no longer include **Inferred LUT** under **Color Data Source**. This page is retained as a reference for earlier versions.
:::

Unlike a Classic LUT that loads a single fixed lookup table, **Inferred LUT** loads a filament brand package containing color databases, supported layer modes, and an optional predictive model. You select a brand first, then choose which databases and supported layer mode participate in color matching.

## Brand and databases

Selecting a brand displays only the databases declared in that brand package. At least one database must remain checked before **Preview** becomes available.

Switching brands clears the previous database selection, applies the new brand package's defaults, and invalidates any existing preview and generated 3MF.

## Layer Count

Moving the layer slider selects from the modes declared in the brand package's `supported_modes`:

- If an exact match for both layer count and current layer height exists, that pair is used directly;
- If multiple layer heights exist for that count without an exact match, the closest layer height is selected;
- If the requested layer count is unsupported by the package, the previous valid mode stays active.

The **Supported Modes** line below the control lists every valid “layers @ layer height” pair used during preview and model generation.

## Model-assisted matching

**Model-Assisted Matching** and **Model only** appear when the selected brand package includes a predictive model. Measured color databases remain the baseline, while the predictive model can step in to replace weak database matches when its prediction is substantially closer. See [Model-Assisted Matching](../../color-matching/model-assisted-matching/model-assisted-matching.mdx) for the full selection rules.
