# Relief

Relief turns a flat color model into 2.5D textured geometry. Color recipes still determine surface colors, while Relief settings control the height assigned to each region.

<img
  src={require('./assets/01-relief-settings.webp').default}
  alt="Relief Settings in Lumina Studio"
/>

## What enabling Relief changes

- Structure Mode switches to Single-sided.
- Cloisonné turns off because the two geometry modes are mutually exclusive.
- When a palette exists without height data, Lumina creates an initial height map using the selected luminance direction.
- Regenerate the preview and 3MF to apply the updated geometry.
- Relief is unavailable in Vector modeling mode.

## Maximum height

**Maximum Height** ranges from **0.08–15 mm** in **0.04 mm** steps. Changing the maximum rescales existing color heights proportionally, preserving relative relief across the palette.

With a Material Archive, the minimum height also accommodates the active optical stack and backing thickness so every color layer fits cleanly.

## Auto Height Mode

| Mode | Height source | Result |
| --- | --- | --- |
| Darker Higher | Current palette luminance | Darker colors receive greater height |
| Lighter Higher | Current palette luminance | Lighter colors receive greater height |
| Use Heightmap | A separately uploaded image | Image luminance maps to continuous height |

Switching between **Darker Higher** and **Lighter Higher** recalculates the height map immediately. **Use Heightmap** accepts PNG, JPEG, BMP, or TIFF files once a standard preview has created an active session.

## Workflow tips

Start with a shallow height, inspect the 3D result to verify relief direction and fine details, then increase height gradually. Before printing, inspect peak regions, thin edges, and backing continuity layer by layer in your slicer.
