# Cloisonné (older versions)

:::warning[Legacy feature]
The Cloisonné settings entry is hidden in the current release, though existing configuration data is retained. The details and screenshot below apply to older versions that expose this control.
:::

Cloisonné extracts a wireframe along matched-color boundaries, generates a separate **Wire** object, and switches Structure Mode to Single-sided. In versions that include it, the feature is experimental and may produce incomplete wireframes on intricate artwork.

## Parameters

- **Wire Width:** 0.2–1.2 mm in 0.1 mm steps. Controls horizontal wireframe thickness.
- **Wire Height:** 0.04–1.0 mm in 0.04 mm steps. Controls how far **Wire** rises above the color regions.

Setting **Wire Width** too low can fall below what the nozzle prints reliably, while setting it too high can cover adjacent colors. Increasing **Wire Height** creates stronger surface texture, though tall wires also increase the chance of nozzle contact during travel moves.

## Limitations

- Mutually exclusive with Relief; enabling one turns off the other.
- Disabled in Vector modeling mode.
- **Wire** uses a fixed gold preview color for visibility; actual print color follows the filament assignment in your slicer.
- Regenerate the 3MF after changing any parameter.

When working in an older version that includes Cloisonné, check the 3D preview, object list, and sliced layers, and print a small test piece before starting a full build.
