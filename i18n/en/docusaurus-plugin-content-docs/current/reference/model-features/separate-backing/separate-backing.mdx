# Separate Backing

**Separate Backing** controls whether the backing mesh merges into the base-color object or exports as its own object in the 3MF, while keeping backing thickness and filament assignment unchanged. Eligible single-sided projects also offer **Backing output**, which can save the artwork and backing as separate 3MF projects.

This option is off by default.

## Location

Open **Converter → Core Settings → Advanced Settings**, then locate **Separate Backing**.

<img
  src={require('./assets/01-separate-backing-location.webp').default}
  alt="Separate Backing in Lumina Studio Advanced Settings"
/>

## When disabled

The backing merges into the object assigned to the selected backing filament. Your slicer presents it alongside artwork geometry that shares the same filament, keeping the object list compact.

## When enabled

Lumina writes a dedicated backing mesh:

- Raster and High-Fidelity models create a separate `Backing` object.
- Native Vector models create a separate `Board` object.
- The backing retains the selected backing-filament metadata without adding an extra filament slot.
- Large-format tiled exports apply the same rule to every valid tile.

After importing the 3MF into your slicer, check the object list to confirm that the backing object is present and mapped to the intended filament.

## Preview and regeneration

The 2D color preview shows color matching only. Regenerate the 3MF after toggling **Separate Backing** and inspect the resulting structure in your slicer's object list. Lumina recipe cards save this setting.

## Typical uses

### Backing output

| Option | Download | Purpose |
| --- | --- | --- |
| Same project | Artwork and separate backing object in one 3MF | Manage and slice them together |
| Independent plate projects (ZIP) | Separate model and backing 3MF files in a ZIP archive | Slice and print each plate independently |

Independent projects preserve exact physical dimensions without scaling artwork down to fit the bed. Extract the ZIP, open each 3MF, resolve any placement warnings, and verify object, brim, and wipe-tower positions before slicing.

**Independent plate projects (ZIP)** is available for single-sided, non-relief, single-model exports. For double-sided, relief, five-color extended, batch, puzzle, large-format, or Model texture workflows, use **Same project** or that workflow's built-in tiled output. Exporting separate plates preserves the color-layer order; bond or assemble the printed parts after printing.

### When a separate backing object helps

- Select, hide, or configure the backing independently in your slicer.
- Print or post-process the backing as a standalone part.
- Match a printer or slicer workflow that manages backing and color objects separately.

If you do not need separate control over the backing, leave this option off for a simpler object list.
