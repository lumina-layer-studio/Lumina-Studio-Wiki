# Transparent Coating

Transparent Coating generates a separate **Coating** object across the outer display face. After importing the 3MF into your slicer, assign **Coating** to a transparent filament to print a clear protective surface layer.

## Coating height

Available heights are **0.04, 0.08, and 0.12 mm** (default **0.08 mm**). Because prints build in whole layers, Lumina divides the selected coating height by the active model layer height, rounds to the nearest whole number (minimum one layer), and outputs an effective thickness of `complete layers × model layer height`.

For example, with a 0.08 mm model layer height, selecting 0.04 mm produces one 0.08 mm layer, while selecting 0.12 mm produces two layers (0.16 mm). Choose an exact multiple of the active layer height when you want a specific physical thickness.

**Coating** follows the model silhouette and expands across the border as well when Outline is enabled.

## If the coating disappears after slicing

Because **Coating** is generated outside the model's bottom face, it can import slightly below the build plate—visible in the object list, yet omitted from sliced toolpaths.

Select the complete model assembly, run **Place on Bed** or **Auto Arrange**, and slice again. Then check Layer 1 to verify that the transparent-filament toolpath is present.

Materials such as transparent PETG are a popular choice; print a small test sample first to dial in temperatures and verify interlayer adhesion with your color filaments.
