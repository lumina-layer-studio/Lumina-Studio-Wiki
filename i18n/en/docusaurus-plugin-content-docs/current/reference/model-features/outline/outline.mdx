# Outline

Outline generates separate border geometry outside the solid boundary of your artwork. Use it to accentuate a silhouette, frame an irregular shape, or reinforce delicate edges.

<img
  src={require('./assets/01-outline-settings.webp').default}
  alt="Outline Settings in Lumina Studio"
/>

## Outline Width

**Outline Width** ranges from **0.5–10 mm** in **0.5 mm** steps and sets the outward expansion distance from the original boundary. Larger values fill narrow notches and round off tight corners, so check the 3D view when working with intricate silhouettes.

Lumina derives the boundary from the active solid or vector geometry: raster images with transparency use the alpha silhouette, while SVG files use parsed vector paths. If no usable boundary exists, no outline is generated.

## Interaction with other features

- When Transparent Coating is enabled, the outline extends downward across the coating thickness to keep the outer edge flush.
- Outline and Separate Backing can be used together and appear as separate objects in the 3MF.
- Regenerate the 3MF after changing **Outline Width**.

After importing into your slicer, check the outline object and sliced first layers. If your artwork contains stray semi-transparent pixels near the edges, clean up the background beforehand for a crisp border.
