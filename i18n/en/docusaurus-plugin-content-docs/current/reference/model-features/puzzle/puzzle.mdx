# Puzzle

Puzzle mode computes a cut layout from the artwork's solid boundary, builds individual mesh geometry for every piece, and packages the complete set into a single downloadable 3MF.

## Style and sizing

- **Regular Puzzle:** Uses an orderly grid with uniform connector behavior.
- **Irregular Puzzle:** Offsets piece boundaries and unlocks **Irregularity Strength** and **Minimum Neck Width**.
- **By Piece Size:** Sets target average piece width and height from 5–200 mm.
- **By Grid:** Sets 1–200 rows and 1–200 columns.
- **By Piece Count:** Sets 2–2000 target pieces and solves the grid from the artwork's aspect ratio.

Transparency silhouettes, irregular outer boundaries, and minimum-feature constraints can adjust the final rows, columns, piece count, or average piece size, so the summary displays both requested targets and resolved values.

## Connectors and labels

**Classic** and **Easy Cut** use different connector profiles, with **Easy Cut** smoothing out tight curves. Actual fit also depends on nozzle size, filament shrinkage, and slicer contour compensation.

**Show Piece Labels** provides piece numbering within the puzzle workflow. **Engrave Back Labels** is currently disabled and not yet written into exported geometry.

In Irregular mode, **Irregularity Strength** ranges from 0–1, and **Minimum Neck Width** ranges from 0.2–20 mm to keep connector necks sturdy. Any automatic solver adjustments appear in the **Warnings** section.

## Mode compatibility

Puzzle mode is unavailable in Batch mode and turns off Large Format, Keychain Loop, and Fridge Magnet mode. Run a standard preview first so Lumina has the active solid mask and physical dimensions before computing the puzzle layout.
