# Keychain Loop parameters

Keychain Loop generates dedicated loop geometry in the exported 3MF. Its thickness matches the model's total layer stack, and its color comes from the filament slot assigned during generation.

## Size

| Parameter | Range | Effect |
| --- | --- | --- |
| Loop Width | 2–10 mm, 0.5 mm steps | Outer horizontal width |
| Loop Length | 4–15 mm, 0.5 mm steps | Outward length from the attachment end |
| Loop Hole Diameter | 1–5 mm, 0.25 mm steps | Inner opening for a jump ring or lanyard |

Keep **Loop Hole Diameter** smaller than the outer width and length so a sturdy, printable wall remains around the hole for your nozzle and filament.

## Position

- **Rotation Angle:** -180° to 180°; 0° points straight up, and positive values rotate clockwise.
- **X Offset:** -200 to 200 mm; positive values move right.
- **Y Offset:** -200 to 200 mm; positive values move up.

Offsets are measured from the model center. Overlap the base of the loop slightly with the model edge so the loop stays anchored to the body.

## Mode compatibility and slicer check

Enabling Puzzle or Fridge Magnet mode turns off and disables Keychain Loop. Regenerate the 3MF after changing any loop setting, then inspect the object list and sliced toolpaths to confirm that the loop merges cleanly into the body and the opening stays clear.
