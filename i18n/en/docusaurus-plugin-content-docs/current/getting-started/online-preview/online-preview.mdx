# Online Preview and Export Allowance

Open the [Lumina Studio online preview site](https://test.luminastudio.com.cn/) to upload an image, adjust its palette and export a model without signing in. Calculations run on the service. Download the resulting 3MF and open it in your local slicer.

## How the daily allowance works

| Access | Daily allowance for new-image exports |
| --- | --- |
| Without signing in | 3 distinct source images |
| With a connected Lumina community account | 3 additional new images on top of the anonymous allowance |

The anonymous allowance is counted per IP address. It counts **distinct source images successfully exported**, not button presses. Re-exporting the same image after adjusting settings does not use another new-image slot; failed generation and queued requests do not consume one either.

The page displays the remaining allowance and reset time in China Standard Time (UTC+8). People sharing an internet connection may share the anonymous allowance. Once it is used up, wait for the reset or continue working in the local desktop edition.

## Connect a community account

Open the community-account entry, follow the sign-in page's verification steps, check the connection code and allow the connection. A successful connection syncs saved resources and grants 3 additional new-image exports each day. Signing in repeatedly does not grant another allowance, so there is no need to disconnect and reconnect.

Saved resources are not all downloaded automatically; obtain them when selected for use. For the full connection procedure, see [Community account, saved resources and submissions](../../reference/materials-and-recipes/community-resources/community-resources.mdx).

## From preview to print

1. Upload the source image and select profiles or a LUT matching your filaments.
2. Set the finished dimensions, layer height and other parameters, then preview the palette.
3. Generate the model, download the 3MF and save it on your computer.
4. Open it in your slicer, check the printer, nozzle, filament slots and layer heights, then slice and print.

Wait for an active generation task to finish instead of repeatedly clicking. For generation or download problems, see [Page and generation troubleshooting](../../knowledge/web-generation-troubleshooting/web-generation-troubleshooting.mdx).

## Does desktop use require sign-in?

No. The packaged desktop edition can use local materials, LUTs, offline resources and model generation without a community account. The account adds online features such as saved resources and submissions. The online site's daily new-image allowance does not apply to the local desktop workflow.
