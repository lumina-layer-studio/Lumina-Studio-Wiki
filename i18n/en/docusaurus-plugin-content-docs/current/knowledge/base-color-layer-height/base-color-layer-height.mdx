# How Should I Set Backing, Color Layers, and Layer-Height Modifiers?

Backing Thickness, Color Layer Height, and your slicer's global layer height control different parts of a print:

- **Color Layer Height** sets the thickness of each color-mixing layer and must match a height supported by your selected Material Archives or Classic LUT.
- **Backing Thickness** sets the structural support and overall thickness of the piece, independent of the color layer count.
- **Backing Layer Height Modifier** applies a coarser layer height solely to the backing Z-range to reduce backing layer count and print time (`0.20 mm` for a `0.4 mm` nozzle, `0.10 mm` for a `0.2 mm` nozzle).
- **Slicer verification**: After clicking **Generate**, open the 3MF as a full project, slice it, and inspect the display surface and layer transitions in Preview.

## Four Key Concepts

| Term | What it controls | Primary impact |
| --- | --- | --- |
| Backing | The structural section behind the color stack | Strength, total thickness, filament usage, and print time |
| Backing Thickness | The physical millimeter thickness of the backing | Number of backing layers and overall model thickness |
| Color Layers | Thin layers stacked in sequence to produce target colors | Color accuracy, light transmission, and fine detail |
| Color Layer Height | The thickness of each color-producing layer | Color recipe behavior, light accumulation, and Z resolution |

For example, a model can pair `0.08 mm` Color Layers with a `1.6 mm` Backing Thickness. Here, `1.6 mm` is the total thickness of the backing section, while the color stack continues to print at `0.08 mm` per layer.

Depending on the structure mode, the display surface may face the build plate or sit on top of the backing. Orientation changes their Z-axis order, while their thicknesses and layer heights remain independent.

## Why Not Set the Whole Project to 0.20 mm?

Layered color recipes are calibrated for specific filaments, layer heights, and layer counts. If a recipe is built for `0.08 mm` color layers and you change the entire slicer project to `0.20 mm`, each layer becomes thicker, light transmission shifts, and the resulting color stack no longer matches the calibration.

Because the backing provides structural support rather than layered color mixing, it can print at a coarser local layer height while the display layers stay fine. That is what the Backing Layer Height Modifier automates: **fine color layers, coarse backing layers.**

## How the Backing Layer Height Modifier Works

When a compatible Bambu-family slicer is selected in **Settings** and **Backing Layer Height Modifier** is enabled, Lumina writes a local height range into the exported 3MF:

- **0.4 mm nozzle**: `0.20 mm` layer height within the backing Z-range.
- **0.2 mm nozzle**: `0.10 mm` layer height within the backing Z-range.
- **Color layers**: Retain the fine layer height specified by your color source and workflow.

This option is enabled by default, saves automatically, and appears when a compatible Bambu-family slicer is selected. It keeps **Backing Thickness** unchanged, printing that same thickness with fewer, thicker layers to save time.

Other slicers may ignore this 3MF height-range metadata and require configuring a local height modifier directly in the slicer.

## Configure It in Lumina Studio

1. Open **Settings** and select your slicer, printer, and nozzle size.
2. If **Backing Layer Height Modifier** appears, enable or disable it for your current workflow.
3. Return to the converter and set **Backing Thickness** for your model.
4. Select **Color Layers** and **Color Layer Height** supported by your Material Archives or Classic LUT.
5. Run **Preview** and click **Generate** to export a new 3MF.

To shorten print time predictably, enable the Backing Layer Height Modifier while keeping Color Layer Height, Color Layers, and the slicer's base layer height unchanged.

## Check the Height Range in Your Slicer

Open the Lumina 3MF as a full project rather than importing raw geometry, which can strip project filaments, object hierarchy, and height-range modifiers.

Expand the model in your slicer's object list to see the height-range entry. Its start and end Z values are calculated automatically from your model's thickness and orientation.

<img
  src={require('./assets/height-range-check.webp').default}
  alt="Concept diagram showing a backing-only modifier range ending before the fine colour layers"

Verify three details:

1. The height range is present and matches the Z interval of the backing.
2. The local layer height matches your nozzle (`0.20 mm` for `0.4 mm`, or `0.10 mm` for `0.2 mm`).
3. The coarse range stops cleanly before the fine color layers begin.

If the height range is missing, check your selected slicer and modifier toggle in Lumina **Settings**, and confirm that you opened the 3MF as a project. Avoid applying a coarse height modifier across the entire object, as that will overwrite the fine color stack.

## Slice and Inspect Layer by Layer

Click **Slice** and switch to **Preview** to inspect the generated toolpaths before printing:

- Rotate the view to the display surface and confirm clean color boundaries.
- Drag the layer slider through the color stack to check layer heights and filament assignments.
- Confirm a clean transition between the fine color layers and coarse backing layers.
- Check the backing, outline, coating, Free Color objects, and attachments for unintended overlap.
- Verify that each project filament maps to the intended physical spool and slot.

## Separate Backing vs. Backing Layer Height Modifier

Both settings involve the backing, but they serve different purposes:

- **Separate Backing** exports the backing as its own object so you can select it, assign a filament, or adjust per-object settings in the slicer.
- **Backing Layer Height Modifier** keeps the object structure intact and assigns a coarser layer height to the backing's Z-range.

You can enable either or both depending on whether you need independent object control, faster backing layers, or both.

## Special Workflows

### Gradient Calibration Cards

Gradient cards rely on fixed layer heights, object-color assignments, and print settings. Leave the standard backing modifier off and follow [Generate and Print Gradient Calibration Cards](pathname:///en/docs/tutorials/gradient-card-generate-print/).

### Puzzle and Specialized Exports

Puzzle and other specialized export modes manage their own geometry and slicing metadata without needing manual height-range additions.

### Double-Sided or Recessed Models

On double-sided prints, or models with magnet recesses and interleaved attachments, step through every layer in slicer Preview to confirm that the coarse range stays strictly inside the backing. If the range touches either display face, disable **Backing Layer Height Modifier** and generate a fresh 3MF.

### Non-Bambu Slicers

If your slicer does not import the height range from the 3MF, configure an equivalent height-range modifier natively in that slicer and verify the sliced layers in Preview.

## Common Questions

### Why does the base still look solid after I lower its infill?

The region of the base closest to each viewing surface stays solid to protect visual uniformity, so a thin base may fall entirely within that solid zone. Meanwhile, the layer-height modifier changes layer thickness rather than infill density. See [Base Plate Infill](../../reference/converter-basic/backing-infill/backing-infill.mdx) for details.

### Why does the process preset still show 0.08 mm when the backing prints at 0.20 mm?

The process header displays the base layer height for the project, while the backing uses an object-level height-range override. Switch the slicer Preview color scheme to **Layer Height** or expand the object tree to inspect both values.

### I selected 0.04 mm. Why do I also see 0.08 mm or 0.20 mm?

Three separate values may be visible: Color Layer Height, the slicer's base process layer height, and the backing's local height range. Check which value you are viewing and verify that your selected Material Archives or Classic LUT supports `0.04 mm`.

### Can I set the color layers to 0.20 mm as well to save more time?

Only if your Material Archives or Classic LUT explicitly supports a `0.20 mm` color layer height. Changing `0.08 mm` color layers to `0.20 mm` alters light transmission and breaks the calibrated color recipes.

### Does a 0.2 mm nozzle also use 0.20 mm backing layers?

No. Lumina sets the backing modifier to half the nozzle diameter: `0.20 mm` for a `0.4 mm` nozzle and `0.10 mm` for a `0.2 mm` nozzle.

### Why is Backing Layer Height Modifier hidden in Settings?

It is displayed only when a compatible Bambu-family slicer is selected in **Settings**. For other slicers, apply a local height-range modifier directly in your slicer.

### Can I raise the backing layer height even further if the print is still long?

Maximum layer height is limited by nozzle diameter, line width, and volumetric flow. Confirm first that the modifier is active in slicer Preview, and test any manual overrides on a small sample print before running a full piece.
