# How Do I Choose High-Fidelity, Pixel Art, or Vector Mode?

Match the modeling mode to the visual structure that matters most in your source artwork:

- For photos, detailed illustrations, soft gradients, and rich textures, start with **High-Fidelity**.
- For pixel art, grid patterns, and mosaic-style designs, start with **Pixel Art**.
- For native SVG logos, text, icons, line art, and flat-color shapes, start with **Vector**.

These three modes target different image structures rather than ranking quality from low to high. You can preview the same artwork in multiple modes and choose based on finished print size, geometry complexity, and visual style.

:::info[Look beyond the file extension]
A PNG can hold either a photograph or crisp pixel art, and an SVG can contain clean vector paths or nothing more than an embedded bitmap. Choose a mode based on whether you want to preserve continuous color transitions, a deliberate pixel grid, or sharp path boundaries.

## What each mode preserves

### High-Fidelity: continuous color, texture, and shading

High-Fidelity processes the input as a continuous-tone image to preserve color transitions, brushwork, lighting, and subtle gradients. It works well for:

- Portraits, pets, landscapes, and product photography
- Detailed illustrations with brush textures, drop shadows, glow effects, or smooth gradients
- Complex PNGs with transparent backgrounds
- SVG artwork that relies on raster effects or complex shading best evaluated from its rendered appearance

Physical print resolution still depends on your nozzle: eyelashes, tiny lettering, or grain narrower than a single extrusion line may merge or drop out during generation or slicing, and dense color noise can create extra tiny regions. Always evaluate Preview at your actual target print dimensions.

### Pixel Art: crisp cell grids and limited palettes

Pixel Art treats regular pixel cells as deliberate structural units, making it ideal for:

- Pixel-art characters, sprites, items, and scenes
- Perler-bead layouts, mosaics, and cross-stitch patterns
- Artwork quantized to a small palette with crisp grid-aligned edges
- Designs meant to keep a stepped, blocky aesthetic on the build plate

Applying Pixel Art mode to an ordinary photograph breaks smooth skin tones, skies, and shadows into visible blocks—useful if you want a stylized mosaic look, though High-Fidelity is better for natural photo detail.

When preparing pixel art, keep the native pixel grid intact. If you scale the image beforehand, use **nearest-neighbor** interpolation so anti-aliasing does not blur cell boundaries. After importing, confirm that each grid cell is wide enough at your target print size to clear your nozzle's line width.

### Vector: smooth geometry from SVG paths

Vector mode builds 3D geometry directly from the mathematical paths, outlines, and fills inside an SVG file. It is designed for:

- Native SVG logos, badges, icons, and wordmarks
- Typography converted to outlines (paths)
- Clean monochrome or flat-color line art
- Graphics with distinct solid-color regions and crisp edges

Vector mode is available only when you upload an SVG file (it is unavailable for raster uploads). Because edges come directly from vector paths rather than a fixed pixel grid, curves and diagonal lines stay sharp at any target print size.

Keep in mind that `.svg` files can also contain embedded bitmaps, blur filters, masks, complex gradients, clipping paths, or live strokes that render differently across parsers. After importing, inspect Preview for missing shapes, shifted fills, lost cutouts, overlapping paths, or unoutlined text.

## Quick reference by artwork type

| Source artwork | Mode to try first | What to check in Preview |
| --- | --- | --- |
| Portrait, pet, or landscape photo | High-Fidelity | Facial features, fur, shadow transitions, background noise, and tiny color islands |
| Textured or soft-gradient illustration | High-Fidelity | Smoothness of gradients and whether fine texture breaks into excessive tiny regions |
| Native pixel art | Pixel Art | Clean grid alignment and absence of blurred edges from prior scaling |
| Mosaic or grid pattern | Pixel Art | Whether individual cells are wide enough for your nozzle line width |
| Native SVG logo or icon | Vector | Closed paths, interior cutouts, overlapping shapes, fills, and canvas bounds |
| Typography and line art | Vector or High-Fidelity | Outlined text paths and whether thin strokes or small letters will print cleanly |
| Transparent PNG | Match to image style | White or gray edge fringes, stray semi-transparent pixels, and isolated specks |
| Auto-traced SVG | Compare Vector and High-Fidelity | Excess anchor points, fragmented color patches, and distorted contours |

Treat this table as a starting point. A crisp three-color PNG logo works well in High-Fidelity; if you also have the original design SVG, you can preview it in Vector mode as well and pick whichever geometry slices cleaner.

## Which mode should a transparent PNG use?

A transparent background does not turn a PNG into vector paths—it is still a raster image:

- Choose **High-Fidelity** for photos, shaded illustrations, or soft gradients.
- Choose **Pixel Art** for native pixel art on a transparent canvas.
- Choose **High-Fidelity** for flat logos or line art when you only have a PNG, or run a clean vector trace first if you want to compare it in **Vector** mode.

Cutout PNGs often carry faint white or gray halos or stray semi-transparent pixels along their silhouette. Halos that blend into a light or dark screen background can turn into an unwanted border ring in the 3D model. Preview your PNG against both dark and light backgrounds before importing.

## Clean up your source file before importing

### Transparent edges

Trim unwanted white or gray matte fringes and stray semi-transparent pixels around cutouts. If your artwork has intentional soft feathering or outer glow, check it in High-Fidelity Preview first before stripping translucent edges.

### Stray specks and compression artifacts

Erase isolated background specks, JPEG artifacts, and scanner dust outside the main subject so they do not generate tiny disconnected islands in the model.

### Hairline strokes and tiny text

Check stroke weights and font sizes at your actual print dimensions in millimeters. Details that look sharp when zoomed in on screen may fall below your nozzle's minimum line width once scaled to 60 mm or 100 mm. Thicken fine lines, enlarge small lettering, or simplify tiny ornaments as needed.

### Gradients, filters, and masks

When shadows, glows, blurs, or complex masks define the look of an artwork, export a clean high-resolution PNG and use High-Fidelity. If you prefer Vector mode, expand strokes, live text, and appearances into standard closed paths and solid fills in your vector editor before saving the SVG.

:::note[Why clean up the source image]
Removing edge halos, stray noise, and sub-nozzle fragments upfront keeps region boundaries clean so model generation focuses on the details you want on the print.
:::

## Four helpful distinctions

### Auto-tracing to SVG cannot restore missing detail

Automatic bitmap-to-vector tracing guesses contours from existing pixels. While it can tidy up a bold, simple logo, tracing a noisy photo or compressed image often shatters edges into thousands of jagged micro-paths—and cannot recover facial features or lettering already blurred in the source.

### Print sharpness is bounded by print size and line width

A high-resolution image gives Lumina plenty of pixel data, while the finest printable detail is ultimately set by physical print dimensions, nozzle diameter, and extrusion line width. To see how image pixels map to nozzle width, read [What Image Resolution Is a 0.2 mm or 0.4 mm Nozzle Equivalent To?](pathname:///en/docs/knowledge/nozzle-equivalent-resolution/).

### Vector mode defines boundaries rather than adding colors

Vector paths keep curves and sharp corners crisp, while your available color palette is still governed by your selected Material Archives (or Classic LUT) and layer stack.

### Pixel Art preserves intentional grid styling

Pixel art relies on a visible cell grid and compact palette as part of its aesthetic; smoothing those crisp steps into rounded curves softens the original design. For a closer look at raster grids versus vector paths, see [Bitmap vs. Vector Images: What’s the Difference?](pathname:///en/docs/knowledge/bitmap-vs-vector/).

## One-minute selection workflow

1. **Check the subject:** Is it a photo/shaded illustration, pixel art, or a flat logo/text/line drawing?
2. **Inspect the file contents:** If it's an SVG, does it contain real vector paths or just an embedded bitmap and live filters?
3. **Pick what to preserve:** Smooth tonal transitions, crisp grid cells, or mathematical path edges?
4. **Tidy up the file:** Clean up cutout fringes, stray specks, hairline strokes, and tiny text.
5. **Preview at target size:** Zoom in on eyes, lettering, interior cutouts, and small isolated color islands.
6. **Compare modes when close:** Preview both candidates and inspect the sliced toolpaths to pick the cleanest result.

## Common questions

### Why does Lumina switch to Vector mode automatically when I upload an SVG?

Uploading a single SVG defaults to Vector mode so native path boundaries stay intact. If your SVG relies on complex gradients, blur filters, or embedded bitmaps, you can switch to High-Fidelity at any time to compare the rendered appearance.

### Can JPG, PNG, or WebP files use Vector mode?

Vector mode is enabled only for SVG uploads because JPG, PNG, and WebP store pixel grids rather than vector paths. To use Vector mode, export a native SVG from your design app or trace the artwork in a vector editor and inspect the paths first (simply renaming a file extension to `.svg` will not convert pixel data).

### Do I have to convert every logo to SVG?

Not at all. A clean, high-resolution PNG logo prints well in High-Fidelity mode. Native SVG shines when scaling to large sizes or preserving razor-sharp curves, whereas sticking with the original PNG in High-Fidelity is often cleaner than using a messy auto-traced SVG.

### Can I use High-Fidelity mode for pixel art?

Yes. Pixel Art mode locks geometry to the cell grid, while High-Fidelity treats the image as continuous artwork. Preview both and choose whichever edge treatment fits your project.

### Why did part of my graphic disappear in Vector mode?

Check whether the SVG contains embedded bitmaps, live filters, masks, clipping paths, unexpanded strokes, unoutlined fonts, or artwork sitting outside the `viewBox` canvas. In your vector editor, convert text to outlines and expand strokes and appearances into standard filled paths, or export a high-resolution PNG and use High-Fidelity mode instead.

### If more than one mode generates cleanly, how should I choose?

Compare Preview at your finished print dimensions, check how cleanly small regions slice, and pick whichever result looks best for your artwork.
