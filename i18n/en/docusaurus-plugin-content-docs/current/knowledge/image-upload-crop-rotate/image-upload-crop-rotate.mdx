# Upload, Replace, Crop, and Rotate an Image

Once you upload an image to Lumina Studio, you can frame and orient it right in the workspace or add more files for batch processing:

- **First import:** Click the dashed upload box or drag files directly onto it.
- **Single vs. Batch workflow:** **Replace current image** keeps you in the single-image workflow, while **Add more images** switches to Batch mode.
- **Crop and rotate:** Cropping trims the canvas to your selection, and rotation turns the artwork by 90°, 180°, or 270°.
- **Automatic state reset:** Replacing, cropping, or rotating the image clears previous Preview data, Color Workstation edits, and generated downloads—simply run **Preview** and **Generate** again for the updated image.

## Keep a copy of your original file

Cropping and rotation only modify the temporary working copy inside your current browser session; Lumina never overwrites your source file on disk. Because browser sessions expire on refresh or tab closure, keeping organized local files makes it easy to start fresh or try alternate crops later.

For important projects, save these together in a project folder:

- The untouched original artwork
- Any pre-trimmed working copies with custom canvas margins
- Your final conversion settings or Share Card recipe
- The verified 3MF file

## Step 1: Upload one or more images

In **Core Settings**, click the dashed upload area or drag files onto it:

- **Select one file** to open the single-image workflow with thumbnail, crop, and rotation controls.
- **Select multiple files** at once to jump straight into Batch mode.

If an upload fails to show a thumbnail, test with a small, known-good JPG or PNG to tell apart an unsupported file from a connection issue.

## Step 2: Crop after upload

When **Crop After Upload** is turned on, importing a single raster image opens the crop dialog automatically. Drag the blue selection handles—or pick a preset aspect ratio—and check the pixel dimensions of your selection before confirming:

- Click **Apply Changes** to keep your crop and orientation.
- Click **Cancel** or the close button (`×`) to close the dialog without applying changes.

After an image is loaded, you can reopen this dialog anytime by clicking **Crop & Rotate** beneath the thumbnail. Note that cropping removes pixels outside the selection from the session copy, and cropping into a tiny region cannot add pixel resolution that wasn't in the original file.

### Leave breathing room around transparent or soft edges

Drop shadows, outer glows, and anti-aliased silhouettes in transparent PNGs taper off through faint semi-transparent pixels. Snapping the crop box tight against the solid edge can clip those soft transitions and leave notched borders on the 3D model. Leave a small margin outside visible edges and verify the silhouette in Preview.

### Why doesn't uploading an SVG open the crop dialog?

Uploading a single SVG preserves native vector paths and uses the SVG's own `viewBox` and artboard bounds rather than raster pixel cropping. To adjust framing or trim off-canvas shapes on an SVG, edit its `viewBox` or artboard in your vector editor—see [SVG Troubleshooting](pathname:///en/docs/knowledge/svg-troubleshooting/).

## Step 3: Replace the image or add more images

In the single-image workflow, two actions sit right beneath the image thumbnail:

### Replace current image

Swaps out the loaded image for a new file while staying in the single-image workflow (clicking the thumbnail itself opens the same file picker). Previous Preview results, Color Workstation edits, and download links are cleared automatically so stale data never carries over to the new artwork.

### Add more images

Keeps the current image, appends one or more additional files, and switches the workspace to Batch mode. Every file in a batch shares one set of primary conversion parameters—if individual artworks need custom crops, orientations, Source Types, or structural settings, process them one at a time instead.

If you clicked **Add more images** by mistake and see the file list alongside **Batch Generate**, click the `×` next to any extra filenames. Once a single file remains, the interface returns to the single-image workflow.

## Step 4: Rotate the current image

In the single-image workflow, click **Crop & Rotate**, then use **Rotate left 90°** or **Rotate right 90°** (click twice in the same direction for 180°). Check the framing and click **Apply Changes**, or click **Cancel** to discard.

Applying a rotation updates the active image for subsequent Preview, 3D view, and 3MF generation without altering files you already downloaded. Rotating by 90° or 270° swaps width and height, so verify your target millimeter dimensions afterward.

SVG uploads can also be rotated in this dialog while keeping their vector paths intact.

:::note[SVG layout and resolution]
Rotation only changes image orientation. If an SVG has missing paths, clipped bounds, or unexpected fills, check its vector structure directly rather than rotating repeatedly.
:::

## Step 5: Review the Batch file list

Before running a batch job, double-check the file list:

- Total file count matches what you intend to convert.
- No duplicate files or outdated drafts were included.
- Use **Add more images** below the list to append additional files, or click `×` beside any entry to remove it.

Because Batch mode does not open individual crop and rotation dialogs per file, crop and orient your working copies beforehand before adding them to the batch.

## What resets when the image changes?

| Action | Active image | Workflow mode | Previous Preview & downloads | Next step |
| --- | --- | --- | --- | --- |
| Replace current image | Swapped for new file | Single image | Cleared | Confirm crop, Source Type, and dimensions, then run **Preview** |
| Apply a crop | Trimmed to selection | Single image | Cleared / outdated | Verify target dimensions, then run **Preview** |
| Apply a rotation | Rotated to new angle | Single image | Cleared | Check swapped width/height, then run **Preview** |
| Add more images | Kept and appended | Switches to Batch | Single-image results cleared | Confirm file list and shared settings, then run **Batch Generate** |
| Remove a Batch file | Selected item removed | Stays Batch (or returns to Single at 1 file) | Previous batch ZIP outdated | Confirm remaining files and generate again |

Clearing session previews never deletes files on your computer—it simply ensures your Preview and exported 3MF always match the current artwork.

## Common questions

### Why didn't the crop dialog open automatically?

Check that **Crop After Upload** is enabled. Also note that multi-file Batch uploads and single SVG uploads skip the raster crop dialog. For any single raster image already loaded, click **Crop & Rotate** beneath the thumbnail to open it manually.

### Can I rotate an image without cropping it?

Yes. Open **Crop & Rotate**, leave the full-frame selection untouched, rotate to the desired angle, and click **Apply Changes**.

### Can I click 90° twice to rotate by 180°?

Yes. Click the same 90° rotation button twice inside the dialog, then click **Apply Changes** once.

### How do I exit Batch mode if I entered it by accident?

Click `×` beside the extra files in the list until only one file remains; the workspace switches right back to the single-image view. Double-check filenames before removing so you keep the intended file.

### Why did my transparent PNG lose a thin outer halo after cropping?

Soft shadows and anti-aliased edges extend outward through subtle semi-transparent pixels. Re-upload the original file and leave a slight buffer outside the solid edge when cropping.

### The image thumbnail faces the right way, so why is my model oriented differently in the slicer?

Verify the thumbnail and 2D Preview in Lumina first, then check **Structure Mode** (such as front vs. face-down printing) and build-plate orientation inside your slicer. Image rotation sets artwork orientation, whereas Structure Mode and slicer placement control how the 3D part sits on the bed.

### What if no thumbnail appears at all after uploading?

Test with a small, standard JPG or PNG first. If that also fails to load, follow [The Page Will Not Open, Keeps Spinning, or Generation Fails](pathname:///en/docs/knowledge/web-generation-troubleshooting/) to troubleshoot network connectivity, file integrity, and service status.
