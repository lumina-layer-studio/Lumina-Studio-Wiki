# Bitmap vs. Vector Images: What’s the Difference?

Digital images store visual information in two main ways:

- A **bitmap** (or raster image) stores a fixed grid of pixels, with each pixel holding its own color value.
- A **vector image** stores points, lines, curves, outlines, and fills, redrawing shapes mathematically at any size.

Each format excels at different kinds of artwork. Photographs, soft gradients, and digital paintings fit bitmap images naturally. Logos, icons, outlined text, line art, and flat-color graphics fit vector paths. Choosing the format that matches your original artwork gives you the cleanest result in Lumina Studio.

:::info[Quick Analogy]
Think of a bitmap as graph paper with every square already colored in, and a vector image as a set of drawing instructions that defines where points sit, how curves bend, and which regions are filled.
:::

## Quick Comparison

| Aspect | Bitmap | Vector |
| --- | --- | --- |
| Core data | Pixel colors in a fixed grid | Points, lines, curves, closed paths, and fills |
| Behavior when enlarged | Becomes blocky or soft past its native resolution | Redraws native paths smoothly at any scale |
| Best suited for | Photos, subtle lighting, textures, gradients, digital paintings, pixel art | Logos, icons, outlined text, line art, flat-color graphics |
| Common file extensions | JPG/JPEG, PNG, WebP, HEIC/HEIF, BMP, TIFF | SVG, AI, EPS |
| Typical editing tools | Brushes, selections, pixel retouching, and color grading | Node editing, path operations, strokes, and solid fills |
| Recommended Lumina workflow | Upload the original bitmap and choose High-Fidelity or Pixel Art mode | Keep native SVG paths intact and use Vector mode |

File extensions are a helpful clue rather than a guarantee. Formats like PDF and SVG can hold both native vector paths and embedded raster images inside the same container, so a `.svg` filename can still wrap a flat bitmap image.

## Matching the Format to Your Artwork

/>

### Artwork That Works Best as a Bitmap

- **Photographs**: Faces, hair, skies, shadows, and surface textures rely on continuous pixel-by-pixel tonal shifts.
- **Painterly illustrations**: Brush grain, soft gradients, translucency, and fine lighting are natural fits for raster canvases.
- **Digital paintings**: Most painted artwork is authored directly on a pixel grid.
- **Pixel art**: Crisp square cells are an intentional part of the style and should stay intact.

### Artwork That Works Best as Vector Paths

- **Logos and icons**: Easy to scale to any millimeter width while maintaining razor-sharp borders.
- **Outlined text**: Converting text to outlines preserves exact letterforms without font-substitution issues.
- **Line art**: Editable strokes and nodes make adjusting line thickness straightforward.
- **Flat-color graphics**: Distinct solid regions map cleanly to closed vector shapes.

:::note[Choose by Content]
A high-resolution PNG logo still works great in Lumina Studio, and an ultra-dense vector illustration can sometimes process more smoothly as a raster image. Pick whichever format preserves your source artwork cleanly.
:::

## File Extensions vs. Actual Contents

Simply renaming `picture.png` to `picture.svg` leaves the pixel data untouched and will cause most apps to reject the file. Watch out for two common container pitfalls as well:

1. **A PNG wrapped inside an SVG**: An `.svg` file can contain nothing more than an embedded bitmap. Scaling the SVG canvas will not add detail to that bitmap.
2. **A bitmap saved as a PDF**: PDF is a container format that can hold vector paths, live text, raster photos, or all three together.

To confirm whether an SVG contains real vector geometry, open it in a vector editor such as Inkscape or Illustrator and click the artwork. If you can select individual anchor points, strokes, and fills, it has editable paths; if you can only select a single bounding box, it wraps an embedded bitmap.

## What Automatic Vectorization Can and Cannot Do

Image-tracing tools analyze pixel boundaries and fit new vector shapes over them. When tracing a bitmap into SVG, expect these trade-offs:

- Similar shades merge into flat color regions;
- Smooth gradients step into discrete color bands;
- Hair, paper grain, noise, and JPG artifacts can turn into thousands of tangled nodes;
- Tiny lettering, thin strokes, and sharp corners may round off or drop out;
- Complex scenes can generate heavy path counts that slow down editing and conversion.

Logos, icons, and clean line drawings usually trace cleanly, whereas photographs and painterly artwork almost always look better kept as bitmaps.

:::warning[Scaling vs. Source Detail]
Tracing a blurry, low-resolution image into SVG makes the canvas infinitely scalable, but any rounded corners or jagged artifacts traced from those pixels scale right along with it. Tracing cannot restore detail missing from the source.
:::

## Choosing Your Workflow in Lumina Studio

Save an untouched copy of your original file first, then follow the path that matches your artwork:

### Photos and Detailed Illustrations

Upload the original PNG, JPG, or WebP directly and use **High-Fidelity** mode. There is no benefit to tracing a photograph into SVG first.

### Native Logos, Icons, and Line Art

If you have the original SVG exported from your design app, upload it directly. Before importing, verify that the artboard bounds are tight, the background is transparent, paths are closed, and live text has been converted to outlines. Avoid exporting a clean vector design to a small PNG only to trace it back into SVG.

### Bitmap Logos When You Need Vector Paths

Run Lumina's **Vectorizer** to generate a candidate SVG, then compare it side by side with the original:

1. Are eyes, small letters, thin lines, and sharp corners intact?
2. Did any gradients split into distracting bands?
3. Did background noise or drop shadows turn into stray shapes?
4. Are the color count and shape count clean and manageable?
5. Does Lumina's converter Preview look cleaner than using the original bitmap directly?

If both versions preview cleanly, pick whichever matches your visual goal and editing workflow.

## Pre-Import Checklist

1. **Check the origin**: Identify whether the file is a photo, a compressed web graphic, or a native design export.
2. **Inspect at target size**: If a bitmap already looks crisp at your finished print dimensions, no format conversion is needed.
3. **Zoom in**: Bitmaps show a pixel grid when enlarged; true vectors expose editable nodes in a vector editor.
4. **Verify container files**: Remember that SVG, AI, EPS, and PDF files can embed raster images.
5. **Keep backups**: Save traced or cropped files under new filenames so your original stays untouched.
6. **Compare in Preview**: Check key edges, color regions, small text, and layer complexity in Lumina before exporting your 3MF.

## Common Questions

### Is a PNG always a bitmap?

Yes. PNG is a raster format. Even when exported from a vector logo, the resulting PNG stores a fixed pixel grid without editable vector paths.

### Is every `.svg` file guaranteed to be pure vector?

No. Because SVG supports embedded raster images alongside vector paths, opening the file in a vector editor to check for selectable nodes and fills is the surest test.

### Are vector images always sharper than bitmaps?

Vector paths keep geometric edges smooth at any scale, while high-resolution bitmaps capture photographic texture, subtle lighting, and continuous color transitions that flat vector shapes cannot easily represent.

### Can tracing a low-resolution image into SVG recover lost detail?

No. Tracing estimates curves from existing pixels—it can smooth out stair-stepped edges on simple shapes, but missing letters, facial features, or textures will not return.

### Does smaller file size mean an image is vector?

Not reliably. A simple SVG icon may be tiny while a complex traced illustration can grow huge; likewise, a heavily compressed JPG can be small while an SVG with an embedded photo can be megabytes in size.

### Should I convert pixel art into SVG?

No. Keep pixel art as a bitmap and use **Pixel Art** mode in Lumina Studio (or nearest-neighbor scaling when resizing) so every grid cell stays sharp instead of getting smoothed away.
