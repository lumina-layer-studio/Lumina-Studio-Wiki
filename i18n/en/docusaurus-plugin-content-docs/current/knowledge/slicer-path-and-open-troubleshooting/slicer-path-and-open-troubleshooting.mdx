# Slicer Not Detected or 3MF Will Not Open

When a 3MF will not open in your slicer, the issue typically occurs at one of five distinct points:

1. Lumina has not finished generating a valid 3MF.
2. The browser download is incomplete or expired.
3. The 3MF downloaded cleanly, while one-click slicer launch is blocked or unconfigured.
4. The slicer being used does not match the export format selected in Lumina.
5. The slicer imported raw geometry only instead of opening the full project.

Identifying which stage failed saves unnecessary reinstallation or repeated generation.

## Step 1: Confirm that a valid 3MF downloaded

Before troubleshooting your slicer, verify that:

- Generation finished cleanly rather than stalling on a loading spinner.
- The **Download 3MF** button is available.
- The downloaded file has a non-zero size and ends with `.3mf`.
- The temporary session output has not expired.

If the file is missing, `0 KB`, or expired, generate a fresh copy in Lumina first. For page-load or generation issues, see [The Page Will Not Open, Keeps Spinning, or Generation Fails](pathname:///en/docs/knowledge/web-generation-troubleshooting/).

## Step 2: Match the export format to your slicer

The slicer setting in Lumina controls both one-click launch and the project metadata written into the 3MF. Open **Settings**, select the exact slicer you plan to use alongside your printer model and nozzle size, and generate a new 3MF whenever you change these options.

## Step 3: Set a manual `.app` path on macOS if auto-detection misses it

On macOS, if your slicer is installed in a custom location and is not detected automatically, enter the path to the **`.app` bundle** itself—never an internal `Contents` directory, binary executable, mounted `.dmg` disk image, or alias.

1. Open **Applications** in Finder and locate the installed slicer app.
2. Check its exact filename on disk, including spaces and capitalization.
3. Enter the full `.app` path in Lumina **Settings**.
4. Click **Validate and Save**.
5. Once validation succeeds, return to the Converter to use one-click open.

<img
  src={require('./assets/02-path-validation.webp').default}
  alt="Real English Lumina manual slicer path comparison showing an invalid spaced filename and the valid installed BambuStudio app path"
/>

Even a single extra space will cause validation to fail—for example, default macOS installations of Bambu Studio omit the space in the `.app` bundle name:

```text
/Applications/Bambu Studio.app   ← fails validation (space in bundle name)
/Applications/BambuStudio.app    ← valid installed .app bundle
```

Check Finder on your own Mac for the exact filename. Once saved, Lumina uses this custom path to launch 3MF projects; click **Clear** at any time to revert to automatic detection.

:::info[Windows]
The manual `.app` path field applies only to macOS bundles (do not enter a Windows `.exe` path here). On Windows, install your slicer with its standard installer and launch it once so system registration completes; if auto-detection is unavailable, download the 3MF and open it via **File → Open Project** inside the slicer.
:::

## Step 4: Open the project manually as a reliable fallback

Whenever one-click launch is unavailable or blocked by OS permissions, opening the downloaded file directly preserves every project setting:

1. Click **Download 3MF** and wait for the download to complete.
2. Open Bambu Studio, OrcaSlicer, or your configured slicer.
3. Choose **File → Open Project** and select the downloaded `.3mf` file.
4. When prompted, choose to open it as a **complete project** rather than importing geometry only.

<img
  src={require('./assets/03-open-full-project.webp').default}
  alt="English concept diagram showing a downloaded Lumina 3MF opened as a complete slicer project with plate, objects, materials, and settings preserved"
/>

Opening as a complete project loads the build plate, object/part hierarchy, project filaments, and process presets intact. If you see only a single merged mesh with no object tree or project filaments, close the window and reopen the file as a complete project.

Always open the downloaded `.3mf` directly without unzipping, editing internal files, and re-zipping it, as manual repacking can break internal XML references.

## Step 5: Quick diagnostic decision tree

<img
  src={require('./assets/04-open-diagnosis-flow.webp').default}
  alt="English diagnostic flow separating Lumina generation, 3MF download, manual slicer open, automatic launch, and incomplete project problems"
/>

- **No Download 3MF button**: resolve preview or generation first.
- **Empty or failed download**: generate again and save the `.3mf` locally right away.
- **Manual Open Project works, one-click launch fails**: the 3MF is intact; check slicer detection, OS launch permissions, or your macOS `.app` path.
- **Opens in one slicer, fails in another**: check that Lumina's selected export format matches the target slicer and verify both app versions.
- **Rejected by all slicers**: generate a fresh copy, compare file sizes, and keep the untouched failing `.3mf` for support.
- **Opens without objects, filaments, or presets**: reopen via **File → Open Project** and select full project import.

## Common messages and actions

| Message or symptom | Recommended action |
| --- | --- |
| Slicer not detected | Download the 3MF and open it via **File → Open Project**; on macOS, check your `.app` path |
| Export format and installed slicer differ | Select the slicer you actually use in **Settings** and generate a new 3MF |
| Slicer path no longer exists | Point to the app's current location after moving or reinstalling, then click **Validate and Save** |
| 3MF result cannot be found | Generate again—temporary session outputs expire after cleanup |
| Download is temporarily unavailable | Generate a fresh 3MF and download it immediately |
| Preparing a launch copy failed | Check free disk space and folder permissions, or download and open manually |
| Slicer starts but no project loads | Let the slicer finish starting up, then click open again or use **File → Open Project** |
| Project opens with missing materials or objects | Reopen as a complete project and confirm the export format matches your slicer |

## Step 6: Verify filament mapping before printing

Once the project loads in your slicer, confirm these final items before sending the print:

- Printer model and nozzle diameter match your hardware.
- Project filaments and per-object assignments are intact.
- Each project filament is mapped to the right physical spool and AMS or external slot.
- In the sliced **Preview** tab, the viewing face, backing, and every color layer appear in the expected order.

For the full mapping walkthrough, see [Import a Lumina 3MF into the Slicer Correctly](pathname:///en/docs/tutorials/slicer-material-mapping/).

## Reporting persistent open issues

If a newly generated 3MF still fails to open, include:

1. Lumina Studio version or build info
2. Operating system and version
3. Slicer name and exact version
4. Slicer, printer, and nozzle selected in Lumina **Settings**
5. A screenshot of the full error message
6. Whether one-click launch fails, manual **Open Project** fails, or both
7. The unmodified `.3mf` file (when safe to share) and whether another slicer can open it

Redact personal account names, email addresses, local usernames, server URLs, and proprietary designs before posting in public channels.

## Common questions

### Why isn't there a Save button for slicer, printer, and nozzle?

Standard dropdown choices save immediately when changed. Only the macOS manual path requires clicking **Validate and Save** so Lumina can verify that the target is a valid, supported `.app` bundle.

### My custom path validated, so why does the Converter still mention another slicer?

One-click launch requires both the **Slicer** export setting and your custom `.app` path to point to the same application. Update the slicer selection in **Settings** and generate a fresh 3MF.

### I moved my slicer app and the saved path stopped working—why?

Manual paths point to an exact filesystem location. After moving, renaming, or reinstalling the app, enter the updated `.app` path and click **Validate and Save**.

### One-click open launches the slicer to an empty plate. What should I do?

On a slow cold start, the slicer may finish initializing before picking up the file argument. Once the slicer window is open, click the open button in Lumina again or load the downloaded file via **File → Open Project**.

### Does an expired download link mean my project is corrupted?

No—generated files live in temporary session storage and expire automatically over time. Run Generate again and save the `.3mf` to a local folder.

### Double-clicking a `.3mf` opens the wrong program on my computer. Why?

File double-click behavior is controlled by your operating system's default file associations rather than Lumina. Either launch your target slicer first and use **File → Open Project**, or change the default app for `.3mf` files in Finder or Windows Settings.
