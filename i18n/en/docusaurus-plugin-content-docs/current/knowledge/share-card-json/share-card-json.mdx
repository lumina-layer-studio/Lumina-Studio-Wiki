# Save projects and share cards

Once you finish tuning colors, click **Save Project** to export an editable `.lumina.json` file, or **Export Share Card** to generate a preview PNG with your project data embedded inside. Both formats restore your editing workspace; when you are ready to print, generate a 3MF and slice it in your slicer.

## Choosing a file format

| File | Control | Purpose |
| --- | --- | --- |
| `.lumina.json` | Save Project | Archive projects locally, move work between computers, or resume editing later |
| PNG share card | Export Share Card | Showcase a preview cover while embedding the full restorable project inside the original PNG |
| 3MF or ZIP | Generate / Generate and download | Inspect toolpaths and print in a slicer (does not store editable selection or recoloring state) |

A PNG share card embeds your source artwork and project metadata directly inside the PNG file. Taking a screenshot, converting to JPG, sending through chat apps that recompress images, or resaving in an image editor strips out that embedded data. Send the original PNG file—or wrap it in a ZIP archive—whenever the recipient needs to import and edit the project.

## Saving a project

1. Upload your artwork, select a color source, filaments, and finished dimensions, and run **Preview**.
2. Complete any global recoloring, regional recipes, and selection adjustments in **Color Adjustment**.
3. Wait for any active edit to finish syncing, then click **Save Project** or **Export Share Card**.
4. For critical projects, archive the source artwork, `.lumina.json` project, Material Archives or LUTs, and final 3MF together.

If Lumina indicates that an edit or selection is still syncing, wait a moment for the update to complete before exporting so every change is captured.

## What a project file stores

- Original bitmap or SVG artwork and conversion settings
- Confirmed global and local recoloring adjustments
- Regional recipes, per-layer filament stacks, and editing state
- Active selection masks
- Selected printer, filament presets, and model add-ons (such as backing and loops)

Importing a project rebuilds a fresh preview and validates regional edits against the source artwork and working coordinates. Renaming the source file has no effect, whereas swapping, cropping, or rotating the image requires saving a new project.

## Importing and resuming edits

1. Select a `.lumina.json` file or an uncompressed PNG share card in the **Image Conversion** upload area.
2. Review the artwork thumbnail, dimensions, color source, and any compatibility notes in the confirmation dialog.
3. Confirm the import and wait for the artwork and preview to load.
4. Verify your local recoloring, regional recipes, and selections, then continue editing.
5. Save a new project file when finished, and generate a fresh 3MF when ready to print (temporary download links from earlier sessions are not stored in project files).

Running **Preview** again preserves your confirmed color edits. Whenever you undo changes or adjust colors further, verify the updated preview before exporting a 3MF.

## Legacy files and external material resources

Older share cards created before regional editing was introduced store global conversion settings only; the import dialog notes which data is present before restoring.

Project files reference your color sources by identity rather than bundling full Material Archives, Classic LUTs, or native slicer presets. Make sure the required archives or LUTs are installed on the target machine before importing—if a resource with the same name cannot be matched automatically, reselect it when prompted.

## Editing `.lumina.json` manually

Valid parameter edits inside `.lumina.json` import normally as long as values conform to the active mode and schema; corrupted artwork payloads or mismatched region coordinates will abort the import. For routine size, color, or filament changes, importing the project into Lumina, adjusting settings in the UI, and saving again is the cleanest approach.

## Model texture projects

Because **Model texture** relies on an external 3D base mesh (STL or OBJ) plus surface face-selection coordinates, **Save Project** and **Export Share Card** are disabled while Model texture is active. Archive your base mesh, source artwork, and exported 3MF together along with notes on face selection, orientation, and placement.

## Before sharing publicly

Both PNG share cards and `.lumina.json` files embed your full-resolution source artwork behind the cover preview. Check licensing rights, personal details, and unreleased designs before sharing project files publicly—if you only want to show off the visual preview, share a regular screenshot or flattened image instead.
