# Batch Generate Multiple Models: File List, Results, and Retry

**Batch Generate** processes multiple prepared images using **one shared color source and one shared set of modeling settings**, then packages the results into a single merged 3MF for layout and slicing.

Key points before starting:

- **Entering Batch mode**: Select multiple files on initial upload, or click **Add more images** from the single-image converter.
- **Shared settings**: Every file in the list uses the same Classic LUT or Material Archives, Width, Backing Thickness, Structure Mode, and Modeling Mode.
- **Image preparation**: Cropping, rotation, Color Workstation edits, and per-image Preview are not available inside Batch mode—prepare your source images beforehand.
- **Results and download**: Check **Success / Total** when generation finishes. If any files fail, the merged 3MF contains all successful models.
- **Bed Preview**: When a batch contains many models or exceeds bed capacity, the 3D preview displays a subset while the downloaded 3MF retains every successful object.

## When to Use Batch Generate

**Good fit:**

- A set of badges, magnets, tags, or test pieces that share the same filaments and layer settings;
- Pre-cropped artwork with finalized orientation, transparent margins, and framing;
- Multiple models you want combined into one 3MF for multi-plate or single-plate arrangement in your slicer;
- Large sets where you want to process everything in one pass and retry any failed files afterward.

**Use the single-image workflow instead when:**

- Different images require different LUTs, Material Archives, thicknesses, structures, or Modeling Modes;
- Individual files still need cropping, rotation, local recoloring, or cleanup;
- You have not yet tested your color source and settings on a single representative image;
- You need features unavailable in Batch mode, such as Puzzle, Validation Card, or uploaded height-map Relief.

If you are choosing between color sources, see [Material Archives or Classic LUT?](../material-profile-selection/material-profile-selection.mdx).

## Step 1: Prepare Every Image First

Before adding images to a batch, make sure each file meets these criteria:

1. Orientation is final;
2. Transparent edges, drop shadows, outlines, and canvas margins are clean;
3. The file opens normally and uses a clear, recognizable filename;
4. It works well with the group's shared Source Type, structure, and target Width;
5. You have saved a backup of the untouched original.

For cropping and rotation tips, see [Upload, Replace, Crop, and Rotate an Image](pathname:///en/docs/knowledge/image-upload-crop-rotate/).

:::warning[Shared Batch Settings]
Batch mode applies the settings currently selected on the Batch page rather than each image's previous single-image settings. If a file needs its own dimensions, color edits, or material set, remove it from the list and process it individually.
:::

## Step 2: Build and Check the File List

Select multiple files during your initial upload, or upload one image and click **Add more images**. The total count and filenames appear at the top of **Core Settings**.

Review three details before adjusting settings:

- **Count**: Confirm that “N files selected” matches your intended batch size.
- **Filenames**: Check for duplicates, older drafts, or accidental inclusions.
- **List edits**: Clicking **×** beside a filename removes it from the queue without deleting the file on disk.

Click **Add more images** to append additional files. Modifying the list clears any previous batch result so you can generate a fresh 3MF; removing files until one remains switches back to the single-image workflow. On long queues, the panel displays the first rows and summarizes the remainder—check the header count for the full total.

## Step 3: Choose Shared Color and Model Settings

<img
  src={require('./assets/02-shared-settings.webp').default}
  alt="Earlier English Batch interface with Legacy LUT, Inferred LUT, Material Archive, a brand, and a selected LUT highlighted"
/>

This screenshot shows an earlier interface: **Legacy LUT** is now named **Classic LUT**, and **Inferred LUT** has been removed.

Select a **Source Type**, then pick a valid Classic LUT or Material Archive set. **Batch Generate** becomes active once a valid color source is configured.

Every image in the queue shares:

- Classic LUT or Material Archives;
- Target **Width** and **Backing Thickness**;
- Single- or double-sided **Structure Mode**;
- **High-Fidelity**, **Pixel Art**, or **Vector** Modeling Mode;
- Color-detail, matching, and printer settings supported in Batch mode.

Each image is scaled to the same target **Width**, while its height follows its own aspect ratio and alpha bounds—so models in the same batch can have different footprints on the build plate.

:::info[Test One Image First]
When using a new material set or parameter combination, run one representative image through 2D Preview, 3D Preview, Generate, and slicer inspection first. Catching a parameter issue on a single file is much faster than re-running an entire batch.
:::

For guidance on modeling modes and feature combinations, see [High-Fidelity, Pixel Art, or Vector?](pathname:///en/docs/knowledge/image-mode-selection/) and [Which Features Can Be Used Together?](pathname:///en/docs/knowledge/feature-compatibility/).

## Step 4: Run Batch Generate

Once your color source and parameters are set, click **Batch Generate**.

<img
  src={require('./assets/03-batch-generating.webp').default}
  alt="Current English Batch interface while Batch Generate is disabled and showing an active task"
/>

While the batch runs, the button shows a spinner. Processing time scales with file count, image resolution, outline complexity, target Width, and detail settings. Leave the tab open without refreshing or uploading new files until processing finishes.

Lumina processes the queue sequentially and merges all completed models into one 3MF. If an individual file fails, the remaining images still finish and export normally.

## Step 5: Check Results and Download the 3MF

<img
  src={require('./assets/04-batch-result.webp').default}
  alt="Current English Batch result showing Success 2, Total 2, Download batch 3MF, and two generated models on the bed"
/>

When processing finishes, check four items in the result summary:

1. **Success**: Number of models generated successfully;
2. **Total**: Total files processed in the batch;
3. **Failed files**: Listed by filename whenever any item fails;
4. **Download batch 3MF**: Available whenever at least one file succeeds, containing all successful models.

In the example above, **Success 2 / Total 2** confirms that both images completed. Download and save the merged 3MF promptly—refreshing the page, editing the file list, or letting temporary session files expire will clear the download link.

### Why does the bed Preview show fewer models than Success?

When a batch produces many models or exceeds what the selected printer bed can display cleanly at once, the 3D viewport previews a subset and notes that the 3MF still includes every successful model. Open the downloaded 3MF in your slicer to view the full object list.

### What does “some models may be outside the bed” mean?

The merged 3MF includes all successful models, but automatic placement extended past your selected build plate boundaries. Rearrange, rotate, or split the models across multiple plates in your slicer before printing.

## Step 6: Arrange and Verify in Your Slicer

Open the merged 3MF in Bambu Studio, OrcaSlicer, or your configured slicer and check the following before printing:

- Total objects match the **Success** count;
- All models sit inside the build plate boundaries without overlapping;
- Millimeter dimensions match expectations for each image's aspect ratio;
- Project filaments map to the right physical spools and AMS/slot positions;
- Printer profile, nozzle diameter, display face orientation, and single/double-sided settings match your setup;
- Layer Preview shows clean color transitions, filament swaps, and expected material usage.

If your slicer preview differs from Lumina's viewport, see [Why Do Lumina Preview, Slicer Preview, and the Physical Print Differ?](pathname:///en/docs/knowledge/preview-slicer-print-differences/).

## Retrying Failed Files

If a batch finishes with **Success 3 / Total 5**, handle the remaining files in this order:

1. Click **Download batch 3MF** first to save the three completed models;
2. Note the two filenames listed under failed files;
3. Upload one failed file in single-image mode with the same color source and settings;
4. Check for file corruption, oversized empty canvas margins, overly dense SVG nodes, or extreme width and precision settings;
5. Fix the source image, then generate it individually or run a small batch containing only the repaired files.

If the file also fails in single-image mode, see [The Page Will Not Open, Keeps Spinning, or Generation Fails](pathname:///en/docs/knowledge/web-generation-troubleshooting/). For SVG artwork, see [SVG Troubleshooting](pathname:///en/docs/knowledge/svg-troubleshooting/).

## Common Questions

### Why does Batch mode use one Batch Generate button instead of separate Preview and Generate steps?

Batch mode is designed for pre-verified settings, processing the entire queue in one run and presenting a combined bed preview and 3MF download. Switch to single-image mode whenever you want to inspect color layers, adjust colors in Color Workstation, or fine-tune structure per image.

### Can each image in a batch use a different Width or Thickness?

No—every file in a batch shares one Width, Backing Thickness, and parameter set. Group images by size into separate batches or generate custom-sized pieces individually.

### Does one failed file block the rest of the download?

No. As long as at least one image succeeds, **Download batch 3MF** exports all successful models and lists any failed filenames separately.

### Does my previous download stay active if I add another image?

Changing the file list resets the batch state for the new queue. Download your existing 3MF before adding or removing files, then run **Batch Generate** again.

### Why do models in the same batch have different heights or footprints?

Target **Width** sets the horizontal dimension, while vertical size and footprint follow each image's aspect ratio, transparent bounds, and attachments. Check exact millimeter dimensions in your slicer.

### Should I put all my images into one huge batch?

Batch mode saves repeated setup clicks and slicer imports, while each image still requires full geometry calculation. Testing 2–3 files first helps confirm your shared settings before running larger queues.

### Can I print the merged 3MF right after downloading?

Always open the 3MF in your slicer first to arrange models within bed bounds, verify filament slot mappings and nozzle size, and inspect the sliced Layer Preview.
