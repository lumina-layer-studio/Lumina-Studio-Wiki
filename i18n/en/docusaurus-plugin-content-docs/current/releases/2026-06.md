# Lumina Studio 2.0 Development Report: June 2026

> 256 pull requests merged

[← May 2026](/en/docs/releases/2026-05) · [Changelog overview](/en/docs/releases/overview) · [July 2026 →](/en/docs/releases/2026-07)

## Monthly overview

June was the largest stability and platform-hardening milestone of Lumina Studio 2.0 to date. Alongside cloud material and LUT libraries, Machine Adapter V2, end-to-end puzzle workflows, high-precision color previews, and hybrid material solving, work systematically overhauled file lifecycles, cache isolation, session transitions, structured error messages, input validation, and reproducible bug reporting. Related pull requests are grouped below by user-facing capability.

## Highlights

### Cloud material and LUT libraries

Material profiles and LUTs gained cloud catalogs for browsing, one-click installation, refreshing, and distinguishing official from community resources. Compatible classic LUTs can now be multi-selected directly for color matching without manually merging files first, and installed resources automatically refresh their details and status.


### Machine Adapter V2

Settings introduced machine cards organized by slicer, printer model, and nozzle diameter, backed by a native slicer-machine registry. Exported 3MF projects preserve printer, nozzle, and filament metadata recognized by Bambu Studio, OrcaSlicer, ElegooSlicer, Anycubic Slicer Next, Snapmaker, and compatible slicers.


### High-precision 3D color preview and stage timing

Advanced Settings added a high-precision 3D color-preview toggle so low-coverage accent colors stay distinct, while Pixel Art mode retains sharper block boundaries. The preview panel also displays per-stage timing to show how much time is spent on upload, color matching, meshing, and GLB generation.


### Hybrid solving for large material sets

Material recommendations added a hybrid candidate runtime that reuses precomputed candidates on large combinations, allowing 10-layer jobs across a dozen or more filaments that previously hit combinatorial limits to finish with a valid recommendation.


## New features

- Puzzle mode added cut-line converter overlays, per-piece generation, merged 3MF export, recipe round-tripping, and inset cut-boundary protection.
- Single-image upload now clearly separates replacing the active image from adding more images, preventing accidental batch appends.
- Added eight KYNIX PETG material profiles; filament brand groups now start collapsed with a one-click clear-selection action for long lists.

## Color Workstation

- Region recolors automatically replay across refreshed previews and final exports, and select-all custom recipes preserve the full target mask.
- Transparent artwork keeps its alpha channel intact during gradient highlighting and region selection instead of filling transparent areas with a solid highlight color.

## Calibration and materials

- Standardized physical frame dimensions across both pages of the 5-Color Extended calibration board, and preserved the sixth black recipe layer across lookup, matching, swatches, and export.
- Added upload progress, timeouts, and cleanup handling for ColorChecker source images so failed DNG or large-file uploads never hang indefinitely.
- Improved classic LUT matching across neutral grays, blacks, and legacy CMYW/NPY channel layouts, reducing unwanted color casts and slot-order mix-ups.

## Vectorization and modeling

- Unified SVG outline, coating, and backing footprints between preview and export, with consistent layer-count fallbacks for transparency, white backings, and material profiles.
- Accelerated SVG preview and mesh preparation; the optional V2 preview kernel remains opt-in and falls back cleanly when optional runtime dependencies are absent.
- Preserved heightmaps across preview refreshes in relief mode, generated material-profile reliefs above five layers at their true layer count, and fixed face-up export orientation.
- Exported SVG keychain loops directly into the 3MF without consuming an extra filament slot, alongside fixes for translucent 5-color stacks, near-identical fills, and extended material templates.

## Preview and interaction

- SVG files defined solely by `viewBox` without fixed width/height attributes now render upload previews properly, and relaxed capacity estimates no longer reject large SVG or multi-material previews prematurely.
- Pixel Art mode preserves its full color budget so small accent regions are no longer lost during preview compression.
- When the backend goes offline, a cleanup beacon is blocked, or a health check briefly times out, the UI degrades gracefully without spamming error toasts or blocking window close actions.

## Slicers and 3MF

- Preserved accurate printer and filament-slot metadata for Snapmaker U1, H2C, and extended-material templates, resolving model recognition, filament-usage, and empty-slot issues in OrcaSlicer.
- Once a 3MF finishes generating, the final download remains available even if an optional GLB preview fails—a safeguard applied consistently across batch, calibration, swatch, and share-card exports.

## File, session, and download reliability

Resolved cases where switching pages after a completed build caused downloads to expire: exported artifacts are now decoupled from source-session lifetimes, with rollback and recovery paths for short writes, registration errors, session-close races, and stale caches, while preview caches remain bounded on disk.


## Feedback and reproducibility

Bug reports now capture the active single-stage session, source artwork, exported artifact, LUT, material profile, and failed attachments accurately—marking unreadable attachments as partial rather than substituting stale files, and keeping draft text intact when clicking the modal backdrop.


## Safer, clearer error messages

Standardized over a hundred API and UI boundaries around structured, localized error messages that strip local file paths, internal dependencies, raw request payloads, and server internals—giving users clear reasons and request IDs while keeping full diagnostic fields in developer logs.


## Stability, performance, and infrastructure

Additional engineering work strengthened upload and parameter validation, temporary-file ownership, atomic material-library writes, cache isolation, worker timeout recovery, structured logging, and end-to-end regression gates—reducing crashes, cross-session leaks, and download failures.


## Known limitations

- Cloud resource libraries remain in beta as catalog size, categorization, and sync policies continue to evolve.
- The SVG V2 preview kernel remains opt-in, with the established pipeline enabled by default.
- Machine Adapter V2 continues to expand coverage across slicer versions, printers, and nozzle sizes.
