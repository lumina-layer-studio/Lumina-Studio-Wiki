# Lumina Studio 2.0 Development Report: July 2026

> Reporting period: July 1–31, 2026





July refined cloud resources, pixel and material previews, and vector model exports while introducing native SVG relief. The second half of the month added planar artwork placement on imported 3D models, Creative Workshop, and Flash Studio Desktop support.

## Native SVG relief and cloud resources



SVG artwork can now enter the relief workflow directly while preserving crisp vector boundaries, alongside a backing-closure fix that prevents open or non-manifold meshes in slicers. Cloud LUT installation refreshes item details, lists, and installed state automatically, with consistent handling for multi-select sources, missing resources, and official/community badges.




Architecture design for Cloud Resource Center V2 was also completed this month ahead of implementation.






















## Materials and previews

- Added image rotation with automatic safeguards for incompatible vector combinations, plus optional browser notifications when long tasks finish.
- Restored simulated optical-stack colors in material 3D previews while preserving true layer counts, thickness, and relief height steps.
- Preserved original canvas dimensions and palettes in Pixel Art previews, and retained full base layers across material-vector previews and 5-color exports.
- Automatically migrated saved filament selections and profiles to the unified Karvax brand name, and clarified whether deleting a duplicate material removes only the duplicate entry or a shared resource.
- Surfaced profile metadata and calibration layer heights in the filament picker, clearing stale color-replacement selections whenever target materials change.
- Kept displayed previews synchronized with parameter edits so outdated previews never linger after settings change.

## Planar artwork and Creative Workshop







Introduced a model-surface workflow for importing a base mesh, selecting a flat face, and embedding multicolor artwork onto the part—followed by fixes aligning previews with face-down print orientation and keeping transparent artwork regions free of unwanted solid fill. This workflow was later renamed **Model Texture**.











Added **Creative Workshop** to the main navigation for managing standalone creative modules. Its first official module, **Fuse Bead Studio**, detects grids and bead colors from clear pattern sheets or screenshots for review before handing the result straight into the standard 3D conversion pipeline.

## Slicer projects and regional edits

- Added multicolor print-project support for Flash Studio Desktop.
- Completed Snapmaker U1 project metadata for OrcaSlicer, with safe defaults when optional printer fields are absent.
- Aligned backing layer-height modifiers with total thickness so top color layers are never truncated, and preserved separated backings and filament assignments in batch exports.
- Scoped large-format regional recolors strictly to the active selection without altering unselected areas of the same color, and unified native SVG tiling between preview and export.
- Added Spacebar-drag and middle-mouse-button panning on the 2D canvas.






## Multi-core performance and ongoing work

Single-task conversion now uses multi-core processing, and material auto-preview triggers intelligently from cache state to cut redundant computation without reducing model detail. Refinements to complex SVG intersections, pinholes, and multi-layer material stacks continued in August and September.
