# Lumina Studio 2.0 Development Report: July 2026

> Completed through the end of July. Subsequent fixes are recorded in their completion month.

July improved cloud resources, pixel/material previews and vector exports, and introduced native SVG relief. The second half added planar artwork on imported models, Creative Workshop and Flash Studio Desktop support.

## Native SVG relief and cloud resources

SVG artwork can enter relief directly while preserving vector boundaries. Backing closure was corrected to reduce open or non-manifold output. Cloud LUT installation refreshes details, lists and installation state; multiple sources, missing resources and official/community labels are handled consistently.

Cloud Resource Center V2 was design work this month, not a released feature.

## Materials and previews

- Added image rotation with restrictions for incompatible vector workflows, and browser completion notifications when permitted.
- Material previews show simulated recipe colors while retaining actual layers, thickness and relief height differences.
- Pixel previews preserve canvas size and palette. Material-vector previews and five-color exports retain the required layers and base.
- Saved material choices migrate to Karvax; duplicate-material deletion explains which resources are affected.
- Material selection exposes profile choices and calibration layer heights. Changing materials clears outdated replacement choices.
- Settings changes are reflected in the displayed result rather than leaving an old preview in place.

## Planar artwork and Workshop

A new model-surface workflow imports a base mesh, selects a plane and places artwork on it. Follow-up fixes align previews with face-down output and preserve transparent artwork regions. This feature was later renamed **Model Texture**.

Creative Workshop adds tool management. Its first official Fuse Bead Studio helps interpret a clear pattern or screenshot, correct the grid and colors, and return the artwork to the conversion workflow. Runtime and installation support continued in later months.

## Slicer projects and regional edits

- Added multicolor Flash Studio Desktop support; machine/nozzle choices follow the application list.
- Completed Snapmaker U1 metadata for OrcaSlicer, including missing-field fallbacks.
- Align backing-layer modifiers with thickness to avoid truncating color layers; batch output retains separated backings and materials.
- Large-format regional edits do not change other regions of the same color. Native SVG tiling retains consistent inputs and previews.
- Added Space and middle-button panning.

## Performance and limits

Single-task conversion began using multiple cores, and material auto-preview follows available cache state. The aim is less repeated work without lowering detail. Actual time depends on artwork, material combinations and hardware. Complex SVG paths, holes and stacks continued to receive fixes later; this report is not a current-version control guide.
