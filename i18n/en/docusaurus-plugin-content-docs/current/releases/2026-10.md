# Lumina Studio 2.0 Development Report: October 2026

> In progress · Updated through October 30, 2026

October integrates continued editing, quick recoloring, filament/plate checks and independent backing projects into existing workflows. Reports follow completed and merged work; installer notes determine which changes your version includes.

## Open-source release and 2.0.1

Closed internal development has ended. Development continues in the public
[Lumina-Layers repository](https://github.com/lumina-layer-studio/Lumina-Layers).
The [2.0.1 source release](https://github.com/lumina-layer-studio/Lumina-Layers/releases/tag/v2.0.1) was published on October 28.
Source archives on GitHub are not installers. Consult the corresponding launcher release notes for the version and changes
included in a launcher download.

Fixes merged on or after October 29 are later source updates; they are not automatically part of 2.0.1 or an already installed build.

## Late-October interface and conversion changes

- Save commonly used conversion settings as named presets, optionally including advanced settings, outline and coating. Size follows the image's long edge.
- Material Archive is the default when no source preference exists. Traditional LUT is now called Classic LUT; the searchable picker supports selections across brands.
- Cropping and rotation share one dialog. SVG images can be rotated while preserving vector content.
- After previewing, download a 3MF or open a slicer; Lumina generates the file as needed.
- Desktop interface scale can be adjusted and saved. At 100%, it follows the system display scale and does not change model dimensions.
- The Cloisonné settings entry is hidden for now; existing settings data remains intact.

## Late-October export and fixes

- A separately exported backing keeps the chosen filament's colour, temperature and flow settings.
- Merged and batch layouts retain model heights and use the selected printer's actual build area; unsafe merges produce a warning.
- If only some Large Format tiles finish, completed files can be downloaded with a warning listing missing parts. Check and complete the set before printing.
- A later source update on October 29 fixed selection feedback and undo history in Color Workstation, and improved viewport retention when comparing the original image.

## Keep editing saved projects

JSON projects and PNG share cards retain confirmed local recoloring, regional recipes and selections. Restoration checks source artwork and working coordinates before applying edits, preventing regional data from being applied to another image merely because dimensions match.

Rebuilding previews retains confirmed edits. Modified valid recipe parameters can be imported; old files still explain when regional information was never saved. Recipe shortcuts accept the Chinese material abbreviations shown in the interface.

Model Texture still cannot restore its base mesh and selected face through these recipe files.

## Color Adjustment

Quick recoloring adds similar-color selection, target color B and an eyedropper. Select an area, then apply a target color or similar recipe. Suggestions show layers, color difference and whether the color is already in the image.

Follow-up fixes address missing suggestions and unwanted solids in transparent regions after replaying global edits. Cached selection outlines improve panning and zooming with many selected regions.

## Model Texture and creative tools

Model Surface Overlay becomes **Model Texture** with its own panel; Advanced becomes **Creative Center**. Drag in a model and artwork, view the selected plane straight on, and retain adjusted model orientation.

Fix pocket generation around small holes, base-material identity and Workshop modules occasionally failing to open. Add a skippable first-run tour that can be replayed from the top bar.

## Print projects and materials

- Check native filament presets and plates before generation, allowing explicit choices among ambiguous matches.
- Reuse supported material/global process settings through custom single-plate 3MF templates.
- Export supported single-sided models and backings as separate original-size 3MF projects in a ZIP.
- Require an explicit coating material and explain mixed material types.
- Show large-format tile edges and matching identifiers.
- Extend Prusa support and update existing slicer/first-layer compatibility.

Layout warnings remain when safety cannot be confirmed. Check model, brim and tower in each project; generation does not replace actual slicing.

## Feedback and stability

- Upload reports directly to the official collection service with progress, result and retry controls; no personal outgoing-mail setup.
- Collect fuller artwork, SVG, base models, outputs and errors; unexpected errors can lead into reporting.
- Wait for the local service on startup and preserve data when recovering occupied ports.
- Correct non-ASCII resource paths and show gradient-card save feedback beside the action.
- Retire old Docker deployment and its update workflow. Old Docker instructions no longer describe current installation.

## Limits

Project recovery needs valid sources and resources. Model Texture does not support recipe export, and custom templates do not apply to every workflow. Follow the current interface rather than assuming every development change exists in every version.
