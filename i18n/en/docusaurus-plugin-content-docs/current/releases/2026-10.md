# Lumina Studio 2.0 Development Report: October 2026

> In progress · Updated through October 30, 2026

In October, Lumina Studio moved to open-source development and published version 2.0.1 while connecting several major workflows end to end: project saving now preserves local spatial edits, Color Adjustment gained quick recoloring and similar-recipe suggestions, exports run pre-flight filament and build-plate checks, and separated backings can be exported as standalone print projects.

## Open-source release and 2.0.1

Lumina Studio is now developed openly in the [Lumina-Layers repository](https://github.com/lumina-layer-studio/Lumina-Layers), with the [2.0.1 source release](https://github.com/lumina-layer-studio/Lumina-Layers/releases/tag/v2.0.1) published on October 28. GitHub Releases hosts source archives, while desktop builds and updates continue to be distributed through the official launcher.

## Late-October interface and conversion updates

- Conversion settings can now be saved as named presets, optionally bundling advanced settings, outlines, and coating; preset dimensions track the image's long edge.
- **Material Archive** is now the default color source when no prior preference is saved. Traditional LUTs have been renamed **Classic LUT**, with cross-brand search and multi-selection in the picker dialog.
- Image cropping and rotation are combined into a single dialog, allowing SVG artwork to be rotated while preserving vector paths.
- After previewing, clicking download 3MF or open in slicer automatically generates the print file on demand.
- Desktop builds added an adjustable, persistent interface scale control; 100% follows the OS display scale without affecting physical model dimensions.
- Temporarily hid the Cloisonné settings entry while preserving existing saved configuration data.

## Late-October export improvements and fixes

- Separately exported backing plates retain the selected filament's color, nozzle/bed temperatures, and flow settings.
- Merged and batch layouts preserve individual model heights and arrange parts within the selected printer's build area, displaying a warning whenever spacing cannot be verified safely.
- When a Large Format job completes only a subset of its tiles, finished tiles can be downloaded immediately alongside a list of missing tile IDs.
- Fixed selection-state feedback and undo history in Color Workstation, and preserved canvas zoom and pan positions when toggling original-image comparison.

## Resuming saved projects

JSON project files and PNG share cards now save confirmed local recolors, regional recipes, and active selections so projects can be reopened for further editing whenever the source artwork and required material or LUT resources are available locally. Project restoration validates source artwork and working coordinates so regional edits are never misapplied to a different image of the same dimensions.

Rebuilding a preview preserves confirmed edits, validly modified recipe parameters can be imported cleanly, and legacy files saved before spatial-edit support clearly note when regional data is absent. Material recipe shortcut inputs also accept the Chinese filament abbreviations displayed in the interface.

**Model Texture** does not yet restore base meshes or selected faces from JSON project files or PNG share cards.

## Color Adjustment

Quick recoloring added similar-color selection, target color B, and an eyedropper tool. Users can select a local region and replace it with a target color or a suggested similar filament recipe without altering matching colors elsewhere in the artwork. Candidate cards display layer order, color difference, and an “already in image” badge for quick comparison.

Follow-up fixes resolved missing recipe suggestions in some sessions and unwanted solid geometry in transparent areas after replaying global edits, while cached selection outlines keep panning and zooming smooth across complex multi-region selections.

## Model Texture and creative tools

Model Surface Overlay was renamed **Model Texture** and promoted from Basic Settings into its own dedicated panel, while Advanced was renamed **Creative Center**. Base meshes and artwork both support drag-and-drop import, selecting a target face aligns the camera straight on, and previously adjusted model orientation is preserved.

Additional fixes resolved pocket-carving failures around tiny holes, base-mesh material assignment issues, and intermittent launch failures in Creative Workshop modules. First-time workspace entry now includes a skippable onboarding tour that can be replayed anytime from the top bar.

## Print projects and materials

- Added pre-generation compatibility checks for native filament presets and build plates, prompting for an explicit choice whenever multiple matches exist.
- Added support for reusing filament and global process settings via custom single-plate 3MF templates in supported single-plate workflows.
- Supported exporting single-sided, non-relief models and their backing plates as separate full-size 3MF projects bundled into a single ZIP archive.
- Required an explicit coating filament assignment and added clear warnings when incompatible material types are mixed.
- Added visible tile grid lines and matching tile IDs in Large Format previews.
- Expanded Prusa printer and project support alongside ongoing slicer parameter and first-layer compatibility updates.

## Feedback and runtime stability

- Bug reports now upload directly to the official collection service with upload progress, status feedback, and retry controls—no personal outgoing-email setup required.
- Expanded diagnostic collection across source images, SVGs, base meshes, generated outputs, and error logs, with direct entry into bug reporting when unexpected errors occur.
- Desktop startup now waits for the local backend service before opening the workspace and preserves existing user data when recovering from an occupied port.
- Fixed static-asset loading on non-ASCII file paths and moved gradient-card save confirmations next to the action button.
- Removed deprecated legacy Docker deployment configurations and update scripts.
