# Lumina Studio 2.0 Development Report: April 2026

> 123 pull requests merged

[← March 2026](/en/docs/releases/2026-03) · [Changelog overview](/en/docs/releases/overview) · [May 2026 →](/en/docs/releases/2026-05)

## Monthly overview

In April, Lumina Studio 2.0 moved from low-level migration into rebuilding end-to-end user workflows. The vector engine, Color Workstation, LUT management, calibration, and material profiles converged onto shared data and preview pipelines. Puzzle, fridge-magnet, single-stage, large-format, and share-card workflows also took shape, alongside major improvements to 3D preview size, session isolation, diagnostics, and bug reporting.

## Highlights

### Unified vector preview and 3MF pipeline

SVG parsing, occlusion clipping, color matching, mesh extrusion, and 3MF export were consolidated into a single native vector pipeline—carrying region recolors, custom recipes, extra color layers, and material profiles directly into the exported model, with printable fallbacks for complex boundary intersections.

<!-- devlog-entry:2026-04-vector-engine prs:24,26,32,41,42,45,47,48,73,79,83,97 -->

### Color Workstation as a dedicated editing workflow

Introduced the 2D Color Workstation with region and connected-component selection, quick source-image comparison, custom recipes, and live layer-preview refresh. Smooth gradients split across multiple filament colors are automatically grouped so banding can be flattened across the whole group or within a local selection.

<!-- devlog-entry:2026-04-color-workstation prs:29,30,31,62,66,69,80,82,89,90,93,94 -->

### LUT browsing, comparison, and gamut visualization

Material Management gained grouped LUT workflows, side-by-side LUT comparison, and detailed LUT inspection—displaying palettes, color usage coverage, hue distribution, and Lab point clouds, with brand and color-count filtering for classic LUTs. Inferred and custom LUTs prioritize their own palettes to prevent stale global settings from causing mismatches.

<!-- devlog-entry:2026-04-lut-management prs:17,19,25,43,74,78,84,95,111,116,135 -->

### Share cards with reproducible recipes

Preview results can be exported as share cards bundling the artwork, materials, layer order, and model settings. Reimporting a card restores the full recipe, with a built-in fallback for plain HTTP environments where browser Web Crypto APIs are unavailable.

<!-- devlog-entry:2026-04-share-card prs:28 -->

## New features

### Puzzle and fridge-magnet workflows

Puzzle mode added piece cutting, per-piece generation, and SVG export, while fridge-magnet mode introduced magnet cavities and combined artwork/backing geometry—both built on the unified preview, recipe, and 3MF export pipeline.

<!-- devlog-entry:2026-04-puzzle-fridge-magnet prs:34,37 -->

### Native SVG, single-stage, and large-format workflows

Added native SVG bundles, a single-stage material workflow, and tiled generation for oversized artwork. Large-format processing checks printable SVG bounds first so vector-ready files stay on the fast native vector path.

<!-- devlog-entry:2026-04-native-single-stage-large-format prs:38,41 -->

### End-to-end 8-color calibration and 5-color validation swatches

Connected the two-page 8-color calibration workflow end to end, and added recipe validation swatches for 5-Color Extended along with fixes for second-page prompts, layer counts, and base-color loading.

<!-- devlog-entry:2026-04-multicolor-calibration prs:36,40,61,132 -->

- Streamlined gradient-card generation, extraction, rotation, corner ordering, and black/white backing orientation; updated the default layer height to 0.08 mm and supported refitting across multiple captured samples.

- Custom recipes now support virtual materials and extra color layers outside the active LUT, generating the corresponding objects in exported SVG 3MF files.

- Preserved fine illustrated stroke widths without silent thickening, and added boundary fallbacks when complex boolean unions fail so jobs complete cleanly without distorting detail.

- Added 2D and 3D hover inspectors showing color, material, and layer details under the pointer, plus a cursor-tracking magnifier in the layer-mask viewer.

- Fixed page scrolling during canvas wheel zoom, half-step slider jumps, cursor occlusion over tiny color patches when zoomed in, and button loading states disrupted by browser extensions.

## Stability, performance, and infrastructure

Established structured diagnostic logging and automated workflow regression gates across extraction, preview, recoloring, SVG, generation, and multicolor modes; fixed cross-session preview path collisions, worker memory growth, and premature input cleanup; and added internal scaffolding for optional database storage.

## Known limitations

- Certain combinations of large-format tiling, outlines, coating, and modeling modes remain mutually exclusive and are automatically restricted in the UI.
- New preview kernels and optional database storage remained internal infrastructure and were disabled by default.
- Material profiles and classic LUTs were still being unified, with compatibility loaders retained for legacy JSON and NPY files.
