# Lumina Studio 2.0 Development Report: September 2026

September focuses on consistent previews, edits and generation, plus desktop operation, transparency and multi-object projects. This report covers completed and merged work; availability depends on the installed version.

## Lightweight previews, complete print files

Smooth lightweight previews expand across vector, relief and model-surface workflows. Changes update the interactive display without immediately loading the large print mesh after generation. Downloads still use geometry generated from the actual settings.

Build-plate appearance, themes and selection state improve. Color edits, selections and generation use consistent editing state to reduce mismatches.

## SVG and transparency

- Add native SVG fast analysis, retaining compatibility processing where required.
- Add optional small-hole compensation based on physical output size, off by default.
- Correct boundary contacts and native-coordinate conversion in generated models.
- Preserve transparent pixel-art regions instead of filling a rectangular backing.
- Retain batch coating settings and align coating with outlines.
- Preserve brightness relationships in 16-bit heightmaps.

Small-hole compensation changes details. Choose it for the artwork and size rather than enabling it for every SVG.

## Slicing and multiple items

Automatic wipe-tower placement becomes configurable and is corrected where enabled placement still used template positions. Off retains template parameters; on handles the model and tower for the selected device. Check brims and printable bounds in the slicer.

**Generate and download 3MF** works without an existing print file. Batch/puzzle generation processes items in parallel while retaining order and materials. Fixes address single-color pieces using the wrong material and keychain loops overlapping irregular contours.

## Desktop and Wiki help

Improve startup, persistent data, resource loading and external Wiki links, including blank-screen and resource-type fixes. Local operation no longer uses the old resource quotas.

Control help links short explanations to the matching Chinese or English Wiki page. A working link does not update old article content automatically.

## Model textures and feedback

Correct repeated placement transforms, rotation drift and clipped panels. Feedback gains unique ticket IDs and better original-image collection. Direct upload to the official feedback service is merged in October and recorded next month.
