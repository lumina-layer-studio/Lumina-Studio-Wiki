# Lumina Studio 2.0 Development Report: September 2026

September focused on synchronizing previews, color edits, and final exports, alongside improvements to the desktop app, transparency handling, and multi-object print projects.

## Lightweight previews, full-precision print files

Lightweight interactive previews expanded across standard vector, relief, and model-surface workflows. Adjusting dimensions or structural settings updates a responsive display mesh without reloading the heavy print mesh after generation, while downloaded 3MF files retain full-resolution print geometry.

Build-plate styling, light/dark theme rendering, and selection states were also refined. Color edits, selections, and exports now share a single editing state so exported models match the active preview.

## SVG details and transparency

- Added a fast native SVG analysis path while keeping automatic fallback compatibility for complex SVG features.
- Added optional SVG small-hole compensation (off by default) to close pinholes and narrow slits based on physical print dimensions when needed.
- Fixed boundary-contact handling and native-coordinate conversion so exported geometry aligns cleanly with the preview.
- Preserved transparent regions in Pixel Art previews and 3MF exports instead of filling a rectangular backing plate.
- Retained transparent coating settings in batch exports with aligned coating and outline footprints, and preserved full tonal gradation in 16-bit heightmaps.

## Slicing layout and batch generation

Added an automatic wipe-tower placement toggle in Settings and fixed cases where enabled auto-placement still fell back to template coordinates. Turning it off preserves template positions; turning it on places both the model and wipe tower dynamically for the selected printer.



**Generate and download 3MF** now builds and downloads the print file in one step whenever no generated artifact exists yet. Batch and puzzle workflows process multiple items in parallel while preserving piece order and filament assignments, alongside fixes for single-color puzzle pieces defaulting to slot 1 and keychain loops overlapping irregular outer contours.





## Desktop app and inline Wiki help

Improved desktop startup reliability, local data persistence, asset loading, and external Wiki link handling—resolving blank-screen launches and MIME-type mismatches on affected systems—and lifted legacy resource quotas when running locally.

Inline help icons next to controls now display concise tooltips with direct links to the corresponding Chinese or English Wiki articles.

## Model Texture and bug reporting

Fixed cumulative transform offsets on repeated placements, rotation drift, and clipped sidebar panels in Model Texture. Bug reports gained guaranteed unique ticket IDs and more reliable source-image collection ahead of October's direct upload service.
