# Lumina Studio 2.0 Development Report: May 2026

> 74 pull requests merged

[← April 2026](/en/docs/releases/2026-04) · [Changelog overview](/en/docs/releases/overview) · [June 2026 →](/en/docs/releases/2026-06)

## Monthly overview

May turned April's new workflows into complete, production-ready pipelines. Material profiles, batch generation, SVG transparency and outlines, 3MF cover thumbnails, ColorChecker calibration, and the macOS desktop experience were rounded out end to end—ensuring exported 3MF files match the preview while preserving material, process, and backing settings in slicers.

## Highlights

### Batch results merged into a single 3MF

Batch generation now arranges completed models onto a single build plate and exports one combined 3MF with process settings, backing layer-height modifiers, and material metadata. Very large batches cap the in-browser 3D preview count while keeping every model in the exported project.


### ColorChecker integrated into calibration

ColorChecker calibration now runs inline on the Extractor and Gradient Card pages. Users can import custom XLSX reference sheets and flow directly from confirmed color correction into extraction or curve fitting, alongside fixes for trigger reliability, device configuration, and heightmap consistency.


### Accurate cover thumbnails in every 3MF

3MF files generated from both raster and SVG artwork now embed recognizable cover thumbnails. SVG exports no longer show blank white covers or mismatched layer patches in OS file managers and slicer recent-project lists.


### Complete material and recipe workflow

Filaments are grouped by brand with explicit backing-material selection. Recipe lookup added a queue and validation-swatch board so multiple recipes can be collected and exported together as a labeled 3MF. Material profiles preserve solid base colors, physical slot assignments, viewing-face layer order, and added layers without unexpectedly overwriting white or backing layers.


## New features

- High-Fidelity SVG conversion added a detail control for balancing fine detail against processing time while keeping the default behavior unchanged.
- Color Workstation now uses exact exhaustive matching for palettes up to 10 colors and 5 layers while preserving source light-to-dark ordering across neighboring tones to prevent gradient inversions.
- Share cards added a documentation QR code and reimport note so recipients can find setup guides and reproduce the recipe directly in Lumina 2.0.

## Calibration and materials

- Calibration patches now accept fractional dimensions such as 5.5 mm, and 6-color LUT/calibration workflows reuse precomputed Smart1296 recipes instead of solving them from scratch each time.
- PETG slots, auxiliary objects, single-stage cards, and keychain loops carry accurate filament names and nozzle/bed temperatures into Bambu Studio and OrcaSlicer instead of reverting to generic PLA.
- Updated Caiduowu gradient-card measurements, added BIQU PLA multicolor material profiles, and standardized recipe lookup and validation swatches around viewing-face order.

## Vectorization and modeling

- Fixed SVG transparency, white cutouts, and nonzero fill rules being misread as black solids, eliminating stray edge artifacts on small icons and antialiased borders.
- Aligned SVG coating, outlines, backing, and single-sided face orientation between preview and export, writing accurate outline widths into the 3MF.
- Preserved extra recipe layers, gradient colors, and large-format material-profile context through final generation without reverting to the first slot or dropping layers.

## Preview and interaction

- Standardized checkerboard rendering for transparent areas; initial SVG previews now show the full backing plate while post-generation previews retain pixel-level optical color mixing.
- Improved macOS desktop startup and shutdown behavior, Dock icon display, and local slicer discovery that cleanly skips damaged `.app` bundles.

## Feedback and stability

- Expanded bug reports to bundle screenshots, source artwork, exported 3MF files, LUTs, material profiles, backing choices, API errors, and recent actions, with manual export fallbacks when email or clipboard access is restricted.
- Kept 3MF and ZIP downloads available after switching LUTs, closing source sessions, or skipping optional previews, alongside safer cache invalidation for share cards, batches, and materials.

## Stability, performance, and infrastructure

Restored full frontend and backend regression gates; resolved vector precision edge cases, SVG cache collisions, material-profile bucket collisions, test-isolation leaks, and missing reference assets; and wired an experimental 3D mesh kernel behind a disabled-by-default flag.


## Known limitations

- The new 3D mesh kernel remained experimental and disabled by default.
- Large-format SVG did not yet support every outline combination; incompatible options are disabled automatically based on the active mode.
- Custom ColorChecker spreadsheets require the expected column layout and measured patch values.
