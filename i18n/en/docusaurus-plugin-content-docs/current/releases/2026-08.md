# Lumina Studio 2.0 Development Report: August 2026

August focused on project saving and iterative editing workflows, alongside improvements to simulated filament-stack consistency, backing controls, and complex SVG exports.

## Projects and unified selection

Projects can now save source artwork, output parameters, whole-image recoloring, and custom-recipe history so different settings or filament combinations can be reopened and compared later. Spatial selection persistence arrived in October with full saving for local recolors, regional recipes, and active selections.

Color Adjustment introduced a shared selection state, a brush tool, and checkpoint undo with clear boundary outlines. Every selection tool operates on the same active region so previews and exported geometry stay aligned, and clearing a selection after applying a regional recipe preserves the confirmed edit.

## Materials and backing

- Completed dynamic layer-count handling across color matching, preview, and 3MF generation.
- Unified simulated optical-stack colors across conversion previews, custom recipes, achievable-color suggestions, and material-library lookups.
- Extended maximum backing thickness to 10 mm and added independent infill control for deeper backing layers while keeping the zone behind the viewing face solid.
- Fixed backing-to-color-layer alignment, semitransparent PNG matching, and large-format backing layer-height modifiers.

## Devices and 3MF exports

- Reorganized system settings by category, with sharper printer illustrations and high-DPI rendering.
- Added native slicer build-plate selection, remembered per slicer and printer model.
- Added multicolor project support for QIDI Studio.
- Added an option to name standard single-model 3MF exports after the uploaded image filename while preserving dedicated naming schemes for batch, puzzle, and large-format exports.
- Resolved cross-slicer wipe-tower placement, mirrored puzzle-piece offsets, and single-slot filament identity issues.

## SVG performance and lightweight previews

Multiple optimization passes reduced initial analysis time and peak memory usage on complex SVGs while fixing open outlines and lost pinhole details. Color-region analysis and material solving now run in parallel within bounded memory budgets.

Browser 3D previews switched to lightweight display meshes for faster interactive loading—expanded across additional workflows in September—while exported 3MF files retain full print geometry.

## Creative workflows and ongoing work

- Added base-mesh manifold validation prior to model-surface generation and fixed vertical artwork translation and orientation.
- Standardized heightmap brightness-to-elevation mapping in relief mode and fixed heightmap drag-and-drop uploads.
- Expanded Creative Workshop module installation and management while keeping seamless handoff from Fuse Bead Studio into native conversion.

Refinements to complex vector boundaries and inner/outer shell geometry continued in September.
