# Add artwork to a flat model surface

Model texture embeds a multicolor graphic into a selected flat face of an STL or OBJ model while preserving the part's outer dimensions. It is designed for parts with flat surfaces—such as signs, coasters, and box lids—rather than curved surface wrapping.

## Prepare the base model and artwork

Prepare an STL or OBJ mesh with a clean flat face, along with a raster image or SVG for the graphic. Make sure the base mesh is a watertight solid with outward-facing normals; open shells, inverted normals, or non-manifold geometry can cause pocketing and generation to fail.

In Image Conversion, select your color source and physical filaments. When using material profiles, the base model automatically uses the selected backing material (the 3D preview swatch is for visual reference only).

## Import the model

Open and enable the **Model texture** panel, then select an STL or OBJ file in its upload area or drag the mesh onto the workspace. Upload your graphic through the standard image uploader; if you drag a mesh and an image in together, Lumina routes each file by type automatically.

Verify the filename and model dimensions, then wait for face selection to become active. Enabling Model texture switches the project to a single-sided layout and hides standard backing-plate controls in Basic Settings.

## Select the flat face

Click the target flat surface in the 3D preview using the face-selection tool. The default coplanar-group mode selects all coplanar triangles across a flat face in one click, while single-triangle mode lets you inspect individual facets.

Verify the highlighted region and its dimensions. On parts with cutouts or mounting holes, confirm that the openings remain intact before positioning the graphic.

Use the view cube, fit view, and front/back toggles to inspect the model. **Rotate model** changes the base mesh's orientation in 3D space; use the planar artwork transform controls to move or rotate the graphic itself on the selected face.

## Position the artwork

| Control | Effect |
| --- | --- |
| Move artwork | Translates the graphic across the selected plane |
| Rotate artwork | Rotates the graphic in-plane without turning the base model |
| Scale artwork | Resizes graphic coverage without scaling the base model |
| Edge | Fits the graphic to the selected face boundary (verify outlines and holes) |
| Inset | Adds a margin in millimeters (`mm`) inside the face boundary |
| Rotate model | Reorients the entire base model in 3D space |

Start with **Fit**, then fine-tune position, angle, and scale. Cross-check the 2D graphic view against the 3D face when aligning around holes, text, and borders. Transparent regions in the source image remain unprinted—keep transparency wherever you want the base surface or cutouts exposed.

## Preview, generate, and slice

1. Configure your graphic and filaments, then generate the 3D preview.
2. Inspect both sides of the model to verify artwork orientation, hole clearance, edge margins, and outer dimensions.
3. Export the 3MF and open it as a project in your slicer.
4. Verify filament assignments for the base model and color regions, then step through the sliced layers to check the recessed pocket, color layers, and backing solid.
5. Confirm that both the model and the prime tower fit inside the build volume before printing.

The 3D preview faces the graphic toward the camera for inspection, whereas the exported 3MF orientation follows your print-face setting (for example, flipping a top graphic face-down onto the build plate). If the graphic is facing the bed when the 3MF opens, switch to the bottom view or inspect the object list and sliced toolpaths. If Lumina reports a face-selection, solid-geometry, or pocketing error, repair the mesh or reselect the face before exporting.

## Archive your source files

Share cards and JSON project files do not embed external STL/OBJ meshes or face selections, and recipe export is disabled while Model texture is active. Save your base mesh, source graphic, exported 3MF, and placement values together if you plan to revisit the design later.
