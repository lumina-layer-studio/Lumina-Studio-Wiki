# Generate and Print Gradient Calibration Cards

This tutorial walks through generating a calibration package in Lumina Studio and printing a matched pair of gradient cards. Both cards print the stepped color blocks with the same test filament; one uses a white base and the other uses a black base.

When printing finishes, keep both cards together with the complete ZIP archive downloaded from Lumina Studio. You will need that exact pair and its matching ZIP in the next tutorial, **Photograph and Extract Gradient Cards**.

## Before you begin

<img
  src={require('./assets/00-settings-check.webp').default}
  alt="Confirm the slicer, printer, and nozzle in Lumina Studio"
/>

Open **Settings** in Lumina Studio and verify that your slicer, printer model, and installed nozzle diameter match your actual hardware before generating the package.

Prepare three filaments:

- White filament for the first base.
- Black filament for the second base.
- The filament you want to calibrate (red in this example).

Complete one spool end to end on your first run so physical cards, photos, and ZIP archives stay clearly paired.

You will also need **Bambu Studio** or **OrcaSlicer**. The screenshots below show Bambu Studio; the object and material-mapping steps work the same way in OrcaSlicer.

## Step 1: Open Gradient Generator

<img
  src={require('./assets/01-open-gradient-generator.webp').default}
  alt="Open Material Management and Gradient Generator"
/>

In Lumina Studio, click **Material Management** in the top navigation bar, then select **Gradient Generator** in the second row. **Generation Settings** appears on the left, and **Instructions & Online Models** appears on the right.

Each test filament requires both a white-base card and a black-base card; a single card alone cannot provide complete optical data during extraction.

## Step 2: Choose the layer height

<img
  src={require('./assets/02-choose-layer-height.webp').default}
  alt="Choose the same layer height that will be used in the slicer"
/>

Under **Generation Settings**, open the **Layer Height** menu and choose **0.04 mm**, **0.08 mm**, or **0.10 mm**.

Start with the default **0.08 mm** for your first calibration card; **0.04 mm** demands tighter first-layer consistency, lighting, and extraction alignment.

Make sure the layer height selected here matches the layer height you slice with. This tutorial uses **0.08 mm** throughout.

## Step 3: Generate and keep the ZIP

<img
  src={require('./assets/03-download-zip.webp').default}
  alt="Generate and download the complete configuration package"
/>

Click **Generate Configuration Package** and wait for Lumina to build the archive. Once **Download Result** appears, click **Download Configuration Package (.zip)** and save it in a dedicated folder named with the filament, layer height, and date—for example, `Red-PLA_0.08_2026-07-20`.

<img
  src={require('./assets/05-zip-contents.webp').default}
  alt="The real files included in the generated ZIP"
/>



Along with the 3MF model, the ZIP archive contains `manifest.json`, instructions, and the dataset folder template needed during extraction. Keep the archive intact without renaming or deleting its supporting files.

## Step 4: Find and open the 3MF



Extract the ZIP archive and locate the `.3mf` file in the root folder alongside `manifest.json`, the read-me file, and the dataset template folders.

Open the `.3mf` in Bambu Studio or OrcaSlicer and expand **Gradient Card** in the **Objects** list. Each card consists of two parts:

- **Base - White** — the backing plate.
- **Step - Sample** — the stepped gradient patches printed with your test filament.





If the slicer warns of an incompatible printer, nozzle, or profile, return to Lumina **Settings**, verify your hardware configuration, and generate a new package rather than overriding the project settings.

## Step 5: Prepare a white-base and a black-base card

<img
  src={require('./assets/07-material-mapping.webp').default}
  alt="Map the four objects to white, red, black, and red"
/>

The project opens with one complete card. Confirm that both **Base - White** and **Step - Sample** are present, then duplicate the card so two identical cards sit on the build plate.

For the first card (white base):

- Assign **Base - White** to the white filament.
- Assign **Step - Sample** to the red test filament.



For the second card (black base):

- Assign **Base - White** to the black filament (**Base - White** is simply the original part name; the assigned filament slot controls the printed color).
- Assign **Step - Sample** to the same red test filament.

Verify all four part assignments in order: **white, red, black, red** (slots **1, 3, 2, 3** in this example). Keep the original scale and Z height intact, and make sure the base and sample steps are never assigned to the same filament.

## Step 6: Slice and inspect the result

<img
  src={require('./assets/08-bottom-view.webp').default}
  alt="Turn the cards to the bottom view and confirm the two bases"
/>

Before slicing, confirm your printer profile, nozzle diameter, and **0.08 mm** layer height, and verify that the white, black, and red filament slots were not reassigned automatically.

Click **Slice Plate** to generate toolpaths.

<img
  src={require('./assets/09-sliced-layer-preview.webp').default}
  alt="Move the layer slider through the sliced bottom preview"
/>



In **Preview**, rotate the camera to the **Bottom** view and drag the layer slider through the print. Confirm that one base prints white, the other prints black, and the stepped patches on both cards print red, with no missing layers, floating paths, or unintended color swaps.

Once the preview looks clean, send the print to your printer. Label both finished cards with the test filament name as soon as they come off the bed.

## What to keep after printing

Keep these three items together as a set:

1. The white-base gradient card.
2. The black-base gradient card.
3. The complete ZIP archive downloaded from Lumina Studio.

An extracted `.3mf` file alone cannot be used for profile extraction. Keep packages from different layer heights or print runs separate so each physical card pair stays matched to its own ZIP.

## Common questions

### Can I print only the white-base card or only the black-base card?

No. Every test filament requires both cards as a matched pair.

### If I print the MakerWorld model, do I still need the ZIP from Lumina?

Yes. The MakerWorld model can substitute for the local 3MF when printing, but profile extraction still requires the configuration ZIP generated by Lumina.

### Which layer height should I choose first?

Start with **0.08 mm**. Move to **0.04 mm** once you are comfortable with printing, photographing, and extracting gradient cards.

### What if the printer or nozzle does not match when I open the 3MF?

Return to Lumina **Settings**, select your actual slicer, printer model, and nozzle diameter, and generate a fresh package.

### Why is the second black base still named “Base - White”?

`Base - White` is the static part name inside the 3MF. The printed base color is determined by the filament slot assigned in your slicer, which you can confirm in the sliced **Preview**.
