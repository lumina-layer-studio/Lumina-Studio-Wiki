# Slicer Guide

> Screenshots show Bambu Studio in Simplified Chinese; setting names below match the English interface.

Recent versions of Lumina Studio bundle printer and slicer presets directly inside exported `.3mf` projects, so files normally open with process parameters ready to use. Use the reference settings below if you need to restore the **0.08 mm** gradient-card parameters manually, or if you want to flip a print so its color surface faces up.

:::note[Reference settings]
The values below apply to **0.08 mm** gradient cards. For everyday `.3mf` project opening, object filament assignment, and AMS slot mapping, see [Open a Lumina 3MF in Your Slicer](../slicer-material-mapping/slicer-material-mapping.mdx).
:::



## Bambu Studio

### Step 1: Select the printer and 0.08 mm process preset

Open Bambu Studio and select your printer profile. Under **Process**, choose a **0.08 mm** preset such as **0.08 mm High Quality**.

<img
  src={require('./assets/p2s01.png').default}
  alt="Select the matching printer and 0.08 mm process preset"
/>

### Step 2: Set layer heights and initial-layer line width

Under **Quality**, set:

- **Layer height:** `0.08 mm`
- **Initial layer height:** `0.08 mm`
- **Line width → Initial layer:** `0.42 mm` (for a `0.4 mm` nozzle)



<img
  src={require('./assets/p2s02.png').default}
  alt="Set layer height, initial layer height, and initial-layer line width"
/>

:::warning[Other nozzle sizes]
If you use a `0.2`, `0.6`, or `0.8 mm` nozzle, keep both **Layer height** and **Initial layer height** at `0.08 mm`, scale the line widths to match your nozzle diameter, and keep the remaining parameters below unchanged.
:::

### Step 3: Set elephant-foot compensation and wall generator

Set **Elephant foot compensation** to `0 mm` to prevent second-layer color bleed around first-layer edges (if slight edge bleed does not matter for your piece, you can leave your usual value).

Set **Wall generator** to **Arachne** to enable variable-width walls.

<img
  src={require('./assets/p2s03.png').default}
  alt="Set elephant-foot compensation to zero and use the Arachne wall generator"
/>

### Step 4: Set initial-layer flow and single first-layer wall

Set **Initial layer flow ratio** to `1.1` as a baseline (tune as needed for your printer and filament), and enable **Only one wall on first layer**.

:::info[Developer Mode]
If **Initial layer flow ratio** is hidden, open **Preferences** from the top-left menu and enable **Developer Mode**.
:::

<img
  src={require('./assets/p2s04.png').default}
  alt="Set the initial-layer flow ratio and enable one wall on the first layer"
/>

### Step 5: Configure shells and surface patterns

Under **Strength**, set:

- **Wall loops:** `1`
- **Top shell layers:** `0` (optional; eliminates crossing top-skin toolpaths)
- **Bottom shell layers:** `1`
- **Top surface pattern:** `Monotonic line`
- **Bottom surface pattern:** `Monotonic line`

<img
  src={require('./assets/0001.png').default}
  alt="Set wall loops, shell layers, and surface patterns"
/>

### Step 6: Configure infill

Still under **Strength**, set:

- **Sparse infill density:** `100%`
- **Sparse infill pattern:** `Aligned Rectilinear` (`Rectilinear` also works)
- **Infill direction:** `0°` (`45°` also works)
- **Detect narrow internal solid infill:** disabled

<img
  src={require('./assets/p2s06.png').default}
  alt="Set the infill density, pattern, direction, and narrow-infill option"
/>

### Step 7: Lower print speeds

Lower print speeds help small color patches lay down cleanly. Start around `50 mm/s` for the speed fields shown below, and adjust upward once you confirm clean extrusion on your machine.

<img
  src={require('./assets/p2s07.png').default}
  alt="Use 50 millimeters per second as the suggested starting speed"
/>

### Step 8: Reshape the prime tower

Under **Others → Prime tower**, disable **Rib wall** to unlock the tower's **Width** field. Increasing **Width** reshapes the prime tower into a long, narrow strip along the edge of the build plate to save space.

<img
  src={require('./assets/p2s08.png').default}
  alt="Disable the rib wall before changing the prime-tower width"
/>

### Step 9: Check filament and object mapping

Verify that the project filament list matches the colors from the mode selected in Lumina Studio. If object assignments are off—most common when importing raw geometry instead of opening the `.3mf` as a project—select each object and assign the intended filament slot.

:::info[CMYW and RYBW names]
In four-color and six-color modes, check whether your preset is **CMYW** (cyan, magenta, yellow, white) or **RYBW** (red, yellow, blue, white). Both modes share internal object names: **red and magenta share one object name**, and **blue and cyan share another**. If you generated an **RYBW** project and see objects labeled magenta or cyan, map them to your red and blue filaments.
:::

<img
  src={require('./assets/p2s09.png').default}
  alt="Check the filament list and correct each object's filament assignment"
/>

Slice the plate and step through the layers in **Preview** before sending the job to your printer.

## OrcaSlicer, ElegooSlicer, Snapmaker Orca, and AnycubicSlicer Next

OrcaSlicer and its derivatives share the same parameter layout. Apply the equivalent values under Quality, Strength, Speed, and Others, then confirm the layer structure in **Preview**.

## Advanced workflow: print with the color surface on top

Textured PEI build plates imprint their surface grain onto the bottom of a print. To get a smooth, ungrained top surface on a textured plate, flip the model 180° so the color layers print on top, then use a height-range modifier so the backing still prints quickly:

### Step 1: Set initial layer height to 0.2 mm

On a standard gradient card, the backing plate is `1.6 mm` thick. Once flipped, the white backing occupies `0–1.6 mm`. Set global **Initial layer height** to `0.2 mm`.



<img
  src={require('./assets/p2s10.png').default}
  alt="Set the initial layer height to 0.2 millimeters for a flipped model"
/>

### Step 2: Add a height range modifier

Right-click the model and select **Height range Modifier**. Set the range to `0–1.6 mm` and set **Layer height** for that range to `0.2 mm`.



<img
  src={require('./assets/p2s11.png').default}
  alt="Set a 0 to 1.6 millimeter height range modifier to a 0.2 millimeter layer height"
/>

### Step 3: Verify the five top color layers

Slice the plate and inspect the top layers in **Preview**. The uppermost **5** layers should be the `0.08 mm` color layers; if you count 4 or 6 color layers instead, recheck your initial layer height and modifier range.



<img
  src={require('./assets/p2s12.png').default}
  alt="Verify that the top five layers are color layers in the sliced preview"
/>

:::tip[Other backing thicknesses]
Match the modifier range to your model's actual backing thickness. For example, if a print uses a `1 mm` backing, set **Initial layer height** to `0.2 mm` and apply a `0–1 mm` **Height range Modifier** at `0.2 mm` layer height so all five color layers on top stay intact.
:::
